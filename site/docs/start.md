# 新手指南：从这里开始

## 这个网站是什么

把 GitHub 上公认最好的 **136 门 AI / Agent 课程**（24,585 页）按学习顺序编排成一套中文教材。**只做三件事**：筛课、按路径排序、把英文课的原文逐段配上中文释义。所有正文与原作者的原文一字不差，每一页都标着出处、原文链接和许可——学到任何一页，都能点「原件」对照上游原文。

一句话：**这是一个不用自己找课、不用翻墙注册、顺着读就能从零到能动手的 AI 学习站。**

## 三条使用规则

1. **跟着「学习路径」读，不要乱翻。** 首页「开始学习」进任意一卷，先读标了 ★★★ 的主线课，读完再碰其它。
2. **页面顶部的标签先看一眼。** 「主线」= 建议精读；「进阶」= 有基础再读；「参考」= 用到再查。
3. **英文课不用怕。** 点页面顶部的「展开全部释义」，每段原文下面就是中文解释；想读原文就收起。

## 小白起步路线（照做即可）

**第一步（本周）：卷 01 → 《Generative AI for Beginners》**（微软出品，中文界面，11 个课时）。目标：建立基本概念，知道别人在说什么。

**第二步（第 2-3 周）：卷 02 → 主线四门里任选一门和你工作最相关的**（豆包工作蓝皮书 / 千问办公指南 / WorkBuddy 指南 / Dify 上手）。目标：AI 真的帮你干上活了。

**第三步（第 4 周起）：想继续做产品 → 卷 03；想深入做 AI 应用 → 卷 04。** 之后 05-08 按兴趣和需要推进。

每天 30-60 分钟，前两卷一个月可以走完。

## 三个常见问题

- **课程是谁的？** 全部来自各原作者的开源仓库，本站逐字保留原文并按其许可转载，来源与原文入口在每个课程页左侧「来源信息」。
- **免费吗？** 免费。内容按原作者许可（MIT / CC 等）开放转载，本站仅用于教育与学习。
- **读完能到什么水平？** 走完前四卷：能独立用 AI 完成办公与开发任务、能搭出可用的 Agent 应用——也就是当前招聘市场上「会用 AI」的真实门槛。
