promoted master plus Hugging Face Jobs and Trackio.

## Prerequisites

- Python 3.10 or newer
- `uv`
- `hf` CLI
- `opencode`
- optional: `hermes`
- optional: `pi`
- a Hugging Face account with Jobs access
