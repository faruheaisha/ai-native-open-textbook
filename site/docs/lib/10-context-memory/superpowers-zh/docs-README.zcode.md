# Superpowers 中文版 — ZCode 安装指南

在 [ZCode](https://zcode.z.ai/)（智谱的 Agentic Development Environment）中使用 superpowers-zh 的完整指南。

## ⚠️ 只支持全局安装，这是证据决定的

```bash
npx superpowers-zh --global --tool zcode
```

装到 `~/.zcode/skills/`，所有工作区共享。
