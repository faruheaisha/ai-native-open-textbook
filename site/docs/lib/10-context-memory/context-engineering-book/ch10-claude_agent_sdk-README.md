# Claude Agent SDK examples

This folder contains examples demonstrating the packaged agent loop of the Claude Agent SDK.

## Requirements

- [Python](https://www.python.org/) 3.10+
- An [Anthropic API key](https://console.anthropic.com/) set as an environment variable (`ANTHROPIC_API_KEY`)
- The Claude Code CLI available on the `PATH`

## Examples

- `basic_agent/`: Running the packaged agent loop with explicit tool and permission defaults.

## Running the examples

Each example is in its own folder and contains a `README.md` with instructions on how to run it.
