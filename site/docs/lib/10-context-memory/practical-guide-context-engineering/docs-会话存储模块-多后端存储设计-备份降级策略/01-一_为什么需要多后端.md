## 一、为什么需要多后端
+ 弹性：如果主数据库不可用，会自动切换到备份进行读取
+ 持久化：所有的写入操作首先记录在 WAL 中，即使备份暂时不可用，也会保证不会丢失任何消息
+ 一致性：WAL 确保所有的消息最终都会持久化到备份中，提供强大的持久化保证
