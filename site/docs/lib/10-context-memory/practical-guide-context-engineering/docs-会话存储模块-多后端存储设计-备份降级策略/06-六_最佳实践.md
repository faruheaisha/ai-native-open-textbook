## 六、最佳实践
+ 使用快速、低延迟的数据库作为主数据库，例如 Redis、Postgres
+ 使用一个高度耐用、可能比较慢的数据库进行备份，例如 S3，SQlit，云数据库
+ 在生产环境中，考虑使用持久的 WAL，而不仅仅是内存中，以实现最大程度的持久性
