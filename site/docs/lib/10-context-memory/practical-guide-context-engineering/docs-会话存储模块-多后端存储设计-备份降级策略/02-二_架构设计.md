![多后端存储架构设计](https://gh-proxy.com/https://raw.githubusercontent.com/WakeUp-Jin/Practical-Guide-to-Context-Engineering/ec349a470e2992adc1d98899a46cb085839c0676/docs/会话存储模块/image/image%20%2826/README.md).png)

1. 主存储（PrimaryDB）：快速的主数据库用于读写（例如：Redis、Postgres）
2. 备份存储（BackupDB）：持久的次级数据库用于冗余（例如：Sqlit、云数据库）
3. WAL：内存中或持久的日志，用于写入持久性和异步备份
