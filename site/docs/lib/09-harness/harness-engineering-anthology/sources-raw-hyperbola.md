# hyperbo.la source snapshots

These files are byte-for-byte snapshots of Ryan Lopopolo's [hyperbo.la] blog
sources, retrieved from the [blog repository]. The source manifest records each
canonical URL and snapshot retrieval date and, for every preserved artifact,
its content hash, exact upstream revision, and upstream path. Each article
source preserves its original front matter, including the slug used by the
canonical `https://hyperbo.la/w/<slug>/` URL. Supporting text assets needed by
an article, such as Mermaid source, are catalogued as separate artifacts.
