# Playbooks

These playbooks are applications composed for this anthology. They arrange its
developed arguments and cases, grounded in Ryan Lopopolo's public writing and
other documented evidence, into procedures that humans and agents can try.
Neither document is a source text or a playbook published by Ryan.

| Job | Playbook |
| --- | --- |
| Improve the harness around one bounded, representative job | [Improve One Harnessed Job] |
| Review several journeys and ownership boundaries across a repository | [Repository Review] |
| Compare conditions or measure change over time | [Evaluate the Harness] |

[Improve One Harnessed Job]: https://github.com/lopopolo/harness-engineering/blob/226c8d35fb6ea3ed55467753dba6dea2b5fd5778/playbooks/improve-harness.md
[Repository Review]: https://github.com/lopopolo/harness-engineering/blob/226c8d35fb6ea3ed55467753dba6dea2b5fd5778/playbooks/repository-review.md
[Evaluate the Harness]: /lib/09-harness/harness-engineering-anthology/evals

The first two procedures are editorial syntheses; this repository does not yet
include an end-to-end application record for either one. Use them under the
target's own instructions and authority and record what happened. Report a
mistake or omission discovered in use; revise a playbook only in a separately
authorized task targeting this repository.
