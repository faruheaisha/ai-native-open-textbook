# Distribution Assets

These assets turn one part of the Claude Code Ultimate Guide into a bounded teaching format. Publication remains separate from production: a ready file still needs approval, a destination, and a dated channel record.

| Asset | State | Source pages | Publication record |
| --- | --- | --- | --- |
| [Learning path slides](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/af05b84fb6e32432dae2114ee2a72c44ef3d29b1/docs/distribution/claude-code-learning-path-slides.pptx) | Ready, visually inspected, overflow test passed | [Learning path](/lib/09-harness/claude-code-ultimate-guide/guide-learning-path), [Best-of-N](/lib/09-harness/claude-code-ultimate-guide/guide-workflows-best-of-n), [Computer Use](/lib/09-harness/claude-code-ultimate-guide/guide-core-computer-use) | [`slides-en`](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/af05b84fb6e32432dae2114ee2a72c44ef3d29b1/machine-readable/distribution-channels.yaml) |
| [Quick-win video series](/lib/09-harness/claude-code-ultimate-guide/docs-distribution-quick-win-video-series) | Production briefs ready, videos not recorded | [Workflow index](/lib/09-harness/claude-code-ultimate-guide/guide-workflows), [learning-path skill](/lib/09-harness/claude-code-ultimate-guide/examples-skills-learning-path-SKILL) | [`youtube-fr`](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/af05b84fb6e32432dae2114ee2a72c44ef3d29b1/machine-readable/distribution-channels.yaml) |

The slides contain a `[Sources]` block in every slide's speaker notes. The video briefs name the guide page, observable check, attributed destination, and research source for each episode.

For a live workshop or recording, the [Proofpack companion project](/lib/09-harness/claude-code-ultimate-guide/examples-learning-project) provides the continuous exercise behind the learning path.

## Before publication

1. Rebuild or reopen the asset and inspect the final output.
2. Confirm the guide links still resolve at the current version.
3. Obtain approval for the named channel.
4. Change the channel status in [`distribution-channels.yaml`](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/af05b84fb6e32432dae2114ee2a72c44ef3d29b1/machine-readable/distribution-channels.yaml).
5. Record the placement evidence URL and verification date.
6. Start the 30-day measurement window defined by the [distribution workflow](/lib/09-harness/claude-code-ultimate-guide/docs-workflows-guide-distribution).

Chinese publication remains blocked until a fluent reviewer validates the localized copy. The [translation registry](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/af05b84fb6e32432dae2114ee2a72c44ef3d29b1/machine-readable/translations.json) records ownership and freshness; it does not grant publication authority.
