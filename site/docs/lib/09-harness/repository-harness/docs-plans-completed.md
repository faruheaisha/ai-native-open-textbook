# Completed Execution Plans

Move a plan here only after the outcome exists and relevant validation passes.

Retain a completed plan only when its recovery or transition details have a
current independent audience. Ordinary work should rely on code, tests,
decisions, pull requests, and Git history instead of accumulating permanent
task narratives.

## Retained Transition Plans

- `repository-protocol-core.md`: the atomic Protocol v1 EOL cut, legacy-data
  preservation boundary, validation evidence, and recovery path.
