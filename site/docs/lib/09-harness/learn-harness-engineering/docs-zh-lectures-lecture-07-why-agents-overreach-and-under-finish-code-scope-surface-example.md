# 范围界定示例

任务：

- 为 Electron 知识库应用添加索引功能

糟糕的范围定义：

- "实现索引"

更好的范围定义：

- 解析导入的文档
- 将文档拆分为块
- 持久化块元数据
- 在 UI 中暴露索引状态
- 添加重新索引操作
