### Beta Managed Agents Base64 Image Source

- `BetaManagedAgentsBase64ImageSource object`

  Base64-encoded image data.

  - `type: "base64"`

  - `data: string`

    Base64-encoded image data.

    minLength: 1

  - `media_type: string`

    MIME type of the image (e.g., "image/png", "image/jpeg", "image/gif", "image/webp").

    minLength: 1
