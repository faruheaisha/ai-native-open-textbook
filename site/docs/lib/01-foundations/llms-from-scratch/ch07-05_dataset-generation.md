# Generating Datasets for Instruction Finetuning

This folder contains utility code that can be used for generating a dataset for instruction finetuning.

- [llama3-ollama.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/ef9fbc2f52bf9bbb6769f43e6d726bbba4aed03e/ch07/05_dataset-generation/llama3-ollama.ipynb): A notebook that creates a synthetic instruction finetuning dataset using Llama 3 and Ollama

- [reflection-gpt4.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/ef9fbc2f52bf9bbb6769f43e6d726bbba4aed03e/ch07/05_dataset-generation/reflection-gpt4.ipynb): A notebook that implements an instruction dataset refinement step based on reflection-tuning
