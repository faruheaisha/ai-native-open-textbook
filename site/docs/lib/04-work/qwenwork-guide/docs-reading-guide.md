# 千问办公阅读与学习指南：从入门到用顺手

这是一条面向新手和任务实践者的千问办公学习路线。全书分为四部分：使用手册、实战案例、进阶使用案例、认知与方法论。你可以按顺序通读，也可以根据当前需求跳到对应部分。

## 千问办公新手入门路线

从[第一部分：使用手册](https://github.com/wangxiaoshuai1998/QwenWorkGuide/blob/002f698a68b69d3635acf6be0d6e27db69069071/greenbook/第一部分%20使用手册：先把%20千问办公%20用起来/README.md)开始，依次完成：

1. 认识千问办公的核心能力与典型场景（[第1章 初识 千问办公](https://github.com/wangxiaoshuai1998/QwenWorkGuide/blob/002f698a68b69d3635acf6be0d6e27db69069071/greenbook/第一部分%20使用手册：先把%20千问办公%20用起来/第1章%20初识%20千问办公/README.md)）。
2. 跑通一条完整的使用链路，拿到第一份可用的交付成果。
3. 把个人资料、偏好与环境调整到顺手的状态（[第4章 通用设置](https://github.com/wangxiaoshuai1998/QwenWorkGuide/blob/002f698a68b69d3635acf6be0d6e27db69069071/greenbook/第一部分%20使用手册：先把%20千问办公%20用起来/第4章%20通用设置/README.md)）。

建议边读边做，不要只浏览截图。每完成一章，至少留下一个可复用的提示词、模板或操作记录。

## 按常用端选择使用链路

- 主要在浏览器里办公：阅读[第2章 Web端使用链路](https://github.com/wangxiaoshuai1998/QwenWorkGuide/blob/002f698a68b69d3635acf6be0d6e27db69069071/greenbook/第一部分%20使用手册：先把%20千问办公%20用起来/第2章%20Web端使用链路/README.md)。
- 需要操作本地文件与浏览器自动化：阅读[第3章 桌面端使用链路](https://github.com/wangxiaoshuai1998/QwenWorkGuide/blob/002f698a68b69d3635acf6be0d6e27db69069071/greenbook/第一部分%20使用手册：先把%20千问办公%20用起来/第3章%20桌面端使用链路/README.md)。

链路跑通后，建议同时记录：

- 输入资料和权限边界。
- 任务拆解方式和失败回退。
- 交付物的验收标准。
- 可以复用的提示词、模板和定时任务。
- 哪些步骤必须由人确认。

## 实战案例与进阶用法

掌握基础后，可以根据兴趣或工作需求直接跳到对应部分：

- **实战案例（第二部分）**：Excel 数据处理、数据分析全流程、文档整理与写作、电商数据大屏、声音克隆、Remotion 视频等，覆盖日常高频任务。
- **进阶使用案例（第三部分）**：公众号排版推送、内容创作全流程、图片设计生成、UI 到前端原型、需求生成原型图等，适合有明确产出目标的创作者和运营人员。
- **认知与方法论（第四部分）**：AI 工作流方法论、如何写 Skill、IP 配图架构详解、公众号排版 Skill 详解，帮你把经验沉淀为可复用的方法论。
