# **第6章 桌面端核心功能**

![](/mirror/9e/9e28b132c10f5395f0693b5305da1cd8d20d297a.webp)

<span style="color: rgb(161, 157, 150); background-color: rgb(248, 248, 247);">image.png</span>

QwenWork 桌面端是一款面向日常办公场景的 AI 智能工作台。用户可以通过自然语言发起任务，结合文件、技能、连接器、电脑操控能力、IM、Hooks等功能，完成信息整理、内容创作、数据分析等工作，减少应用切换，提高任务处理效率。
