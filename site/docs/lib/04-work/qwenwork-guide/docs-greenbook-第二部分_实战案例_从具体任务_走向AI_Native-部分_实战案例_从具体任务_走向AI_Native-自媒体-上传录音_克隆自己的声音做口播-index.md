# **自媒体-上传录音，克隆自己的声音做口播**

提示词：
> 帮我做一个网站，上传音频/在线录音，然后克隆声音，然后根据克隆后的音色，将文本变成音频文件。   
> 方案采用阿里的 cosyvoice-v3-plus 这个模型，api-key是xxx(改成你自己的).
