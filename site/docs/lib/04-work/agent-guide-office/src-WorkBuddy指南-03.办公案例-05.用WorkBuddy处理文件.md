# WorkBuddy 文件处理教程：批量重命名、纪要与视频翻译

电脑里有些工作并不难，却很容易一直拖着。

一个文件夹塞满命名混乱的图片和资料，想整理，又不愿意逐个打开。

会议开完了，录音和聊天记录都在，正式纪要迟迟没有写。

外文视频已经下载，字幕、翻译和摘要还得分别处理。

这类任务有一个共同点。原始材料已经拿到了，接下来要做的是读取内容、重新组织，再生成一份能直接使用的结果。

WorkBuddy 可以接手其中相当一部分重复操作。这篇先跑三个常见案例，分别是批量重命名文件、整理会议纪要和翻译外文视频。

## 开始前先处理权限和备份

只要任务会读取、改名或写入本地文件，就要先确定 WorkBuddy 能访问哪个目录。

最简单的做法，是把准备处理的文件单独放进一个文件夹，再将这个文件夹设为工作空间。

也可以直接把文件拖进对话框。PDF、Word、Excel、PPT、常见图片和文本文件都可以作为输入。

第一次练习不要直接使用整个桌面或下载目录。挑几份副本放进测试文件夹，先看 WorkBuddy 能否正确识别内容，生成的命名和文档是否符合要求。规则确认以后，再换成完整材料。

涉及改名和写入时，还要留意当前使用的权限模式。系统保护目录、企业管控目录和正在被其他程序占用的文件，可能无法直接处理。

## 批量重命名之前先看预览

文件名混乱时，最费时间的部分往往是判断每个文件到底是什么。

图片要看画面，合同和票据要读内容，部分资料还要结合创建时间、修改时间或原始标题。

把这些文件放进工作空间以后，可以直接给 WorkBuddy 一套命名规则。

```text
读取当前文件夹中的文件内容和属性。

按照「日期 + 主题 + 类型」生成新的文件名。日期优先使用文件内容中能够确认的日期，无法确认时再参考文件属性。

先输出新旧文件名对照表，不要立即改名。拿不准的文件标记为待确认，不要猜测。
```

这一步只需要得到预览。对照表里至少要能看到原文件名、建议文件名和未处理原因。

![批量重命名预览](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122818Z-6b1948ba76b56d62-e7e1f689.png)

先检查日期有没有识别错，主题是否过于笼统，同一批文件的命名顺序是否一致。

遇到同名文件，还要补充序号或其他区分信息，不能覆盖原文件。

预览确认无误以后，再回复 WorkBuddy 执行改名。完成后，让它报告成功数量、跳过数量和未处理文件。

![批量重命名结果](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122817Z-c848b77868214d1c-9eeae8c7.png)

批量重命名会直接改变原文件。

重要目录最好先复制一份，或者要求 WorkBuddy 额外保存新旧文件名对照表。

以后需要恢复时，至少知道每个文件原来叫什么。

系统文件、加密文件以及含有财务密钥、账号凭证和个人隐私的资料，不要直接放进批处理目录。

先缩小范围，再决定哪些内容可以交给工具读取。

## 会议纪要先把输入变成文字

会议材料通常来自三处。

有人记了几行笔记，群里留下几段讨论，录音里还有大量细节。

WorkBuddy 整理纪要时主要读取文字。

TXT、Markdown、Word 和 PDF 可以直接拖入任务，聊天记录也可以粘贴到对话框。手里只有录音或视频时，需要先完成语音转写，再把转写文本交给它整理。

输入准备好以后，可以这样写任务。

```text
根据当前会议记录整理一份正式会议纪要。

保留会议主题、讨论议题、关键结论、行动项、负责人和截止时间。

原文没有负责人或截止时间时标记为待确认，不要自行补充。重复讨论合并处理，存在分歧的内容单独列出。

将结果保存为 Markdown 文件。
```

![会议纪要结果](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122819Z-4e7c44f5a5a06151-e2ca0f1d.png)

拿到纪要以后，先核对结论和行动项。

会议里提到一件事，不等于已经形成决定。

转写文本里如果出现同音字和人名错误，也可能影响负责人识别。

记录很长时，可以先让 WorkBuddy 按议题分段，再生成正式纪要。

多轮聊天也适合先小批量验证，确认人物和时间识别正常后，再放入完整记录。

## 外文视频优先使用现成字幕

处理外文课程、访谈、产品演示和培训视频时，先检查视频是否带有内嵌字幕，或者同目录下是否有 SRT、VTT 字幕文件。

有字幕就直接使用。

没有字幕时，需要先把音频转成文字。

转写效果会受到音质、语种和口音影响，专业术语、人名与产品名尤其需要人工核对。

可以把视频路径或字幕文件交给 WorkBuddy，再说明翻译和摘要要求。

```text
读取当前外文视频的字幕文件，将内容翻译成中文。

按照原有顺序整理，保留重要专业术语的原文，并在首次出现时给出中文解释。

翻译完成后生成一份摘要，列出核心观点、关键案例和需要继续核实的内容。

不要省略原文中的限制条件，也不要补充视频中没有出现的结论。
```

![外文视频翻译结果](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122820Z-a3b154f33ee8fa42-bef85f17.png)

视频越长，转写、翻译和整理需要的时间越多。

超长视频可以按章节或时间段拆开处理，最后再合并摘要。

任务提交后保持电脑在线，避免转写或写入过程中断。

## 文件任务能否做好，取决于要求有没有写清楚

同一个文件夹交给 WorkBuddy，只说一句「帮我整理一下」，它需要自行猜测分类、命名和输出格式。

要求越含糊，后面返工越多。

一条能执行的文件任务，最好写清下面几件事。

- 输入范围包括哪些文件，哪些文件不要碰
- 判断时优先读取内容，还是优先使用时间和原标题
- 最终需要 Markdown、Word、表格还是纯文本
- 能否修改原文件，执行前是否必须给出预览
- 遇到缺失信息、重复文件和无法识别内容时怎样处理
- 结果文件保存到哪个目录

第一次跑任务，可以只放三到五个文件。

看到预览后再补规则，通常比一次提交几百个文件更稳妥。

## 写在最后

这三个案例可以从任意一个开始。

准备几份副本，给 WorkBuddy 一个边界清楚的工作目录，再把输入范围、输出格式和修改权限写明。

如果它能读对材料，先给出可检查的结果，并把不确定内容留下来让人判断，这项文件任务就已经值得继续交给它。

等小批量结果稳定以后，再扩大文件数量。
