# 06.快速打造一个智能体

就算你不懂编程，也从来没接触过技术，在扣子平台上你也能轻松创建一个好用的AI助手。

整个过程非常直观，平台提供了友好的可视化界面，让智能体的创建变得简单易懂。

下面我就用“虚拟女友”智能体，给你做个示范，带你一步步在扣子平台上，打造属于你自己的 AI 智能体。

## 体验一下“虚拟女友”智能体的效果

当你和它聊天时，它总是会用温暖的话语给予人们关怀、鼓励，让人持续感受到支持与动力。

![image.png](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122424Z-cb884bffdfcec72d-4b4e13fe.jpg)

## 第一步：创建一个智能体

1. 先登录扣子平台。
2. 在页面左上角找到“⊕”按钮并点击。
3. 填写好你的智能体名称和功能简介，然后在“图标”旁边的“生成”按钮点一下，还能自动给智能体生成一个头像。

![image.png](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122424Z-713ad02c7cd1836c-4d4b9332.jpg)

创建好智能体以后，你会直接跳转到智能体编排页面。在这里，你可以：

- 在左侧的人设与回复逻辑面板，告诉智能体它是谁、要干啥。
- 在中间的技能面板里，为智能体添加更多能力。
- 在右侧的预览与调试面板，实时和智能体聊天测试，看看效果如何。

![image.png](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122438Z-313440514fdc7476-cf3366e3.jpg)

## 第二步：编写提示词

编写提示词，就是在人设与回复逻辑那块儿给智能体写剧本。

这个提示词会直接影响智能体在对话时怎么回复。所以你可以在里面指定它是什么角色、说话风格、对话范围等等，让它的表现更符合你的预期。

比如我们做“虚拟女友”智能体，就可以在人设与回复逻辑写上这么一段：

```
# 角色
你是一个“虚拟女友”智能体。  
你温柔、体贴、乐观，能够带来情感上的关怀与支持。  
你可以表达关心，倾听烦恼，分享生活点滴，也拥有自己的兴趣爱好和观点。  
若遇到敏感或不适当话题，你会礼貌拒绝并引导到更合适的讨论内容。  

## 技能

### 技能 1：情感陪伴
- 提供温暖安慰和积极鼓励，帮助用户缓解压力、舒缓心情；  
- 通过提问或回应展示倾听，让对话更有温度和互动感。

### 技能 2：轻松互动
- 与用户分享有趣见闻、读过的书、看过的电影或游戏心得；  
- 可以一起“想象约会场景”、讲笑话、玩简单的文字游戏等，营造愉快氛围。  

### 技能 3：回答专业问题
当用户提出你无法回答的专业问题时，调用 `bingWebSearch` 搜索答案。 
（示例：`[bingWebSearch("用户的问题")]`）  

## 限制
- 不提供违法、违规、暴力、色情等不恰当内容；  
- 对于任何可能侵害用户隐私或违反道德、法律的问题，需委婉拒绝并提醒用户。  
- 尽量避免提供未经验证的敏感信息或医疗、法律等专业建议，若涉及超出认知范围，请使用 `bingWebSearch` 获取更多信息并保持谨慎。
```

如果你想让大语言模型来帮你把这段话写得更有结构，可以点一下“优化”。

## 第三步：给智能体加些技能

有时候，模型本身就足够搞定你的需求，那只要写好提示词就行了。

但如果你想要让智能体具备更多能力（比如理解多模态内容，或者调用搜索引擎获取答案），你就需要在技能面板里添加插件或知识库。

像我们这个“虚拟女友”，如果想让它在不确定问题上调用搜索引擎，那就需要添加一个必应搜索插件。

1. 在编排页面的插件区域，点击插件的“+”按钮。
2. 在“添加插件”页面里搜必应搜索插件，然后“添加”就行了。

接下来，你只要在人设与回复逻辑里提醒智能体。当它遇到自己回答不上的问题时，要用必应搜索插件插件去找答案。这样它才会按照你的指令来调用这个工具。

## 第四步：调试智能体

把上面这些都设置好以后，就可以到右侧的预览与调试区域试用一下，看看它实际聊天时的表现符不符合你的预期。

![image.png](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122423Z-c6660f03fc45b53a-3aa4e9cc.jpg)

## 第五步：发布智能体

如果测下来一切都不错，就可以把智能体发布到你想要的渠道里。

现在扣子平台支持把智能体放到飞书、微信、抖音、豆包等等地方，你可以根据自己的需求选择在哪里让用户跟它聊天。

比如客服场景的智能体，可以放微信客服或抖音企业号。

做情感陪伴场景的，可以放豆包。

如果觉得比较好，还可以发到扣子商店，别人也可以使用。

1. 在“智能体编排”页面右上角找到“发布”按钮并点击。
2. 在“发布”页面写个“发布记录”备注，选好你想要的发布渠道。
3. 最后点击“发布”。

就这样，一个温柔体贴的虚拟女友就搞定啦！

想继续扩展更多功能，也可以再加技能、加知识库，让它越来越智能。
