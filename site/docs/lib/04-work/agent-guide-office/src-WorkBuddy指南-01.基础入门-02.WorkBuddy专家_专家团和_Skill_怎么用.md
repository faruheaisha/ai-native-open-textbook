# WorkBuddy Skill、专家和专家团怎么用？区别与选择方法

专家、专家团和 Skill 都能帮我们完成任务，用法却各有侧重。

专家处理一项专业任务，专家团组织多个专业角色协作，Skill 固定一套能反复执行的步骤。

普通问答先用常规对话，需要专业知识再找专家，任务跨越多个领域再考虑专家团。

## 专家适合边界清楚的专业任务

专家中心按行业和工作场景整理了不同的垂直 Agent。

每个专家都有能力说明，选中后可以直接对话。

![image-20260805145209418](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122723Z-c789759a50b7697a-46eb4ed1.jpg)

![image-20260805145252310](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122724Z-058b787566eaf1ed-8322a0cd.jpg)

选择时先看能力页面，确认它擅长的问题、需要的材料和交付结果。

开始对话后，再把材料范围、使用场景和输出格式说清楚。

比如分析项目材料，可以要求它重点检查风险，最后给出摘要和行动建议。

## 专家团留给真正复杂的任务

专家团会把任务拆给多个专家并行处理，再汇总结果。

它适合材料多、专业分工明显的研究任务，例如一份报告同时要看市场、产品、技术和财务。

![image-20260805145344074](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122723Z-eef9cda0cd25105e-ce49d55e.jpg)

使用前要写清研究问题、可用材料和预期目录，否则几个子任务容易各说各话。

专家团的积分消耗通常更高。

写文档、整理表格和总结会议纪要，单个专家或普通对话往往已经够用。

## Skill 解决重复劳动

Skill 是一份可以反复执行的工作说明。

它会告诉 WorkBuddy 按什么顺序做事，最后交付什么格式。

比如每周把会议纪要整理成周报，或者固定清洗数据、生成图表再写结论，就适合交给 Skill。

Skill 页面分为官方精选、SkillHub 和套件。

![image-20260805145421993](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122725Z-8fd1a573a1be11d8-2ef11096.jpg)

![image-20260805145445000](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122726Z-84b7560b7f8da06c-c0d75c4e.jpg)

![image-20260805145501781](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122721Z-6c30a5c16fdffe5e-d0bba326.jpg)

不知道技能名称时，直接按需求搜索。

处理 PDF 就搜 PDF，制作图表就搜图表。

安装前先看功能说明和适用场景，确认它支持自己的文件类型和输出要求。

## 安装、调用和管理 Skill

安装完成后，在对话框输入 `/`，就能调出已经安装的 Skill。

选中后还要补充本次任务的材料、目标和格式要求。

外部下载的技能包可以通过上传技能导入，导入前要确认来源和它需要访问的内容。

![image-20260805145604499](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122724Z-503cd3a8b7087e03-9f954705.jpg)

进入「我安装的」页面，可以停用或删除不再使用的技能。

![image-20260805145639511](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122725Z-bd68fa6cc9900617-3dd1068b.jpg)

## 把自己的固定流程做成 Skill

需要固定自己的工作步骤，也可以在右上角选择添加技能，再用自然语言描述功能。

![image-20260805145732388](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122722Z-0cbe78a86fbd08b5-fcf2e68e.jpg)

创建时，要把输入材料、执行顺序、检查规则和输出格式讲清楚。

比如先读取指定文件夹，再按主题归类，把缺失信息单独列出，最后生成带来源标注的 Markdown 文档。

![image-20260805145751256](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122724Z-0adfa57f0d38c456-ad20e71b.jpg)

创建完成后，先拿一份测试资料试跑。

发现漏步骤、误读文件或格式不一致，就回到 Skill 里修改说明。

等流程跑稳以后，再用于长期工作。
