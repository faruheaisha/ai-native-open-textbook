## 项目特色

- **从入门到实战**：先理解大模型和 Agent，再通过具体任务学习工具，不只停留在概念层面。
- **覆盖两类 Agent 路线**：既包含 WorkBuddy 这类电脑操作与办公助手，也包含 Coze 这类可搭建、可编排的智能体平台。
- **强调真实工作流**：围绕内容创作、PPT、数据分析、资料处理、自媒体运营等场景组织案例。
- **补足工程能力**：提供数百篇编程与架构文章，帮助读者理解 Agent 背后的应用开发、数据存储和系统设计。
- **稳定的文章地址**：源码可以保留易维护的中文目录，公开页面使用英文永久链接，便于长期访问和分享。
- **自动生成导航**：侧边栏根据文章目录和页面元信息生成，新增内容后无需重复维护大段菜单配置。

## 本地阅读与开发

建议使用 Node.js 20 LTS，并确保本机已经安装 npm。

```bash
git clone git@github.com:tangshiyegit/agent-guide.git
cd agent-guide
npm install
npm run docs:dev
```

启动后，根据终端输出的本地地址在浏览器中访问站点。

## 构建与打包

生成生产环境静态站点：

```bash
npm run docs:build
```

构建产物位于 `src/.vuepress/dist/`。

项目还提供了打包脚本，可在完成构建后将静态文件压缩为 `src/.vuepress/dist.zip`：

```bash
bash package-prod.sh
```
