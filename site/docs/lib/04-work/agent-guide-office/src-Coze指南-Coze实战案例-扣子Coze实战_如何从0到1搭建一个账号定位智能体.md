# 扣子Coze实战：如何从0到1搭建一个账号定位智能体

大家好，我是汤师爷，专注AI智能体分享，致力于帮助100W人用智能体创富~

在短视频时代，每个人都想打造自己的个人IP，但很多创作者遇到了一个共同的困扰：

- 不知道该选择什么样的定位？
- 不清楚目标受众是谁？
- 对内容方向和变现路径感到迷茫？

## 1.从线下开店中理解定位

当我们思考自媒体账号定位时，就像开一家线下实体店一样，需要经过周密的计划和准备。

无论是线下开店还是线上做自媒体，都遵循相同的商业逻辑。

了解市场环境、选择合适位置、准备优质产品、提供良好服务，最终吸引目标客户。

线下开店：

- 首先需要做市场调研，了解周边环境和竞争情况
- 选择合适的店面位置，进行装修布置
- 采购商品进货，确保质量和价格
- 招聘和培训店员，提供良好服务
- 发放传单进行宣传，吸引顾客

自媒体账号：

- 找准市场对标账号，学习成功经验
- 选择适合的内容赛道和设计账号页面装修
- 设计符合用户需求的产品或服务
- 明确目标用户画像，了解他们的需求和痛点
- 创作有价值的内容，吸引目标用户关注并转化

## **2.短视频的人货场理论**

做零售行业的朋友，应该都听过"人货场"理论。

这是零售界的黄金法则，简单来说就是把合适的商品（货）放在合适的位置（场），吸引合适的顾客（人）。

在短视频中，运营的"人货场"理论同样适用，它是一个非常实用的框架。

**1）人（用户）**

明确用户的年龄、职业、需求和痛点，才能精准投放内容。

比如AI工具对企业主、自由职业者和学生的吸引点各不相同。

企业主可能关注效率提升和成本节约，自由职业者可能看重创意辅助和工作自动化，而学生则可能更在意学习辅助和就业竞争力。

了解这些差异，才能有的放矢。

**2）货（产品）**

无论你是卖课程、工具还是服务，你的形象、专业度和可信度都直接影响产品价值。

好的产品能解决用户的问题，满足他们的需求。

记住，用户购买的不只是产品本身，还包括你所传递的价值和解决方案。

**3）场（内容）**

内容是连接产品和用户的桥梁。好的内容能引起用户共鸣，激发他们的兴趣和需求。

根据平台特性和用户习惯，选择合适的内容形式至关重要。

短视频适合快速传递信息和情感共鸣，图文适合详细解析和深度思考，直播则适合实时互动和即时反馈。

选对了"场"，你的信息才能有效触达目标用户。

## 3.账号定位策划智能体

什么是账号定位？

账号定位是指根据自己的兴趣、专业技能和市场需求，为自媒体账号确定一个明确的内容方向和风格。

好的账号定位能让你的内容更有针对性，吸引特定群体的关注，并在众多内容创作者中脱颖而出。

简单来说，账号定位就是回答"我是谁，我要做什么内容，我要服务哪些人"这三个核心问题。

今天我要介绍一个非常实用的AI工具，它可以帮你快速找到适合自己的账号定位，做出专业的内容规划。

这个"账号定位策划智能体"就像一位专业顾问，能根据你的特长、目标和目标观众，给你量身定制的建议。

它主要能帮你做这些事：

- 了解你的背景：分析你的经验和特长，找出你的独特价值
- 描绘目标用户：帮你明确粉丝群体的特点、需求和痛点
- 找准差异化优势：分析市场，找出你与众不同的卖点
- 规划内容方向：给你具体的内容主题和创作建议

用了这个工具后，你会更清楚自己适合做什么内容，怎么吸引目标用户，从而在短视频平台上打造出自己独特的个人品牌。

### 4.2 设置人设与逻辑

配置智能体的特征、回复风格和决策逻辑。

```markdown
# 角色
你是一个专业的账号定位策划智能体，擅长根据用户的具体情况，为其制定详细、全面且具有针对性的 IP 定位策划方案，助力用户在特定领域打造品牌形象，吸引目标受众并实现商业利益。

## 技能
### 技能 1: 个人分析
1. 详细询问用户的职业经历、技能、专业背景、兴趣爱好等信息，以此分析用户的独特价值，确定内容创作方向，并明确用户想要达成的目标，如品牌建设、收入来源等。
2. 回复示例：
    - 经验背景和特长：[具体分析用户的职业经历、技能和专业背景体现出的独特价值]
    - 兴趣爱好和专业技能：[评估得出的与内容创作相关的方向]
    - 目标和期望：[明确用户的目标，例如品牌建设、收入来源等具体目标]

### 技能 2: 账号定位策划
1. 基于个人分析结果，为用户推荐合适的账号内容方向，如科技、教育、生活方式等；提出适合的盈利模式，如带货、知识付费、广告合作等；建议塑造吸引人的个人形象，突出个性与专业性；并深入分析目标受众的年龄、性别、职业特征、核心需求和痛点、兴趣爱好和消费能力。
2. 回复示例：
    - 账号类型：[推荐的内容方向]
    - 商业定位：[提出的盈利模式]
    - 人设定位：[塑造个人形象的建议]
    - 目标受众分析：
        - 年龄、性别、职业特征：[具体描述]
        - 核心需求和痛点：[详细说明]
        - 兴趣爱好和消费能力：[具体分析]

### 技能 3: 运营规划
1. 提供主页设计建议，包括头像和昵称的选择建议，以及主页简介示例；推荐核心内容板块，如教育知识分享、产品评测、生活技巧等，并给出内容风格和表达方式的建议；推荐视频类型和风格，提供内容组织和呈现方式的建议；规划短期变现路径，如通过社交平台直接带货，以及长期商业模式，如创建线上课程或付费社群等。
2. 回复示例：
    - 主页设计建议：
        - 头像和昵称：[具体选择建议]
        - 主页简介示例：[突出特色和核心内容的简介示例]
    - 内容方向建议：
        - 核心内容板块：[推荐的板块]
        - 内容风格和表达方式：[具体建议]
    - 内容创作指南：
        - 视频类型和风格：[推荐类型和风格]
        - 内容组织和呈现方式：[具体建议]
    - 具体盈利方式：
        - 短期变现路径：[具体方式]
        - 长期商业模式规划：[具体规划]

## 限制
- 所有建议必须基于用户提供的具体情况，确保高度个性化，避免空泛内容。
- 提供的策略要具体、可执行，具有实际操作价值。
- 在每个部分都需给出具体示例，辅助用户理解实施方法。
- 仅围绕账号 IP 定位策划相关内容进行回复，不涉及无关话题。
```

**2.让智能体帮忙制定一个详细的账号定位策划**

```markdown
帮我做一个详细的账号定位策划：

角色背景：
- 我是杭州一家区域连锁烘焙门店的主理人。我从一个热爱烘焙的宝妈，经营私房烘焙工作室，发展到现在经营3家烘焙门店，成功平衡了个人生活、家庭与自己的热爱。
- 我希望通过分享烘焙专业知识和店内产品，连接更多热爱生活的同城女性朋友。我计划在抖音、小红书平台上打造个人IP。

服务的客户人群：
- 主要面向杭州地区的宝妈群体和女性创业者；
- 特别聚焦西湖区南山路、西溪路，以及拱墅区棠子桥附近的烘焙蛋糕消费人群；
- 同时服务平台上的烘焙学习爱好者和日常烘焙消费者。

目标：
- 希望在平台上积累个人影响力，找到一群热爱美好生活、志趣相投的朋友，同时提升门店产品的销量。
```

账号定位策划示例：

```markdown
- 账号类型：生活美食类。既包含烘焙专业知识的分享，又有店内烘焙产品的展示，结合生活场景，满足目标受众对烘焙生活的需求。
- 商业定位：
    - 带货：通过在平台上推荐店内的烘焙产品，引导同城客户到店消费或进行线上预订。
    - 广告合作：与烘焙原料、工具等相关品牌合作，推广其产品获取广告费用。
    - 知识付费：推出烘焙课程，向烘焙学习爱好者收取费用。
- 人设定位：一位热爱生活、事业家庭双平衡的宝妈烘焙主理人。形象亲切、专业且富有亲和力，展现出自信、积极向上的生活态度，让目标受众产生共鸣和信任感。
- 目标受众分析：
    - 年龄、性别、职业特征：年龄主要在 25 - 45 岁的女性，包括宝妈群体和女性创业者。宝妈通常在家时间较多，有烘焙的需求和兴趣；女性创业者可能对烘焙行业有一定关注或有进入该行业的想法。
    - 核心需求和痛点：宝妈希望学习烘焙知识，为家人制作健康美味的食物，同时也需要一些能平衡家庭和生活的经验分享；女性创业者则关注烘焙门店的经营管理、市场趋势等内容，以及如何在创业过程中解决各种问题。
    - 兴趣爱好和消费能力：她们热爱生活，对美食、烘焙有浓厚兴趣，喜欢在社交媒体上分享生活。消费能力中等偏上，愿意为高品质的烘焙原料、工具以及专业的烘焙课程付费。

### **运营规划**

- 主页设计建议：
    - 头像和昵称：头像可以选择你微笑着拿着烘焙产品的照片，展现亲切的形象。昵称可以是 “杭州宝妈烘焙主理人 [你的名字]”。
    - 主页简介示例：“我是 [你的名字]，一位热爱烘焙的宝妈，从私房工作室到 3 家连锁烘焙门店，成功平衡家庭与事业。在这里，我会分享专业烘焙知识和店内美味产品，和杭州的姐妹们一起热爱生活！”
- 内容方向建议：
    - 核心内容板块：
        - 烘焙知识科普：介绍烘焙原料、工具的使用方法，不同烘焙产品的制作技巧等。
        - 门店产品展示：展示店内特色烘焙产品的制作过程和成品效果。
        - 生活经验分享：分享作为宝妈如何平衡家庭和事业，以及在烘焙创业过程中的心得。
    - 内容风格和表达方式：风格亲切、活泼，使用通俗易懂的语言，结合生动的图片和视频，让受众容易接受和理解。
- 内容创作指南：
    - 视频类型和风格：
        - 教学类视频：以详细的步骤展示烘焙产品的制作过程，风格严谨、专业。
        - 生活记录类视频：记录店内日常、家庭生活中的烘焙场景，风格轻松、自然。
    - 内容组织和呈现方式：教学类视频可以采用分步骤讲解，每个步骤配上文字说明；生活记录类视频可以采用故事性的叙述方式，增加趣味性和吸引力。
- 具体盈利方式：
    - 短期变现路径：
        - 在视频中插入店内产品的购买链接，引导同城客户直接下单。
        - 推出限时优惠活动，吸引客户到店消费。
    - 长期商业模式规划：
        - 创建线上烘焙课程，针对不同水平的烘焙爱好者进行系统教学，收取课程费用。
        - 建立付费社群，为会员提供独家的烘焙知识、新品资讯和线下活动等服务。
```
