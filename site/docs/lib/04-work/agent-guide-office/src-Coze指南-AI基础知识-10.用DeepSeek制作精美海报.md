# 10.用DeepSeek制作精美海报

你是否遇到这样的困扰，想用AI快速生成一张精美海报，却被各种设计术语搞得头晕脑胀？

"三分法构图"、"景深模糊"、"莫兰迪灰调"这些专业术语看起来很高大上，但对我们这些设计小白来说，简直就像天书一样。

确实，许多教程的提示词复杂得让窒息，对非专业人士来说根本无从下手。

有没有一种方法，能让我们这些不懂设计的人，也能轻松写出属于自己的提示词呢？

现在有了DeepSeek，都能轻松搞定。

本文不仅要告诉你如何用DeepSeek生成提示词，更重要的是要教你背后的方法。

这样就能真正做到"授之以渔"，下次制作海报时就能自如应用。

## 一、DeepSeek生成提示词模板

生成海报提示词其实很简单，有了DeepSeek的帮助，我们可以轻松完成。下面是我向DeepSeek提出的要求：

```markdown
我是一个设计小白，现在要利用AI绘图软件通过文生图的方式做海报，但我不知道如何完整描述一张海报的设计，你帮我生成一个万能公式，后面我只需要换主题，就可以文生图制作海报了。
```

然后记得开启“深度思考”模式，DeepSeek很快就给了我一个通用公式：

```markdown
这是一个专为AI文生图设计的海报描述万能公式，建议收藏后根据需求灵活替换关键词：

「设计风格」+「主体元素」+「布局构图」+「色彩搭配」+「文字排版」+「背景处理」+「细节特效」+「情感氛围」

🖌️ 具体拆解模板（以括号内为可替换内容）：
设计风格
（极简主义/故障艺术/3D渲染/赛博朋克/手绘水彩/复古蒸汽波/孟菲斯风格/中国风/霓虹光感）

主体元素
核心元素：（产品/人物/图标）x（数量）
辅助元素：（几何图形/流体/粒子/植物/科技线条）
动态表现：（漂浮/发光/爆炸效果/动态模糊）

布局构图
（中心对称/三分法构图/对角线构图/网格系统/Z型视觉流）
留白区域：顶部30% / 底部信息栏15%

色彩搭配
主色系：（渐变橙紫/莫兰迪灰调/荧光撞色）
色彩效果：（弥散阴影/半透明叠加/故障色差）

文字排版
主标题位置：（顶部居中/左侧纵向排列）
字体风格：（哥特体/毛笔字/无衬线超细体）
文字特效：（霓虹边框/金属浮雕/玻璃折射）

背景处理
（低多边形建模/噪点质感/液态金属/星空深景/抽象色块）

细节特效
（丁达尔光线/胶片颗粒/飘散花瓣/电流脉冲/全息投影）

情感氛围
（未来科技感/轻松治愈/神秘奇幻/热血澎湃/高端奢华）

✨ 应用示例（儿童绘画比赛海报）：
「3D卡通渲染风格，中央漂浮的七彩蜡笔与调色盘构成视觉焦点，背景采用柔和的马卡龙渐变色，顶部20%留白区域用圆润的泡泡字体展示主标题，添加星星粒子飘落特效，整体营造天真梦幻的童趣氛围，细节加入纸张褶皱纹理和柔和投影——超高清8k，Octane渲染，细节锐化」

💡 使用技巧：

先确定核心关键词（如"赛博朋克 健身房"），再填充模板要素

用「--」分隔不同参数（例：--v 5 --ar 3:4 --style raw）

中英混合描述更精准（例："霓虹灯管neon light环绕的哑光金属质感logo"）

添加艺术指向词（厚涂/平涂/概念艺术/插画风）

📌 注意事项：

避免矛盾描述（如"极简风"与"复杂装饰"）

控制元素数量（AI容易混淆超过5个重点）

用比喻强化画面（"如融化奶酪般的金色渐变"）

测试时先简后繁，逐步添加细节

附送常用风格关键词表：
🔹 质感类：磨砂/镭射/丝绸/大理石/生锈金属
🔸 光影类：伦勃朗光/霓虹漫反射/逆光剪影
🔹 构图类：黄金螺旋/框架式构图/负空间
🔸 特效类：景深模糊/运动轨迹/镜像倒影

现在你可以像搭积木一样组合这些元素啦！需要我针对某个具体主题帮你示范完整描述吗？
```

有了这个模板公式，我们就完成了一半的工作。

但这个模板看起来好像还是挺复杂的，别担心，可以继续和DeepSeek，让它帮助我们解决。

### 二、快速生成自己的提示词

光有模板公式还不够，怎么快速应用才是关键。我以“蛋糕店开业”为主题，跟DeepSeek再次沟通：

```markdown
我是一个设计小白，我只有海报的主题【蛋糕店开业】，标题是“新店开业”，基于上面的模板公式，帮我生成5组提示词。
```

继续发送给DeepSeek，然后关闭深度思考模式。几秒钟内，DeepSeek就能生成五组详细的提示词！只需复制粘贴就能用，非常简单方便。

```markdown
以下是5组针对「蛋糕店开业」海报的AI绘图提示词，涵盖不同风格方向，您可根据需求选择或组合使用：

---

**1. 甜美童话风**  
「3D卡通渲染风格，中央漂浮着巨型彩虹蛋糕与金色开业横幅，周围环绕发光糖霜和跳舞的草莓人偶，马卡龙色气球自动飘向顶部留白区，主标题使用糖浆质感的圆润字体，背景采用柔焦处理的棉花糖云朵，添加闪烁星尘特效——梦幻治愈氛围，8k细节，Octane渲染，工作室灯光」

**2. 极简高级感**  
「北欧极简设计，纯白背景上悬浮单层裸蛋糕实体模型，蛋糕顶部用无衬线金属字呈现"新店开业"，侧光投射出细腻的奶油质地阴影，底部15%区域为浅灰信息栏，搭配极细的香槟金分割线——低饱和度色调，负空间构图，商业级摄影质感」

**3. 复古手绘风**  
「水彩纹理纸本效果，居中展示插画风格的维多利亚式三层蛋糕，周围散落复古糕点剪贴画元素，主标题采用老式招牌油漆字体，背景做旧处理搭配淡茶渍纹理，边缘添加铅笔草稿线迹——温暖怀旧氛围，模拟亚克力颜料笔触」

**4. 赛博朋克风**  
「霓虹故障艺术，全息投影构成的机械蛋糕结构，糖霜部分呈现数据流效果，背景为暗黑都市+全息菜单投影，标题使用像素字体带RGB分裂效果，添加虚拟粒子环绕和霓虹光晕——未来科技感」

**5. 日系清新风**  
「淡彩插画风格，45度俯视角展示木质甜品台，摆满草莓蛋糕卷和玛德琳，背景是虚化的咖啡馆场景，标题用细明朝体搭配手写英文，顶部悬挂简约风开业三角旗，添加阳光透过玻璃窗的光斑效果——治愈系日常感」

---

🛠️ **进阶调整建议**：  
- 想突出优惠信息，可在描述中加入「底部20%区域为促销信息栏，带价格标签浮动动画」  
- 需要人物元素可添加「开心举托盘的服务生Q版角色，微笑顾客剪影」  
- 强化食欲感可补充「食物特写镜头，强调奶油反光和草莓水滴细节」
```

### 三、即梦AI一键生成海报

有了提示词，接下来就该进入AI作图环节了。

这里我推荐使用即梦AI，它不仅中文支持非常友好，每天提供的免费积分也完全够用。

打开即梦AI官网，进入【AI作图】→【图片生成】，在左侧粘贴DeepSeek给的提示词。

模型选择推荐用【图片2.1】，精细度可以选8-9，画面比例建议3:4或9:16。

![image.png](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122447Z-0a587dc0aab37160-e245e58c.jpg)

点一下生成按钮，短短几秒，精美的海报就出炉了！

### 四、小结

有了这个方法，以后再做海报，再也不怕不会写提示词了，真正做到一键生成、轻松搞定。

关键不在于掌握单个海报的制作，而是要理解背后的思维方法，从而实现知识的灵活运用。
