# 用 WorkBuddy 写小红书图文和 60 秒短视频脚本

做自媒体，很容易把时间耗在第一稿上。

一个选题刚冒出来，接着就要想标题、正文、封面文案和话题标签。

准备拍视频时，还要把同一个主题改成口播稿，补上开头、镜头和结尾。

每一项单独看都不算复杂，连在一起却很磨人。

WorkBuddy 可以先接下这些整理和起草工作。

你把账号定位、目标读者和这次内容要讲什么交代清楚，让它生成一套可修改的初稿。

然后再按平台要求逐项调整，比对着空白页面从头憋内容轻松得多。

下面用小红书图文和 60 秒短视频两个任务，把操作过程走一遍。

## 先把账号和内容说清楚

直接输入「帮我写一篇小红书」通常很难得到贴合账号的内容。

WorkBuddy 不知道你的账号平时谈什么，也不知道这篇内容准备写给谁，只能自行补足这些空白。

开始前，至少准备下面几项信息。

- 账号主要分享什么内容
- 读者或观众是谁
- 这次准备介绍什么产品或话题
- 希望读者看完采取什么行动
- 账号平时使用什么语气
- 有哪些产品资料和事实可以引用

其中，产品功能、价格、适用范围和使用限制最好来自现有资料。

材料里没有的信息，可以要求 WorkBuddy 标记出来，留待人工确认，不要让一句顺口的宣传语变成未经核实的承诺。

如果平时已经积累了产品介绍、账号样稿或品牌用语，也可以集中放进工作目录。

后面下达任务时，明确告诉 WorkBuddy 参考哪些文件。

## 先生成一套小红书图文初稿

小红书内容不只有正文。标题能否让人点开，封面文案能否在小屏幕上看清，话题标签是否贴合内容，都会影响最后的呈现。

第一次生成时，可以把这些结果放在同一条指令里，让 WorkBuddy 先给出完整草稿。

```text
请根据我放在当前工作目录中的产品资料，策划 3 个适合小红书发布的选题。

账号主要分享职场效率工具，读者是经常需要写方案、整理资料和制作汇报的职场人。整体语气自然、克制，不要使用夸张承诺。

请从 3 个选题中选出一个最适合新手理解的方向，并生成标题、正文、封面文案和话题标签。

正文需要说明适用场景、基本操作和使用时需要注意的地方。资料中无法确认的信息请标记为待核实。
```

这条指令先让 WorkBuddy 提供三个方向，再选择其中一个继续写。

这样做的好处很直接。你可以先判断选题是否符合账号，再决定要不要花时间修改正文。

生成结果后，先看选题和标题。方向偏了，正文写得再完整也没有多少用。

标题确定以后，再检查正文有没有说清使用场景，产品卖点能否在资料中找到依据，封面文案是否足够简短。

## 分轮修改标题、正文和封面

初稿出来后，不建议用一句「再优化一下」把所有内容重新改一遍。

标题、正文、封面和标签承担的任务不同，分开修改更容易控制结果。

标题太宽泛时，可以限定读者和使用场景。

```text
请只修改标题，正文暂时保持不变。

标题要让经常制作工作汇报的职场人一眼看懂内容用途。给出 5 个版本，避免夸张词和无法验证的效果承诺。
```

正文信息太多时，可以要求删掉重复说明，并把最重要的操作放到前面。

封面文案则要更短，重点是让人扫一眼就知道这篇内容讲什么，不能直接把长标题缩小字号塞进去。

标签也要回到文章本身。

正文讲的是职场效率工具，就围绕工具、办公场景和目标人群选择，不必堆一串与内容关系很弱的热门词。

## 把同一主题改成 60 秒视频脚本

图文初稿确认后，还可以继续把这个主题改成短视频脚本。

视频脚本需要补充时长、平台、目标观众和输出格式。

尤其要说清楚是否需要完整口播、镜头建议和结尾引导，否则生成结果可能只有一段适合阅读的文字，拿到镜头前却不好说。

可以这样下达任务。

```text
请根据刚才确认的小红书内容，生成一份 60 秒短视频脚本。

视频面向想提高办公效率的职场人，节奏紧凑，但不要连续堆砌口号。

脚本需要包含开头引入、完整口播文案、对应镜头建议和结尾行动引导。请按时间顺序整理，口播句子要自然，适合直接读出来。

不要增加现有产品资料中没有的功能和数据。
```

![短视频脚本示例](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122818Z-31ea7819b492ccd1-98119a46.png)

拿到脚本后，最好自己完整读一遍并计时。

纸面上很顺的句子，读出来可能太长。60 秒也只是任务边界，最终能不能装下，要看实际语速和停顿。

如果超时，可以让 WorkBuddy 先保留开头、核心步骤和结尾，再压缩解释。

不要一上来把每句话都砍短，否则口播会变得一顿一顿，听起来很累。

镜头建议也要看现有条件。

一个人拍摄时，可以多用正面口播、屏幕录制和结果展示。

暂时无法拍摄的复杂场景，直接换成手头能够完成的画面，没必要为了照搬脚本增加拍摄负担。

## 发布前做一次人工检查

WorkBuddy 完成的是内容初稿，发布决定仍然留在人手里。

图文发布前，要核对产品名称、功能、价格和操作步骤，删掉待核实标记。

再检查标题与正文是否对应，封面文案有没有错字，标签是否确实与主题相关。

视频开拍前，先把口播稿读出声。遇到拗口的长句就拆开，遇到平时不会说的词就换掉。

镜头顺序、字幕长度和结尾引导也要根据拍摄条件调整。

还可以把最终发布稿和第一版放在一起对照。

哪些信息经常需要补，哪些措辞每次都会删，记录几次以后，下一次下达任务就能提前说明，修改轮数也会慢慢减少。

## 写在最后

第一次练习，可以选择一个资料齐全、自己熟悉的主题。

先生成三个小红书选题，确认方向后完成图文，再把同一份内容改成 60 秒视频脚本。

这一轮不用急着发布。

先检查事实，读一遍口播，再看哪些内容确实省了时间，哪些地方仍然需要自己判断。

等任务说明和修改方式逐渐稳定，再把它用到日常选题和更新中。
