# 09.Coze智能体-插件

要让智能体变得更聪明、更高效，就离不开插件。

那么，插件到底是什么？该怎么用？有哪些注意事项？

今天就给大家来个大揭秘，彻底帮你搞懂扣子插件！

### 一、到底什么是插件？

简单来说，插件就是一个工具包，它里面可以包含多个不同功能的工具（也就是API）。

比如扣子平台提供的插件就非常丰富，涵盖了资讯阅读、旅游出行、效率办公、图片理解等各类API和多模态模型。

使用这些插件，你的智能体瞬间变身全能助手。例如，你给智能体装上一个新闻搜索插件，智能体马上就拥有了搜索最新资讯的能力！

当然，如果现有插件不能满足需求，扣子还贴心地支持你创建自定义插件，把你需要的API统统集成进去。

### 二、插件和工具有什么关系？

很多人经常会混淆插件和工具的关系，这里再通俗地解释一下：

- 插件是一个大的工具包。
- 工具则是插件中的具体功能，也就是单个API。

举个例子，有个天气查询的插件，里面可能会包含两个工具：

- 查询当前天气：[http://api.weather.com/current](http://api.weather.com/current)
- 查询未来天气：[http://api.weather.com/forecast](http://api.weather.com/forecast)

这两个工具虽然功能不同，但都属于同一个插件，因为它们使用相同的域名（[api.weather.com](http://api.weather.com/)）。

智能体调用插件时，实际上就是调用其中某个工具的API。

### 三、扣子插件要收费吗？

扣子插件分为免费插件和付费插件两种。

值得注意的是，每个插件每天都会提供一定次数的免费试用额度，具体区别如下：

- **基础版**：每个插件每天有20次免费试用，超过当天额度就无法继续使用了。
- **专业版**：付费插件每天有30次免费试用；免费插件则无限次，但存在调用频率（QPS）的限制。

另外，同一插件内的所有工具共用免费次数。如果你开通了专业版，主账号和所有子账号共享每天的免费试用额度。

### 四、使用插件的限制有哪些？

虽然插件强大，但使用时也有一些限制需要注意：

- 每个工作空间最多创建1000个插件。
- 单个插件最多包含100个工具。
- 每个账号最多可创建15个IDE插件。

这些限制一般情况下足够用，但也需要提前规划好，避免资源浪费。

### 五、如何给智能体绑定插件？

下面一步步教你怎么操作：

1. 登录扣子平台。
2. 在左侧导航栏选择【工作空间】，选择你的个人空间或团队空间。
3. 在【项目开发】页面中选中你要配置的智能体。
4. 在智能体编排页面找到【技能】-【插件】区域。
5. 你可以选择“直接添加插件”或者让大模型帮你“自动添加插件”。
6. 添加完成后，记得去【人设与回复逻辑】中定义智能体调用插件的场景，最后别忘了在【预览与调试】里验证一下效果。

简单几步，你的智能体马上“学会”新技能。

### 六、插件也可以用于工作流

插件除了绑定给智能体，还可以直接加入到工作流中，构成自动化流程。

具体步骤如下：

1. 登录扣子平台后，进入【资源库】，找到要配置的工作流。
2. 在左侧面板选择【插件】，搜索并添加到工作流画布上。
3. 配置插件节点输入参数，连接节点，完成自动化流程。

当用户触发对话时，插件节点就能自动运行，大大提高效率。
