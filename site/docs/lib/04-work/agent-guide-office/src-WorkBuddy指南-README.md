# WorkBuddy 教程：从入门到 Skill、自动化与办公实战

这套 WorkBuddy 教程面向希望把 AI 真正用进日常工作的人，从 WorkBuddy 是什么、怎么描述任务开始，逐步讲清专家、专家团、Skill、连接器、手机版和自动化任务，再通过 PPT、Word、Excel、文件整理、会议纪要与内容创作等案例完成实战。

第一次使用 WorkBuddy，可以按照基础入门的顺序学习；已经熟悉核心能力，可以直接按工作需求选择自媒体或办公案例。每篇教程都强调输入范围、执行权限、交付结果与人工验收，帮助你把一次成功的对话变成能够重复使用的工作流程。

## WorkBuddy 是什么

WorkBuddy 是一款运行在电脑上的通用 AI Agent。它不仅能回答问题，还可以在用户授权的工作空间内读取和整理文件、分析表格、生成文档与 PPT，并通过连接器使用会议、邮箱等外部服务。

和普通聊天机器人相比，WorkBuddy 更适合处理有明确输入、执行动作和交付物的任务。开始前仍要限定目录、权限和修改范围，完成后也要人工检查事实、数据和文件结果。想先了解完整能力，可以阅读 [WorkBuddy 是什么？核心功能、适用场景与入门方法](https://github.com/tangshiyegit/agent-guide/blob/ae8b2262e7a1e5bd0d466037c6ad9f6037b72c33/workbuddy-guide/getting-started/01-work-buddy.html)。

## 适合谁学习

- 第一次接触 WorkBuddy，不清楚专家、专家团、Skill 和连接器区别的用户。
- 希望让 AI 整理文件、分析 Excel、制作 PPT，而不只是聊天问答的职场人。
- 想把选题、写作、资讯收集和邮件简报变成稳定流程的内容创作者。
- 已经用过 WorkBuddy，但任务经常中断或结果不稳定，希望改善任务表达和验收方式的用户。
- 想用自然语言制作本地应用或创建个人 Skill 的进阶用户。

## WorkBuddy 常见问题

### WorkBuddy 和普通聊天机器人有什么区别？

普通聊天机器人主要返回文字回答，WorkBuddy 还能在授权范围内读取本地文件、生成交付物并调用连接器。具体能力和使用边界可查看 [WorkBuddy 入门教程](https://github.com/tangshiyegit/agent-guide/blob/ae8b2262e7a1e5bd0d466037c6ad9f6037b72c33/workbuddy-guide/getting-started/01-work-buddy.html)。

### WorkBuddy 新手应该从哪里开始？

先选择一个范围小、结果容易核对的任务，例如整理几张图片。明确工作目录、不能修改的内容和结果格式，执行后逐项检查，再逐步尝试连接器和自动化任务。

### 专家、专家团和 Skill 应该怎么选？

专家适合一项专业任务，专家团适合多个角色协作，Skill 适合固定并重复执行一套流程。三者的判断示例见 [WorkBuddy Skill、专家和专家团的区别](https://github.com/tangshiyegit/agent-guide/blob/ae8b2262e7a1e5bd0d466037c6ad9f6037b72c33/workbuddy-guide/getting-started/02-work-buddy-skill.html)。

### WorkBuddy 可以处理本地文件吗？

可以，但应只授权当前任务需要的目录。涉及改名、移动、覆盖或删除时，先让它返回候选清单和预览，并保留原文件备份。可以从 [WorkBuddy 文件处理教程](https://github.com/tangshiyegit/agent-guide/blob/ae8b2262e7a1e5bd0d466037c6ad9f6037b72c33/workbuddy-guide/office-productivity/05-work-buddy-file-management.html) 开始练习。

### WorkBuddy 能分析 Excel 并生成图表吗？

可以。开始前要写清分析问题、字段含义、时间范围和统计口径，生成后抽查原始数据。完整步骤见 [WorkBuddy Excel 数据分析与图表教程](https://github.com/tangshiyegit/agent-guide/blob/ae8b2262e7a1e5bd0d466037c6ad9f6037b72c33/workbuddy-guide/office-productivity/08-work-buddy-data-analysis-charts.html)。

### WorkBuddy 能定时执行任务吗？

可以把已经手动跑通的资讯、简报等任务配置成周期执行。应先确认时间、重复规则、输出位置和失败时的说明方式，具体操作见 [WorkBuddy 自动化任务教程](https://github.com/tangshiyegit/agent-guide/blob/ae8b2262e7a1e5bd0d466037c6ad9f6037b72c33/workbuddy-guide/getting-started/07-work-buddy-automation.html)。

### 使用 WorkBuddy 时怎样保护原文件？

把操作范围限制到独立工作目录，默认只新增结果文件，不允许覆盖或删除原文件。批量任务先用副本和少量文件测试，确认预览后再扩大范围。

## 使用建议

不要一开始就追求全自动。先挑一个输入清楚、结果容易检查的任务，亲自跑通并记录问题；等提示词、资料范围和交付格式稳定以后，再把它交给 Skill 或自动化任务长期执行。

不确定从哪篇开始，可以先读 [WorkBuddy 是什么](https://github.com/tangshiyegit/agent-guide/blob/ae8b2262e7a1e5bd0d466037c6ad9f6037b72c33/workbuddy-guide/getting-started/01-work-buddy.html)，再从图片整理、数据分析或 PPT 中选择一个和当前工作最接近的案例。
