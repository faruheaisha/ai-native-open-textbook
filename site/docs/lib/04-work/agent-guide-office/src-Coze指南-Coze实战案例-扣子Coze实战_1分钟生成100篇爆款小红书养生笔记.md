## 1. 工作流整体流程

![image.png](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122538Z-c5b89f18f45e9f50-1c1c1bdc.jpg)

1. 用户输入养生主题：用户只需输入一个养生主题，如"湿气越吃越少10种食物"
2. AI生成专业养生内容：AI大模型自动生成10条专业的养生知识点，每条包含名称和详细说明
3. 批量生成精美配图：为每个养生知识点自动生成温暖治愈系插画，并进行背景透明化处理

5. 转换为小红书风格：将专业内容转换为符合小红书等平台调性的文案，自动添加emoji表情

### 2.4 批量处理节点

批量处理节点负责将生成的养生内容列表拆分，为每个养生项目生成独立的图片。

批量处理配置：

- 批量大小：100（最多处理100个项目）
- 并发大小：3（同时处理3个任务）
- 输入：大模型节点输出的养生内容列表

![image.png](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122538Z-44890faa17e739c8-c85a26db.jpg)

### 2.5 图像生成节点

在批处理内部，图像生成节点为每个养生项目生成精美插画。

图像生成节点配置：

- 输入：批量处理节点传入的养生项目名称
- 图像尺寸：1024×1024
- 模型：通用pro
- 提示词模板：

```markdown
根据{{prompt}}生成一个只有主体图案的内容，温暖治愈系插画，图像的主题位于一个正方形中央，背景留白。
```

![image.png](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122537Z-b2750e6c39a3310a-a8228ea8.jpg)

### 2.6 抠图节点

为了让生成的图片更加精美，使用抠图插件将图像主体提取出来，去除背景。

抠图节点配置：

- 输入：图像生成节点的输出
- 输出模式：透明背景图
- 产物尺寸：抠图结果尺寸

![image.png](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122620Z-730a7105a733d910-49757faa.jpg)

### 2.7 画板节点

画板节点将抠好的图片和养生内容文字组合在一起，形成精美的图文卡片。

画板节点配置：

- 输入：
    - subject：主题
    - description：养生项目描述
    - image：抠图后的透明背景图
    - name：养生项目名称
- 画板尺寸：1080×1920（适合手机屏幕竖向浏览）
- 布局：顶部显示主题，中间是图片，底部是名称和描述

![image.png](https://vtang.oss-cn-hangzhou.aliyuncs.com/images/2026/08/25/20260825T122539Z-10ba2e1fc9813b6c-ffb6c666.jpg)

### 2.8 结束节点

连接"批处理"节点到"结束"节点

配置结束节点输出：

- output：文字优化节点的output
- output1：批处理节点的output（图文内容）
