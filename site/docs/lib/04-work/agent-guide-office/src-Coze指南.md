# Coze指南：从 AI 基础到智能体实战

这份指南按照“理解 AI → 认识智能体 → 掌握 Coze → 搭建工作流 → 完成业务案例”的路径组织内容，帮助你从零开始构建真正能够解决问题的智能体。

如果你没有 AI 基础，可以从 AIGC、大模型和提示词开始；如果已经了解基本概念，可以直接进入 Coze 基础入门，再通过实战案例完成一次完整交付。

## 适合谁看

- 想系统了解 AIGC、大模型和 AI 智能体的零基础学习者。
- 希望掌握 Coze 人设、工作流、插件、知识库、记忆和卡片等核心能力的用户。
- 想用智能体提高内容生产、数据分析和账号运营效率的自媒体创作者。
- 需要把热点监控、内容改写、视频生产等流程自动化的业务人员和开发者。

## 学习重点

- 理解大模型和智能体的能力边界，先定义业务目标，再选择工具和模型。
- 掌握提示词、人设、工作流、插件、知识库与记忆之间的分工和组合方式。
- 让工作流的每一步都有明确输入、处理规则、失败分支和结构化输出。
- 实战时重点关注数据来源、内容质量、执行成本、发布风险和人工验收。

## 实战方法

复刻案例时，不要只复制工作流节点。先写清楚目标用户、输入数据、内容标准和最终交付物，再替换提示词、插件和知识库。跑通以后记录每个失败点，逐步增加重试、校验和人工确认，才能把演示项目变成稳定工具。

指南会持续补充新的 Coze 能力和真实业务案例。
