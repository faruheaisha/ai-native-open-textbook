# qwenwork-official-help-cn

帮助中心 企业旗舰版能力 订阅与用量 订阅管理
 通用官方知识库
订阅管理
订阅管理用于核对企业当前套餐、有效期和席位数量。新成员无法授权或需要续费时，先在这里检查订阅情况。
查看订阅与席位
- 进入 数据与运营 → 订阅与用量 → 订阅管理。
- 核对当前套餐、订阅状态、订阅周期和剩余时间。
- 查看已购席位、已授权席位与剩余席位。准备批量开通成员前，确认剩余席位足够。
- 需要核对某位成员的授权情况时，进入用户查询。
