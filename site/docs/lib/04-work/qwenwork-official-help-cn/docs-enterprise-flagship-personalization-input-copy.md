# qwenwork-official-help-cn

帮助中心 企业旗舰版能力 个性化配置 输入框文案
 通用官方知识库
输入框文案
输入框文案在成员尚未输入内容时提示可以做什么。后台分别维护正常状态和 AI 回复中的提示文字，便于成员理解当前可以输入的内容。
编辑两种状态的提示
- 进入 用户与体验 → 个性化配置 → 输入框文案。
- 在「正常状态」填写一条简短提示，例如“描述任务，或上传需要处理的文件”。
- 在「AI 回复中」填写对应提示，例如“补充要求或继续输入问题”。每项最多 128 个字符。
- 使用字段旁的语言编辑入口，按需要维护简体中文或英文文案。
- 在预览中切换两种状态，确认文字适合输入框宽度，再点击【保存并发布】。

检查实际显示
在客户端新建任务，先查看空输入框，再发送一条消息，检查 AI 回复过程中的提示。这里修改的是界面提示文字，不会自动作为成员消息发送，也不会为任务增加固定指令。
