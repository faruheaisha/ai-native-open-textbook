桌面端核心功能
QwenWork 桌面端是一款面向日常办公场景的 AI 智能工作台。用户可以通过自然语言发起任务，结合文件、技能、连接器、电脑操控能力、IM、Hooks等功能，完成信息整理、内容创作、数据分析等工作，减少应用切换，提高任务处理效率。
目前，企业版能力主要支持 PC 端和 Web 端，QwenWork 桌面客户端的相关能力将在后续版本中逐步开放，敬请期待。
