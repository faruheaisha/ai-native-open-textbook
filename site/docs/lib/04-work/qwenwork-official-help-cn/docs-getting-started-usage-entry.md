# qwenwork-official-help-cn

帮助中心 入门指南 快速开始
 通用官方知识库
快速开始
功能简介
千问办公现阶段提供三种使用方式，覆盖日常办公、移动响应与深度编辑等多元场景，您可根据需求灵活选择。
操作流程
钉钉内使用：
电脑端钉钉 > 左侧 导航栏 > 千问办公 可在工作台内直接唤起。无需额外登录或跳转，AI能力与钉钉原生界面无缝融合，支持在聊天、文档、日程等场景中随时调用。
网页端
浏览器访问 qwenwork.cn/signin，登录钉钉账号后即开即用，无需下载安装。出差途中、临时换设备或紧急任务处理时，网页端保证用户第一时间进入工作状态，所有数据云端实时同步。
桌面端
访问官网下载并安装桌面客户端，登录后即可获得完整的产品体验。桌面端直连本地文件系统，支持对本地文档、表格、图片、视频进行直接分析与处理，操作逻辑与本地软件完全一致，适合需要高强度文件处理或内容创作的深度办公场景。
