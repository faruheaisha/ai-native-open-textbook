# qwenwork-official-help-cn

帮助中心 企业旗舰版能力 数据统计 综合看板
 通用官方知识库
综合看板
综合看板用于查看组织的积分消耗和活跃情况。先选择时间范围，再解读总量、日均和趋势，避免把不同周期的数据放在一起比较。
⚠️ BYOK 适用说明： BYOK（Bring Your Own Key，自带模型密钥）能力仅对已开放该能力的部分用户可用。BYOK 模型不适用千问办公-旗舰版的用量统计与限额管理；相关统计数据和限额规则不包含 BYOK 模型。
查看组织使用趋势
- 进入 数据与运营 → 数据统计 → 综合看板。
- 在「筛选条件」选择周期，记录页面显示的起止日期与数据截至时间。
- 查看累计消耗积分、日均消耗积分、当前周期剩余积分和活跃人数。
- 查看组织积分消耗趋势，找到明显增长或下降的日期，再进入用量明细定位成员。

理解指标口径
指标阅读方法
累计消耗积分所选时间段内的消耗，不等同于企业所有历史消耗
日均消耗积分按所选时间段的自然日计算，不只计算有使用记录的日期
当前周期剩余积分对应组织当前周期额度，不是给每位成员单独发放的额度
活跃人数筛选周期内至少使用一次的成员数量，不等同于已授权席位数

统计数据保留 180 天。页面显示的数据截至时间可帮助判断最新使用是否已进入统计。
用量突然增加时
先确认周期没有改变，再到用量统计在「用户」页签按周期内已用排序，查看增量集中在哪里。需要进一步了解任务内容时，在权限允许的范围内结合AI 日志查询相关对话轮次。
