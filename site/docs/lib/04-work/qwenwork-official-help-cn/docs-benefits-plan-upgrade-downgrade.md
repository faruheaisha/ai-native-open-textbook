套餐升降级策略
一、基础规则
- 连续包月购买：套餐到期后自动续费，用户可主动取消后续订阅。
- 单次购买：仅购买当前套餐周期，到期后不自动续费。
- 套餐升级：升级后立即生效，原套餐截止时间不变。
- 套餐降级：当前暂不支持。
- 最终支付金额和套餐有效期以订单确认页面为准。
