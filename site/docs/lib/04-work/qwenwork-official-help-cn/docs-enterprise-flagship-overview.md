# qwenwork-official-help-cn

帮助中心 企业旗舰版能力 概览
 通用官方知识库
概览
概览显示企业初始化指引、当前套餐、剩余席位、剩余积分和近 30 天使用情况。
查看企业情况
- 登录管理后台，点击左侧【概览】。
- 在「当前套餐」查看组织名称、订阅状态和到期时间，点击【查看订阅】进入订阅管理。
- 查看剩余席位和已授权人数，点击【管理席位】进入用户管理。
- 查看近 30 天的积分消耗趋势。在「积分消耗排行」切换「总消耗」或「人均消耗」，比较部门用量。
图 1：上方提供初始化指引和订阅信息，下方显示积分趋势、部门排行与席位数据。
使用初始化指引
「完成企业初始化」提供四个入口：配置登录方式、设置额度分配规则、邀请或导入用户、配置管理员。点击其中一项进入对应配置页面。
