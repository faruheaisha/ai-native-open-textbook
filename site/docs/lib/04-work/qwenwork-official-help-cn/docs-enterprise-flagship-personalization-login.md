# qwenwork-official-help-cn

帮助中心 企业旗舰版能力 个性化配置 登录页
 通用官方知识库
登录页
登录页配置用于为企业登录入口设置背景图片。准备好企业图片后，可先在管理后台预览，再保存发布。
上传企业登录背景
- 进入 用户与体验 → 个性化配置 → 登录页，开启企业登录页配置。
- 在背景图片区域选择上传图片。使用 JPG 或 PNG，文件不超过 5 MB，建议尺寸不小于 720 × 720 像素。
- 查看旁边的登录页预览，确认主体内容没有被裁切，登录区域仍清晰可读。
- 点击【保存并发布】，重新打开页面确认当前图片。
【截图：登录背景上传区域与登录页预览 · personalization--login.png】
图 1：上传后先查看预览；图片边缘不宜放置必须完整显示的文字。
替换或关闭企业背景
替换时重新上传图片并发布，检查不同窗口宽度下的展示。关闭企业登录页配置后按页面提示保存，客户端将使用对应的默认登录展示。
确认登录入口
从组织信息确认企业访问地址，再打开企业登录页检查背景。登录方式是否出现由身份认证控制，上传背景不会自动启用 SSO 或密码登录。
