# qwenwork-official-help-cn

帮助中心 企业标准版能力 积分管理
 通用官方知识库
积分管理
1. 使用范围与权限
积分管理用于查看组织实际积分、订阅计划和资源包，并为组织、团队或成员设置使用上限。左侧菜单只对超级管理员和团队管理员显示。
管理员身份进入后看到的内容
超级管理员“组织积分”和“成员限额”两个页签；可编辑组织限额。
团队管理员直接进入成员限额；可查看团队限额并管理成员限额。

2. 组织积分概览
指标说明
积分组织实际可使用的积分总量，由所有获得坐席的成员共同使用。
冻结积分当前暂时不可用的积分。
有效资源包仍在有效期内的积分资源包数量。

重要区别：积分余额是实际可用资源；限额是允许使用的上限。提高限额不会增加积分余额。

3. 当前计划、历史计划与资源包
3.1 当前计划
查看计划名称和状态。 查看每周期限额、月付/季付/年付周期、总周期数和有效日期。 “暂无有效订阅计划”表示当前没有生效中的企业计划。
3.2 历史计划
查看生效中、待生效、已排期、已过期、已取消或已终止的计划。 可查看每周期限额、生效/到期日期及内部备注。
3.3 资源包明细
可按全部、有效或失效状态筛选。 查看来源、初始容量、当前余额、冻结积分、生效日期和到期日期。 余额消耗与到期情况应结合组织实际使用判断。
4. 组织、团队和成员限额
层级说明谁能操作
组织限额组织层面的使用上限。超级管理员可编辑。
团队限额团队层面的使用上限。团队管理员可查看。
成员限额单个成员的使用上限，不得超过上级限额。超级管理员或团队管理员按权限编辑。

降低限额的顺序：如果新组织限额低于现有成员限额，系统会阻止或提示可能部分更新。建议先降低成员限额，再降低组织限额。

5. 编辑组织限额
- 打开“成员限额”超级管理员切换到该页签。

- 点击“编辑限额”在组织限额卡片中打开设置窗口。

- 填写新限额必须输入整数，最低 2,000 积分。

- 确认并检查保存后检查“已用 / 限额”和使用率是否更新。

6. 设置单个成员限额
- 找到成员可按名称或联系方式搜索，也可用标签筛选。

- 判断使用情况查看已用积分、成员限额和使用率；点击表头可排序。

- 点击编辑在操作列点击编辑成员限额。已移除成员不能编辑。

- 输入并保存输入整数，最低 2,000；不得超过组织限额或团队限额。

7. 批量设置成员限额
- 进入批量模式点击“批量选择”。

- 选择成员逐个勾选或全选当前筛选范围。

- 点击“批量设置限额”系统先预览实际更新人数，已离开范围的成员会跳过。

- 填写统一限额输入不低于 2,000 的整数，且不能超过页面显示的上级限额。

- 确认设置完成后查看成功提示，其中会说明更新人数和跳过人数。

6.
筛选与全选：如果先搜索或筛选再“全选所有成员”，批量操作只针对当时的筛选范围。操作前务必核对预览人数。

8. 成员限额列表信息
字段含义
已用积分成员已经消耗的积分。
成员限额允许该成员使用的最高额度。
使用率已用积分 ÷ 成员限额；超过 80% 时建议关注。
标签成员分类，可筛选和批量维护。
状态/操作已移除成员不可编辑；正常成员可按权限调整。

9. 与坐席的关系
设置成员限额并不代表成员立即可以使用组织积分。成员还必须在“成员管理”中获得坐席。建议按以下顺序开通：
- 确认成员已加入组织成员出现在成员列表中。

- 分配坐席在成员编辑窗口点击“分配坐席”。

- 设置成员限额回到积分管理，设置适合的使用上限。

- 观察使用率定期按使用率排序，及时调整。

10. 常见问题
问题处理方法
为什么限额调高后余额没有增加？限额不是充值；它只控制最高可用量。
为什么不能保存 1,000 积分？当前最低限额为 2,000 积分。
为什么提示超过上级限额？成员限额不能超过团队或组织限额，请降低输入值或先调整上级限额。
成员有额度但仍不能使用？检查是否已在成员管理中分配坐席。
页面没有组织积分页签？团队管理员只显示成员限额；组织积分仅超级管理员可见。
数据加载失败怎么办？点击“重试”；若仍失败，刷新页面并联系系统管理员。

11. 管理建议
新成员按“加入组织 → 分配坐席 → 设置限额”的顺序开通。 按月查看资源包到期日和冻结积分，避免可用余额突然下降。 定期按使用率从高到低排序，提前处理接近上限的成员。 批量修改前先筛选和预览，避免误改大范围成员。
