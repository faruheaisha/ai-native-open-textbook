# qwenwork-official-help-cn

帮助中心 入门指南 购买指引 阿里云官网购买
 通用官方知识库
阿里云官网购买
【重要】确认千问办公组织是否和钉钉组织绑定，若需要绑定请在钉钉内切换到需要绑定的钉钉组织，从钉钉内访问千问办公，从钉钉内的免费注册入口获取组织ID。从该入口进入会自动绑定钉钉组织（需要钉钉组织主管理员及以上身份）。后续流程相同。
千问企业版商品包括席位和积分包，积分包单独购买无效，需要有效期内的席位才能使用。
席位购买
购买地址

选择购买的席位数量和购买时长，若不需要与钉钉组织绑定，点击免费注册链接获取组织ID
