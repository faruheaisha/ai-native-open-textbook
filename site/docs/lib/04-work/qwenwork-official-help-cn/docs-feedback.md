# qwenwork-official-help-cn

帮助中心 问题反馈
 通用官方知识库
问题反馈
用户可以通过问题反馈中的AI客服功能，以自然语言对话的方式查询产品信息、功能说明、使用规则及常见问题，并获得清晰的操作指引，快速了解从功能入口到任务完成的完整链路。
如在使用过程中遇到异常，也可以通过 AI 客服提交问题反馈，并提供 User ID、Session ID 等信息，帮助千问办公技术团队快速定位和处理问题。
