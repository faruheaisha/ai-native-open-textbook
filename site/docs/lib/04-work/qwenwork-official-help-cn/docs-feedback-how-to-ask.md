# qwenwork-official-help-cn

帮助中心 问题反馈 提问指南
 通用官方知识库
提问指南
在使用千问办公过程中，如果遇到功能异常，可以按照本指南通过AI客服提交反馈。完整的问题信息能够帮助开发人员更快定位和解决问题。
可能遇到的问题
- 无法发送消息，点击发送后没有反应
- 消息长时间处于处理中
- 回答中途停止、内容缺失或重复输出
- 回答与问题无关，或未正确理解上下文
- 多轮对话中遗忘前文、引用错误内容
- 页面提示任务执行失败或请求超时
- 同一个任务被重复执行
- 显示任务执行成功，但实际结果未生成
- 文件无法上传、解析、预览或下载
- 文件内容识别不完整或格式错乱
- 生成的文档、表格等文件无法打开
- 专家套件或技能无法安装、启用或使用
- 连接器无法授权、提示权限不足或数据获取失败
- 会话记录丢失、无法打开或内容显示异常
- 页面空白、按钮无响应或频繁卡顿
- 登录失败、功能不可见或提示没有权限
- 移动端与电脑端的内容或任务状态不一致
- 其他影响正常使用的问题
提交反馈时需要提供的信息
请尽量提供以下内容：
- 问题描述：实际发生了什么。
- 预期结果：正常情况下希望得到什么结果。
- 发生时间：问题发生的具体日期和时间。
- 复现步骤：出现问题前进行了哪些操作。
- 图片或者视频
- User ID：用于确认发生问题的用户账号。
- Session ID：用于定位发生问题的具体会话。
请务必提供发生异常的那条会话对应的 Session ID，不要提供其他正常会话的 Session ID。
如何获取 User ID 和 Session ID
进入发生问题的会话，在会话信息或问题反馈页面中查看并复制：
- User ID
- Session ID
如果暂时无法找到相关信息，请提供问题发生时间和对应会话截图，由工作人员协助查询。User ID 和 Session ID 仅用于定位账号、会话及相关运行记录。请勿在反馈中提交密码、验证码、访问令牌或其他敏感信息。
