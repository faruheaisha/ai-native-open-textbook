# qwenwork-official-help-cn

帮助中心 企业旗舰版能力 订阅与用量 订单记录
 通用官方知识库
订单记录
订单记录通过外部的「费用与成本」查看。
在管理后台依次点击 数据与运营 → 订阅与用量 → 订单记录，浏览器会在新标签页打开费用与成本，当前管理后台页面保持不变。
ℹ️ 说明： 订单查询在费用与成本中完成，管理后台不展示订单列表或订单详情。
