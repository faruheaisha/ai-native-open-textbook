# @coze-project-ide/biz-plugin

A plugin system package for the Coze Studio monorepo

## Overview

This package is part of the Coze Studio monorepo and provides plugin system functionality. It serves as a core component in the Coze ecosystem.

## Getting Started

### Installation

Add this package to your `package.json`:

```json
{
  "dependencies": {
    "@coze-project-ide/biz-plugin": "workspace:*"
  }
}
```

Then run:

```bash
rush update
```
