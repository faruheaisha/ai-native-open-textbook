## Overview

This package is part of the Coze Studio monorepo and provides architecture functionality. It includes sdk.

## Getting Started

### Installation

Add this package to your `package.json`:

```json
{
  "dependencies": {
    "@coze-studio/tea-adapter": "workspace:*"
  }
}
```

Then run:

```bash
rush update
```
