# 附录 C · 术语表

## C.1 术语总表

| 术语 | 英文 | 定义 | 定义章 |
|-|-|-|-|
| 工程挽具 | Harness | 围绕模型、使其能力落地的工程系统；沙盒做减法，挽具做加法 | 第 2 章 |
| 系统提示词 | system prompt | 每次请求拼装注入的规则与上下文总集，不落盘 | 第 1 章 |
| 提示词模板 | prompt template | 带占位符的主模板文件（Jinja2 语法），决定提示词结构 | 第 5 章 |
| 插槽 | slot | 模板中运行时填充内容的占位变量 | 第 5 章 |
| 系统提醒通道 | system reminder | 以标签包裹注入对话的内容通道（专家人设、规则均走此通道） | 第 5 章 |
| 专家 | Expert | 带头像与开场白的插件包；人设提示词接管对话；分单 Agent 型与 Team 型 | 第 7 章 |
| 专家团 | Expert Team | Team 型专家：团长拆解、成员并行、整合交付 | 第 7 章 |
| 插件 | Plugin | MCP+技能+规则+钩子+资产的安装分发单位；三层作用域 | 第 8 章 |
| 技能 | Skill | 按需加载的方法论文档（SKILL.md） | 第 9 章 |
| 规则文件 | rules file | 项目内常驻约束（WORKBUDDY.md 约定） | 第 9 章 |
| 连接器 | Connector | 市场预集成的外部服务接入包 | 第 11 章 |
| 模型上下文协议 | MCP, Model Context Protocol | 外部工具接入的业界标准协议 | 第 11 章 |
| 身份四件套 | — | SOUL/IDENTITY/USER/MEMORY 四个身份记忆文件 | 第 6 章 |
| 三层记忆 | — | 云端画像（只读）+用户级 MEMORY.md+工作区日志 | 第 4 章 |
| 会话流水 | session JSONL | 按项目存储的逐事件会话记录（带 parentId 链） | 第 10 章 |
| 执行轨迹 | traces | 请求执行链与 token 消耗的跨度记录 | 第 10 章 |
| 提示词注入 | prompt injection | 内容以数据进场、以指令生效的攻击面 | 第 12 章 |
| 权限模式 | permission mode | 默认权限（四类操作确认）与完全访问两档 | 第 12 章 |
