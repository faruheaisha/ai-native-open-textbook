# 附录 D · 版本快照与取证方法

## 冻结版本

- 产品：WorkBuddy 5.3.13，build 20fd9da5c9a0cac41feb61b133f7bce4fe183a89（本机安装版本，约 2026-08-13；官方 Changelog 两轮抓取存在 5.3.12/5.3.13 差异，以本机 renderer-version.json 为准）
- 声明环境：macOS（Apple Silicon，darwin 25.5.0），本机真实账户
- 取证窗口：2026-08-15；27 项关键文件 SHA-256 指纹存本书研究档案（local-snapshot-manifest.json）

## 核对本书是否仍适用于你的版本

```
cat ~/.workbuddy/app/renderer-version.json
```

版本一致 → 机制描述按书为准；版本更新 → 先查官方更新日志中涉及以下关键词的条目：提示词、模板、专家、插件、记忆、权限、沙箱、MCP。命中条目对应章节按「文件现状」重新核对（每章动手环节的命令即核对工具）。

## 读者可复用的取证方法

1. **结构取证**：`find  -maxdepth 2` 建立地图；`ls -lt` 找最新变化。
2. **行为取证**：会话 JSONL 逐事件分析（第 10 章 grep 方法）；`parentId` 链回溯决策依据。
3. **注入取证**：会话首条消息找 system-reminder 包裹；专家会话找 expert_selection 标签。
4. **指纹冻结**：对关键文件记 sha256，更新前后对比即知变化面：

```
shasum -a 256 ~/.workbuddy/settings.json
```

1. **反证习惯**：任何机制断言，找一个「若断言为假则应出现」的反例样本；找不到才算验证完成。
