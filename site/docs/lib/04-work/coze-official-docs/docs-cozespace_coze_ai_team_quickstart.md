# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

在扣子中，你可以不只拥有一个 Agent，而是组建一支真正能协作的 AI 团队。无论是一个人调度多个 Agent，还是团队成员和多个 Agent 一起推进项目，都可以在同一个项目空间里共享上下文、分工执行、沉淀成果。

## 1 分钟了解 AI 团队 \{#102a4ee8\}

在扣子中，AI 不再只是一个单独的助手，而是一支可以被你调度、分工和协作的团队。你可以一个人指挥多个 Agent，也可以邀请团队成员一起进入项目，让人和 Agent 围绕同一个目标共同推进任务。

* **多人多 Agent 协作**：支持一人+多 Agent、多人+多 Agent 等协作模式。需要谁加入，@ 一下即可就位。
* **项目化工作空间**：每个项目都有独立的对话、文件和资产空间，任务背景、过程和成果会持续沉淀。
* **Agent 分工执行**：不同 Agent 可以各司其职，分别负责资料整理、方案撰写、行业分析、代码实现、视频生成等任务。
* **云端与本地统一托管**：你可以创建云端 Agent，也可以接入 Claude Code、Codex CLI、OpenClaw 等本地 Agent，在扣子中统一调度。
* **团队协作更清晰**：真人成员和 Agent 共享上下文、同步进度，减少反复沟通和重复交接，让复杂项目持续向前推进。

## 打造行业专家 Agent \{#f5c4ccc3\}

在扣子中，你可以基于行业模板快速创建行业专家 Agent，让它成为法务、内容、互联网等领域的专业伙伴，例如小红书创作达人、公众号创作达人、数据分析师、投资理财顾问、法务助手等，让它开箱即用地处理专业任务。

相比从零培养，一个行业专家 Agent 可以直接带着职业设定、专业技能和工作方法加入项目，帮你更快处理复杂问题。

操作步骤如下：

::::tabs
@tab 网页端、桌面端
1. 在[扣子网页端](https://www.coze.cn/overview?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)的对话列表中，单击➕ > **新增 Agent**。
   ![Image=396x215](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0eba517402b746258657b086a2094405~tplv-goo7wpa0wc-topic.webp)
2. 单击**选择职业模板**对应的➕图标。
3. 选择职业模板，单击**下一步**。
   浏览模板库，选择匹配 Agent 需求的模板。
4. 设置 Agent 信息，然后单击**创建 Agent**。
   * Agent 名称：建议带岗位前缀，方便后续识别。例如：运营-小红书助手、法务-合同审核员。
   * 描述：说明该 Agent 的用途。
   * 部署设备：选择该 Agent 运行环境。支持多个 Agent 部署在同一台云电脑上。

@tab 移动端
1. 在扣子 App 顶部，单击➕ > **新增 Agent**。
   ![Image=141x275](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f431524b43fb4a2e8d555b0ccd028cc4~tplv-goo7wpa0wc-topic.webp)
2. 单击**选择职业模板**对应的➕图标。
3. 选择职业模板，单击**下一步**。
   浏览模板库，选择匹配 Agent 需求的模板。
4. 设置 Agent 信息，然后单击**创建 Agent**。
   * Agent 名称：建议带岗位前缀，方便后续识别。例如：运营-小红书助手、法务-合同审核员。
   * 描述：说明该 Agent 的用途。
   * 部署设备（可选）：选择该 Agent 运行环境。建议部署到云电脑，享受更稳定的运行环境。
::::

当你创建了多个 Agent 后，还可以把它们加入同一个项目，通过 @ 指定不同 Agent 处理不同任务，让你的 AI 团队真正开始协作。

## 开始组建 AI 团队 \{#96209258\}

创建好 Agent 后，你可以把它们加入项目，组建一支围绕同一目标协作的 AI 团队。项目就像一个独立工作空间，团队成员、Agent、对话、文件和产出都会集中在这里，方便长期推进和管理。

### 步骤一：创建项目 \{#0e45f28f\}

根据你的任务目标创建一个项目，例如“新品发布方案”“合同审查”“AI 视频创作”“网站开发”。每个项目都有独立的对话、文件和资产空间，方便保存背景信息、讨论过程和最终成果。

2. 在左侧导航栏附近单击加号（+）。
3. 单击**新建项目**。

## 常见问题 \{#ae94525a\}

### Q：一个项目里可以添加多个 Agent 吗？ \{#933dfb09\}

A：可以。你可以根据任务需要，把多个 Agent 加入同一个项目，让它们分别负责资料整理、内容创作、代码开发、视频生成、行业分析等不同任务。

### Q：团队成员和 Agent 可以一起协作吗？ \{#ee4a6d3c\}

A：可以。扣子支持人和 Agent 在同一个项目中协作。团队成员可以补充背景、提出需求、评审结果和做关键决策，Agent 则负责执行具体任务。

### Q：我的本地 Agent 能一起协作吗？ \{#1d9a882f\}

A：可以。Claude Code、Codex CLI、OpenClaw 等本地 Agent 可以接入扣子，在同一个入口统一托管和调度，并加入项目参与协作。

### Q：项目里的内容会保存吗？ \{#9034ae25\}

A：会。项目中的对话、文件、素材和产出会持续沉淀，方便你随时查看进度、复用资产，也方便团队成员同步上下文。
