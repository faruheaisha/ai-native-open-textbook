# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

扣子是面向 Agent 时代的新一代 AI 产品。它不仅能陪你聊天、回答问题，更能帮你办公、做视频、写代码、处理文件，真正从“陪你聊”走向“帮你干活”。

全新的扣子内置持续在线的 Coze Agent，支持主流模型自由切换，具备长期记忆、技能调用和工作台能力。它会理解你的目标、记住你的偏好，并在一次次任务中和你建立默契，成为一个开箱即用、越用越懂你的 AI 工作伙伴。

## 1 分钟了解新版扣子 Agent \{#972c96b1\}

你不需要从零调教一个助理，而是上手就有个能理解任务、会调用工具、还能记住你习惯的专业伙伴。它不是只会对话，是真能陪你把事情往前推进。

* **满配的模型能力**：支持 Doubao-Seed、Kimi、GLM、Minimax 等主流模型自由切换，还能使用你自己的模型 API，你可以根据不同任务选择更合适的模型。
* **满配的任务执行力**：具备技能调用、长期记忆能力，可以帮你拆解任务、处理文件、生成内容、推进开发和视频创作。
* **满配的云端工作台**：配备云电脑、云手机、邮箱、日程等工作环境，可以跨越软件和设备限制，持续执行更复杂的任务。
* **满配的专业场景**：内置编程、视频、办公、行业技能等能力，从写代码、做视频到处理专业问题，都能直接上手。
* **满配的个人默契**：它会记住你的工作习惯、表达偏好和项目背景，越用越懂你，越用越像你的专属搭档。

## 积分消耗与常见问题 \{#92d466d2\}

### 扣子是如何消耗积分的？ \{#1531f137\}

与扣子的每次交互（对话、做视频、跑云手机任务）都会消耗相应的平台积分。

* 常规对话：约 10-50 积分
* 云手机跑任务：约 200 积分
* 制作一支视频：约 6000 积分

### 常见问题 （FAQ） \{#c4d643f6\}

**Q：使用云手机登录软件，会被封号吗？**

A：建议为扣子注册专属的 App 账号。如果直接登录私人大号并进行高频自动化操作，可能会触发第三方平台的机器人风控导致封号。

**Q：怎么看扣子还有多少积分？**

A：在扣子页面左下角单击“积分卡片”，即可查看余额及各项任务的消耗明细。

**Q：它真的能记住我之前说的话吗？**

A：当然！扣子会自动提取重要信息。你也可以直接指定：“`重点记住：新品推广的截止日期是3月31日`”。它会妥善保管在专属记忆档案中。
