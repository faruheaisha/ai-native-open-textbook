# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

团队版是扣子平台提供的多人订阅计划，适用于需要成员管理的团队。团队成员可以分别使用成员账号登录扣子，共享团队版积分。本文介绍团队版的套餐选择、定价、订阅变更、席位等信息。

## 了解团队版 \{#3966638e\}

### 套餐概述 \{#haCyqgyWo\}

扣子团队版适合已经有明确 AI 使用场景，并希望通过团队协作方式落地 AI 应用的小团队、业务部门和中小组织。

* 它在个人版的基础上，提供成员、积分和权限的统一管理，支持团队共同创建 Agent、维护知识、开发应用，帮助团队从个人探索升级为可协作、可管理、可持续使用的 AI 生产力套件。
* 相比企业版，团队版在满足基础企业管理需求的同时，提供更简单的购买流程和成员管理方式。

### 套餐、席位和积分的关系 \{#hmTSSaROe\}

购买团队版前，请先了解套餐、席位和订阅积分之间的关系。

| **项目**  | **说明**  |
| --- | --- |
| 套餐  | 团队版包括团队高阶版、团队旗舰版、团队尊享版。套餐档位决定可使用的产品权益、资源配额。  |
| 席位  | 席位数决定企业可添加的成员数量。  |
| 订阅积分  | 每个席位对应一定数量的订阅积分。成员共享团队版积分。  |

### 套餐版本 \{#hK5AQrBlw\}

扣子团队版提供三个档位，适用于不同规模的团队。

| **套餐版本**  | **适用场景**  |
| --- | --- |
| **团队高阶版**  | 适合刚起步的小团队，提供团队协作所需的核心能力。  |
| **团队旗舰版**  | 适合协作频繁、项目较多的成长型团队，提供更大的积分配额、更多协作人数。  |
| **团队尊享版**  | 适合大规模团队或对资源要求较高的企业，成员数量不设上限，积分配额更高，并可优先体验新模型。  |

更多信息，请参考订阅套餐。

## 定价 \{#hFYIj8dud\}

不同套餐档位的席位单价和对应积分各不相同。

| **订阅套餐**  | **套餐席位数**  | **获得积分**  | **单价**  |
| --- | --- | --- | --- |
| 团队高阶版  | 1 ～ 50  | 9.9 万积分/个/月  | 142 元/席位/月  |
| 团队旗舰版  | 1 ～ 100  | 19.9 万积分/个/月  | 283 元/席位/月  |
| 团队尊享版  | 1 ～ 无限增购  | 99.9 万积分/个/月  | 1399 元/席位/月  |

> * 企业超级管理员占用一个席位。

你可以对团队版套餐进行以下操作：**购买、升级、降级、续订**。

因产品类型及服务规则限制，当前团队版暂不支持退款。升级套餐时，符合条件的旧套餐可自动退订，并退还剩余价值费用。更多信息，请参考升级套餐。
:::

### 购买套餐 \{#4339fdf3\}

### 续订套餐 \{#4c9f609b\}

续订是指对当前套餐进行续期，延长其使用时间。团队版套餐支持按原计费方式自动续订，也支持在当前套餐档位不变的情况下，将连续包月变更为连续包年。为避免影响功能正常使用，请在套餐到期前及时续订。

:::tip 说明
续订套餐默认不会延长增购席位的有效期。签约席位自动续费服务后，系统才会在席位到期前自动扣款续费。更多信息，请参考开启席位自动续费。

### 取消自动续订 \{#34f7a8f6\}

如果你购买的是连续包年或连续包月团队版套餐，可以随时取消自动续订。取消后，当前计费周期内仍可正常使用套餐权益，**当前计费周期结束后**取消才会生效。 具体操作，请参考如何取消自动续订？。

## 套餐席位 \{#4840cfa7\}

团队版支持添加企业成员，包括**子用户**和**访客**。两者都可以访问和使用团队版内的扣子资源，共享团队版积分。

### 席位规则 \{#e5e47e6a\}

* **套餐与席位独立**：席位与套餐需分开购买。
* **有效期与价格折算**：未开启席位自动续费服务时，席位有效期以**购买席位时套餐的到期日**为准。席位价格按购买席位时套餐的剩余有效期等比折算，例如包年套餐剩余 8.5 个月，则按 8.5 个月的价格收取席位费用。
* **自动续费：​**开启席位自动续费服务后，系统会在席位到期前 48 小时内，根据当前团队版下的席位数量和套餐剩余有效期自动计算费用并发起扣款续费，并于到期当天停止扣款尝试。如果到期后续费扣款失败，成员账号将不可用。
* **退订**：席位不支持退订。
* **席位不足**：可分配席位不足时，你可以增购席位，或移除不再需要的成员以释放席位。
* **到期失效**：如果席位分批到期后未增购，系统会按成员添加时间倒序依次失效，即最新加入企业的成员最先过期。席位过期后，对应成员账号不可用。 请在到期前及时新购，以确保成员能够正常使用。

### 购买席位 \{#e5e42fb8\}

购买团队版后，你可以按需购买席位。团队规模扩大时，可以随时增购。

1. 在[扣子](https://www.coze.cn/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)或[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)的左下角，单击**积分**卡片。
2. 在**当前套餐**区域，单击**增购席位**。
3. 填写待购买的席位数量，确认席位费用和有效期，然后单击**支付**。
   系统将根据购买的席位，发放对应的订阅积分。每增购一个席位，增加对应积分。
4. 根据页面提示，完成购买。

### 开启席位自动续费 \{#hbTTHcntJ\}

你可以通过以下方式开启席位自动续费服务：

* 已有增购席位：如果你的团队已增购过席位，你可以通过站内信、短信等方式收到开启提醒。
* 首次增购席位：购买团队版后首次增购席位时，可在增购席位页面选择开启席位自动续费。开启后，你可以在**购买记录**中查看席位自动续费记录，席位有效期将跟随当前套餐有效期。
   **目前仅抖音支付支持签约席位自动续费服务。**   

首次增购席位时，操作步骤如下：

1. 在[扣子](https://www.coze.cn/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)或[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)的左下角，单击**积分**卡片。
2. 在**团队管理**区域，单击**增购席位**。
3. 选择席位数量，单击**开启席位自动续费**。
4. 使用抖音 App 扫码，完成支付并开通席位自动续费服务。
   在购买席位时同步开启席位自动续费服务，页面展示的费用为本次席位购买费用，不是续费费用。

### 取消自动续费 \{#hHz6s3yHO\}

开启席位自动续费服务后，你可以随时取消。取消后，当前有效期内席位仍可正常使用；有效期结束后，席位将到期失效。具体操作，请参考如何取消自动续订？。

## 到期与关停 \{#fd356508\}

套餐到期后，状态如下：

* 当前团队版套餐终止。
* 主账号会自动切换到个人版，团队版工作空间及已创建的 Agent 和项目均不可用；成员账号不可用。
* 旧套餐的订阅积分不可用，增购积分和活动积分仍可使用。
* 已有的超额资源（如团队版工作空间）会保留，但不可访问或使用。
