# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

图片去水印功能允许你在复制或导出 AI 生成的图片时，移除“AI 生成”文本水印与“扣子”品牌水印，以满足内容创作、专业演示或商业发布等不同场景。

## 水印类型与移除规则 \{#819dea11\}

扣子生成的图片含两种水印，分别为“AI 生成”文本水印和“扣子”品牌水印。其中，“扣子”品牌水印的移除权益，仅面向订阅用户开放。

## 适用范围 \{#ba7f8722\}

图片去水印功能适用于扣子平台内多个 AI 图片生成的使用场景，包括：

* **写作**：一键配图、AI 生图
* **PPT**：HTML PPT 生图、图片 PPT
* **设计**：各类生图工具
* **视频**：视频封面、视频片段配图

## 使用须知 \{#2834a5c3\}

* 如需在 App 端使用此功能，请确保你的应用已更新至**2.0.0** 或更高版本。
* 免费用户直接下载或导出的内容默认带有“扣子”品牌水印。

## 操作指南 \{#15dbb05c\}

### 移除“AI 生成”文本水印（所有用户） \{#af04f3ec\}

此设置对你后续所有保存、下载或复制的 AI 图片生效。

::::tabs
@tab 桌面端、网页端
在扣子的[通用设置](https://www.coze.cn/settings?tab=general-settings&surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)页面，打开**保存图片时无“AI 生成”水印**开关，在弹窗中阅读并确认相关提示。

:::tip 说明
启用后，应用内预览时仍会显示AI生成水印，但是导出的图片会自动移除AI生成水印。
:::

![Image=382x185](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cff9d1dfc80549fabfee57ff4751d757~tplv-goo7wpa0wc-topic.webp)

@tab 手机端
1. 在扣子 App 的右下角，单击**我的**。
2. 在**我的**页面，单击**通用设置**。
3. 在**通用设置**页面，打开**保存图片时无“AI 生成”水印**开关，在弹窗中阅读并确认相关提示。
   :::tip 说明
   启用后，后续导出的图片均移除AI 生成水印，但应用内预览时仍会显示AI 生成水印。
   :::

### 移除“扣子”品牌水印（免费用户） \{#9d08372b\}

订阅用户导出图片时默认移除品牌水印，无需此操作。

1. 对扣子生成的图片，单击**保存**。
2. 在导出面板中，选择**无品牌水印导出**。
3. 根据指引完成支付，下载的文件将不含品牌水印。
