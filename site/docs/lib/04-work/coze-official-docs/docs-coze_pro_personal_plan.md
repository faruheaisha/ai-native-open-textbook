# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

本文介绍扣子个人版的计费规则，帮你快速了解个人版生命周期管理及各类订阅操作。

## 套餐概述 \{#c5a2216c\}

扣子个人版是面向个人 AI 爱好者、创作者、开发者推出的阶梯式服务套餐，覆盖从免费体验到专业生产的全场景需求，共包含五个档位，档位越高，包含的积分、权益及资源配额越丰富。

**个人免费版**：适合新手用户，**免费**体验扣子。

**个人进阶版**：适合普通创作者，**高性价比**满足日常创作需求。

**个人高阶版**：适合高频使用者，提供更充裕的积分和资源额度。

**个人旗舰版**：适合专业开发者，提供个人版全面的资源配额。

**个人尊享版**：适合专业开发者，提供个人版最高积分额度，享有新模型优先内测资格。

## 生命周期 \{#3e6ea6d8\}

注册扣子后，默认订阅个人免费版，你可以随时升级至个人进阶版、个人高阶版、个人旗舰版或个人尊享版，升级立即生效。你也可以按需进行降级、续订、购买积分等操作。

## **升级套餐** \{#bb7b1070\}

你可以从个人版低档位升级到个人版高档位。

| **说明项**  | **说明**  |
| --- | --- |
| **生效时间**  | 立即生效。  |
| **积分发放**  | 新套餐的订阅积分立即发放。  |
| **到期时间**  | 升级后，根据新套餐购买时间重新计算到期时间。  |
| **费用与差价**  | 升级时，支付新套餐费用。旧套餐的退款逻辑与其支付渠道有关，与新套餐的支付渠道无关，具体说明如下： | \
| | | \
| | * **原套餐是通过支付宝、抖音支付的** | \
| |    * 根据其**剩余价值按比例自动退款**，退款金额= **(剩余订阅积分 / 套餐总订阅积分) × 实付金额**。 | \
| |    * 原套餐的订阅积分按比例退款，购买时赠送的活动积分清零；增购积分和部分活动积分可继续使用。 | \
| | * **原套餐是通过 Apple Pay 支付的** | \
| |    * 所有退款流程均由 **Apple 官方处理**。如有疑问，你可以拨打 400-6668-800 联系 Apple 人工客服。 | \
| |    * Apple 的退款流程和涉及的积分处理由其官方政策决定。扣子无法获取退款细节，也无法预测或影响你的退款申请结果。 | \
| |    * 如果是通过 **Apple Pay** 支付包年、包月套餐，然后在网页端升级套餐，为**避免被重复扣费**，请在升级后及时前往 iOS 取消原有订阅。具体操作，请参考如何取消自动续订？。 | \
| | | \
| | :::notice 注意 | \
| | * 如果原套餐已开发票，那么升级时不会退款，将在新套餐到期后，重新生效。 | \
| | * 通过天猫、抖店等特殊渠道购买的套餐，升级时新套餐将立即生效，原套餐不退款，有效期顺延。 | \
| | ::: | \
| | | \
| |   |

升级步骤如下：

升级套餐时，你可以选择连续包年/包月购买形式。即按年或按月自动续订，可随时取消订阅。根据自动续费协议，系统将于套餐到期前 48 小时内发起续费扣款，并于到期当天停止扣款尝试。如果到期后续费扣款失败，套餐将在到期后降级为免费版。

2. 在**订阅管理**页面，单击**升级套餐**。
3. 在**个人工作**页签下，选择购买周期及目标套餐，单击**购买**。
4. 根据页面提示，支付费用。

@tab 移动端
1. 在扣子 App 的右下角，单击**更多**。
2. 单击**订阅套餐**卡片。
3. 在**个人版**页签下，选择购买周期及目标套餐，单击**确认协议并订阅**。
4. 根据页面提示，支付费用。

## 降级套餐 \{#dabc5167\}

你可以从个人版高档位降级到个人版低档位。

| **说明项**  | **说明**  |
| --- | --- |
| **生效时间**  | 当前计费周期结束，**下个计费周期**新套餐生效。  |
| **积分发放**  | 新套餐的订阅积分立即发放。  |
| **费用与差价**  | 当前计费周期内仍为旧套餐的订阅积分，新套餐生效后系统将发放新套餐的订阅积分。旧套餐内的活动积分和增购积分可继续使用。  |
| **超额资源处理**  | 不支持新增资源（如知识库空间），保留存量的超额资源且不额外收费。  |

降级步骤如下：

::::tabs
@tab 网页、桌面端
1. 在[扣子](https://www.coze.cn/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)或[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)的左下角，单击**积分**卡片。
2. 在**订阅管理**页面，单击**升级套餐**。
3. 在**个人工作**页签下，选择低档位，单击降级。
4. 确认降级。

@tab 移动端
1. 在扣子 App 的右下角，单击**更多**。
2. 单击**订阅套餐**。
3. 选择低档位，单击**降级**。
4. 确认降级。
::::

## 续订套餐 \{#65e21d6c\}

续订是指对当前套餐进行续期，延长其使用时间。个人版套餐支持按原计费方式自动续订，也支持在当前套餐档位不变的情况下，将连续包月变更为连续包年。为避免影响功能正常使用，请在套餐到期前及时续订。

| **续订场景**  | **说明项**  | **说明**  |
| --- | --- | --- |
| * 按当前计费周期续订 | 生效时间  | 当前计费周期结束，**下个计费周期**新套餐生效。  | \
|    * 连续包月 | | | \
|    * 连续包年 | | | \
| * 从连续包年变更为连续包月  | | |
|^^| 续订扣款  | 系统将在当前周期结束前 48 小时内自动扣款续订。  |
|^^| 续订日期  | * Apple Pay 支付（iOS App）：自动续订日期与初始订阅日期保持一致。如果次月无对应日时则为月末结束，后续恢复初始订阅日。 | \
| | | * 支付宝、抖音支付（Android App、网页端）：续订日期按“1个月 + 1 天”计算，如果次月天数不足，续订日将顺延调整。  |
|^^| 积分发放  | 不会增加当前生效月内的积分，新积分将于新生效月首日 0 点发放。  |
| 从连续包月变更为连续包年  | 生效时间  | 立即生效。  |
|^^| 续订扣款  | 系统将在当前周期结束前 48 小时内自动扣款续订。  |
|^^| 积分发放  | 新的订阅积分立即发放。  |
|^^| 到期时间  | 根据续订时间重新计算到期时间。  |
|^^| 费用与差价  | 从连续包月变更为连续包年时，支付新订阅费用。旧订阅的退款逻辑与升级套餐时一致，具体请参考升级套餐。  |

续订步骤如下：

::::tabs

你可以在订阅套餐时，选择连续包年、连续包月模式，开启自动续费功能。

1. 在[扣子](https://www.coze.cn/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)或[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)的左下角，单击**积分**卡片。
2. 在**订阅管理**页面，单击**升级套餐**。
3. 在**个人工作**页签下，开启**按年**或**按月**，然后确认变更。
   系统将于套餐到期前 48 小时内发起续费扣款，并于到期当天停止扣款尝试。如果到期后续费扣款失败，套餐将在到期后降级为免费版。

1. 在扣子 App 的右下角，单击**更多**。
2. 单击**订阅套餐**。

## 取消自动续订 \{#74b2e29f\}

如果你购买的是连续包年或连续包月的个人版套餐，可以随时取消自动续订。取消后，当前计费周期内仍可正常使用套餐权益，**当前计费周期结束后**取消才会生效。 具体操作，请参考如何取消自动续订？。

## 套餐到期 \{#4fa2c947\}

套餐到期后的套餐和资源状态如下：

* 回退到个人免费版。
* 旧套餐的订阅积分不可用，增购积分和活动积分仍可使用。
* 保留存量的超额资源。

## 服务关停 \{#d6a62b96\}

为确保你的 AI 编程项目或低代码项目平稳运行，请关注以下积分规则：

* 个人版不支持超额使用，**积分为 0 后**，系统将停止服务，自动拦截扣子所有可能产生资源消耗的请求，包括但不限于开发 AI 编程项目、智能体调用、API 请求等。
* **积分余额持续 14 天为 0**，系统将执行物理删除。届时记忆库将被自动删除且不可恢复， 记忆库以外的其他资源暂不会被系统自动删除。
