# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

欢迎来到扣子！本文档将指导你如何完成扣子账号的注册和登录。

扣子是字节跳动旗下的 AI 办公协作与 AI 编程平台，包含扣子和扣子编程两款产品，注册完成后的扣子账号可同时用于登录扣子和扣子编程。

## 注册 \{#c8e780cd\}

目前支持通过手机号、抖音账号、飞书账号、火山引擎账号注册扣子。

以手机号注册扣子网页版为例，注册扣子账号的详细操作步骤如下：

1. 访问[扣子](https://www.coze.cn/overview/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)，单击**使用网页版**。
2. 输入手机号码和获取的验证码，阅读并同意页面展示的协议列表，然后单击**登录**。
   ![Image=472x227](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b13eb410bfb240469c93e9d96117144e~tplv-goo7wpa0wc-topic.webp)
3. 设置用户名和昵称，完成注册流程。

## 登录 \{#7d55461f\}

### 登录个人版 \{#b1a433be\}

1. 访问[扣子](https://www.coze.cn/overview/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)，单击**使用网页版**。
2. 在登录页面顶部选择**个人版**。
3. 输入手机号和验证码。
4. 阅读并同意页面展示的用户协议和隐私政策。
5. 单击**登录**。
6. 你也可以在页面底部的**其他登录方式**区域，选择抖音、飞书或火山账号登录。

> 找不到你的扣子账号？参考如何找回扣子账号？

### 登录团队版 \{#69e772ec\}

团队版提供**团队主账号**和**团队员工**两种登录方式。请根据账号来源选择对应入口。

> **如何判断自己是团队主账号还是团队员工账号？**
> 如果你使用手机号和验证码管理或登录团队，选择**团队主账号**。如果账号由团队管理员创建，且你收到了包含登录名和密码的通知邮件，选择**团队员工**。

::::tabs
@tab 团队主账号登录
1. 访问[扣子](https://www.coze.cn/overview/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)，单击**使用网页版**。
2. 在登录页面顶部选择**团队版** > **团队主账号**。
3. 输入手机号和验证码。
4. 阅读并同意页面展示的用户协议和隐私政策。
5. 单击**登录**。

@tab 团队员工登录
团队版员工暂不支持绑定手机号，需要使用创建成员时设置的登录名和密码来登录扣子。

1. 访问[扣子](https://www.coze.cn/overview/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)，单击**使用网页版**。
2. 在登录页面顶部选择**团队版** > **团队员工**。
3. 输入你的**扣子登录名**和**登录密码**。
4. 单击**登录**。

> 忘记了自己的登录凭据？参考团队版员工如何找回扣子登录名和密码
::::

### 登录企业版 \{#hDeMrilTc\}

企业版支持**企业主账号**和**企业员工**登录。

::::tabs
@tab 企业主账号登录
1. 访问[扣子](https://www.coze.cn/overview/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)，单击**使用网页版**。
2. 在登录页面顶部选择**企业版**。
3. 阅读并同意页面展示的协议，然后前往火山引擎登录。
4. 输入火山引擎账号的手机号或邮箱，并按提示完成验证。

@tab 企业员工登录
1. 访问[扣子](https://www.coze.cn/overview/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)，单击**使用网页版**。
2. 在登录页面顶部选择**企业版**。
3. 输入企业 ID（团队别名），然后单击**下一步**。
4. 输入火山企业成员名和密码，然后单击**立即登录**。
5. 完成验证后返回扣子。

> 忘记了自己的登录凭据？参考企业版员工如何找回登录凭据
::::

## 常见问题 \{#bd9cd843\}

### 手机号登录后，为什么看不到以前的多个账号？ \{#f21e4c8c\}

扣子账号体系升级后，一个手机号只能绑定一个扣子账号。如果该手机号此前关联过多个扣子或火山引擎账号，系统会将手机号默认绑定至最近登录的账号，其他账号不会丢失。

如需登录其他扣子账号，请在登录页面底部选择**火山引擎**，使用手机号和验证码登录，然后从账号列表中选择目标账号。

如需换绑手机号，可以在“系统设置 > [账号与安全](https://www.coze.cn/settings?tab=account-settings&surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)”中操作。

### 团队版员工如何找回扣子登录名和密码 \{#fd7cc8dc\}

团队版员工的登录名和密码由企业超管或管理员在创建成员时设置，扣子会将这些信息以邮件形式发送到成员邮箱。如果团队版员工忘记了自己的登录名或密码，可以在邮箱中搜索“扣子团队成员创建通知”，邮件中标明了成员的登录信息。例如：

![Image=205x201](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b82905b7a7ea4d888dbe504896767ee5~tplv-goo7wpa0wc-topic.webp)

> 团队版暂不支持修改登录名或重置密码。

### 企业版员工如何找回登录凭据 \{#37ec5e3c\}

企业版员工如果忘记了自己的登录凭据，可以通过以下方式找回：

* **找回企业 ID**：企业 ID，即团队别名。企业超管或管理员在[火山扣子成员管理](https://console.volcengine.com/coze-pro/user/list)页面右上角扣子登录信息处查看。
* **找回火山企业成员名**：企业超管或管理员在[火山扣子成员管理](https://console.volcengine.com/coze-pro/user/list)页面**成员列表**处查看。
* **找回密码**：企业超管或管理员在[火山扣子成员管理](https://console.volcengine.com/coze-pro/user/list)页面为此成员重置密码。
