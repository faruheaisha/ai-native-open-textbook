# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

当一件事不是一次对话就能完成，而是需要持续跟进、或需要多个 Agent 多人分工处理时，你可以创建项目来推进。

## 什么是项目 \{#ff75890e\}

项目是扣子中围绕特定话题、目标或任务创建的协作场景。在项目中，你可以和 Agent 围绕一个主题持续沟通，也可以邀请人类成员和多个 Agent 加入，一起补充信息、分配任务、确认结果并沉淀产出。更多信息，请参考项目。

项目适合承载需要持续推进的任务，例如：

* 持续打磨一份产品方案、内容规划或分析报告。
* 和 Agent 围绕固定主题长期沟通，保留独立的讨论记录。
* 邀请团队成员一起确认需求、补充信息和检查结果。
* 让多个 Agent 分工处理复杂任务，例如资料整理、内容生成、代码开发、审核发布等。
* 沉淀项目过程中的消息、文件和 Agent 产物，方便后续继续查看和复用。

## 项目成员 \{#5a07e0d3\}

项目中可以包含两类成员：

* **人类成员**：人类成员可以参与讨论、补充信息、确认方向和检查结果，也可以通过 @Agent 向指定 Agent 下达任务。
* **Agent**：Agent 可以根据成员的指令处理具体任务，例如整理资料、生成方案、编写代码、分析问题等。项目成员可以根据任务需要添加不同能力的 Agent。

## 协作流程 \{#cae2aca5\}

你可以按照以下流程开始使用项目协作：

1. **创建项目**：为一个明确的话题、目标或任务创建项目，并选择要对话的 Agent。
2. **邀请成员或 Agent 加入协作**：根据需要邀请人类成员加入项目，也可以添加自己的 Agent 参与协作。
3. **补充项目背景**：在项目中发送消息、上传文件或补充已有资料，让成员和 Agent 了解任务目标和背景。
4. **@ 成员或 Agent 推进任务**：通过 @ 人类成员提醒对方查看、补充或确认，通过 @Agent 让指定 Agent 处理任务。
5. **持续讨论和沉淀结果**：基于 Agent 的产出继续讨论、修改和确认。项目中的消息、文件和产物会保留下来，方便后续继续推进。

## 协作场景 \{#e6af5b4d\}

项目可以承载不同类型的协作任务。你可以根据任务复杂度、参与成员和 Agent 能力，选择合适的协作方式。

* **围绕一个主题持续推进**：适合需要长期跟进、反复讨论或持续积累资料的任务。例如持续打磨产品方案、跟进用户问题、维护某个主题的资料库等。项目会保留独立的讨论记录和上下文，方便后续继续推进。
* **多人共同确认需求和结果**：适合需要多个人类成员参与判断的任务。例如产品、设计、研发、运营等成员一起补充信息、确认方向、检查 Agent 输出结果，再决定下一步如何推进。
* **多个 Agent 分工处理复杂任务**：适合包含多个专业环节的任务。例如撰写公众号文章时，可以由选题 Agent 确定选题，写作 Agent 生成正文，审核 Agent 检查风险内容，发布 Agent 提交草稿或发布内容。
* **成员和 Agent 接力推进任务**：适合需要持续产出、确认和调整的任务。例如项目负责人先明确目标和分工，Agent 维护计划并在关键节点提醒成员跟进；成员补充进展后，Agent 再整理风险和阶段性结论。

更多场景和示例可参考在项目中协作。

## 费用说明 \{#d072b073\}

* 项目和多人协作功能不收取功能使用费。
* 项目成员和 Agent 对话时，收取对话任务费用，由 Agent 的创建者承担。详细费用说明可参考套餐与定价。
