# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

使用扣子时，会产生一定的费用，通过积分方式抵扣。购买套餐可获得积分与专属权益。

## 扣子如何收费 \{#fb120a4d\}

使用以下扣子功能，会消耗一定的积分。

* [扣子任务](https://docs.coze.cn/coze_pro/coze_task_fee)：与 Agent 的每一次互动，都会占用平台算力、消耗模型 Tokens 等资源，从而消耗你账号中的积分。任务越复杂、占用资源越多，消耗的积分就越多。比如：
   * 与 Agent 聊天，例如提问、咨询、让 Agent 分析或总结内容。
   * 让 Agent 制作多媒体内容，例如生成图片、制作 PPT、生成视频等。
   * 在飞书、微信等其他应用中与扣子 Agent 交互，向 Agent 下达任务指令。
   * 让 Agent 操作云手机，例如打开应用、查询信息等。
* [云手机](https://docs.coze.cn/coze_pro/cloud_device_fee)[、](https://docs.coze.cn/coze_pro/cloud_device_fee)[云电脑](https://docs.coze.cn/coze_pro/cloud_device_fee)：在扣子中创建了云手机、云电脑后，将根据设备规格和在线时长，消耗你账户中的积分。
* [编程任务](https://docs.coze.cn/coze_pro/task_fee)：创建编程项目后，与编程 Agent 对话开发网页应用、移动应用或小程序，消耗你账户中的积分。
* [内置集成](https://docs.coze.cn/coze_pro/internal_integrations_fee)：开发编程项目时，使用了编程 Agent 已经打包好的各种 AI 功能和服务（数据库、模型等），消耗你账户中的积分。
* 云盘**：​**扣子为每个用户配备一个云盘，你可以把常用文件集中放在这里，让项目或 Agent 直接使用同一批资料。
* 旁听：开启旁听后，Agent 会通过手机麦克风记录并实时转写会议内容，在会议结束后自动生成会议纪要、结论和待办。
* **邮箱**：功能使用限时免费。后续正式计费的时间计划与产品定价请关注平台公告。

## 套餐与权益 \{#7557c887\}

为满足不同用户使用需求，扣子推出的订阅制服务，就像手机通讯套餐一样，每个月为你提供固定的功能权益与积分额度。扣子订阅套餐包括个人版、团队版和企业版。

* **个人使用**：根据日常使用频率、功能需求，选择一款合适的个人版套餐即可。
* **团队协作**：如果需要多个成员分别登录扣子、共享团队版资源，并由团队统一管理席位和成员用量，建议选择团队版。
* **企业管理**：如果需要更完整的企业级安全、权限、合规和售后能力，建议选择企业版。
