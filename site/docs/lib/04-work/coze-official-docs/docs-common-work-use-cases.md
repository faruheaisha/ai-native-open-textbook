# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

在日常工作中，很多任务看起来分散，其实都离不开几类高频需求：整理信息、生成内容、推进协作和沉淀成果。扣子适合从这些真实、具体的工作场景切入，帮助团队把原本需要反复整理、来回沟通、多人接力完成的任务，变得更高效、更清晰。

本章将结合企业中常见的办公场景，介绍扣子如何参与你的实际工作。

## 写总结：周报、复盘、汇报材料 \{#ho1RoF3g0\}
