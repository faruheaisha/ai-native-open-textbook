# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

为了方便你在扣子中统一管理和维护各个形态的 AI 资产，扣子支持将你在扣子编程中已创建的 AI 编程项目，导入到扣子中，便于后续继续开发、调试、部署和管理。

## 功能介绍 \{#fe8ac503\}

[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)是一个 AI 驱动的应用开发平台，打造了兼容多种开发范式的开发者生态，可帮助你构建并交付生产级别的全栈 AI 应用。你只需清晰描述需求，扣子编程即可辅助生成网页应用等产品，并支持持续迭代和优化。

通过导入功能，你可以将你在**扣子编程**中创建的 AI 编程项目完整导入到[扣子](https://www.coze.cn/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)中，导入内容包括项目代码、应用配置、页面与组件等项目资产。当前支持导入网页应用、移动应用和小程序。导入后，你可以在扣子中继续进行开发、调试、部署和管理。

如果你已有本地项目或 GitHub 项目，想要导入扣子，可先将项目导入扣子编程，再通过当前入口同步导入至扣子继续开发。具体操作，请参考导入项目。

:::notice 注意
* 在扣子中删除导入项目后，扣子编程中的对应项目将同步被删除，无法恢复，请谨慎操作。
* 在团队版和企业版中，企业超级管理员可以通过**功能访问控制**和**空间资源可见性**，控制成员可见的功能入口和空间资源范围。如果你未看到预期的功能和资源，请联系企业超级管理员确认。更多信息，请参考功能访问控制和空间资源访问控制。
:::

## 导入项目 \{#b935cf2c\}

::::tabs
@tab 网页端、桌面端
1. 在扣子左侧导航栏中，单击 + >**新建编程项目。**
2. 选择项目所属的工作空间。
   ![Image=316x174](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f2203c4f500d49e3bdec4b2e11a5d91d~tplv-goo7wpa0wc-topic.webp)
3. 在页面中，单击**从已有编程项目导入**。
4. 选择你已创建的编程项目，单击**导入**。
   支持导入同一组织下的项目。

@tab 移动端
1. 在扣子 App 顶部，单击 + >**新建编程项目**。
   ![Image=156x304](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/78232dffab244babb29a26c9d6f823eb~tplv-goo7wpa0wc-topic.webp)
2. 扣子 App 底部，选择项目所属的工作空间，然后单击**确认**。
   ![Image=153x302](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b26b341c38db453c908eec41d1d0c9d8~tplv-goo7wpa0wc-topic.webp)
3. 在页面中，单击**从已有编程项目导入**。
   ![Image=182x355](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/549782c2e9bc49cf9874b909ee3b58f1~tplv-goo7wpa0wc-topic.webp)
4. 选择你已创建的编程项目，单击**导入**。
   支持导入同一组织下的项目。
::::
