# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

企业版是扣子平台提供的多成员订阅计划，专为希望整个团队使用扣子平台的组织而设计，允许多个成员独立访问和使用扣子平台。每个用户都将拥有自己的扣子平台账号。本文介绍扣子企业版的套餐、席位、积分、订阅规则等信息。

:::notice 注意
为持续提升企业级服务能力，并支持扣子 3.0 中新增的多 Agent 协作、模型自定义、项目空间、专业技能、多端协同等企业权益，相关服务投入和运维成本也将随之增加。基于此，我们将对企业版套餐的价格和权益进行调整，新的价格将于 **2026 年 7 月 14 日 00:00** 起生效。更多信息，请参考[企业版套餐定价调整公告](https://docs.coze.cn/guides/enterprise_plan_pricing_adjustment)。
:::

## 概览 \{#hFOm0pHnQ\}

### 企业版和其他版本的区别 \{#hrl0dmcig\}

你可以从适用对象、结算方式等方面，快速了解企业版与个人版、团队版的区别。

| **对比维度**  | **企业版**  | **个人版、团队版**  |
| --- | --- | --- |
| **适用对象**  | 适合对协作规模、数据安全、服务支持有较高要求的团队或企业。 | **个人版：​**个人创作者、个人开发者以及面向社交媒体平台的用户 | \
| | | | \
| | 企业旗舰版支持`SSO` 单点登录、`VPC` 私网连接、`KMS` 密钥等企业级安全能力。  | **团队版：​**适配无需 SSO、企业安全等企业级能力的小型团队  |
| **结算方式**  | 依托火山引擎平台完成交易与结算。当积分余额不足时，系统按 `1000:1`（积分:现金）比例自动从你的火山引擎现金账户扣款。 | 通过扣子平台完成交易与结算，不支持超额使用。  | \
| | | | \
| | 现金余额不足时，火山引擎账号转为**欠费状态**。  | |

### 套餐、席位和积分的关系 \{#db224d6e\}

购买企业版前，请先了解套餐、席位和订阅积分之间的关系。

| **项目**  | **说明**  |
| --- | --- |
| 套餐  | 企业版包括企业标准版和企业旗舰版。套餐档位决定企业可使用的产品权益和资源配额。  |
| 席位  | 席位数决定企业可添加的成员数量。企业标准版至少购买 5 个席位，企业旗舰版至少购买 30 个席位。  |
| 订阅积分  | 每增加一个席位，企业对应增购 6.9 万订阅积分。企业成员共享企业版积分。  |

企业版购买、变更、续费和退订的关系如下：

* 购买、续费、退订时，套餐、席位和订阅积分作为整体处理，具有相同有效期。
* 变更时，可单独变更套餐档位或席位数，也可同时变更。

### 套餐版本 \{#hHI5tSvfm\}

你可以根据企业规模、安全要求和业务复杂度选择合适的套餐。

| **套餐版本**  | **适用场景**  |
| --- | --- |
| 企业标准版  | 适合中小型企业团队，提供协作开发环境和核心功能支持。  |
| 企业旗舰版  | 提供更高资源配额，以及 SSO、VPC、KMS 等安全能力，适合复杂业务的大规模应用。  |

更多信息，请参考订阅套餐。

## 定价 \{#hqCu9NUqM\}

企业版总费用由套餐费用、席位费用和订阅积分费用组成。

| **分类**  | **单价**  |
| --- | --- |
| 套餐费用  | * 企业标准版：490 元/月 | \
| | * 企业旗舰版：6,040 元/月  |
| 企业席位费用  | 29 元/席位/月  |
| 订阅积分费用  | 69 元/席位/月  |

> * 本文价格为刊例价，实际订购价格可能因优惠活动而有所不同，请以订购界面为准。
> * 企业标准版最低费用： 490 + 5 ×（29 + 69）= 980 元/月。
> * 企业旗舰版最低费用：6,040 + 30 ×（29 + 69）= 8,980 元/月。

## 订阅规则 \{#hXoyr7QRr\}

你在注册火山引擎账号并完成实名认证后，可以购买企业版。购买后，你也可以按需续费、变更套餐和席位，或退订企业版。

![Image=574x369](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5154ca57356d44a9bf09cb8bad5b2cf1~tplv-goo7wpa0wc-topic.webp)

### 购买套餐 \{#0d5d750c\}

购买企业版时，请重点关注以下计费规则：

* 购买资格
   * 每个火山引擎账号仅限购买一个企业版。
   * 火山引擎主账号或具备扣子服务购买权限（如 CozeFullAccess 权限）的 IAM 用户，可购买企业版。
   * 完成火山引擎实名认证。具体操作，请参考[实名认证](https://www.volcengine.com/docs/6261/64935)。
* 版本限制
   * 已购买**个人版**：可直接购买企业版，个人版剩余价值费用不退，两者可切换使用。
   * 已购买**团队版**：团队版生效期间，不支持购买企业版。

### 升级套餐 \{#ef00b890\}

当你需要更高档位权益时，可以升级套餐，即从企业标准版升级为企业旗舰版。

| **升级场景**  | **升级差价计算**  | **档位权益**  | **席位和积分**  | **有效期**  |
| --- | --- | --- | --- | --- |
| 标准版升级为旗舰版  | 按剩余时长补齐差价。 | 立即升级为新档位权益。  | 不变  | 与升级前一致。  | \
| | | | | | \
| | 补差费用：（旗舰版价格➖标准版价格）✖️ 剩余时长  | | | |

> * 如果需要增加席位，请参考增加席位。
> * 如果同时升级套餐并增加席位，则套餐升级规则和增加席位规则分别适用。

### 降级套餐 \{#7abd24a0\}

当前套餐配置超出实际需求时，可以进行降级，即从企业旗舰版降级为企业标准版。

:::notice 注意
企业版不支持降级到个人版、团队版。
:::

| **降级场景**  | **差价计算**  | **生效时间**  | **说明**  | **有效期**  |
| --- | --- | --- | --- | --- |
| 旗舰版降级为标准版  | 按剩余时长退回套餐档位差价。 | 实时生效  | 席位数和积分不变。 | 与降级前一致。  | \
| | | | | | \
| | 退回费用：（旗舰版档位价格➖标准版档位价格）✖️ 剩余时长  | | 超额资源（如连接本地 Agent、组织、工作空间等）不会被回收。  | |

> * 如果需要减少席位，请参考减少席位。
> * 如果同时降级套餐并减少席位，则套餐降级规则和减少席位规则分别适用。

### 续费套餐 \{#hmCHLpCIW\}

企业版即将到期时，可以通过续费延长使用时长。

* 续费不会增加当前生效月内的积分，**新积分将在新生效月首日 0 点发放。**
* 套餐续费时，会同步续费席位、订阅积分的有效期。

### 退订套餐 \{#hEdE8M8xT\}

企业版退订规则说明如下表所示。**退订套餐时，会同步退订席位和订阅积分**。

| **退款类型**  | **无理由全额退款**  | **部分退款**  |
| --- | --- | --- |
| **退订条件**  | 同时满足以下两个条件 | 不满足 7 天未使用无理由退款条件。  | \
| | | | \
| | * 购买 7 天内且未使用。 | | \
| | * 每个账号每自然年内享受一次。 | | \
| |    扣子增购积分、企业版套餐、增购项等服务总计仅可使用一次。  | |
| **费用计算**  | 全额退款。  | * 套餐档位费用：按剩余天数比例退款。 | \
| | | * 席位、积分费用：仅退还**剩余未生效月份**的费用。当前生效月内的费用不予退还，退订后积分无法使用。  |

示例如下：

在 2026 年 1 月 20 日购买了为期 2 个月的企业版，当天使用后申请了退订，那么退还费用说明如下：

* 套餐档位费用：仅收取 2026 年 1 月 20 日的档位费用，退还剩余所有天数费用。
* 席位、积分费用：退还第二个生效月（2026 年 2 月 21 日～2026 年 3 月 20 日）的成员和积分费用，第 1 个月已生效不予退还。

## 席位规则 \{#hUaCjmUtv\}

席位数决定企业可添加的成员数量。企业成员包括子用户和访客，两类成员都会占用企业席位，并可使用企业资源、共享企业积分。关于成员的操作，请参考[创建成员](https://docs.coze.cn/guides_create_member)。

### 初始席位 \{#hjD8xei9s\}

首次购买企业版套餐时，需满足对应套餐的席位起订要求：企业标准版至少 5 个席位，企业旗舰版至少 30 个席位。购买后如需添加更多成员，可通过增加席位完成。

### 增加席位 \{#hRnHVfDzP\}

当企业需要添加更多成员时，可以增加席位。新增席位立即生效，新增席位对应的积分按剩余时长发放。

| **场景**  | **增购费用**  | **生效时间**  | **当月权益**  |
| --- | --- | --- | --- |
| 增加席位数  | 增购费用= 席位费用 + 订阅积分费用  | 立即增加  | * 变更当月（非自然月）：原订阅积分➕新增的席位数✖️单个成员的订阅积分✖️剩余自然天数/当前月实际天数 | \
| | | | * 剩余生效月（非自然月）：席位总数✖️单个成员的订阅积分  |

费用明细如下：

| 费用项  | 说明  |
| --- | --- |
| 席位费用  | 席位费用 = 新配置费用 - 原配置剩余价值，即变更后席位数 ✖️ 席位每小时单价 ✖️ 剩余时长（小时） - 原席位数 ✖️ 席位每小时单价 ✖️ 剩余时长（小时） | \
| | | \
| | * 席位每小时单价= 席位月单价 / 30 / 24 | \
| | * 剩余时长（小时）=（席位到期时间（秒） - 提交订单时间（秒）+ 1 秒）/ 3600  |
| 订阅积分费用  | 订阅积分费用 =变更当月费用 + 剩余生效月费用 | \
| | | \
| | * 变更当月（非自然月）：新增席位数 × 订阅积分单价 × 剩余自然天数 / 当前生效月实际天数 | \
| | * 剩余生效月（非自然月）：新增席位数 × 订阅积分单价 × 剩余生效月数 | \
| | | \
| | > 剩余自然天数包括变更当天。  |

### 减少席位 \{#hLvmL03fv\}

当企业席位数超出实际需求时，可以减少席位。

:::tip 说明
减少席位数后，成员按照添加时间倒序依次失效，即最后加入企业的成员最先过期。
:::

| **场景**  | **费用计算**  | **生效时间**  | **当月权益**  |
| --- | --- | --- | --- |
| 减少席位数  | 退回剩余生效月的订阅积分费用。 | 下一个生效月生效  | 变更当月仍享受原套餐权益、席位数和积分。  | \
| | | | | \
| | 退回费用：减少的席位数✖️（席位单价+订阅积分单价）✖️剩余生效月数  | | |

### 如何操作 \{#hLfF5ow7U\}

如需增加或减少席位数，请参考如下步骤。

1. 在[火山引擎扣子控制台](https://console.volcengine.com/coze-pro/overview)概览页面，单击目标企业版中的**变更套餐**。
2. 设置席位数。
   例如当前有 40 个席位，设置**变更后总成员数**为 42 个，那么表示新增 2 个席位。
3. 勾选协议，单击**确认订单**，根据页面提示完成购买与支付。
   ![Image=376x238](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3bd306e023de4fcda229c4c205c63595~tplv-goo7wpa0wc-topic.webp)   

## 退订、到期与欠费影响 \{#1930014a\}

如果出现企业版到期未续费、被退订或账号欠费的情况，对应的套餐权益都将受到影响。账号欠费后企业版不可用，且存在关停风险。更多信息，请参考欠费与关停。

| **影响维度**  | **说明**  |
| --- | --- |
| **权益回退**  | * 企业版到期 | \
| |    * 到期 12 小时内：可继续使用功能。 | \
| |    * 到期超过 12 小时：服务关停。 | \
| |    * 到期 15 天内：可续费使用。 | \
