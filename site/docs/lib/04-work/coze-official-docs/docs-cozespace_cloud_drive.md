# 扣子 Coze 官方文档

> ## Documentation Index
> Fetch the complete documentation index at: https://docs.coze.cn/llms.txt
> Use this file to discover all available pages before exploring further.

扣子为每个用户配备一个云盘，你可以把常用文件集中放在这里，让项目或 Agent 直接使用同一批资料。开启本地同步后，你还可以在电脑上继续处理这些文件。

:::tip 说明
新版云盘上线后，原「文件」中的内容将统一纳入云盘容量管理。已有文件的用户可享受过渡期，期间仍可按原容量规则正常使用。**过渡期将于 2026 年 9 月 13 日结束，相关容量限制预计自 9 月 14 日起陆续生效。**

过渡期结束后，云盘容量将按照你当前的套餐权益执行。如果已用容量超出套餐上限，已有文件不会被删除，你仍可查看、下载和清理文件，但暂时无法上传或同步新内容。清理存储空间或升级套餐，使已用容量低于套餐上限后，即可恢复正常使用。
:::

## 什么是云盘 \{#hg5j27LTW\}

扣子云盘是你、项目和 Agent 共用的文件空间。你上传的素材、项目里的资料、Agent 生成的内容，都会保存在这里。你可以随时查找、整理，也可以继续让项目或 Agent 基于这些文件工作。

你可以这样理解云盘：

* **作为你的线上文件库**：你可以像使用普通网盘一样，新建文件夹、上传文件、预览文件、重命名、删除、搜索和下载文件。例如根据项目、客户、时间或主题，把运营复盘、客户方案、课程资料、市场调研等分别存放在不同的文件夹下，方便后续查找和复用
* **作为项目、Agent 的工作目录**：创建项目或 Agent 时，你可以指定一个云盘文件夹作为工作目录。之后，项目或 Agent 会在这里读取资料、保存产物。
* **同步到电脑本地使用**：使用扣子桌面端时，你可以把云盘文件同步到电脑本地。这样你在电脑上修改文件后，内容会自动同步回云盘。

## 云盘能帮你做什么 \{#hpY8l1IzQ\}

云盘的核心价值，是让文件、项目和 Agent 围绕同一个工作空间持续协作。

* **搭建专属资料库，让 Agent 越用越懂你的业务**
   你可以在云盘中创建“公司资料库”、“客户资料库”等文件夹，集中保存产品资料、合同模板、客户档案和历史方案。将这些文件夹设为 Agent 的工作目录后，Agent 就可以长期基于这批资料生成报价、合同、方案等内容。
* **出门在外用手机派活，回到电脑接着处理**
   在手机上上传文件并让 Agent 处理，例如校验表格、整理合同要点或生成文档初稿。Agent 产出的文件会保存在云盘中，回到电脑后通过本地同步继续用 Excel、Word 等工具加工。
* **做 PPT 等商务文件时，Agent 出初稿，你负责精修**
   Agent 可以基于工作目录中的资料生成 PPT、预算表、投标文档或合同初稿。你再用 PowerPoint、Excel、Word 等本地软件调整排版和细节，保存后同步回云盘，后续还可以让 Agent 基于最新版继续补充内容或校对数据。
* **多台电脑之间无缝接力**
   如果你在公司和家里各有一台电脑，可以在多台电脑上开启本地同步。同一批云盘文件会同步到各设备中，下班前没改完的文档，回家后可以继续编辑，保存后自动保持一致。
* **团队协作时，一个项目共用一套文件**
   团队项目可以使用同一个云盘工作目录。成员上传的资料、Agent 生成的方案和项目产物都会保存在这里，大家看到的是同一批文件，项目结束后也可以继续沉淀为后续项目的资料。

## 使用须知 \{#hbgFv5AqE\}

* 使用云盘前，请先了解云盘内容管理、数据处理与保护等相关说明。更多信息，请参考云盘使用须知。
* 使用云盘过程中，请注意以下限制：
   * 仅桌面端支持开启本地同步，网页端和移动端均不支持。
   * 暂不支持上传或同步单个超过 500 MB 的文件。
   * 创建项目或 Agent 后，不支持变更工作目录。 若已绑定的云盘工作目录被删除，系统会为其生成新的默认工作目录。

## 项目、 Agent 的工作目录 \{#hYzE7PMpQ\}

每个项目或 Agent 都需要一个工作目录，用来存放资料、文件和生成产物。项目的工作目录可以选择**云盘文件夹**或**本地目录**；Agent 的工作目录只能选择**云盘文件夹**。默认情况下，推荐使用云盘文件夹。

选择云盘文件夹作为工作目录时，你可以选择已有的云盘文件夹，也可以新建一个。如果不手动选择，系统会自动生成一个工作目录。后续，项目或 Agent 会围绕这个目录工作：读取你上传的资料，并把生成的文档、表格、报告、图片等文件保存到这里。

使用工作目录前，你需要了解这些规则：

* 每个项目或 Agent 只能选择一个工作目录。
* 云盘中任意层级的文件夹都可以作为工作目录。
* 多个项目或 Agent 可以共用同一个工作目录。
* 删除项目或 Agent 后，工作目录中的文件仍会保留在云盘中，你可以继续使用或按需删除。
* 在项目中，所有成员都可以查看和使用项目工作目录中的文件。
   上传或生成的文件，会保存在项目工作目录中，并占用项目所有者的云盘容量。
* 在项目中，文件默认保存至项目的工作目录。若需要保存至 Agent 工作目录，Agent 所有者可以在提示词中明确指定目标位置。仅支持向自己的 Agent 工作目录写入文件，不能向别人的 Agent 工作目录写入文件。

例如你是运营人员，有两个 Agent：「运营助手」负责生成活动方案、执行清单和宣传文案，「复盘助手」负责生成季度复盘报告。让两个 Agent 共用一个「运营工作台」文件夹作为工作目录后，活动前，运营助手基于目录中的资料生成全套活动物料；活动结束后，复盘助手直接读取同一目录下的方案与数据，生成复盘报告。全程无需在两个 Agent 之间搬运文件。更多信息，请参考场景一：多个 Agent 共用一个工作目录，完成活动策划和复盘。

## 桌面端本地同步 \{#hndcQFapb\}

本地同步是桌面端提供的云盘与电脑本地文件双向同步能力。开启后，系统会将你选择的云盘文件夹同步到电脑本地，同步位置固定为 `~/Coze/Drive`，不支持修改。

* 你在云盘中新增、修改、重命名或删除文件，变更会同步到本地。
* 你在本地 `~/Coze/Drive` 中进行的文件增删改操作，也会同步回云盘。

同步后，你可以像使用普通本地文件夹一样使用云盘文件：

* 用 Word、Excel 等本地软件打开、编辑文件。
* 在本地新增、修改、重命名或删除文件。
* 让本地 Agent 能够处理云盘文件。
* 同一账号可在多台电脑开启同步，但一台电脑同一时间只能绑定一个账号

例如：你先让 Agent 基于资料生成一份 PPT 初稿，再在电脑上用 PowerPoint 调整内容和排版。保存后，最新文件会自动同步回云盘，后续 Agent 也可以继续基于这个版本工作。本地编辑与 Agent 协作无缝衔接，无需反复下载、上传。更多信息，请参考场景二：本地与云端协同处理文件。

### 释放云盘空间 \{#hDEHLhEAM\}

你可以删除不再需要的文件来释放云盘空间。删除后的文件会先进入垃圾箱。只有清空垃圾箱，对应空间才会真正释放。

* 垃圾箱中的文件默认保留 30 天，到期后自动彻底清理。在这 30 天内，误删的文件可以随时从垃圾箱中恢复。
* 垃圾箱中的文件在彻底清理前，仍会占用云盘空间。
* 如果删除项目或 Agent 的工作目录，原工作目录及其中的文件将移至垃圾箱；系统会自动创建并绑定一个与该项目或 Agent 同名的空工作目录。

释放云盘空间的操作步骤如下：

1. 在[云盘](https://www.coze.cn/cloud-drive?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)页面，找到待删除的目标文件夹或文件，单击··· > **删除**。
   你也可以在左侧的文件夹列表中，右键单击文件夹，删除整个文件夹。
   ![Image=432x153](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cf34c6ac3c1f4bcdaa4c4bbd8bf612d5~tplv-goo7wpa0wc-topic.webp)
2. 在**垃圾箱**页面，找到待删除的文件夹或文件，单击**删除**。
   ![Image=432x193](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/56f25ee1e8784096a303ec6683c015aa~tplv-goo7wpa0wc-topic.webp)
