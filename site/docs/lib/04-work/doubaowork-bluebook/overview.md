# 初始豆包工作

**豆包工作**是一款面向真实工作任务的 AI 助手。

它面向HR、教育、金融、财务、营销、法律、科研、研发等不同职场角色，能够理解目标、规划步骤、调用工具并交付可继续编辑的工作成果。

## 它和普通聊天有什么差别

聊天工具擅长给答案。豆包工作还会读取你授权的资料、拆步骤、调用技能和连接器，并生成能继续编辑的文件。能不能交差，最后仍要你验收。

例如，用户可以直接告诉豆包工作，分析指定文件夹中的销售数据，并生成一份汇报 PPT。

第一次用这类工作 Agent，最容易犯的错就是一上来问“你能做什么”。回答通常很长，关掉以后还是不会用。

豆包工作更适合从一个小交付开始：给材料、说结果、定边界，然后看它怎么把事做完。

左边找入口，中间看过程和结果，底部写任务、加材料、控权限。

豆包工作会读取用户提供或授权访问的资料，理解数据内容，完成分析和总结，并生成可以查看和继续修改的工作成果。

任务开始后，用户可以让它自主推进，也可以在关键步骤选择按需确认，随时检查过程和结果。
