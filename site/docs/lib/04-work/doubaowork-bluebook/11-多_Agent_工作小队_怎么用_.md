# 多 Agent（工作小队）怎么用？

一个任务需要调研、分析、写稿和复核时，多 Agent 确实能省时间（也就是工作小队）。

前提是每个角色都知道自己要干什么、交付什么、交给谁。

以「爆款内容创作小队」为例，打开它，点击「对话」

可以看到，小队成员有四位，分别是创意总监（队长），爆款营销策划师，爆款内容创作专家，AI画师。

队长的职责主要是创意设计，以及团队分工，还有最后的总结交付。

在对话框中表达清楚需求：

"我在小区开了家猫舍，养了十几只猫咪，想拍抖音但完全不知道拍啥，帮我想想第一个月怎么拍。"

然后豆包工作就会主动安排合适的多个专家Agent来跟进任务

需要注意的是，如果你点到了其他界面，想要找回刚刚发布的任务，需要在伙伴对话->任务里面去找

而不是在最近的普通工作任务中找。

最终，几个专家联手协作，完成了本次任务～
