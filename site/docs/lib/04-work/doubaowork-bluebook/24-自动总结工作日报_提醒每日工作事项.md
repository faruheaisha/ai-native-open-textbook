# 自动总结工作日报，提醒每日工作事项

一天忙下来，最后那几行日报常常最难写。会开了几场，群里回了不少消息，文档也改了几版，真到下班前回想，却很难一句句说清今天到底推进了什么。

明天要跟进的事也散在各处。有的藏在聊天记录里，有的只在会上顺口提过，还有的已经过了截止时间。

让豆包工作先把这些记录收拢起来，日报和提醒就有了可靠的起点。

日报和周报可以共用同一套处理过程。先从群消息、任务和日历里收集当天发生的事，再区分成果、决定、待办和风险，最后把需要继续推进的事项转成提醒。这样写报告依靠的是当天留下的记录，不用等到最后凭记忆补齐。

## 汇总群消息

群消息里同时存在讨论、通知、表情回复和临时闲聊。汇总时更有用的做法，是提取已经确认的结论、明确交付、待回答问题和阻塞事项，并保留必要的上下文。

```Plain Text
请帮我汇总今天 “xxx群”的内容，生成日报
```

**执行过程**系统会读取指定工作群在当天时间范围内的消息，过滤重复通知和闲聊，再提取已经确认的结论、行动项、待回答问题和风险。

## 代办任务提醒

提醒要帮助第二天决定先做什么，不能只把待办再念一遍。可以结合截止时间、依赖关系、对他人的影响和预计工作量排序。提醒可以留在豆包工作里，也可以写入飞书日历。

```Plain Text
将今日代办内容生成提醒，明天早上 9 点提醒我要先做哪些事情
```

**豆包工作内的提醒**

**写入飞书日历** 需要在固定时间开始，或需要预留一段完整时间的工作，也可以生成日历提醒。创

日报负责说明今天发生了什么，提醒负责接住明天的动作。两边使用同一份待办状态，任务才不会在不同工具里反复出现。

一套稳定的日常流程可以很简单。

早上看优先级，白天在群里和任务里留下记录，晚上汇总成果与风险，再把未完成事项带到下一天。报告因此成为工作的结果，提醒也能接住后续动作。
