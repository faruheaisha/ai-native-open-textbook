# 千问办公官方帮助中心（阿里云）

概览显示企业初始化指引、当前套餐、剩余席位、剩余积分和近 30 天使用情况。

## 查看企业情况
1. 登录管理后台，点击左侧【概览】。

2. 在「当前套餐」查看组织名称、订阅状态和到期时间，点击【查看订阅】进入订阅管理。

3. 查看剩余席位和已授权人数，点击【管理席位】进入用户管理。

4. 查看近 30 天的积分消耗趋势。在「积分消耗排行」切换「总消耗」或「人均消耗」，比较部门用量。

![](https://docs.qwenwork.cn/zh/images/qwenwork-flagship-b0f2b353cdb068e2.png)

*上方提供初始化指引和订阅信息，下方显示积分趋势、部门排行与席位数据。*

## 使用初始化指引
「完成企业初始化」提供四个入口：配置登录方式、设置额度分配规则、邀请或导入用户、配置管理员。点击其中一项进入对应配置页面。
