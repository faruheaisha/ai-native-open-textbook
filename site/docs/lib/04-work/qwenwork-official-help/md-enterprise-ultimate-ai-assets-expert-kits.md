# 千问办公官方帮助中心（阿里云）

专家套件把特定工作的能力与配置组合在一起，适合向一个团队交付成套的工作方式。管理员负责市场来源、资源审核和成员开放范围。

## 配置套件市场
1. 进入 AI 管理 → AI 资产管理 → 专家套件，打开「市场管理」。
2. 按企业需要开启官方市场与企业市场。
3. 企业市场点击【配置】，选择「专属市场」或「私有市场」。专属市场在后台维护套件；私有市场填写企业已有市场的名称、完整地址和允许来源。
4. 保存后检查客户端能否打开对应市场。私有市场中的内容由企业自有系统提供，后台列表和上架审批需要使用专属市场模式。

![](https://docs.qwenwork.cn/zh/images/qwenwork-flagship-5bcb934703db8d41.png)

*独立设置套件市场、成员上传能力和申请上架的规则。*

## 上传与整理企业套件
1. 在已启用的专属市场中切换到「列表」，通过【分类管理】准备业务分类。
2. 使用【从官方市场添加】选择现成套件，或点击【上传专家套件】，选择符合套件格式的 ZIP 包。
3. 选择分类，点击【上传并启用】，在列表核对名称、唯一标识、版本与状态。
4. 点击【查看】检查套件内容，确认包含的资源和说明适合目标成员使用。

![](https://docs.qwenwork.cn/zh/images/qwenwork-flagship-cff8777aa21c963f.png)

*对照套件名称、标识和版本检查上传对象，避免发布错误文件。*

## 审批成员提交的套件
在「市场管理」分别配置「允许上传专家套件」及「允许上架专家套件到专属市场」。成员提交上架申请后，在「上架审批」查看内容；通过时选择分类，拒绝时填写具体修改意见。

审核套件时应检查所引用服务或资源能否被目标成员使用。套件上架不会自动授予外部业务系统的访问权限。

## 发布给指定团队
1. 打开「开放策略组」，点击【新增专家套件策略组】。
2. 选择白名单或黑名单，设置成员范围、套件范围和目标端。
3. 希望成员打开客户端后自动安装时，在白名单策略中选择指定资源后开启「自动安装」。「全部资源」不能与自动安装同时开启，黑名单不支持自动安装。
4. 保存并启用，使用【命中验证】分别检查团队内和团队外成员。
5. 请目标成员在客户端打开套件并完成一次代表性任务，确认套件依赖的资源也可用。

黑名单优先；默认开放策略始终启用，可以编辑允许的资源范围。停用套件前确认正在使用的团队，删除后检查策略中的资源引用是否已移除。
