# 千问办公官方帮助中心（阿里云）

管理员角色决定谁能进入后台，以及能查看或修改哪些功能。先明确要委派的工作，再授予对应权限；普通用户的席位和模型可用范围在其他功能中管理。

## 新建一个管理员角色
1. 进入 组织与安全 → 组织管理 → 管理员角色，点击【新增管理员角色】。
2. 填写角色名称和说明，例如「用户运维」「负责成员与席位维护」。
3. 在角色用户区域点击【添加用户】，搜索并选择企业中已有的成员。
4. 切换到「管理权限」，按菜单勾选需要开放的功能。选中一个页面，即可访问并使用该页面的全部能力；未选中时，侧栏、搜索和直接链接均不能访问。
5. 确认角色状态并保存。回到列表检查角色、用户和启用状态。

![](https://docs.qwenwork.cn/zh/images/qwenwork-flagship-84d6d774bba6b624.png)

*在角色中维护管理员名单与权限；停用角色前检查负责工作的接任人。*

![](https://docs.qwenwork.cn/zh/images/qwenwork-flagship-b674029e95463e4f.png)

*勾选对应页面会开放该页面全部能力，请按实际工作范围选择。*

## 检查权限是否合适
请角色中的成员重新进入管理后台，确认所需菜单可以打开，且能完成被委派的操作。再检查一个不应开放的页面，确认菜单、搜索和直接链接均不能访问。当前管理员角色按页面授权，不能把同一页面拆为只读与可编辑权限。开放平台应用的 API 权限另行配置，不与这里的菜单权限混用。

成员拥有多个角色时，应一起检查这些角色，避免在一个角色中移除权限后，另一个角色仍保留相同权限。

## 调整或撤销管理员权限
点击目标角色进入编辑，修改用户或权限后保存。暂停整类管理员工作可以停用角色；不再使用时按删除提示处理。撤销后台权限不会自动删除该成员的普通用户账号或回收席位。

## 转交超级管理员
超级管理员负责全企业管理。转交前，确认接任人正确且能够登录。

1. 在超级管理员入口选择【转交】，搜索接任用户。
2. 输入「确认转交」，点击【认证并转交】。
3. 完成身份认证后，点击【完成转交】。
4. 由接任人重新进入后台，确认可以访问。

创建普通自定义角色不能代替超级管理员转交。
