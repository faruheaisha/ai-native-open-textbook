# 千问办公官方帮助中心（阿里云）

出现配置变更、登录异常或任务失败时，先记下用户、时间和相关对象，再进入对应日志查询。不同日志记录的事件不同，不能用一个页面代替全部排查。

管理员日志最多查询最近 180 天，用户日志和 AI 日志最多查询最近 90 天。列表、详情及导出使用相同查询窗口；查询窗口不代表历史数据会被删除。
