# 千问办公官方帮助中心（阿里云）

IM（即时通信）频道控制企业成员可以使用哪些消息渠道。

## 开启或关闭渠道
1. 进入 组织与安全 → 安全管控 → IM 频道。
2. 找到需要设置的渠道：钉钉、飞书、微信、企业微信或 Lark。
3. 点击该渠道的开关。提交期间开关不可重复操作；保存失败时保留原状态，可以重试。
4. 回到列表，查看「可用／不可用」、启用开关和更新时间。五个频道直接完整展示，不需要分页。

![](https://docs.qwenwork.cn/zh/images/qwenwork-flagship-517455e6d7399714.png)

*每个渠道独立设置；飞书和 Lark 是两个选项。*
