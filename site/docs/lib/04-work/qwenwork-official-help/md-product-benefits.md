# 千问办公官方帮助中心（阿里云）

<br />

![产品界面](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5908475871/p1092449.bin)

千问办公提供企业版和个人版两类产品方案，分别满足组织协作与个人办公需求。用户可以了解不同版本的功能权益、使用额度及适用场景，并完成对应版本套餐的购买、续费、取消订阅等操作。套餐发生升级或降级时，将按照对应规则处理生效时间、权益变化、订阅状态及相关费用。

目前桌面端暂不支持企业版链路的订阅，敬请期待。
