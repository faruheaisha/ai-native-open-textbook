# 千问办公官方帮助中心（阿里云）

订单记录通过外部的「费用与成本」查看。

在管理后台依次点击 数据与运营 → 订阅与用量 → 订单记录，浏览器会在**新标签页** 打开[费用与成本](https://usercenter2.aliyun.com/)，当前管理后台页面保持不变。  
**说明**

订单查询在费用与成本中完成，管理后台不展示订单列表或订单详情。
