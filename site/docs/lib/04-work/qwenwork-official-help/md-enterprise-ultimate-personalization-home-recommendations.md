# 千问办公官方帮助中心（阿里云）

首页推荐为成员提供可直接开始的任务提示词。您可以分别维护卡片上显示的短句与点击后填入输入框的完整提示词。

## 编辑一条推荐
1. 进入 用户与体验 → 个性化配置 → 首页推荐。
2. 选择「展示」，再通过分类、状态或搜索找到要修改的推荐。
3. 点击该行【编辑】，填写分类、展示 Prompt 和实际输入 Prompt。Prompt 即提示词；展示文字应便于识别，实际输入文字应交代任务和所需材料。
4. 点击编辑窗口中的【保存】，检查列表中的内容与启用状态。

例如，展示文字可以是"整理本周会议待办"，实际输入文字可以是"根据我上传的会议记录，按负责人整理待办、截止时间和待确认事项"。不要在实际输入中写入只适用于某一位成员的内部资料。

![](https://docs.qwenwork.cn/zh/images/qwenwork-flagship-c1a03b0d5a482a36.png)

*上方设置分类，中间维护展示文字，下方填写完整任务提示词。*

## 批量导入或移除推荐
1. 点击【下载模板】，使用当前模板填写分类与提示词，不要自行改动列名。
2. 点击【导入 Excel】，选择文件，在导入窗口检查解析结果；有错误时先修正文件。
3. 确认导入后，在列表中查看新增的推荐文字和启用状态。
4. 不再使用的推荐可以关闭单条开关；需要移除时点击【删除】，或勾选后使用批量操作。

首页整体是否展示推荐单独保存：选择「展示」或「不展示」，确认后点击【保存并发布】。编辑单条推荐、调整单条开关和导入不需要再执行这一步。

## 检查成员看到的结果
打开客户端首页，确认推荐分类、卡片文字和点击后带入的内容。特别检查长句是否被截断、实际提示词是否仍包含待填写的材料提示，以及停用条目是否停止展示。
