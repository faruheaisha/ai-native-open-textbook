# 千问办公官方帮助中心（阿里云）

当成员用尽本周期个人积分限额时，可以显示企业自定义说明，告诉成员联系谁或去哪里申请调整。先准备有效的处理入口，再设置提示文字。

## 设置提示内容
1. 进入 用户与体验 → 个性化配置 → 积分不足提示，开启自定义提示。
2. 填写标题和说明。标题最多 30 个字符，说明最多 120 个字符。
3. 需要跳转入口时，开启「操作按钮」，填写按钮名称与完整 HTTPS 跳转链接。按钮名称最多 20 个字符。
4. 按需要维护简体中文或英文文案，点击【保存配置】，核对最近保存时间。

*按钮应指向成员有权访问的处理入口，关闭按钮时保留文字说明。*

## 核对触发条件与处理办法
这项提示对应个人周期限额不足。需要调整额度时，到[限额管理](https://docs.qwenwork.cn/enterprise-ultimate/subscription/quota)检查用户命中的策略组；还要核对组织是否有可用额度。改提示文案不会增加个人或组织积分。

保存后检查链接，并使用符合触发条件的测试成员确认显示内容。普通成员无法打开的管理后台页面不适合作为申请入口。
