# 千问办公官方帮助中心（阿里云）

管理后台提供费用与成本的访问入口。

在管理后台依次点击 数据与运营 → 订阅与用量 → 发票与合同，浏览器会在**新标签页** 打开[费用与成本](https://usercenter2.aliyun.com/)，当前管理后台页面保持不变。
