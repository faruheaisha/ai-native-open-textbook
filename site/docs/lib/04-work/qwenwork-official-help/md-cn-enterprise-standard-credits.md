# 千问办公官方帮助中心（阿里云）

## 1. 使用范围与权限
积分管理用于查看组织实际积分、订阅计划和资源包，并为组织、团队或成员设置使用上限。左侧菜单只对超级管理员和团队管理员显示。

## 2. 组织积分概览
<table> <thead> <tr> <td><p><b>指标</b></p></td> <td><p><b>说明</b></p></td> </tr> </thead> <colgroup></colgroup> <colgroup></colgroup> <tbody> <tr> <td><p>积分</p></td> <td><p>组织实际可使用的积分总量，由所有获得坐席的成员共同使用。</p></td> </tr> <tr> <td><p>冻结积分</p></td> <td><p>当前暂时不可用的积分。</p></td> </tr> <tr> <td><p>有效资源包</p></td> <td><p>仍在有效期内的积分资源包数量。</p></td> </tr> </tbody> </table>  
**说明**

积分余额是实际可用资源；限额是允许使用的上限。提高限额不会增加积分余额。

## 3. 当前计划、历史计划与资源包
### 3.1 当前计划

* 查看计划名称和状态。

* 查看每周期限额、月付/季付/年付周期、总周期数和有效日期。

* "暂无有效订阅计划"表示当前没有生效中的企业计划。

### 3.2 历史计划

* 查看生效中、待生效、已排期、已过期、已取消或已终止的计划。

* 查看每周期限额、生效/到期日期及内部备注。

### 3.3 资源包明细

* 按全部、有效或失效状态筛选。

* 查看来源、初始容量、当前余额、冻结积分、生效日期和到期日期。

* 结合组织实际使用情况判断余额消耗与到期风险。

## 4. 组织、团队和成员限额

**警告**

如果新组织限额低于现有成员限额，系统会阻止操作或提示可能仅更新部分成员。建议先降低成员限额，再降低组织限额。

## 5. 编辑组织限额
1. **打开"成员限额"**：超级管理员切换到该页签。

2. **点击"编辑限额"**：在组织限额卡片中打开设置窗口。

3. **填写新限额**：输入不低于 2,000 的整数。

4. **确认并检查**：保存后检查"已用 / 限额"和使用率是否更新。

## 6. 设置单个成员限额
1. **找到成员**：按名称或联系方式搜索，也可用标签筛选。

2. **判断使用情况**：查看已用积分、成员限额和使用率；点击表头可排序。

3. **点击编辑**：在操作列编辑成员限额。已移除成员不能编辑。

4. **输入并保存**：输入不低于 2,000 的整数，且不得超过组织限额或团队限额。

## 7. 批量设置成员限额
1. **进入批量模式**：点击"批量选择"。

2. **选择成员**：逐个勾选或全选当前筛选范围。

3. **点击"批量设置限额"**：系统会预览实际更新人数，已离开当前范围的成员会被跳过。

4. **填写统一限额**：输入不低于 2,000 的整数，且不能超过页面显示的上级限额。

5. **确认设置**：完成后查看成功提示，确认更新人数和跳过人数。

**说明**

如果先搜索或筛选再选择"全选所有成员"，批量操作只针对当时的筛选范围。操作前请核对预览人数。

## 9. 与坐席的关系
设置成员限额并不代表成员可以立即使用组织积分。成员还必须在"成员管理"中获得坐席。建议按以下顺序开通：

1. **确认成员已加入组织**：成员出现在成员列表中。

2. **分配坐席**：在成员编辑窗口点击"分配坐席"。

3. **设置成员限额**：回到积分管理，设置适合的使用上限。

4. **观察使用率**：定期按使用率排序并及时调整。

## 11. 管理建议
* 新成员按"加入组织 → 分配坐席 → 设置限额"的顺序开通。

* 按月查看资源包到期日和冻结积分，避免可用余额突然下降。

* 定期按使用率从高到低排序，提前处理接近上限的成员。

* 批量修改前先筛选和预览，避免误改大范围成员。
