# 千问办公官方帮助中心（阿里云）

本文面向第一次进入千问办公的用户，介绍如何从登录、创建任务开始，通过多轮对话推进工作，查阅与管理结果，并按需使用我的网盘、扩展、电脑操控和网页发布等平台能力。

完成本章后，你将能够独立完成一次完整任务：  
**说明**

登录并进入工作空间 → 创建任务并补充资料 → 持续沟通和修改 → 检查结果 → 保存、复用或发布成果。

## 1. 进入千问办公
### 1.1 使用入口

千问办公网页端提供两个使用入口：

**网页端** ：在浏览器打开 [qwenwork.cn/app](https://qwenwork.cn/app)，使用钉钉扫码或中国大陆手机号登录。

![千问办公网页端入口](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7582209871/p1096676.png)

**钉钉内**：通过钉钉底部导航栏进入千问办公。

![钉钉内千问办公入口](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7582209871/p1096677.png)

### 1.2 注册与登录

### 钉钉扫码登录

首次使用时需要绑定一次手机号。系统会优先读取钉钉关联的手机号并自动发送验证码；如果无法获取，也可以手动输入手机号。完成绑定后，再次扫码即可直接登录，无需重复验证。

### 手机号登录

使用中国大陆手机号接收验证码并完成登录。

### 1.3 进入正确的空间

登录后，系统会根据账号所属组织自动处理：

* 没有企业身份：进入个人空间。

* 只属于一个企业：直接进入该企业空间。

* 属于多个企业：先显示空间选择页，由你选择本次要进入的空间。

**说明**

企业空间中可见的资源和可用能力，可能受企业订阅及成员权限影响。

## 2. 创建第一个任务
千问办公以"任务对话"为主要工作方式。一个任务可以包含多轮交流、附件、执行过程和最终产物。

![千问办公网页端新任务](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7582209871/p1096676.png)

### 2.1 新建任务

1. **新建任务**

   点击左侧栏的「新建任务」。
2. **描述需求**

   在输入框中描述要完成的工作。
3. **添加参考资料**

   如有参考资料，添加本地文件或从我的网盘选择文件。
4. **发送**

   检查要求后发送消息，等待千问办公回复或执行。

**说明**

一个独立目标对应一个任务。同一份报告的补充资料、调整结构和修改版式，应继续在原任务中进行；开始无关的新目标时，再新建任务。

### 2.2 写清任务要求

一条清楚的任务指令通常包含四项信息：
<table> <thead> <tr> <td><p><b>要素</b></p></td> <td><p><b>说明</b></p></td> <td><p><b>示例</b></p></td> </tr> </thead> <colgroup></colgroup> <colgroup></colgroup> <colgroup></colgroup> <tbody> <tr> <td><p>目标</p></td> <td><p>最终想得到什么</p></td> <td><p>写一份 Q2 项目状态报告</p></td> </tr> <tr> <td><p>输入</p></td> <td><p>需要参考哪些资料</p></td> <td><p>参考附件中的会议纪要和数据表</p></td> </tr> <tr> <td><p>要求</p></td> <td><p>结构、语气、范围或限制</p></td> <td><p>包含进展、阻碍和下一步，面向管理层</p></td> </tr> <tr> <td><p>交付</p></td> <td><p>希望得到什么形式的结果</p></td> <td><p>输出为 Word，并附一页摘要</p></td> </tr> </tbody> </table>

例如：  
**说明**

请参考我附上的销售数据表，分析今年各月营收趋势，指出三个主要变化和可能原因，并生成一份适合周会汇报的 PPT。图表要标注数值，最后增加下一步建议。

如果暂时无法一次说清全部要求，也可以先描述目标，再根据千问办公的提问逐步补充。

### 2.3 添加文件

* **添加本地文件**：通过输入框的添加入口上传。

* **添加网盘文件** ：点击「**+** 」→「**从我的网盘选择** 」，勾选文件后点击「**添加所选**」。

* 每条消息最多添加 20 个网盘文件，每个文件最大 500 MB；超过数量限制时，可先打包为 ZIP。

## 3. 选择输入方式与模型
### 3.1 选择模型

<table> <thead> <tr> <td><p><b>模型</b></p></td> <td><p><b>适用任务</b></p></td> <td><p><b>常见示例</b></p></td> </tr> </thead> <colgroup></colgroup> <colgroup></colgroup> <colgroup></colgroup> <tbody> <tr> <td><p>基础</p></td> <td><p>日常、规则明确、追求效率的任务</p></td> <td><p>格式转换、基础润色、翻译、模板邮件、简单查询</p></td> </tr> <tr> <td><p>高级</p></td> <td><p>复杂分析、多步骤流程、长文或高质量创作</p></td> <td><p>研究报告、趋势推理、竞品分析、复杂工作流</p></td> </tr> </tbody> </table>

在输入框旁打开模型下拉菜单即可切换。切换后，新模型会用于当前任务的后续对话，已有上下文不会丢失。

你也可以在同一个任务中分阶段切换，例如：先用标准模型收集和整理信息，再切换旗舰模型完成深度分析，最后切回标准模型处理格式。

## 4. 管理和推进任务
### 4.1 在原任务中持续修改

千问办公给出初稿后，不必重新描述全部背景。直接说明要保留和修改的部分即可，例如"保留前三页结构，把趋势图改成柱状图，并在每个柱子上显示数值"。

### 4.2 管理任务上下文

* 与当前成果有关的补充和修改，留在同一任务中进行。

* 新主题单独创建任务，方便后续查找，也能减少背景混淆。

* 涉及日期、数字、品牌规范或不可更改内容时，在最终确认前再次核对。

* 对于执行时间较长的任务，关注对话中的状态与步骤说明；如果执行失败，补充信息后让千问办公修正并重试。

## 5. 查阅和确认结果
### 5.1 先预览，再验收

结果生成后，建议从以下四方面检查：

* **内容**：是否完成原始目标，结构是否完整。

* **格式**：文件类型、页面比例、表格和图表是否符合要求。

* **事实**：数字、日期、人名、来源和结论是否准确。

* **可用性**：文件能否打开、编辑和下载，是否适合直接发送或发布。

## 6. 使用我的网盘管理成果
我的网盘是千问办公内置的云端文件空间。你上传的资料、需要长期保存的文件，以及千问办公生成的成果，都可以在这里管理。

![千问办公个人网盘](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7582209871/p1096678.png)

### 6.1 查找任务产物

千问办公生成的文件会自动进入 Agent 工作区，并按任务或会话存放。进入左侧「我的网盘」，即可预览、编辑、下载、重命名或删除文件。Word、Excel 和 PowerPoint 文件可以在线编辑，修改后会自动保存回我的网盘。

### 6.2 常用操作

文件名和文件夹名不能包含 `/` 或 `\`，同一目录下不能存在同名文件。空文件不能上传。

### 6.3 存储额度

<table> <thead> <tr> <td><p><b>套餐</b></p></td> <td><p><b>我的网盘空间</b></p></td> </tr> </thead> <colgroup></colgroup> <colgroup></colgroup> <tbody> <tr> <td><p>免费</p></td> <td><p>1 GB</p></td> </tr> <tr> <td><p>个人标准版</p></td> <td><p>10 GB</p></td> </tr> <tr> <td><p>个人高级版</p></td> <td><p>20 GB</p></td> </tr> </tbody> </table>

我的网盘不消耗积分，只受套餐存储空间限制。空间用尽后无法继续上传，但已有文件不受影响。  
**警告**

我的网盘没有回收站，也不自动备份。删除文件夹会永久删除其中的全部内容。删除重要成果前，请先下载留底。

### 7.1 查找和安装资源

1. **进入扩展**

   在专家套件、技能和连接器之间切换。
2. **查找资源**

   使用分类或关键词查找资源。
3. **确认能力**

   打开详情页，确认能力和使用要求。
4. **安装或使用**

   点击「安装」或「使用」。
5. **完成配置**

   如果页面提示，完成连接器配置或外部账号授权。

### 7.2 在任务中使用资源

* 在主聊天框的「添加资源」列表中手动选择资源，然后描述任务。

* 直接描述需求，由千问办公在合适时使用已经安装的资源。

* 对于带预设输入的技能，可按照页面提示补充信息并发起任务。

**说明**

安装资源不代表每次对话都会自动启用。需要时可以手动选择，或在指令中明确说明希望使用哪个资源。更新专家套件时，创作者发布的最新版本会覆盖你的个人修改，更新前请先确认并保存仍需保留的内容。

## 8. 使用网页发布成果
QwenWork Pages 是内置的网站托管服务。你可以在任务对话中创建并发布静态网页或动态网页，无需自行准备服务器、域名或 CDN，并可在「我的网页」中查看和管理已发布的网页。

![千问办公我的网页](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7582209871/p1096679.png)

### 8.1 发布一个网页

1. **描述需求**

   在任务中描述需求，例如"帮我做一个个人简历页"。
2. **预览**

   千问办公准备网页内容并在对话中提供预览。
3. **发布**

   确认无误后点击「发布」。系统会分配形如 `xxx.qwenwork.host` 的默认域名并完成部署。
4. **查看与管理**

   发布完成后，对话中会显示发布卡片和访问链接，之后可在左侧「我的网页」入口查看和管理。

**说明**

「我的网页」入口用于管理已有网页，不能直接新建网页。新网页需要在任务对话中由千问办公创建。

### 8.2 选择网页类型

<table> <thead> <tr> <td><p><b>类型</b></p></td> <td><p><b>适合场景</b></p></td> <td><p><b>说明</b></p></td> </tr> </thead> <colgroup></colgroup> <colgroup></colgroup> <colgroup></colgroup> <tbody> <tr> <td><p>静态网页</p></td> <td><p>个人主页、作品集、营销页、文档站、单页应用</p></td> <td><p>纯前端展示，打开更稳定</p></td> </tr> <tr> <td><p>动态网页</p></td> <td><p>表单、保存数据、调用其他服务</p></td> <td><p>当前后端为 Node.js；数据库能力以产品页面实际开放状态为准</p></td> </tr> </tbody> </table>

网页类型在创建后不能更换。如需从静态改为动态，或反向更改，需要新建网页。

### 8.3 版本与管理

* 每次修改并重新发布，都会生成一个新版本。

* 如果新版本不满意，可在网页卡片菜单中选择「切换版本」，回到历史版本。

* 可在网页卡片中查看状态、打开链接、重命名、设置访问密码、查看用量或删除网页。

* 已发布版本不能原地修改，即使只改一处文案，也会生成新版本。

**警告**

删除网页不可恢复。如果网页关联数据库，删除网页会同时清空数据库中的数据。删除前应先请千问办公协助导出需要保留的数据。

### 完整示例：从销售数据到周会汇报

* **准备资料**：将销售数据表上传到我的网盘，或在新任务中直接添加。

* **创建任务**：提出目标，例如"分析各月营收趋势，制作周会 PPT，并列出三项建议"。

* **选择模型**：使用旗舰模型完成趋势推理和多步骤制作。

* **补充要求**：说明汇报对象、页数、品牌颜色和图表偏好。

* **检查初稿**：核对月份、数值、结论和图表标签。

* **追加修改**：在原任务中要求精简文字、调整图表或补充风险。

* **查阅产物**：在对话中预览，并到「我的网盘 → Agent 工作区」打开文件。

* **完成交付**：在线编辑或下载最终文件；以后需要复用时，从我的网盘重新添加。

## 常见问题
### 安装资源后，为什么任务中没有自动使用？

安装只表示资源已经加入可用列表。请在输入框的「添加资源」中手动选择，或明确说明"请使用某某技能/连接器完成"。

### 连接器安装后仍然不能使用怎么办？

检查是否仍需填写参数、完成外部账号授权，或取得相应组织权限。完成后确认连接器处于可用状态。

### 网盘上传卡住或提示空间不足怎么办？

先查看网盘顶部的存储用量。上传过程中断网或关闭千问办公时，未完成的文件需要重新上传；空间接近上限时，可以删除不需要的文件或升级套餐。

### 网页访问出现 503 或 403 是什么原因？

503：通常表示网页仍在部署，或动态网页正在冷启动，可稍后重试。

403：常见于访问量或流量达到套餐上限、降级后网页数量超额，或自定义域名权益暂停。

### 怎样减少返工？

先说明目标、受众、输入和交付形式。复杂任务可先让千问办公提供提纲或样例，确认方向后再生成完整成果。最终交付前，再核对关键数字、权限和不可撤销操作。
