# 千问办公官方帮助中心（阿里云）

## 文档说明
### 读者对象

## 一、进入管理后台
### 1.1 前提条件

* 已拥有千问办公账号，并已加入一个企业组织；

* 在该组织中拥有**超级管理员** 或**管理员**角色。

### 1.2 操作步骤

1. 打开浏览器，访问 [千问办公网页版](https://qwenwork.cn/app/)；

2. 使用您的账号登录；

3. 点击页面左下角的头像/设置区域，展开账号菜单；

4. 在菜单中点击【进入企业管理后台】。

**说明**

系统会在新标签页打开管理后台（qwenwork.cn/admin），默认进入「成员管理」页面。
![0A996DD6-B5F2-4137-BF6E-C6D2D2F535ED_副本.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1284146871/p1094259.png)

*在账号菜单中点击「进入企业管理后台」进入后台*  
**说明**

管理后台左下角提供【返回千问办公】入口，可随时切回工作台。普通成员（无管理角色）不会看到该入口。

成员管理用于查看和管理组织内的所有成员，包括成员邀请、坐席分配、入组申请审批与成员信息维护。

点击左侧导航「团队」分组下的【成员管理】进入。具体页面如下：

### 2.2 邀请成员

点击页面右上角的【邀请成员】按钮，可选择两种邀请方式：
![邀请成员方式选择](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1284146871/p1094261.png)

*两种邀请方式*
<table> <colgroup></colgroup> <colgroup></colgroup> <colgroup></colgroup> <thead> <tr> <td><p><b>方式</b></p></td> <td><p><b>审批要求</b></p></td> <td><p><b>适用场景</b></p></td> </tr> </thead> <tbody> <tr> <td><p><b>链接批量邀请</b></p></td> <td><p>需要审批</p></td> <td><p>批量邀请多人加入组织</p></td> </tr> <tr> <td><p><b>邮箱单人邀请</b></p></td> <td><p>无需审批</p></td> <td><p>快速邀请单个成员</p></td> </tr> </tbody> </table>

#### 方式一：链接批量邀请

1. 在「邀请成员」弹窗中选择【链接批量邀请】卡片下的「选择此方式」；

2. 在「创建邀请链接」弹窗中填写：

* **可邀请人数**：该链接最多可接受的加入人数（弹窗顶部显示「当前可用余量」，即组织剩余可邀请名额）；

* **名称**（选填）：为链接命名以便识别，例如「7月新员工入职」；

1. 点击【创建链接】；

2. 点击【复制】，再点击【完成】，即可将链接发送给目标成员。

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1284146871/p1094262.png) ![复制邀请链接](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1284146871/p1094263.png)

*创建邀请链接*  
**说明**

成员通过链接提交加入申请后，会出现在「待审批申请」页签，管理员审批通过后方可加入组织。  
**警告**

邀请链接有**总名额** 与**过期时间**限制，超过任一限制后链接失效。链接在失效前可随时停用（见 2.5 节）。

**邀请链接列表字段说明：**

#### 方式二：邮箱单人邀请

1. 在「邀请成员」弹窗中选择【邮箱单人邀请】卡片下的「选择此方式」；

2. 按向导完成三步操作：

* **步骤 1 · 填写信息**：填写成员邮箱（必填）、姓、名（选填），点击【下一步】；

* **步骤 2 · 设置权限** ：为成员选择角色------**超级管理员** （拥有组织所有管理权限）、**管理员** （可管理团队成员和配置）或**成员**（普通团队成员，使用基础功能），并可设置其加入的团队，点击【下一步】；

* **步骤 3 · 确认邀请**：核对邀请信息后，点击【发送邀请】。

*邮箱单人邀请向导*  
**说明**

系统向目标邮箱发送邀请邮件，成员点击邮件中的链接填写信息后即可加入组织，**无需审批**。邮箱邀请适合快速邀请少量成员；批量邀请请使用链接方式。

### 2.3 处理坐席申请

「坐席申请」页签展示成员提交的坐席分配申请，列表字段包括：成员、所属团队、申请时间、备注、操作。
![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1284146871/p1094267.png)

*坐席申请列表*

对每条申请，您可以：

* 点击【分配坐席】：立即为该成员分配坐席；

* 点击【拒绝】：驳回本次申请。

**说明**

通过后将立即为成员分配坐席；若当前没有可用坐席，会提示"暂无可分配的企业坐席"，申请会继续保持待处理状态。若当前可用坐席充足，成员状态将由「未分配坐席」变为「已分配坐席」，即可正常使用组织积分。

### 2.4 审批入组申请

「待审批申请」页签展示通过邀请链接提交的加入申请，列表字段包括：申请人、手机号、目标团队、邀请链接、备注、操作。
![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1284146871/p1094268.png)

*待审批申请列表*

页面顶部的审核提醒会提示申请人的验证状态。请核对申请人信息后再操作：

* 点击【通过】：申请人加入组织（**默认未分配坐席**，需另行分配）；

* 点击【拒绝】：驳回本次申请。

**警告**

审批通过仅代表成员加入组织，不等于分配坐席。成员加入后如需使用组织积分，请在「坐席申请」页签或成员编辑页签中为其分配坐席。

### 2.5 管理邀请与链接

「待接受邀请」页签展示已通过邮箱发出、但尚未被接受的邀请。列表字段包括：邀请对象、席位、角色、邀请时间、备注、操作。
![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1284146871/p1094269.png)

*待接受邀请列表*  
**说明**

若成员长时间未接受邀请，可在「操作」列选择撤销邀请或重新发送邀请。

### 2.6 管理已有成员

在「成员」页签的成员列表中，您可以：

**查看成员信息**：列表展示用户（姓名与联系方式）、角色（超级管理员/管理员/成员）、状态（已分配坐席/未分配坐席）、存储用量、标签与备注。页面上方提供搜索框（按成员名称或联系方式搜索）与【批量选择】按钮。

**编辑成员**：点击成员行右侧的编辑图标，打开「编辑成员」弹窗，可以：

## 三、积分管理
积分管理用于查看组织的积分余额、订阅计划与资源包使用情况，并设置组织与成员的积分限额。点击左侧导航「团队」分组下的【积分管理】进入。

### 3.1 组织积分

页面默认展示「组织积分」页签，顶部的「积分概览」呈现三项核心指标：
![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1284146871/p1094271.png)

*组织积分概览*
<table> <colgroup></colgroup> <colgroup></colgroup> <thead> <tr> <td><p><b>指标</b></p></td> <td><p><b>说明</b></p></td> </tr> </thead> <tbody> <tr> <td><p><b>积分</b></p></td> <td><p>企业钱包当前可用积分余额</p></td> </tr> <tr> <td><p><b>冻结积分</b></p></td> <td><p>当前被冻结、暂不可用的积分数量</p></td> </tr> <tr> <td><p><b>有效资源包</b></p></td> <td><p>当前处于有效期内的资源包数量</p></td> </tr> </tbody> </table>

概览下方提供三个子页签：**当前计划** 、**历史计划** 、**资源包明细**。默认展示当前计划。

**当前计划**：以卡片形式展示当前生效的订阅计划，包括计划名称（如「企业标准版」）、生效状态与周期区间、每周期限额、周期类型（如月付）、总周期数与备注。

**历史计划**：以表格展示过往订阅计划记录，字段包括名称、周期类型、每周期限额、状态、生效日期、到期日期与备注。

*历史计划列表*

**资源包明细**：以表格展示各资源包的详细情况，支持按状态筛选（全部 / 生效中 / 已过期），字段包括：来源、初始容量、余额、冻结、生效日期、到期日期。
![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1284146871/p1094273.png)

*资源包明细表*  
**说明**

资源包按来源区分，常见类型包括**订阅套餐积分** （随订阅计划发放）、**套餐升级积分** （升级订阅时发放）与**积分包**（单独增购）。不同资源包的有效期不同，过期后余额失效，建议优先关注临近到期的资源包。

### 3.2 成员限额

切换到「成员限额」页签，可查看和控制积分的使用限额。
![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1284146871/p1094274.png)

*成员限额管理*

**组织限额**：页面顶部卡片展示组织总限额及已使用量（含使用率），点击【编辑限额】可修改。在「设置组织限额」弹窗中填写新限额后点击【确认】生效。  
**警告**

组织限额最低为 **2,000 积分**，不可设置低于该值的限额。

**成员限额列表**：展示每位成员的成员、状态、已用积分、成员限额、使用率、标签与备注，支持按成员名称或联系方式搜索，以及批量选择。

**设置单个成员的限额**：组织限额与成员限额分开管理。如需调整某位成员的限额，请点击该成员行右侧的【✏️】按钮，在「设置成员限额」弹窗中填写新限额后点击【确认】。  
**警告**

成员限额最低为 **2,000 积分**，且不能超过当前组织限额。  
**说明**

通过「组织限额 + 成员限额」的两级控制，可以灵活分配积分资源，避免个别成员超额消耗。

## 五、常见场景速查
以下为高频管理场景的端到端操作路径，方便快速上手：

**场景一：新员工批量入职**

创建邀请链接（成员管理 → 邀请成员 → 链接批量邀请）→ 分享链接 → 在「待审批申请」页签审批【通过】→ 在「坐席申请」页签或成员编辑弹窗中为新成员【分配坐席】→（可选）在积分管理中设置成员限额。

**场景二：快速邀请单个成员**

成员管理 → 邀请成员 → 邮箱单人邀请 → 填写邮箱 → 设置角色与团队 → 发送邀请 → 成员通过邮件直接加入 → 为其分配坐席。

**场景三：成员离职处理**

成员管理 → 成员页签 → 点击该成员行的编辑图标 → 在「危险区域」点击【移除此成员】→ 确认操作。移除后该成员失去对团队资源的访问权限。

**场景四：积分用量监控与成本控制**

积分管理 → 组织积分页签查看积分余额、冻结积分与有效资源包 → 切换到「资源包明细」关注临近到期的资源包 → 在「成员限额」页签设置组织限额与成员限额，控制消耗。

**场景五：启用企业 SSO 登录**

单点登录 → 配置 SSO → 选择提供商类型并填写连接名称与身份凭据 → 设置邮箱域名白名单 → 开启「启用 SSO」→ 创建连接。

## 六、常见问题（FAQ）
### Q1：如何邀请成员加入组织？

**A：** 有两种方式：**链接批量邀请** （创建邀请链接，成员点击链接提交申请，管理员审批通过后加入，适合批量邀请）和**邮箱单人邀请**（向成员邮箱发送邀请，点击邮件链接直接加入，无需审批，适合快速邀请少量成员）。操作详见 2.2 节。

### Q2：成员加入组织后为什么不能使用积分？

**A：** 成员加入组织后默认「未分配坐席」。未分配坐席的成员可以登录，但不能使用组织积分。管理员需在「坐席申请」页签处理其坐席申请，或在成员编辑弹窗中直接【分配坐席】。分配后状态变为「已分配坐席」，即可正常使用。

### Q3：超级管理员、管理员和成员有什么区别？

**A：** 三级角色的权限范围为：**超级管理员** 拥有组织所有管理权限；**管理员** 可管理团队成员和配置；**成员**为普通团队成员，使用基础功能。邀请成员或编辑成员信息时可以调整角色，建议按最小必要原则授权。

### Q4：如何查看组织的积分余额与订阅情况？

**A：** 点击左侧导航【积分管理】，「组织积分」页签可查看积分余额、冻结积分与有效资源包；下方「当前计划」展示生效中的订阅计划（周期、每周期限额等），「历史计划」与「资源包明细」提供历史记录与资源包详情。

### Q5：如何控制成员的积分消耗？

**A：** 在【积分管理】的「成员限额」页签进行两级控制：点击【编辑限额】设置组织总限额（最低 2,000 积分）；点击成员行内的【编辑限额】设置单个成员的限额（最低 2,000 积分，且不能超过组织限额）。

### Q6：邀请链接无法使用怎么办？

**A：** 请检查三种情况：链接是否已**过期** （查看「过期时间」列）、名额是否已**用完** （查看「已使用/总名额」）、链接是否被**停用**。链接过期或名额用尽后需重新创建；被停用的链接无法恢复，请创建新链接。

### Q7：组织 ID 是什么？可以修改吗？

**A：** 组织 ID 是系统为每个组织生成的唯一标识符，用于系统内部识别，不可修改。您可以在【组织设置】页面点击【复制 ID】将其复制到剪贴板，在联系客服或处理订阅事务时使用。

### Q8：如何配置单点登录（SSO）？支持哪些身份提供商？

**A：** 点击左侧导航【单点登录】→【配置 SSO】，选择提供商类型（通用 OAuth2/OIDC（含 BUC）、Microsoft Entra ID（原 Azure AD）、钉钉、飞书、企业微信），填写连接名称与身份凭据，设置邮箱域名白名单并开启「启用 SSO」，然后创建连接并提交审核。不同提供商所需凭据字段不同，详细操作请参见SSO登录。

### Q9：误将成员移除后如何恢复？

**A：** 移除成员后，该成员失去对团队资源的访问权限。如需恢复，请重新通过邀请链接或邮箱邀请该成员加入组织，加入后需重新分配坐席。

### Q10：成员的「存储用量」是什么？

**A：** 成员列表中的「存储用量」展示该成员已使用的存储空间及其个人额度（如 0 B / 20 GB），用于了解成员的存储占用情况。
