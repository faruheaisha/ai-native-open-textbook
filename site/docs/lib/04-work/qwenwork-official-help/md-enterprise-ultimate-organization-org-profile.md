# 千问办公官方帮助中心（阿里云）

组织信息显示当前企业的名称、组织 ID 与访问地址。创建外部集成或交接管理员工作时，先在这里确认正在操作的企业。

## 查看和复制访问信息
1. 进入 组织与安全 → 组织管理 → 组织信息。
2. 核对组织名称与组织 ID。组织 ID 用于识别企业，不随显示名称调整而改变。
3. 使用地址旁的复制按钮取得「管理后台登录地址」或「客户端服务地址」，按用途提供给管理员或成员。
4. 需要维护可信邮箱域名时，点击该项编辑入口，进入身份认证中的域名列表。

![](https://docs.qwenwork.cn/zh/images/qwenwork-flagship-aec874f680a930e5.png)

*管理员登录地址与客户端服务地址用途不同，应复制对应字段。*

## 修改组织名称
点击【编辑】，修改组织名称并保存。重新打开页面确认显示名称。需要管理云账号及购买信息时，使用页面中的控制台跳转入口，进入对应账号处理。

## 排查成员进入了错误环境
先让成员核对客户端的企业服务地址，再对比本页显示值。使用邮箱发现企业环境时，检查[可信邮箱域名](https://docs.qwenwork.cn/enterprise-ultimate/users/authentication)是否包含该成员邮箱域名。不要把管理后台网页登录地址填作客户端服务地址。
