# 千问办公官方帮助中心（阿里云）

## 1. 使用范围与进入方式
本功能面向组织管理员，用于维护人员、权限和组织积分使用资格。进入管理后台后，在左侧"团队"分组选择"成员管理"。

## 4. 邀请成员
![邀请成员](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3410209871/p1096715.png)

### 4.1 邮箱单人邀请

1. **点击"邀请成员"**：选择"邮箱单人邀请"。

2. **填写基本信息**：邮箱必填，姓和名可选填。

3. **设置权限**：选择团队成员、团队管理员或当前账号有权授予的角色。邀请超级管理员时还需填写 11 位中国大陆手机号。

4. **核对摘要并发送**：确认邮箱、角色、手机号和团队后，点击"发送邀请"。对方通过邮件接受后加入团队。

### 4.2 链接批量邀请

1. **选择"链接批量邀请"**：适合多人使用同一链接加入。

2. **设置人数和备注**：人数会占用可用成员名额；备注可填写批次用途，如"新员工入职"。

3. **创建并复制链接**：把链接发给目标人员。通过链接发起的加入需要管理员审批。

4. **停止使用**：在邀请链接列表点击"停用"。停用后链接失效，未使用名额会释放。

**说明**

若组织已配置钉钉，点击"邀请成员"可能直接进入钉钉邀请流程，请以页面实际显示为准。

## 6. 分配或回收坐席
![分配或回收坐席](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3410209871/p1096716.png)

1. **打开成员列表**：在"成员"页签找到目标成员，可先搜索姓名或联系方式。

2. **进入编辑窗口**：点击该成员右侧的编辑按钮。

3. **执行坐席操作**：未分配时点击"分配坐席"；已分配时点击"回收坐席"。

4. **确认结果**：成功后成员状态和顶部坐席用量会更新。

## 7. 编辑成员信息和角色
* 姓名可以修改；联系方式为只读，不能在此页面更换。

* 超级管理员可授予超级管理员、团队管理员或团队成员；团队管理员只能授予不高于自身权限的角色。

* 管理员可以编辑自己，但不能把自己提升到超过当前权限的角色。

* 保存前确认姓名不为空；点击"保存修改"后等待成功提示。

## 8. 批量管理
1. **进入批量模式**：在成员页签点击"批量选择"。

2. **选择范围**：逐个勾选，或使用"全选所有成员"；搜索后全选仅作用于当前筛选范围。

3. **选择操作**：可"分配坐席""取消坐席"或"批量标签"。

4. **预览并确认**：系统会列出实际处理人数，不适用的成员自动跳过；坐席分配还会校验剩余数量。

## 9. 标签、备注、存储与搜索
* **标签**：可在列表中编辑，用于人员分类；支持"任意匹配、全部匹配、不含"等筛选。

* **备注**：记录内部说明，例如区域、岗位或跟进状态。

* **存储用量**：展示成员当前占用的组织存储。

* **搜索**：成员页可搜索成员；待接受邀请页可搜索邀请记录。

## 10. 移除成员
1. **确认权限**：只有具备权限的管理员才能看到"移除"按钮。

2. **发起移除**：在成员行或编辑窗口的危险区域点击"移除此成员"。

3. **二次确认**：确认后成员会失去团队资源访问权限。
