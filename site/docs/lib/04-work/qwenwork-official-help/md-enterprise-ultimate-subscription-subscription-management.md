# 千问办公官方帮助中心（阿里云）

订阅管理用于核对企业当前套餐、有效期和席位数量。新成员无法授权或需要续费时，先在这里检查订阅情况。

## 查看订阅与席位
1. 进入 数据与运营 → 订阅与用量 → 订阅管理。
2. 核对当前套餐、订阅状态、订阅周期和剩余时间。
3. 查看已购席位、已授权席位与剩余席位。准备批量开通成员前，确认剩余席位足够。
4. 需要核对某位成员的授权情况时，进入[用户](https://docs.qwenwork.cn/enterprise-ultimate/users/user)查询。

![](https://docs.qwenwork.cn/zh/images/qwenwork-flagship-b28f7d99b7b6cc59.png)

*订阅状态决定服务有效性，剩余席位决定还能授权多少成员。*

需要购买时，点击右上角的【去购买】打开购买页面。
