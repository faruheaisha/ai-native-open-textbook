# 新一代扫地机器人发布会预览

合成产品代号R3，核心能力为低矮空间清扫、毛发防缠和可拆洗基站。所有参数和价格仅用于演示，不可发布。

| 页 | 屏幕文字（≤15字） | 口述动作 |
|---:|---|---|
| 1 | 它又卡在沙发底了 | 念一条合成差评 |
| 2 | 扫地，不该要人救 | 停顿两秒 |
| 3 | 机身低了12毫米 | 展示进入沙发底 |
| 4 | 毛发先切，再吸走 | 慢镜演示 |
| 5 | 基站能整套拆洗 | 手拆给观众看 |
| 6—14 | 三个家庭场景 | 真实路径演示 |
| 15—17 | 测试、隐私、售后 | 讲边界 |
| 18 | R3，合成价3999元 | 公布权益 |
| 19—20 | 让清洁少一次打断 | 记忆点 |

## 开场讲稿摘录

“这条合成差评只有一句：‘它不是没扫干净，是每次卡住都要我去救。’（停顿）所以这次，我们先不讲参数。先看它能不能自己从沙发底出来。”

## 朋友圈记忆点三选一

1. 现场铺一条“最难清扫路线”，一次通过；
2. 把一周缠绕毛发装进透明盒，展示新旧差异；
3. 让观众投票选择隐藏垃圾点，现场盲扫。
