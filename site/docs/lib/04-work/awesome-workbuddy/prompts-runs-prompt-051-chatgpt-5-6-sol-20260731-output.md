# 首次合作洽谈邮件预览

## 客户A｜区域连锁零售

**主题：把门店费用核对从月底提前到每天**

张总您好，我负责一家费用管理SaaS的行业合作。根据合成客户卡，贵司有80家门店，店长报销与总部预算核对主要靠表格，月底退回较多。我们可以先解决两件具体事：门店提交时自动校验科目和额度；总部按区域实时看到预算占用，而不是月底追账。

如果这也是您正在处理的问题，想约30分钟了解现有流程。会前我会发一页范围说明，不做长演示。下周二下午或周四上午是否方便？

## 客户B｜专业服务公司

**主题：项目费用能否在报销前就归到正确客户**

李经理您好，合成资料显示贵司按项目核算，但差旅和采购常在月底手工分摊。我们的方案让员工提交时选择项目，并在审批前提示合同预算和可报范围；财务保留最终口径，不让系统替业务拍板。若您愿意，我想用30分钟对照一个真实项目流程，看看是否值得做小范围试点。

## 通用模板变量

| 变量 | 来源 | 禁止做法 |
|---|---|---|
| 近期动态 | 官网/公告原文 | 编造新闻 |
| 两个痛点 | 客户表+访谈 | 写泛化“提效” |
| 会议目标 | 一个流程问题 | 直接索要采购 |

第三家合成客户可复用同一骨架，但必须换成它自己的业务动作、两项痛点和会议价值，不能只替换公司名。正式发送前必须读取客户名单并联网核验动态；本次没有真实收件人，也未发送邮件。
