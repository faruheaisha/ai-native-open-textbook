# 618 大促项目复盘预览

合成目标GMV 1500万元，实际1620万元；毛利目标360万元，实际298万元；新客目标2万人，实际2.4万人。GMV超额不能掩盖毛利缺口。

| 做得好 | 做得差 | 运气成分 |
|---|---|---|
| 预售人群分层带来高转化 | 优惠叠加损失毛利 | 竞品两款缺货 |
| 每小时库存校验避免超卖 | 客服话术晚两天冻结 | 平台临时给流量 |
| 老客召回成本低于新客 | 退款原因未实时回流 | 天气带动宅家消费 |

## 可复用经验

1. T-21冻结人群与货品映射；
2. 每个优惠规则必须有唯一Owner；
3. 看GMV同时看毛利、退款和新客质量；
4. 峰值每小时开15分钟战情会；
5. 事故只记录事实、影响、处置和机制修复。

## 下次必须改

- 促销组合做自动冲突测试，覆盖至少20组；
- 客服知识库在T-7冻结并演练；
- 平台额外流量单列，不把运气归成功方法。

## 下次大促 Checklist

- [ ] 目标含GMV、毛利、退款、新客留存
- [ ] 库存与优惠规则双人复核
- [ ] 客服、支付、物流降级方案演练
- [ ] 每个报表能回到源数据
- [ ] T+7与T+30分别复盘

真实报告必须给每条经验附 ./项目归档 的文件名和页码/行号，本预览仅展示合成成品。
