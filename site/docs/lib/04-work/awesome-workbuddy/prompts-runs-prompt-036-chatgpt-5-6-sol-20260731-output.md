# 双11项目复盘 PPT 预览

合成目标GMV 3000万元，实际2820万元，完成94%；毛利目标720万元，实际548万元，完成76%。因此不能只用GMV接近目标来宣布成功。

| 页段 | 结论 | 证据 |
|---|---|---|
| 1—3 | GMV接近目标，但利润承压 | 目标/实际瀑布 |
| 4—6 | 预售分层与老客召回可复用 | 渠道、用户数据 |
| 7—10 | 优惠叠加事故暴露规则治理缺口 | 事故时间线、5Why |
| 11—12 | 运气成分：竞品断货带来流量 | 异常来源 |
| 13—15 | 五条承诺进入下次门禁 | 责任表 |

## 5Why 摘录

问题：直播首小时错误叠加优惠，损失18万元。
为什么1：两张券可同时使用；为什么2：测试用例未覆盖跨渠道券；为什么3：促销规则在三个表维护；为什么4：没有统一规则负责人；为什么5：项目章程只写销售目标，未写配置治理。

## 改进承诺

| 承诺 | 负责人 | 截止 | 验收 |
|---|---|---|---|
| 建统一优惠规则表 | 商品负责人 | T-45 | 所有渠道同源 |
| 加跨券自动测试 | 测试负责人 | T-30 | 覆盖20组组合 |
| 峰值降级演练 | 技术负责人 | T-14 | 30分钟恢复 |

做得好的动作也要留下条件：老客召回在有历史标签和客服承接时有效，不应机械复制。正式复盘必须回到 ./retro 的原始记录，问题只写事实和机制，不点名甩锅。
