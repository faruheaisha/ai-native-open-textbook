# 关于追加年度培训预算的请示

集团人力资源部：

为落实年度数字化能力建设计划，我部门原培训预算30万元已用于管理课程、岗位认证及安全培训。因新增数据治理与智能工具实操课程，现有预算无法覆盖讲师、实验环境和考核费用。

现申请追加年度培训预算12万元，其中课程开发5万元、外部讲师4万元、实验环境2万元、考核与教材1万元。新增课程拟覆盖120人次，按课后测验、岗位作业和三个月应用复盘验收。预算获批后严格执行采购及费用审批制度，未使用部分年末收回。

妥否，请批示。

数字化运营部
2026年7月30日
