# 年度供应商续约谈判手册预览

合成背景：年采购3000万元，对方要求涨8%；两家备选供应商报价分别高2%和低1%，但切换认证需8—12周。内部目标3%以内，本预览不含真实底线文件。

| 档位 | 我方动作 | 条件交换 |
|---|---|---|
| 开价 | 0%涨幅 | 接受年度预测共享 |
| 目标 | 2%—3% | 换更长框架期与分批下单 |
| 边界测试 | 超3%不当场答应 | 要求成本证据与管理层审批 |

## BATNA

立即全量切换不现实；可执行替代是把20%非关键品类转给备选供应商，并用12周完成认证。BATNA价值在于真能执行，不是桌上威胁。

## 五回合中的两回合

对方：“原材料涨了12%，8%已经让步。”
我方：“请把影响本合同的原料占比、基期和传导公式拆开。我们愿意讨论可验证成本，不接受笼统比例。”

对方：“不接受今天就无法保供。”
我方：“保供是双方核心利益。我们可以先确认预测与安全库存，但价格需在成本明细和非价格条件一起确认后签。”

## 非价格筹码

账期45天改30天可换价；滚动12周预测换优先产能；联合库存换交付SLA；两年长约必须换价格上限与降价联动。

A4速查：不被最后期限逼签；每次让步都换回可写入合同的条件；不泄露内部底线；会后24小时形成纪要。正式谈判前需法务核合同和采购核真实BATNA。
