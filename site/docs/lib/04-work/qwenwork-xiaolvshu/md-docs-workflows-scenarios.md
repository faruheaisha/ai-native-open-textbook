# 场景实战 (/docs/workflows/scenarios)

场景实战不只是展示单个产物，而是把调研、内容、数据、系统操作和人工确认串成完整业务链。这里按五类场景组织内容，并补上输入契约、验收标准与安全边界。

## 与任务、案例和行业手册的区别 [#与任务案例和行业手册的区别]

| 内容类型                                 | 解决的问题                    | 适合何时使用            |
| ------------------------------------ | ------------------------ | ----------------- |
| [常见任务](https://qwenwork.org/docs/workflows)              | 如何完成文档、数据、调研、多媒体、网站或钉钉任务 | 已经知道要做哪一种产物       |
| 场景实战                                 | 如何把多项任务串成一条业务链           | 需要完成选品、营销、教学或咨询闭环 |
| [独立案例](https://qwenwork.org/docs/workflows/case-library) | 如何复现一个有明确输入和交付物的案例       | 需要逐步照做并验收         |
| [行业落地手册](https://qwenwork.org/docs/playbooks/industries) | 如何处理行业责任、监管和高风险边界        | 需要进入组织正式流程        |

## 五条核心链路 [#五条核心链路]

| 场景 | 核心链路                       | 建议首个试点           |
| -- | -------------------------- | ---------------- |
| 电商 | 数据与选品 → 商品素材 → 经营复盘        | 一个品类、一个平台、十个候选商品 |
| 闪购 | 商品上下架 → 活动测算 → 商品诊断 → 视觉升级 | 一家门店、一周数据、一次活动   |
| 教育 | 内容体系 → 教学或学习材料 → 反馈与调整     | 一节课或一个知识单元       |
| 营销 | 热点与策划 → 多平台素材 → 分发 → 复盘    | 一个主题、两个渠道、一个周期   |
| 咨询 | 客户材料 → 行业对标 → 风险诊断 → 报告    | 一个问题、一个数据包、一次评审  |

## 开始前的共同约束 [#开始前的共同约束]

1. 先说明要支持的业务决定，不用“全面分析”代替具体问题；
2. 给输入标注来源、日期、权限和缺失项；
3. 把读取、生成、写入、发布和删除拆成不同授权阶段；
4. 先用小样本验证字段、风格、公式和输出格式；
5. 对数字、外部事实、敏感内容和不可逆操作设置人工确认点；
6. 验收通过后再沉淀为模板、[Skill](https://qwenwork.org/docs/features/knowledge-skills)或[定时任务](https://qwenwork.org/docs/features/channels-scheduler)。

  页面中的流程只说明如何组织任务。实际读取账号数据、修改文件、发送消息、发布内容或操作商品前，仍需按当前连接器权限和业务责任逐项确认。
