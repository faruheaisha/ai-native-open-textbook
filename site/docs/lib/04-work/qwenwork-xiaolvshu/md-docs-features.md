# 核心功能 (/docs/features)

千问办公把自然语言理解、文件处理、内容生成、数据分析和工具执行组合成一条任务链。在钉钉场景中，它还可以处理消息、汇报、文档、会议、表格、待办等工作；不同使用端、账号和授权范围看到的入口可能不同。

## 选择入口的简单规则 [#选择入口的简单规则]

| 需求                | 首选入口         |
| ----------------- | ------------ |
| 一次性的研究、写作或文件处理    | 新任务          |
| 汇总钉钉消息、任务、会议或业务数据 | 对应的钉钉办公能力    |
| 查询商品、供应链或跨平台内容    | 调研与电商数据能力    |
| 要复用稳定方法和输出规范      | 技能           |
| 要按计划生成日报、监控或归档    | 定时任务         |
| 要从聊天软件远程发起或接收任务   | IM 频道        |
| 要访问外部工具或账号        | 连接器或 MCP     |
| 要在工具调用前后强制运行本地检查  | Hooks        |
| 要设计界面、生成演示或维护长文   | 对应的垂类工作台     |
| 要让 AI 操作网页或浏览器    | 浏览器连接器（仅客户端） |
| 要快速提交当前应用画面       | 应用快照         |
| 要交付在线网页或交互报告      | 网站与应用能力、我的网页 |
| 要跨会话保留偏好和规范       | 长期记忆与意识      |
| 要了解分端、套餐或待开放范围    | 功能状态         |
