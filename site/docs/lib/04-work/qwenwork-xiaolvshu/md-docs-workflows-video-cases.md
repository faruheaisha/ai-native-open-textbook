# 视频案例库 (/docs/workflows/video-cases)

视频案例库收录 41 条千问办公真实案例，其中 33 条配有完整任务录屏：从输入要求到交付产物，全程可对照复现。案例按业务目标分组，标注任务分类、适用角色和可见的示例产物；17 条案例另附案例库分享的原始 Prompt，可在详情页展开查看并粘贴改写。

录屏文件已随案例本地化托管，点击封面进入案例详情页播放；需要输入、步骤与验收标准时，请继续进入本站的[独立案例教程](https://qwenwork.org)，或先在[官方案例索引](https://qwenwork.org)中按表格检索。

  案例可能依赖特定端、模型、连接器、数据源或账号权限。先用脱敏的小样本验证，再处理真实业务数据；涉及对外发布前，请设置人工确认关口。
