# 桌面端系统设置 (/docs/features/desktop-settings)

从桌面客户端侧边栏底部的设置入口，可以管理通用偏好、扩展与集成以及高级设置。不同系统和客户端版本显示的项目可能不同，修改前先记录原值。

## 常用设置 [#常用设置]

| 分组  | 主要项目                        | 使用建议                |
| --- | --------------------------- | ------------------- |
| 偏好  | 语言、亮暗主题、界面风格、字体、字号、对话宽度     | 先调整可读性，再考虑外观        |
| 对话  | 提示词建议、工具调用默认展开、IM 中是否展示执行过程 | 涉及共享频道时避免暴露不必要的工具细节 |
| 系统  | 开机启动、保持唤醒、桌面与声音通知、网络代理      | 长任务或本地连接器任务再开启保持唤醒  |
| 快捷键 | 新任务、任务搜索、侧边栏、任务监控、QuickPick | 避免与系统和常用软件快捷键冲突     |
| 工作台 | 通用、设计、幻灯片、写作和默认模式           | 按主要交付物选择，不必永久固定     |
| 高级  | 安全工作环境、实验功能、历史消息显示修复        | 先用非关键任务验证           |

  较早的通用设置页写着“当前仅支持简体中文”；更新更晚的桌面设置页已经列出中文和 English 选择器。因此本站仅确认桌面客户端当前文档中的中英文切换，网页端和钉钉端仍以各自界面为准。

## 系统权限 [#系统权限]

| 权限        | 可能用于               | 开启前检查             |
| --------- | ------------------ | ----------------- |
| 完全磁盘访问    | 读取或写入更多本地目录        | 优先使用明确工作目录，非必要不开启 |
| 屏幕录制与系统录音 | 应用快照和反馈材料          | 关闭密码、客户资料等无关窗口    |
| 辅助功能      | 全局快捷键与界面读取         | 等同于较高系统控制能力       |
| 麦克风       | 语音输入               | 核对系统输入设备和录音环境     |
| 自动化       | 日历、提醒事项、备忘录等系统应用协作 | 逐个应用授权，不做全量预授权    |
| 通知        | 任务等待、完成和消息提醒       | 避免锁屏通知泄露敏感摘要      |
| 位置服务      | 与位置有关的任务           | 没有明确场景时保持关闭       |

  一次授权可能持续影响后续会话。每完成一类高权限任务，都应检查连接器、系统隐私设置和当前执行策略；不再需要时及时撤销。

## 保持唤醒、通知与网络 [#保持唤醒通知与网络]

* “保持系统唤醒”适合使用本地连接器的定时任务和长时间桌面任务，但会增加设备耗电；
* 桌面、声音和未读状态可以提醒等待确认或任务完成，公共场所应检查通知预览；
* 自定义代理会影响登录、模型、连接器和更新请求，修改前保存原配置；代理支持“跟随系统”和“手动配置”两种模式；
* 网络诊断可以检测服务连接状态，依次检查 DNS 解析、代理连通性和关键服务可用性，诊断报告可复制附在反馈中；
* 开机自启动不代表任务自动获得授权，也不保证本地连接器任务在设备休眠、断网或客户端退出时执行。

## 语音、应用快照与 QuickPick [#语音应用快照与-quickpick]

语音输入和应用快照都可以配置全局快捷键。QuickPick 则用于在不切换主窗口时快速提交任务，支持组合键（如 `⌥ Space`）和双击修饰键两种触发模式，双击的修饰键可以自定义。快捷入口提高速度，但也更容易把当前屏幕、口述内容或错误窗口带入任务；先检查焦点、附件和账号，再发送。

## 安全工作环境 [#安全工作环境]

桌面设置页把“安全工作环境”描述为独立的任务运行空间，并提供清理环境文件的操作。不要把该说明外推为所有数据、连接器或模型请求都只在本机处理；真实数据边界仍取决于当前任务、启用工具和服务说明。

清理环境文件前先确认：

1. 当前没有任务正在使用该环境；
2. 重要产物已经复制到明确的工作目录；
3. 清理范围不包含对话记录之外的业务文件；
4. 完成后用低风险任务验证环境可以重新建立。

## 数据导入 [#数据导入]

设置页提供数据导入入口，可以扫描本机已安装的 Agent 应用并导入其本地数据。当前已支持 QoderWork CN、QoderWork；Claude Code、Claude CoWork、Codex 标注“即将支持”。导入只读取本地数据，不会覆盖现有会话，过程中可以取消。

## 已归档 [#已归档]

已归档页面管理归档的对话，支持恢复、单条删除和全部删除；删除操作不可恢复，执行前应确认归档内容不再需要。

## 工具执行上限 [#工具执行上限]

工具执行上限默认为 100。单任务达到上限后会自动暂停并等待人工确认，防止异常循环持续消耗积分；确有需要时可以在确认后继续。

## 实验功能 [#实验功能]

设置页当前列出生成式 UI、弹出独立窗口、浏览器上下文接力和助手过程折叠等实验选项，其中浏览器上下文接力要求浏览器插件版本不低于 1.4.0；对话列表筛选等条目同样属于实验性质。名称和行为变化较快，只在测试任务中逐项开启；出现历史消息显示异常时，使用修复显示功能前也应先记录问题和客户端版本。
