# 钉钉办公协作 (/docs/features/dingtalk-work)

钉钉办公能力适合处理已经沉淀在消息、任务、会议、文档和业务表格中的信息。可靠的做法不是要求“一键生成”，而是明确数据范围、输出位置和人工验收人。

## 可调用的钉钉能力 [#可调用的钉钉能力]

能否读取或写入以下模块，仍取决于当前账号原有权限、组织配置、用户授权和对应接口能力。

| 模块    | 千问办公可以协助什么              |
| ----- | ----------------------- |
| 工作汇报  | 汇总消息、文档、会议和待办，生成周期性工作汇报 |
| 钉钉文档  | 创建、改写、总结和整理文档内容         |
| 知识库   | 归档资料，辅助查询、整理和维护知识内容     |
| 日程会议  | 查询空闲时间、预约会议并生成会议安排      |
| AI 听记 | 从会议内容提取结论、待办和责任人        |
| AI 表格 | 建表、整理数据并生成分析结论          |
| 钉钉消息  | 总结消息、提取重点与待办，辅助发送提醒     |
| 群聊    | 总结讨论，识别结论、分歧、风险和下一步     |
| 邮件    | 总结邮件并辅助编辑、发送            |
| 云盘    | 查找、分类、整理文件并提取关键信息       |
| 待办    | 创建和整理待办事项               |
| 通讯录   | 查询人员与部门，辅助整理组织关系        |
| 考勤    | 查询记录并汇总异常               |
| DING  | 对关键事项提醒和催办              |
| 审批    | 根据事项生成审批内容并发起流程         |

  千问办公只能在当前账号和授权范围内工作。发送消息、发起审批、创建 DING、修改文档或批量写表前，应再次确认对象、内容和影响范围。

## 工作汇报 [#工作汇报]

可以把指定时间范围内的聊天、任务、会议或业务数据整理为日报、周报、项目小结和阶段总结。提示中至少写明：

* 汇总谁、哪个群或哪个项目；
* 开始与结束时间；
* 需要突出哪些进展、风险和待办；
* 输出到哪个钉钉文档或汇报入口；
* 哪些内容在发布前必须由负责人确认。

## 文档创建与管理 [#文档创建与管理]

适合新建项目文档、产品说明和知识条目，也适合将散落资料整理进既有目录。让 Agent 修改已有文档前，应提供准确链接，并说明是追加、改写还是替换。

## 会议纪要分析 [#会议纪要分析]

输入会议转写、AI 纪要或补充材料后，可以整理：

1. 议题与背景；
2. 已确认结论；
3. 未决问题；
4. 行动项、负责人和截止时间；
5. 下一次跟进方式。

转写中的人名、数字和承诺必须回听或由参会者复核，不能把模型推断当成会议结论。

## 钉钉 AI 表格 [#钉钉-ai-表格]

常见任务包括字段设计、批量补全、数据校验、筛选排序、分组汇总和经营分析。批量写入前先复制一份数据或限定测试行，确认字段类型、公式和覆盖规则后再扩大范围。

## 企业管理后台 [#企业管理后台]

企业功能包括成员、席位、组织共享积分、连接器和团队知识库；角色分为主管理员、管理员和成员，但部分菜单和完整权限矩阵可能因组织配置而不同。人员开通、权限回收和额度分配都属于管理动作，应遵循最小权限原则并保留变更记录。

  先检查数据范围，再核对事实和负责人，最后确认写入位置与可见范围。对外发送或覆盖原文应作为单独的确认步骤。

## 钉钉隐藏玩法（直播实战） [#钉钉隐藏玩法直播实战]

公开直播「9 个钉钉隐藏玩法」拆解了三类高频联动，适合作为本页能力的实战补充：

* **休假复工消息总结**：返岗后集中汇总休假期间错过的群消息，快速恢复工作上下文；
* **客户群消息筛选**：从多个客户群的消息中筛出需要跟进的内容，减少逐群翻找；
* **会议全流程管理**：围绕会议把资料、纪要和后续待办串成一条链路，减少手工整理。

完整演示与配套速览图见[直播回放与 One Page 速览](https://qwenwork.org/docs/workflows/live-sessions)。玩法基于录制时的版本，入口和名称以当前端为准。
