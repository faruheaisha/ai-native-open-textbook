# 设计、幻灯片与写作工作台 (/docs/features/workspaces)

桌面端工作台会根据交付物改变右侧工作区。通用模式是默认模式，适合普通任务，不预设产物形态，产物以消息而非文件形式存在，不自动落盘；设计、幻灯片和写作模式分别提供更适合画布、演示文稿和长文的结构化流程。

## 四种工作台模式 [#四种工作台模式]

| 工作台 | 核心工作区                 | 主要交付                             |
| --- | --------------------- | -------------------------------- |
| 通用  | 对话消息流                 | 问答、总结、改写等消息形式的回答，不自动落盘           |
| 设计  | 无限画布、设计文件、预览、风格参考、计划  | 可运行和可编辑的界面、海报、Banner 或原型         |
| 幻灯片 | 幻灯片、大纲、源文件            | 16:9 演示文稿，可放映并导出 PPTX、PDF 或 HTML |
| 写作  | Markdown 文件树与只读 / 编辑器 | 文章、报告、指南和内部文档，可导出 PDF            |

可以在输入框的工作台切换器中选择模式，也可以在桌面设置中调整默认工作台。当前账号没有对应入口时，不要根据文件夹或旧截图手动推断。

无论选择哪种工作台，先说明受众、用途、必须包含的内容、格式和验收标准。固定工作目录后，检查生成文件实际保存的位置，不要只依赖画布预览。

## 设计工作台 [#设计工作台]

设计模式把产物视为可以运行和继续编辑的工程文件。当前文档描述了三个主要机制：

* **Questions**：信息不足时先结构化追问；
* **Design Plan**：生成前列出布局、风格、内容层级和交付契约；
* **Nudge**：生成后直接微调配色、间距、圆角等关键参数。

开始时可以选择保真度、风格参考、工作目录和组件库。保真度可在线框图（先梳理低保真结构）与高保真（接近最终交付的视觉细节，默认）之间切换；风格参考可以指定 Apple、Carbon 等风格，也可以保持自动选择，让画布从 160 个参考中自动挑选；组件库默认不指定（HTML 优先，除非需求明确要求 React 或其他框架），也可以从 shadcn/ui、Spark Design、Ant Design 三个 React 组件库中选择一个。复杂项目建议先进入设计规划，确认产物、平台、输出、保真度和组件库，再运行；需求已经非常明确时才考虑直接生成。

生成后在预览中走查真实交互，在画布上圈选局部区域继续修改，并检查设计文件是否具备可读结构、响应式行为和可交接性。

## 幻灯片工作台 [#幻灯片工作台]

幻灯片模式先生成大纲，再按页创建 16:9 HTML 幻灯片，画布默认为 1280×720。可以从 35 个内置模版中挑选一个作为视觉基调，定稿后还可以把当前幻灯片「保存为模版」便于后续复用。一个稳定流程是：

1. 说明主题、受众、演讲时长、页数、语言和核心结论；
2. 选择当前模板或让系统按需求生成视觉方向；
3. 审核每节标题、简介与版式标签；
4. 接受大纲后再生成页面；
5. 检查文字密度、图表数据、页间节奏和演讲者备注；
6. 根据下游需要导出 PPTX、PDF 或 HTML，并重新打开验收。

  导出后必须在目标演示软件和实际屏幕比例下重新检查字体、换行、图片、动画替代和备注。事实、数据与引用也要回到原始材料复核。

## 写作工作台 [#写作工作台]

写作模式把产物保存为工作目录中的 Markdown 文件，当前文档示例目录为 `outputs/`。编辑器可以在渲染后的只读视图和直接编辑之间切换，并从工作区文件版本中比较多轮结果。

使用时写清受众和语气，先确认结构，再让 Agent 写入文件。用户手动修改正文后，后续任务应基于已经保存的文件继续，而不是要求重新生成全文。导出 PDF 前检查标题层级、链接、表格、代码块和分页。

## 选择建议 [#选择建议]

| 目标             | 首选                     |
| -------------- | ---------------------- |
| 快速验证网站或应用界面    | 设计工作台                  |
| 先讲清故事，再逐页生成    | 幻灯片工作台                 |
| 长期维护文章、报告或指南   | 写作工作台                  |
| 同时包含调研、数据和多类文件 | 通用工作台先完成资料与结构，再切换垂类工作台 |

  需要 MCP 工具链路、联网搜索、处理附件或运行通用代码的任务不适合放进工作台，建议直接在普通对话中完成。

模型名称、模板数量、风格参考和组件库都属于高时效项目，以当前工作台菜单为准。
