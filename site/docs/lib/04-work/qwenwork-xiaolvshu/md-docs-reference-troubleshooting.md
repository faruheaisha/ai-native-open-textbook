# 故障排查 (/docs/reference/troubleshooting)

排查前先记录：使用端、脱敏账号标识、发生时间、任务名称、完整错误文字、截图、输入文件类型和已经尝试的步骤。不要提供密码、验证码、Token 或密钥。

## 任务异常 [#任务异常]

1. 检查任务是否正在等待授权、补充信息或外部页面；
2. 确认文件上传完成、链接可访问；
3. 用一个更小的任务验证当前模型和工具；
4. 把过重任务拆成单一目标，再通过新任务执行；
5. 记录失败步骤、完整报错和发生时间。

如果长线程中的旧要求与新要求相互干扰，先让千问办公总结目标、完成进度、已确认结论和待办，再用总结开启新任务。

无法读取图片、Office 文件或 PDF 时，还要检查文件是否损坏、加密、清晰度不足，或位于当前授权工作区之外。

## 文件无法预览或下载 [#文件无法预览或下载]

* 确认文件没有仍在生成；
* 超大文件或不支持格式可能无法在线预览，尝试下载；
* 个人网盘空间不足时删除不需要的文件或升级套餐；
* 上传中断后重新选择文件；
* 文件名不能包含 `/` 或 `\`；
* 同一目录不能存在重名文件；
* 空文件不能上传；
* 删除的个人网盘文件和文件夹无法恢复。

## 积分或 Token 看起来异常 [#积分或-token-看起来异常]

* 在当前账号的用量页面核对模型、文件、输出长度和工具调用；
* 检查是否使用多智能体或重复执行；
* 长对话先总结再继续，减少重复读取历史上下文；
* 复杂任务先确认计划和输出格式，避免整批返工；
* 精确计费和套餐额度以当前订阅与用量页面为准。

## 定时任务没有运行 [#定时任务没有运行]

定时任务的调度在云端完成，设备休眠或关机仍会触发；只有使用本地连接器（浏览器自动化、本地应用操作）的任务，需要设备唤醒且联网。按以下顺序检查：

| 检查      | 说明                              |
| ------- | ------------------------------- |
| 任务是否启用  | 在任务列表确认启用状态和下一次执行时间             |
| 计划时间与时区 | 核对工作日、月末、节假日和时区转换               |
| 执行记录    | 从执行记录进入独立会话，查看运行中、成功或失败原因       |
| 本地连接器任务 | 确认设备处于唤醒且联网状态，必要时开启“保持系统唤醒”     |
| 云端依赖    | 检查云端文件、连接器授权与积分余额               |
| 本地依赖    | 本地连接器任务还要检查本地目录、浏览器、系统应用与客户端登录态 |

任务列表以当前端实际显示为准，不要在错误的端或任务列表里查找。

## 连接器或浏览器无法使用 [#连接器或浏览器无法使用]

* 刚开启或关闭连接器后，新建一个对话任务再测试；
* 核对连接器安装状态、授权账号、读写权限和第三方服务状态；
* 浏览器任务检查扩展连接、Chrome 运行状态和网站登录态；
* 页面结构变化、弹窗或登录过期时，先由用户处理再继续；
* 图形验证码、短信验证、扫码登录和人脸识别必须人工接管；
* 自定义 MCP 检查服务地址、启动命令、请求头、环境变量和本地运行依赖。

  提供精确时间、使用端、任务名称、完整错误、复现步骤、User ID 和异常会话对应的 Session ID。发送前遮盖个人数据；不要提交密码、验证码、Token 或密钥。

如果暂时找不到 User ID 或 Session ID，先提供问题时间和对应会话的脱敏截图，由支持人员协助定位。Session ID 必须来自发生异常的会话。
