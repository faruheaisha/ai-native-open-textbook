# 汽车与出行服务落地手册 (/docs/playbooks/industries/automotive-mobility)

## 推荐首个试点 [#推荐首个试点]

整理售后工单，把客户原话、车型版本、时间线、已做检查、更换部件、当前状态和待确认项分开记录，不自动给出维修安全结论。

| 场景    | 交付物             | 人工责任       |
| ----- | --------------- | ---------- |
| 售后工单  | 故障描述、时间线和待确认项   | 维修方案与安全结论  |
| 经销商运营 | 线索、活动、库存和服务周报   | 价格、优惠和客户授权 |
| 用户反馈  | 车型、版本、主题和证据摘录   | 召回、质量与责任判断 |
| 技术培训  | 已批准手册的路径、题库与速查表 | 版本和操作安全    |
| 车队服务  | 维保到期、异常和沟通草稿    | 驾驶、调度与车辆控制 |

```text
请对售后工单建立结构化摘要。保留客户原话与技术人员记录的区别；按车型、版本、现象、发生条件、已做检查和当前状态输出。不要推断故障原因或责任。
```

验收时重点核对 VIN 或内部车辆标识、车型版本、日期、部件和客户原话。任何涉及制动、转向、电池、消防或道路安全的问题立即交专业人员。
