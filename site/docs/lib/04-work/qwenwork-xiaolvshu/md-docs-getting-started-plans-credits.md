## 订阅、升级与取消 [#订阅升级与取消]

* 连续包月到期后自动续费，用户可以取消后续订阅；
* 单次购买只覆盖当前套餐周期，不会自动续费；
* 取消订阅不会立刻移除已支付周期内的权益；
* 套餐升级在支付成功后立即生效，原套餐截止时间不变；
* 当前周期通常支付升级补差，下一周期按升级后的价格续费；
* 升级后积分补到高级套餐对应数量，但不会因此延长原截止时间；
* 当前文档明确暂不支持生效中套餐直接降级。

变更页面中的组合规则较多，且部分条目标为后续支持。执行升级、续费方式变更或取消前，必须以订单确认页显示的金额、截止日和订阅状态为准。

## 什么会增加任务消耗 [#什么会增加任务消耗]

* 使用的模型；
* 历史上下文长度；
* 文件数量和大小；
* 输出内容长度；
* 工具与连接器调用次数；
* 是否使用多智能体；
* 定时任务运行次数；
* 反复修改或重新执行的次数。

Token 是模型处理文本和上下文的计算单位；积分或 Credits 是产品侧记录模型与工具消耗的额度。两者不能直接按固定比例互换。

## 降低无效消耗 [#降低无效消耗]

| 方法     | 做法                        |
| ------ | ------------------------- |
| 减少无关材料 | 只上传当前目标需要的文件              |
| 一次说清需求 | 写明目标、背景、格式、范围和禁止事项        |
| 控制输出范围 | 明确字数、页数、数量和文件类型           |
| 先确认再执行 | 复杂任务先确认计划、大纲或字段           |
| 合理选择模型 | 日常任务使用基础，复杂分析再使用高级或当前高阶模型 |
| 管理长对话  | 完成一个阶段后先总结，必要时新建任务        |
| 测量自动任务 | 定时运行前先查看一次真实执行的积分和耗时      |
