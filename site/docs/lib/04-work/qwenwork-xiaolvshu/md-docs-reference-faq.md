# 常见问题 (/docs/reference/faq)

本页汇总使用千问办公时最常见的边界问题。需要逐步排查时进入[故障排查](https://qwenwork.org)；涉及组织治理时进入[团队安全](https://qwenwork.org/docs/team/security)。

## 产品能力 [#产品能力]

### 可以处理本地文件吗？ [#可以处理本地文件吗]

PC 客户端更适合处理本地文件，可以用于整理、重命名、分类、格式转换、信息提取和汇总分析。实际范围取决于当前客户端能力、授权目录和文件状态。

### Skill、连接器和专家套件有什么区别？ [#skill连接器和专家套件有什么区别]

| 概念    | 主要目的                  |
| ----- | --------------------- |
| Skill | 规定 AI 怎么完成一类重复任务      |
| 连接器   | 接入外部账号、应用和数据          |
| 专家套件  | 组合多个 Skill、数据连接、流程和标准 |

### 专家套件和多智能体有什么区别？ [#专家套件和多智能体有什么区别]

专家套件强调一个岗位或行业的完整工作方案；多智能体强调多个角色拆分、并行或交叉复核同一个复杂任务。两者都不会自动获得额外权限。

### Web、钉钉和桌面客户端功能相同吗？ [#web钉钉和桌面客户端功能相同吗]

不同。Web 端支持云端定时任务和网页全栈制作；浏览器自动化和直接本地文件操作主要在桌面客户端。Pages 的 Web 付费套餐数据库权益已经进入较新文档，桌面端网页制作入口仍待开放。实际范围以当前账号界面为准。

## 任务与结果 [#任务与结果]

### 任务失败怎么办？ [#任务失败怎么办]

1. 查看任务监控、完整报错和是否等待授权；
2. 检查素材、必要参数、账号和连接器；
3. 用更小的任务验证当前模型与工具；
4. 将复杂任务拆分后重新执行；
5. 保留时间、使用端、任务名称和复现步骤。

### 复杂任务应该一次完成还是分步骤完成？ [#复杂任务应该一次完成还是分步骤完成]

建议分阶段完成。以制作宣传片为例，可以按“脚本 → 分镜 → 图片或视频 → 配音 → BGM → 修改完善”的顺序推进，每个阶段先检查结果再进入下一步。分阶段便于逐步验收，也能把返工控制在当前环节，避免最后整体重做。

### 生成的文件打不开怎么办？ [#生成的文件打不开怎么办]

常见原因是生成时未指定格式。在 Prompt 中明确要求输出 Word、Excel、PPT 或 PDF 等具体格式后重新生成或导出；仍无法打开时按任务失败流程排查。

### 结果不好时应该立即换模型吗？ [#结果不好时应该立即换模型吗]

不一定。先检查目标、材料、输出格式、限制条件和参考样例是否明确。输入已经完整且任务确实需要更强推理时，再考虑切换模型。

### 长对话为什么越来越混乱或消耗更高？ [#长对话为什么越来越混乱或消耗更高]

模型需要持续读取更多历史上下文。完成一个阶段后先让千问办公总结目标、结果和剩余步骤，再决定是否通过新任务继续。

## 定时任务 [#定时任务]

### 关闭浏览器后还会执行吗？ [#关闭浏览器后还会执行吗]

会。定时任务的调度在云端完成，不依赖本机浏览器是否打开，也不依赖电脑是否开机；只有使用本地连接器（浏览器自动化、本地应用操作）的任务，需要设备保持唤醒且联网。

### 电脑睡眠后会补跑吗？ [#电脑睡眠后会补跑吗]

云端调度的任务在设备休眠或关机时仍会准时触发，不涉及补跑；但任务中涉及本地连接器的部分在设备休眠时无法完成，可在执行记录确认后使用“立即运行”。

### Web 与桌面定时任务会同步吗？ [#web-与桌面定时任务会同步吗]

定时任务统一在云端调度。不同端的任务列表展示以当前端实际显示为准。

## 用量与效率 [#用量与效率]

### 哪些因素影响积分？ [#哪些因素影响积分]

模型、上下文长度、文件数量与大小、输出长度、工具调用、多智能体和重复执行都会影响消耗。精确计费以当前账号的用量页面为准。

### 个人套餐当前有哪些？ [#个人套餐当前有哪些]

本次文档列出免费版、个人标准版和个人高级版，提供不同积分、网页数量、网盘、访问密码和数据库权益。价格与活动变化较快，参见[个人套餐、积分与用量](https://qwenwork.org/docs/getting-started/plans-credits)，支付前仍以订单确认页为准。

### 怎样减少无效消耗？ [#怎样减少无效消耗]

* 只提供当前目标需要的材料；
* 一次写清目标、范围、格式和禁止事项；
* 复杂任务先确认计划或大纲；
* 分阶段检查，避免在最后整批返工；
* 简单任务不必始终使用最高档模型；
* 多智能体只用于可拆分并需要协作的复杂任务。

## 权限和企业数据 [#权限和企业数据]

### 可以看到企业里的全部钉钉数据吗？ [#可以看到企业里的全部钉钉数据吗]

不可以。可访问内容由当前账号原有权限、企业管理员配置、用户授权和钉钉接口能力共同决定，使用千问办公不会自动提升权限。

### 授权后会替我发送或删除吗？ [#授权后会替我发送或删除吗]

可能会。最新 FAQ 明确说明，授权后可以协助发送消息、生成或写入文档、发起审批、公开发布和删除文件。这些操作会产生真实影响，执行前必须核对对象、内容和范围。

### 连接器会访问哪些数据？ [#连接器会访问哪些数据]

取决于连接器能力、实际账号和授权范围。安装前检查服务提供方、读写权限、传输范围和撤销方式；刚启停连接器后需要通过新对话使工具列表生效。

## 文件和数据安全 [#文件和数据安全]

### 批量处理本地文件前要做什么？ [#批量处理本地文件前要做什么]

备份重要文件，先让千问办公输出操作清单，用少量文件测试规则，并在删除、覆盖或移动前复核目标目录。

### 批量整理后找不到文件怎么办？ [#批量整理后找不到文件怎么办]

先检查任务记录、目标文件夹和回收站，确认文件是否被移动、重命名或归入新目录。批量重命名、移动或删除前先备份重要文件，可以大幅降低找回成本。

### 可以上传个人信息或企业机密吗？ [#可以上传个人信息或企业机密吗]

只有在具备合法处理权限、符合组织规则且任务确实需要时，才能提供必要的最少信息。不要上传与任务无关的个人信息、商业秘密、密码、验证码或访问密钥。

## 专业责任与发布 [#专业责任与发布]

### 专业数据源的结果一定准确吗？ [#专业数据源的结果一定准确吗]

不一定。专业数据仍受统计口径、覆盖范围和更新时间影响；重要报告应记录来源、时间、指标口径和估算部分。

### 专业建议可以直接作为决策依据吗？ [#专业建议可以直接作为决策依据吗]

不建议。医疗、法律、投资、财税、合规和重要经营事项必须由具备相应责任或资质的人复核。

### 生成内容可以直接发布吗？ [#生成内容可以直接发布吗]

发布前检查事实、版权、肖像权、商标、数据来源、隐私、企业品牌和可见范围。对外发送、发布或覆盖原内容应设置单独确认步骤。

## 问题反馈 [#问题反馈]

### 官方有哪些反馈渠道？ [#官方有哪些反馈渠道]

官方帮助中心说明产品内置 AI 客服，可以查询产品信息、功能说明、使用规则和常见问题，并给出从功能入口到任务完成的操作引导；确认是产品异常时，也可以通过同一入口提交问题报告。

### 支持团队最需要哪些信息？ [#支持团队最需要哪些信息]

提供问题描述、预期结果、发生时间、复现步骤、脱敏截图或录屏，以及异常会话对应的 User ID 和 Session ID。不要提供其他正常会话的 Session ID，也不要提交密码、验证码或访问令牌。
