# 直播回放与 One Page 速览 (/docs/workflows/live-sessions)

本页整理千问办公两个直播系列的公开回放与配套速览图：「问点新东西」演示新功能与隐藏玩法，「岗位提效实战课」面向具体岗位落地。回放在钉钉直播平台观看，可用性与有效期以平台页面为准；One Page 速览图已本地化，可直接在本页查看。

  One Page 把一场直播浓缩成一页图。先用它判断内容是否解决你的问题，再决定是否投入完整回放时长；复现其中操作前，仍应以当前端实际入口为准。

## 问点新东西 · 第一期：产品开箱演示 [#问点新东西--第一期产品开箱演示]

* 回放地址（复制到浏览器打开）：`live.dingtalk.com/r/CZJU8BXC0R`

## 问点新东西 · 第二期：9 个钉钉隐藏玩法 [#问点新东西--第二期9-个钉钉隐藏玩法]

围绕「一周的活 1 天搞定」拆解 9 个不常被注意的钉钉联动玩法，包括休假复工消息总结、客户群消息筛选、会议全流程管理等，适合已经在用钉钉办公的团队。

* 回放地址（复制到浏览器打开）：`live.dingtalk.com/r/ppUIWhBdow`

## 岗位提效实战课 · 第一期：师生提效实战课 [#岗位提效实战课--第一期师生提效实战课]

嘉宾徐华斌（杭州市滨江区数字教育负责人）主讲，不讲概念，只讲 AI 在一线怎么落地，覆盖教育场景的真实痛点与上手功能，适合教师、教务和教育信息化负责人。
