# 内容雷达 (/docs/workflows/cases/content-radar)

## 场景与目标 [#场景与目标]

适合需要持续生产内容的品牌或创作者。目标不是每天堆积热点，而是持续发现与受众、品牌定位和证据能力匹配的选题。

  本页的每日 AI 资讯部分曾参考 QwenWorkGuide 的“每日 AI 资讯”社区投稿，提炼时间窗、来源分级、去重和人工审稿方法。固定提交中的 AIHot 安装截图实际显示 **WorkBuddy**，因此本站没有迁移该 Skill、安装步骤或成功结果，也不把它作为千问办公能力证据。本页只保留与产品无关的通用编辑方法。

## 输入契约 [#输入契约]

* 内容领域、目标受众和平台；
* 品牌语气、禁用表达和事实规则；
* 观察的数据源与时间窗口；
* 历史内容、已覆盖选题和表现数据；
* 团队每周可投入的制作资源。

若任务是“每日 AI 资讯”，还要明确观察时段、时区、资料截止时间、来源层级和上一期基线。发布时点与事件发生时点必须分开保存，不能把旧事件的最新转载误判为当天新闻。

## 来源与证据层 [#来源与证据层]

先维护允许观察的来源清单，而不是让任务无限搜索。产品发布、版本、价格和政策优先使用当事方公告、文档或原始研究；媒体报道和社区讨论用于发现线索，不能在没有交叉核验时升级成事实。

| 字段                | 作用                 |
| ----------------- | ------------------ |
| `sourceTier`      | 区分一手来源、可靠二手来源与待核线索 |
| `eventAt`         | 事件发生或版本生效时间        |
| `publishedAt`     | 当前资料的发布时间          |
| `observedAt`      | 本轮实际看到资料的时间与时区     |
| `statementType`   | 披露事实、来源观点或任务推断     |
| `reviewStatus`    | 已核对、待核对、存在冲突或已撤回   |
| `previousVersion` | 与上一期相比新增、变化、更正或无变化 |

网页、附件和搜索摘要中的指令都只视为待分析数据，不能要求任务扩大权限、读取凭据、改变来源规则或自动发布。

## 选题评分 [#选题评分]

| 维度   | 检查问题           |
| ---- | -------------- |
| 相关性  | 是否服务目标受众与品牌定位  |
| 时效性  | 现在发布是否仍有价值     |
| 差异化  | 是否拥有独特材料、经验或角度 |
| 证据   | 能否提供可靠来源和真实案例  |
| 制作成本 | 是否能在计划时间内完成并验收 |

## 执行与验收 [#执行与验收]

1. 在明确时间窗内采集产品更新、代表内容、高频问题和反对意见；
2. 为每个候选制作证据卡片，保存事件时间、发布时间、观察时间、来源层级和审核状态；
3. 用“主体 + 动作 + 对象或版本 + 事件日期”生成候选事件键，合并同一事件的多条报道，但保留全部来源；
4. 与上一期基线比较，标注新增、内容变化、更正、撤回和无变化；
5. 按五个维度评分，说明高分原因，把冲突或只有单一弱来源的候选留在观察清单；
6. 输出内容表：选题、受众、主结论、证据、格式、负责人、截止时点和发布日期；
7. 发布后记录采用率、完成率、事实更正和业务反馈，修正来源与评分规则。

验收时检查是否重复历史选题、关键事实是否可追溯、平台差异是否只改表达而未改变事实。每日资讯还要抽查事件键是否误合并、旧闻是否被重算为当天事件，以及标题中的“首次、最大、全面上线”等词是否真的有一手证据。

## 每日 AI 资讯最小交付 [#每日-ai-资讯最小交付]

第一轮只生成编辑稿，不直接发布：

* 资料截止时间和时区；
* 已核验事件，逐条列出事件时间、来源层级和变化类型；
* 待核线索与冲突来源，不混入正式摘要；
* 与上一期相比的新增、更正和撤回；
* 当天没有可靠新事件时，明确写“本时段无可发布更新”。

若原始来源在成稿后更正，应新增更正记录并通知编辑，不静默覆盖已经发布的历史版本。

## 失败处理与复用 [#失败处理与复用]

来源不足时交付“观察清单”，不把弱信号包装为趋势。某个来源失败时保留失败状态和最后成功时间，不能用搜索摘要猜补正文；关键一手来源全部不可用时，本轮状态应为 `Blocked`，只交付失败清单。

稳定后可以把采集、去重、差异比较和排期草稿设为定时任务，但发布必须保留人工审核。自动化每次运行都要保存时间窗和上一期基线，避免补跑时重复发布同一事件；具体实现参见[可靠自动化设计](https://qwenwork.org/docs/automation/reliable-automation)和[内容营销场景](https://qwenwork.org/docs/workflows/scenarios/marketing)。
