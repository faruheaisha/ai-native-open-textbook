# 应用快照 (/docs/features/app-snapshot)

应用快照用于把最前方应用的截图和可读文本加入当前对话输入框，当前仅 macOS 客户端提供。它适合快速提交报错、界面细节、终端输出或其他需要“看见当前窗口”才能理解的问题。

  应用快照的快捷键、可读取内容和支持的应用仍可能随版本变化。处理敏感工作前先用无敏感信息窗口测试。

## 它会捕获什么 [#它会捕获什么]

触发应用快照后，千问办公会尝试获取：

* 当前最前方应用的屏幕截图；
* 系统能够读取的界面文字与结构；
* 当前对话所需的上下文附件。

内容先进入输入框，用户可以检查、补充说明或删除后再发送。它不会替代任务目标：仍需说明希望分析什么、保留什么以及最终需要什么结果。

## 设置快捷键 [#设置快捷键]

    ### 打开设置 [#打开设置]

    进入“设置 → 应用快照”，确认当前客户端显示该功能。

    ### 选择全局快捷键 [#选择全局快捷键]

    从当前界面提供的选项中选择触发方式，例如同时按下左右两个 `Command`（⌘）/ `Ctrl` 键。

    ### 使用无敏感信息的窗口测试 [#使用无敏感信息的窗口测试]

    切换到一个普通应用，触发快捷键，检查截图范围和可读文本是否符合预期。

    ### 发送前检查 [#发送前检查]

    查看输入框中的截图和文字，遮盖或移除与任务无关的信息，再补充任务说明。

## macOS 权限 [#macos-权限]

| 权限   | 用途             | 风险检查             |
| ---- | -------------- | ---------------- |
| 辅助功能 | 读取前台应用的界面文本和结构 | 可能接触窗口中的可读内容     |
| 屏幕录制 | 捕获当前屏幕画面       | 屏幕上可见的敏感信息可能进入截图 |

首次触发时，macOS 可能要求授权。授权是系统级的，范围通常大于单个任务；只在受控设备上开启，不再使用时从系统设置中复核或撤销。

  密码、验证码、客户资料、内部聊天、财务数据和未公开文档都可能出现在可见画面中。触发前先整理桌面，发送前再次检查附件。

## 适合与不适合 [#适合与不适合]

| 适合              | 不适合             |
| --------------- | --------------- |
| 提交报错截图和可读错误文字   | 截取含密码或完整个人信息的页面 |
| 让 AI 评审当前 UI 细节 | 在未检查附件时直接发送     |
| 解释终端或设计工具中的状态   | 完整处理多页 PDF 等长文档 |

## 使用限制 [#使用限制]

* 只捕获最前方的应用窗口，被其他窗口遮挡或需要滚动才能看到的内容不会进入快照；
* 不适合完整处理多页 PDF，此类任务建议直接上传原文件；
* 受系统保护的应用可能限制截屏，企业设备还可能受管理员策略限制；
* 连按两次语音输入快捷键，可以把语音要求和当前屏幕快照一起提交。

如果目标是让 AI 在浏览器中完成查询、填写等操作，应使用[连接器与 MCP](https://qwenwork.org)中的浏览器连接器（仅客户端支持）；如果只需口述任务，可使用[语音输入](https://qwenwork.org)。
