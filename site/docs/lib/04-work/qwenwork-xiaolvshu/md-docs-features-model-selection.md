# 模型选择与用量优化 (/docs/features/model-selection)

千问办公会持续更新、替换或下线模型。选择时先看任务复杂度，再考虑质量、速度和积分；长期流程应记录“需要哪一档能力”，不要只绑定一个可能变化的模型名称。

## 当前文档中的选择 [#当前文档中的选择]

| 选择            | 特点               | 推荐任务                      |
| ------------- | ---------------- | ------------------------- |
| 高级（Advanced）  | 顶级性能，面向复杂任务      | 关键分析、研究报告、复杂方案、长文和多步骤工作流  |
| 基础（Basic）     | 智能高效，适合规则清楚的日常工作 | 简单问答、格式转换、文案润色、信息整理、模板化邮件 |
| 经济            | 经济实惠，适合简单任务      | 高频轻量操作、草稿生成、简单整理          |
| `Qwen3.8-Max` | 上游标注为前沿模型，抢先体验   | 进阶推理、复杂问题求解和高质量长文         |

  `Qwen3.8-Max` 不代表长期保留，也不保证所有账号与使用端都可见。选择器中的当前名称、说明和用量规则优先。

## 如何选择 [#如何选择]

* 任务步骤稳定、主要是转换或整理时，先用基础；
* 高频的轻量简单任务可以用经济档控制消耗；
* 结果会影响重点项目，或需要多步分析和稳定表达时，使用高级；
* 确实需要前沿推理能力时，再测试 `Qwen3.8-Max`；
* 图片、视频、语音和音乐等任务还需使用当前界面提供的对应多模态能力；
* 同一个真实样本分别测试质量、耗时和用量，再决定长期默认值。

## 在同一任务中切换 [#在同一任务中切换]

Web 与桌面端都可以在同一任务的后续步骤中切换模型，已有上下文不会因为切换而清空。

    ### 找到模型选择器 [#找到模型选择器]

    在当前任务输入框附近打开模型菜单，确认可见的档位和名称。

    ### 按阶段切换 [#按阶段切换]

    资料收集和格式整理可以使用基础；复杂分析时切到高级或当前高阶模型；最终格式化可按质量要求切回基础。

    ### 重新对齐上下文 [#重新对齐上下文]

    切换前让千问办公总结目标、已确认事实、已完成步骤和剩余交付，降低不同模型理解长上下文时的偏差。

    ### 抽查结果 [#抽查结果]

    重点检查切换后的事实、数字、约束和输出格式是否仍与前文一致。

## 减少无效消耗 [#减少无效消耗]

1. 一个任务只保留一个清晰目标；
2. 只附加当前阶段相关的文件和历史材料；
3. 写清输出格式、篇幅、数量和禁止事项；
4. 复杂任务先确认计划或大纲，再批量生成；
5. 长对话完成一个阶段后先总结；
6. 定时任务先手动运行一次，查看单次积分和耗时；
7. 结果不理想时先检查输入和验收标准，不立即反复换模型。

当前文档建议从界面右上角的用量入口查看余额与明细。具体入口、不同模型消耗、充值和有效期都属于高时效信息，以当前账号页面为准。
