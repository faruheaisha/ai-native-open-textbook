# 我的网页 (/docs/features/my-webpages)

“我的网页”用于管理由千问办公创建并发布的 QwenWork Pages。新网页通常从任务对话创建；左侧网页入口负责查看状态、版本、域名、用量和管理操作。

## 当前能力与使用端 [#当前能力与使用端]

| 能力    | 当前说明                                                       |
| ----- | ---------------------------------------------------------- |
| 静态网页  | 当前支持，适合展示页、文档站和纯前端应用                                       |
| 动态网页  | 当前仅支持 Node.js 22 运行环境，可处理表单和调用其他服务；Python、Java、Go 等后端未来将支持 |
| 数据库存储 | 较新的产品与个人权益页确认 Web 可用，个人标准版和高级版支持；钉钉端也已列入网页全栈能力，桌面客户端仍为后续开放 |
| 默认域名  | 发布后分配一个 `*.qwenwork.host` 地址，不可更换                          |
| 版本与回滚 | 每次发布形成新版本，可切换到历史版本                                         |
| 访问密码  | 个人标准版和高级版的 Web Pages 权益                                    |
| 自定义域名 | 详细操作章节仍明确标为“即将上线”                                          |

  Web 付费套餐可能包含 Pages 数据库权益以及 Web / 钉钉网页全栈能力，但当前账号是否已开放仍以创建界面为准。

## 从对话创建和发布 [#从对话创建和发布]

    ### 选择静态或动态 [#选择静态或动态]

    写清网页用途、受众、页面、数据、第三方服务和验收标准。网页类型创建后不能在线互换，需要更换类型时新建网页。

    ### 选择是否使用数据库 [#选择是否使用数据库]

    只有动态网页可以挂载数据库。先确认当前套餐和创建界面提供该选项，再定义数据结构、保留与导出要求。

    ### 预览并验收 [#预览并验收]

    检查桌面和移动布局、链接、表单、权限、内容准确性、版权和敏感信息。

    ### 确认首次发布 [#确认首次发布]

    千问办公创建网页、分配默认域名并部署。创建后仍需完成第一次发布才会正式上线。

    ### 回到“我的网页”管理 [#回到我的网页管理]

    查看状态、当前版本、域名、访问量、流量和套餐配额。

网页入口本身不直接新建网页。当前详情页要求网页名称只包含小写字母、数字和连字符，最多 30 个字符。

## 动态网页与数据库 [#动态网页与数据库]

动态网页当前仅支持 Node.js 22 运行环境；Python、Java、Go 等后端未来将支持，需要这些后端的应用暂时不适合在“我的网页”上运行。复杂数据库管理和自定义服务器环境（如自行安装中间件、配置 Nginx、运行守护进程）同样不适用。每个网页最多挂载一个独立数据库；详情页说明挂载后不能卸载或换绑，网页管理入口也暂不提供直接查看或编辑数据库内容的界面，需要在任务对话中由千问办公协助。

  删除网页会释放域名、版本、数据库等关联资源，无法恢复。删除前应在对话中导出业务数据，并单独保存源文件和部署所需材料。

## 版本、密码与域名 [#版本密码与域名]

* 修改后重新发布会产生新版本；一个网页只有当前选择的版本对外服务；
* 切换历史版本不需要重新构建全部版本，但切换后首次访问可能稍慢；
* 访问密码保护整个网页，不能只保护单个路径；
* 更新或清除密码后，已经验证的访客需要重新验证；
* 密码遗失后应重设，不能依赖平台找回明文；
* 自定义域名仍按“即将上线”处理，不能把文档中的未来配置步骤视为当前入口；
* 自定义域名开放后还需按中国大陆适用要求处理 ICP 备案与 DNS 配置。

## 网页数量与配额 [#网页数量与配额]

| 套餐    | 可发布网页数量 | Web 访问密码 | Web 数据库存储 |
| ----- | ------- | -------- | --------- |
| 免费    | 5       | 不支持      | 不支持       |
| 个人标准版 | 10      | 支持       | 支持        |
| 个人高级版 | 50      | 支持       | 支持        |

网页服务按网页数量、月度访问量和流量额度管理，不按访客访问次数扣任务积分。用量按 30 天周期重置。达到访问量或流量上限时，网页通常被暂停而不是继续按量扣费；配额恢复或套餐升级后无需重新发布。

个人版不保障高并发、大流量的商业应用场景；有这类需求时，企业版可以单独保障。

## 状态与排查 [#状态与排查]

| 状态        | 常见原因                       | 处理                 |
| --------- | -------------------------- | ------------------ |
| `503` 部署中 | 首次发布、动态网页冷启动或版本切换窗口        | 查看网页卡片状态，稍后重试      |
| `403` 不可用 | 流量或访问量到顶、套餐降级后网页数超额、相关权益失效 | 核对套餐、网页数量和当前用量     |
| 发布失败      | 构建、运行或数据库准备失败              | 返回原任务查看过程，修复后发布新版本 |

主动删除与被动暂停不同：暂停会保留网页、版本和数据库；删除会永久释放。降级后还可能移除访问密码或暂停自定义域名权益，变更套餐前先导出配置与数据。

动态网页冷启动后的首次访问通常需要几秒到十几秒；首次发布或版本切换的部署窗口一般在 1-2 分钟内恢复，遇到 `503` 时稍后重试即可。
