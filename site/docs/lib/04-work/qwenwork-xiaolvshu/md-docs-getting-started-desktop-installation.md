# 桌面端安装与首次启动 (/docs/getting-started/desktop-installation)

桌面客户端适合处理本地文件、浏览器自动化、桌面工作台和需要较长时间运行的复杂任务。下载安装包前，先确认操作系统与处理器架构，再从千问办公当前官网入口获取安装文件。

## 系统要求 [#系统要求]

| 系统      | 最低要求                                 | 安装包                                          | 空间参考                  |
| ------- | ------------------------------------ | -------------------------------------------- | --------------------- |
| macOS   | macOS 14 或更高版本；Apple Silicon 或 Intel | Apple Silicon 使用 ARM64，Intel 使用 X64 的 `.dmg` | 约 700 MB，并为任务文件预留额外空间 |
| Windows | Windows 10 64 位或更高版本；x86\_64         | `.exe`                                       | 约 500 MB，并为任务文件预留额外空间 |

两个平台都需要稳定网络完成下载、登录、模型调用和更新。具体包名、大小与支持版本会变化，以当前下载页和安装器显示为准。

  不要从网盘、群文件或不明镜像下载安装程序。遇到 macOS Gatekeeper 或 Windows SmartScreen 提示时，先重新核对下载来源、开发者或发布者和数字签名；无法确认时停止安装，不要直接绕过系统保护。

## 安装步骤 [#安装步骤]

```
```
        ### 确认处理器 [#确认处理器]

        打开“关于本机”，查看芯片或处理器。Apple M 系列选择 ARM64，Intel 处理器选择 X64。

        ### 下载并安装 [#下载并安装]

        从千问办公官网的下载入口获取对应 `.dmg`，打开后按安装窗口提示把应用放入“应用程序”。

        ### 首次启动 [#首次启动]

        从“应用程序”启动千问办公，核对系统显示的开发者信息。若系统阻止打开，只有在来源与签名均确认无误后，才按系统提供的受控方式继续。

## 登录与首次检查 [#登录与首次检查]

安装页与不同使用端展示的登录选项可能不完全相同。网页端明确支持钉钉扫码和中国大陆手机号登录；桌面端应以当前登录页实际提供的方式为准，不根据其他端推断隐藏入口。官方桌面端文档说明：首次启动在欢迎页点击登录后，需要在浏览器中完成认证，再回到客户端自动进入主界面；登录页同时提供语言切换和配置代理的网络设置入口。

首次登录后建议完成以下检查：

1. 确认登录的是正确个人账号和组织空间；
2. 打开设置查看客户端版本，并完成必要更新；
3. 只授权第一个测试任务真正需要的系统权限；
4. 选择一个不含敏感信息的目录作为测试工作目录；
5. 用一个小文件完成读取、生成、保存和重新打开；
6. 检查产物真实落盘位置，而不是只看对话中的预览。

  官方桌面端文档明确：历史任务仅保存在当前设备，不会跨设备同步。换电脑或重装系统前，先下载需要保留的任务产物和重要文件；不要依赖另一台设备找回历史会话。

## 更新与卸载 [#更新与卸载]

客户端设置中提供检查更新入口；发现新版本时，先保存正在执行的任务和本地文件，再确认下载与重启。卸载客户端前应导出需要保留的本地配置、记忆或任务资料，并检查定时任务、IM 频道、连接器与系统权限是否仍需停用或撤销。

  浏览器扩展、第三方账号授权、IM 机器人、系统隐私权限和云端数据可能需要分别处理。完成卸载后仍应逐项检查。
