# IM 频道 (/docs/features/im-channels)

IM 频道把桌面客户端接到日常聊天工具。消息从哪个会话进入，结果就回到同一个会话；桌面端仍是查看进度、配置 Skill、连接器和其他工具的管控中心。

## 当前文档列出的平台 [#当前文档列出的平台]

| 平台        | 文档中的主要接入方式                  | 适合场景        |
| --------- | --------------------------- | ----------- |
| 钉钉        | 扫码绑定                        | 钉钉组织内的单聊与群聊 |
| 飞书 / Lark | 扫码授权并创建应用                   | 国内或海外团队协作   |
| 微信        | 扫码绑定                        | 移动端轻量交互     |
| 企业微信      | 扫码快捷绑定或手动配置                 | 企业内部机器人     |
| Slack     | Bot Token 与 App-Level Token | 海外团队与频道     |
| WhatsApp  | 扫码绑定                        | 移动消息场景      |

平台列表、授权方式和 Teams 版管控能力会变化。只有当前“IM 频道”页面实际显示并允许配置的平台，才视为当前账号可用。

## 会话与消息如何工作 [#会话与消息如何工作]

* 每个 IM 平台和聊天窗口映射为独立会话，上下文彼此隔离；
* 从 IM 发起的任务会把结果回传到原会话；
* 从桌面端直接创建的普通任务不会自动推送到 IM；
* 可以在桌面端打开对应会话查看进度或继续操作；
* 当前文档列出文本、图片、常见办公文件、语音、合并转发和图文组合消息；
* 连续消息会按顺序处理，但重要任务仍应在一条消息中写清目标和附件关系。

  上下文分开只说明不同聊天不会自动串线。群成员、机器人权限、文件可见范围和第三方平台的数据规则仍需分别核对。

## 开放与配对策略 [#开放与配对策略]

| 策略   | 行为                  | 建议            |
| ---- | ------------------- | ------------- |
| 开放模式 | 可见范围内的用户或群可直接与机器人对话 | 只用于边界清楚的受控组织  |
| 配对模式 | 私聊或群聊需要所有者批准后才能使用   | 新接入和敏感场景的默认选择 |

配对通常以会话为单位：批准群聊意味着群内成员可能共同使用机器人。切换策略前检查已有配对、群成员变化、机器人能调用的连接器以及当前积分边界。

## 接入流程 [#接入流程]

    ### 选择平台 [#选择平台]

    在桌面端“IM 频道”页面选择当前可见的平台，阅读所需权限和数据范围。

    ### 完成授权 [#完成授权]

    扫码类平台在对应官方客户端确认；需要 Token 的平台只在受控配置框中填写，不放进对话、截图或文档。

    ### 使用配对模式测试 [#使用配对模式测试]

    先用测试私聊验证文本、附件、回复位置和失败行为，再测试受控群聊。

    ### 检查桌面映射 [#检查桌面映射]

    确认桌面端出现独立会话，回复没有进入错误频道，工具和连接器范围符合预期。

## 远程接管已有任务 [#远程接管已有任务]

当前文档描述了两条会话命令：

* `/bind`：查看可绑定的桌面任务，并用 `/bind <编号>` 绑定当前 IM 会话；
* `/unbind`：解除绑定，恢复为普通独立 IM 会话。

绑定后，IM 中的新消息会转发到所选桌面任务，任务回复也会同步回来。操作前核对任务名称、数据敏感级别和聊天参与者；验证码、密码和访问令牌不得作为普通群消息发送。

## 与定时任务配合 [#与定时任务配合]

定时任务可以把结果发送到已配置的 IM 会话。上线前先手动运行一次，并确认：

1. 任务是否使用本地连接器（浏览器自动化、本地应用操作），这类任务需要设备唤醒且联网；
2. 目标频道、群或联系人没有选错；
3. 结果中不包含不应公开的过程、文件或个人信息；
4. 失败时不会重复发送或跨群补发；
5. 频道登录态和平台授权是否仍在有效期内。

## 安全清单 [#安全清单]

* Token 和机器人 Secret 只保存在受控配置入口；
* 群聊默认使用最小准入范围；
* 关闭频道不一定清除配置，彻底停用时使用移除配置并到平台侧撤销；
* 发送文件前确认群成员、可下载范围和平台留存规则；
* 远程操作涉及删除、发布、支付或权限变更时，回到可信设备人工确认；
* 定期复核长期未使用的频道、配对会话和机器人应用。
