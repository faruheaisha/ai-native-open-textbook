# 地产、园区与物业落地手册 (/docs/playbooks/industries/real-estate-property)

## 推荐首个试点 [#推荐首个试点]

从物业工单周报开始，按项目、楼栋、问题类型、报修时间、响应时间、当前状态和责任部门整理，高频问题和超时工单单独列示。

| 工作流    | 输入            | 输出              |
| ------ | ------------- | --------------- |
| 项目资料盘点 | 图纸、会议、变更和交付资料 | 专业、版本、日期和缺失清单   |
| 物业工单分析 | 报修、派单、处理和回访记录 | 高频、超时、重复报修和责任部门 |
| 巡检报告   | 照片、点位、记录与整改   | 异常清单、证据与待复核项    |
| 园区月报   | 服务、能耗、活动与投诉   | 指标、变化、风险和下一步    |
| 租赁材料检查 | 合同、证照和交付清单    | 缺失、过期、金额与主体冲突   |

```text
请按楼栋和问题类型汇总本周物业工单。计算响应与关闭时长，列出超时、重复报修、无回访和状态冲突记录。不要推断安全等级或责任归属。
```

## 人工关口 [#人工关口]

房价与估值、工程签证、合同承诺、费用审批、消防及结构安全结论必须由相应专业人员完成。涉及现场风险时直接升级，不等待报告周期。
