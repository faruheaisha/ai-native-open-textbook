# 什么是千问办公 (/docs/getting-started/introduction)

千问办公是一站式 AI Agent 平台。你用自然语言说明目标，它可以规划步骤、调用已授权的工具、处理文件，并交付文档、表格、PPT、PDF、图片、音视频、网页、代码或分析报告。

## 它和普通 AI 对话有什么不同 [#它和普通-ai-对话有什么不同]

&lt;Mermaid
  chart="flowchart LR
  A[说明目标] --> B[补充资料与约束]
  B --> C[规划并调用工具]
  C --> D[生成交付物]
  D --> E[人工验收]
  E -->|需要修改| C
  E -->|通过| F[下载、分享或沉淀复用]"
/>

普通 AI 对话更侧重回答问题或生成初稿；千问办公更侧重围绕目标推进任务并交付可继续使用的产物。一个完整任务通常包含：

* 任务目标和成功标准；
* 输入文件、参考资料和可用账号；
* Agent 的计划、工具调用和授权请求；
* 可以查看、下载或继续编辑的结果；
* 人工验收与必要返工。

## 核心能力 [#核心能力]

| 能力             | 典型任务                                                   |
| -------------- | ------------------------------------------------------ |
| 钉钉办公协作         | 汇总消息和群聊、生成工作汇报、安排日程会议、整理 AI 听记、创建文档与 AI 表格、管理待办等       |
| 多类型产物          | 交付 Word、Excel、PPT、PDF、HTML 报告、网页、代码和多媒体内容              |
| 调研与数据分析        | 检索网页、新闻、图片和内容平台，支持读取 URL、MCP、API 等来源，分析在线或本地数据并生成可视化结果 |
| 电商专业数据         | 查询 1688、淘宝天猫等电商数据，支持选品、商品洞察和经营分析                       |
| 网站与应用          | 生成产品页、表单、数据看板、管理后台和轻量应用，还能提供数据库和域名服务                   |
| 多模态创作          | 生成或编辑图片、视频、语音和音乐                                       |
| 浏览器与本地文件（仅客户端） | 在客户端和明确授权范围内操作登录页面或处理电脑文件                              |

## 使用入口 [#使用入口]

| 形态      | 进入方式                     | 更适合什么              |
| ------- | ------------------------ | ------------------ |
| 钉钉 PC 端 | 钉钉左侧栏中的“千问办公”            | 日常办公、团队协作和钉钉内容处理   |
| 网页端     | 浏览器访问 `qwenwork.cn/app/` | 快速发起任务、处理在线资料和生成内容 |
| PC 客户端  | 从 `qwenwork.cn` 下载       | 高频复杂任务、本地文件与浏览器自动化 |

网页端明确支持钉钉扫码和中国大陆手机号登录；桌面客户端的登录方式以当前登录页为准。不同端功能并不完全相同，浏览器自动化和本地文件操作为仅客户端支持的能力，以桌面客户端实际入口为准。

  正式使用方式包括钉钉 PC 端、网页端和桌面客户端，目前没有独立移动客户端安装入口。手机上的钉钉或浏览器可见范围仍以当前产品、组织配置和实际入口为准。

## 认识界面 [#认识界面]

| 入口    | 用途                                     |
| ----- | -------------------------------------- |
| 新任务   | 提交目标、背景、素材、交付格式和验收要求                   |
| 扩展    | 管理专家套件、连接器和技能；当前端没有显示的入口不要视为已开放        |
| 定时任务  | 云端统一调度，设备休眠或关机仍会触发；使用本地连接器的任务需要设备唤醒且联网 |
| 我的网页  | 查看和管理已经发布的网页产物                         |
| 个人网盘  | 管理上传资料和千问办公生成的文件                       |
| IM 频道 | 把桌面端接入钉钉、飞书、微信、Slack 等消息平台；入口以当前端为准    |
| 工作台   | 在通用、设计、幻灯片和写作模式之间选择                    |
| 最近任务  | 返回历史任务，继续补充、修改或检查结果                    |

新任务输入区的 `+` 菜单可以上传本地文件、从个人网盘选择文件；支持的端还会显示多智能体模式。较新模型页面列出基础、高级、经济和 `Qwen3.8-Max`；具体选项仍以当前端为准，参见[模型选择与用量优化](https://qwenwork.org)。

  本地文件、浏览器、钉钉数据和第三方系统都受当前账号、端能力和授权范围限制。不要因为页面展示某项能力，就默认它可以读取所有文件或企业数据。

## 使用边界 [#使用边界]

* 涉及发送消息、提交表单、修改第三方系统等外部动作时，先确认授权范围。
* 财务、法律、医疗和重要经营决策必须由具备责任与资质的人复核。
* 不要上传无权处理的个人信息、商业秘密或受限制数据。
* 功能可用性可能因使用端、套餐、组织配置和当前版本而不同。
