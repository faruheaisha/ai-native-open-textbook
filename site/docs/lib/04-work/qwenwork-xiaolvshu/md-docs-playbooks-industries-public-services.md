# 公共服务与社会组织落地手册 (/docs/playbooks/industries/public-services)

## 推荐首个试点 [#推荐首个试点]

将一项已经发布且仍然有效的政策整理为办事指南，输出适用对象、材料、步骤、时限、办理地点、原文位置和咨询渠道，并由政策责任部门逐条确认。

## 可用工作流 [#可用工作流]

* 政策材料转办事指南、内部 FAQ 和材料清单；
* 公众意见、问卷与服务反馈的主题归类和证据摘录；
* 会议、项目、采购和执行进展材料整理；
* 公益项目的活动方案、志愿者手册和影响报告底稿；
* 公开政策变化跟踪与责任部门通知。

```text
请把所附有效政策整理为办事指南。每项要求必须附原文章节；区分法定条件、建议材料和内部提醒。原文未说明的资格、时限或例外不得补写。
```

## 公共权力边界 [#公共权力边界]

资格认定、福利分配、许可、执法、处罚和公共资源配置不能由通用办公 Agent 决定。正式服务必须提供责任主体、解释依据、人工渠道和申诉路径。
