# 行业路线图 (/docs/playbooks/industry-roadmap)

## 识别行业场景的五个问题 [#识别行业场景的五个问题]

1. 工作对象是什么：订单、商品、合同、课程还是内容素材？
2. 流程由哪些岗位和系统共同完成？
3. 哪些字段、口径和版本必须一致？
4. 错误会造成什么后果，谁拥有最终责任？
5. 哪一步最重复、最耗时，又最容易人工验收？

第五类步骤最适合作为首批 AI 试点。

## 电商与零售 [#电商与零售]

  A[商品与市场数据] --> B[规格与口径统一]
  B --> C[选品 采购 内容 经营分析]
  C --> D[业务负责人复核]
  D --> E[下单 发布或调整]"
/>

| 场景   | 交付物          | 验收重点           |
| ---- | ------------ | -------------- |
| 企业采购 | 候选商品、价格和风险清单 | 规格、含税口径、供应商和交期 |
| 商品研究 | 同款、评论和趋势分析   | 查询日期、样本范围和证据   |
| 内容运营 | 选题、素材和平台草稿   | 事实、版权和平台差异     |
| 经营复盘 | 指标、异常和建议     | 时间、归因和成本口径     |

淘宝闪购等即时零售场景的重点是把经营动作落地：

| 闪购场景   | 可以辅助什么              | 人工确认         |
| ------ | ------------------- | ------------ |
| 库存与上下架 | 规划库存、识别缺货风险、形成上下架清单 | 实际库存与最终上架动作  |
| 活动测算   | 拆解规则、测算优惠成本和利润影响    | 平台规则、成本与报名决定 |
| 经营分析   | 识别爆品、低效品和断货损失       | 数据口径与菜单调整    |
| 页面优化   | 生成定位、商品文案和视觉草稿      | 价格、资质、版权与发布  |

## 专业服务与企业咨询 [#专业服务与企业咨询]

适用于法律、财税、咨询和研究场景。AI 负责资料处理和底稿，专业人员负责观点、承诺与签字。

| 场景   | 基础交付           | 人工责任      |
| ---- | -------------- | --------- |
| 行业研究 | 来源表、证据矩阵和摘要    | 观点与决策含义   |
| 咨询项目 | 访谈纪要、材料盘点、假设树  | 建议与客户承诺   |
| 财税材料 | 单据识别、字段核对、差异清单 | 申报和税务判断   |
| 法律工作 | 法规、合同和案件底稿     | 法律意见和案件策略 |

## 文化传媒与品牌内容 [#文化传媒与品牌内容]

&lt;Mermaid
  chart="flowchart LR
  A[热点与品牌目标] --> B[选题评分]
  B --> C[脚本与素材计划]
  C --> D[内容制作]
  D --> E[事实 版权 品牌审核]
  E --> F[人工发布]
  F --> G[数据复盘]"
/>

应沉淀品牌语气、禁用词、事实来源库、授权素材库、平台格式、选题评分和复盘指标。

官方营销场景按“热点与用户洞察 → 策划 → 多平台素材 → 分发节奏 → 数据复盘”组织。自动分发前必须单独确认平台账号、发布时间、目标人群和撤回方式。

## 教育与培训 [#教育与培训]

| 场景   | 交付物        | 边界         |
| ---- | ---------- | ---------- |
| 企业培训 | 学习路径、课件和题库 | 版本与适用人群    |
| 教学备课 | 教案、活动和练习   | 知识准确与年龄适配  |
| 学习反馈 | 共性问题和反馈草稿  | 不使用敏感特征贴标签 |
| 课程介绍 | 页面和咨询话术草稿  | 不夸大效果和承诺   |

教育任务的核心是把零散知识体系化为课程大纲、教案、讲义、课件、练习和反馈报告；同一知识点可以按入门、进阶、考试或企业培训版本改写，但知识准确性和适龄性仍由教师审核。

## 项目型服务 [#项目型服务]

建筑装饰、技术服务和实施项目通常材料多、版本多、责任链长。适合从资料盘点、响应矩阵、会议纪要、项目周报、风险与变更清单开始；资质、专业计算、报价、签字和合同承诺必须人工确认。

  [场景实战](https://qwenwork.org/docs/workflows/scenarios)将本页的电商、闪购、教育、营销和咨询方向展开为输入契约、分步流程、验收清单与安全关口。

  [更多行业场景](https://qwenwork.org/docs/playbooks/industry-scenarios)补充制造、物流、金融保险、医疗、药研、文旅、地产物业、能源、公共服务、汽车、农业食品与软件服务，并给出每个行业的首个试点建议。
