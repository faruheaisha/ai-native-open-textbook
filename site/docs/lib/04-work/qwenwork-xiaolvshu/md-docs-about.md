# 关于本手册 (/docs/about)

**千问办公小绿书第三方粉丝编辑组**维护本站内容。本站由第三方粉丝组织制作，是独立、非官方的千问办公实践手册；本站不是千问办公官方网站，与千问办公、千问、钉钉及其所属公司不存在官方隶属或授权关系，也不代表相关公司的正式承诺。千问办公官方网站为 `qwenwork.cn`，官方下载页为 `qwenwork.cn/download`；产品入口、套餐、权限和实际开放能力始终以官网、当前账号界面、合同及官方公告为准。

  我们把千问办公的常见使用问题整理成可搜索、可执行、可验收的中文指南，并明确适用端、必要权限和不确定状态，帮助读者判断一条说明是否适用于自己。

## 页面内容分为三类 [#页面内容分为三类]

| 类型     | 页面中的表现                         | 使用方式                   |
| ------ | ------------------------------ | ---------------------- |
| 产品事实   | 说明适用端、账号条件和必要权限                | 可用于理解产品能力，但仍应在自己的账号中确认 |
| 状态受限内容 | 明确标注 `Beta`、`WIP`、即将上线、未开放或待确认 | 可用于规划和验收，不视为已经全面开放     |
| 实践建议   | 给出输入、步骤、验收、失败处理和安全边界           | 先在低风险真实任务中复现，再沉淀为团队流程  |

## 内容编辑原则 [#内容编辑原则]

1. **明确适用边界**：分别说明 Web、桌面端、钉钉端、账号类型和组织权限；
2. **区分事实与建议**：产品能力说明与教程方法分开表达，实践建议必须说明输入、产物和验收方法；
3. **保留不确定性**：对 `Beta`、`WIP`、即将上线、未开放和待确认状态保持明确标注；
4. **发布前检查**：检查页面标题、描述、站内链接、代码块、结构化数据和移动端展示；
5. **优先维护高影响内容**：套餐、积分、文件限制、权限、功能状态和企业角色发生变化时及时修正。

编辑过程中可以使用 AI 辅助整理，但涉及功能入口、额度、权限和外部操作的说明，仍需在实际产品环境中确认。页面署名指向编辑组及本页的共同内容标准，不冒充产品官方或虚构个人资历。

## 纠错与反馈 [#纠错与反馈]

如发现内容过期、入口不存在或适用范围错误，请前往[反馈与共创](https://qwenwork.org/docs/community)，并尽量提供：

* 页面地址和需要修正的原句；
* 使用端、账号类型、地区和组织环境；
* 实际看到的菜单、完整错误文字或脱敏截图；
* 预期结果与实际结果之间的差异。

编辑组会先确认问题属于产品事实、功能状态还是实践建议，再修正文案。涉及密码、验证码、Token、密钥、个人信息或商业秘密的材料不应提交。
