# 语音输入 (/docs/features/voice-input)

语音输入把口述内容转成输入框中的文字，适合描述长任务、多步骤流程或快速追加修改意见。转录完成后仍由用户检查和编辑，再作为普通文字消息发送。

## 使用前提 [#使用前提]

* 当前客户端输入框显示麦克风入口，或支持公开页面描述的语音快捷键；
* 系统已经授予千问办公麦克风权限；
* 操作系统已安装需要使用的语言和语音识别能力；
* 环境相对安静，口述内容不包含无关敏感信息。

  语音已经拥有公开教程，但入口仍可能受客户端、系统和当前版本影响。当前界面没有麦克风或快捷键时，不要自行推断隐藏入口。

## 使用方法 [#使用方法]

    ### 开始录音 [#开始录音]

    默认快捷键是右侧 `Command`（macOS）或右侧 `Ctrl`（Windows）：按一次开始录音，再按一次结束。也可以点击输入框右侧的麦克风图标。以当前界面实际显示为准。

    ### 说出需求 [#说出需求]

    用正常语速说明目标、背景、资料、限制和交付格式。复杂任务可以在段落之间停顿。

    ### 检查转录 [#检查转录]

    停止录音后，检查人名、数字、日期、专有名词、否定词和标点。

    ### 编辑并发送 [#编辑并发送]

    修正识别错误，补上无法从口述中准确表达的结构、链接或文件，再发送任务。

## 语音相关功能 [#语音相关功能]

* 识别润色：自动把口语化表述整理为通顺文字，减少语气词和重复；
* 声纹识别：降低环境中其他人声的干扰，但不能完全隔离，嘈杂环境下仍需人工核对；
* 常用词纠正：对常用词、姓名和专有名词进行纠正，降低重复识别错误；
* 历史记录：语音输入记录保留 30 天，最多 100 条；
* 全局语音输入：不限于千问办公界面内，可在其他场景通过快捷键调用；
* 语音唤起：连按两次语音快捷键唤起千问办公，并把当前屏幕快照一起提交，与[应用快照](https://qwenwork.org)联动。

  转录完成后自动发送目前仅限 DJI Mic Mini 2 合作套装用户。其他用户在发送前仍需检查转录内容并手动发送。

## 不适合语音输入的内容 [#不适合语音输入的内容]

* 密码、验证码等敏感凭据——既有识别误差风险，也不应口述暴露；
* 需要逐字符精确的代码、公式和路径；
* 嘈杂环境中的口述——声纹识别只能降低干扰，无法保证准确，建议改用键盘。

## 提高识别质量 [#提高识别质量]

* 保持正常语速和清晰发音；
* 句子之间留出短暂停顿；
* 长内容先口述草稿，再用键盘精确修订；
* 人名、数字、文件名和路径尽量逐项确认；
* 环境噪音较大时改用键盘输入。

## 与其他能力组合 [#与其他能力组合]

| 组合        | 用法                    |
| --------- | --------------------- |
| 语音 + 文件   | 先附加文件，再口述需要总结、分析或修改什么 |
| 语音 + 应用快照 | 先捕获当前界面，再口述希望检查的具体问题  |
| 语音 + 结果修改 | 查看产物后口述简短反馈，再核对转录文字   |

  发送、审批、金额、日期、合同、医疗和法律内容不能只依赖转录。涉及真实外部影响时，必须在发送前重新核对文字和附件。
