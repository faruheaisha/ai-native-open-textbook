# 中英文术语表 (/docs/reference/glossary)

| 术语                    | 本手册用法                                    |
| --------------------- | ---------------------------------------- |
| 千问办公小绿书               | 本站及本手册的正式中文名称，也借“效率书”的谐音表达提高办公效率的定位      |
| QwenWork Green Book   | 千问办公小绿书的正式英文名称                           |
| 千问办公 / QwenWork       | 本手册统一使用的产品名称及英文名称                        |
| Agent                 | 能规划、调用工具并交付结果的智能体                        |
| 新任务                   | 主要对话式任务入口                                |
| 任务 / Session          | 一次围绕目标展开的完整对话任务                          |
| Tool Call             | Agent 调用搜索、文件、代码、浏览器等工具的记录               |
| Authorization Card    | 高权限或外部操作前的授权请求                           |
| 个人网盘                  | 保存上传资料、任务产出和长期文件的云端空间                    |
| Agent 工作区             | 个人网盘中按任务或会话保存产出文件的目录                     |
| Skill / 技能            | 规定一类专业任务的场景、输入、步骤、工具、输出和边界               |
| Connector / 连接器       | 把具体外部账号、数据源或工具接入千问办公                     |
| MCP                   | Model Context Protocol，AI 发现和调用外部工具的标准协议 |
| 专家套件                  | 组合角色、方法、技能和连接器的领域解决方案                    |
| 定时任务                  | 按设定时间执行的任务；Web 由云端调度，桌面端由本地客户端调度         |
| IM 频道                 | 把桌面端接入钉钉、飞书、微信、Slack 等聊天工具的消息入口          |
| Hook                  | 在会话、工具或通知事件发生时运行的确定性本地命令                 |
| 工作台                   | 为通用、设计、幻灯片或写作交付提供的专用工作区                  |
| 意识                    | 管理协作风格、工作手册、用户画像和跨会话记忆的桌面能力              |
| 我的网页 / QwenWork Pages | 创建、发布和管理静态或动态网页、版本与访问状态的能力               |
| 积分 / Credits          | 产品侧记录模型与工具消耗的使用额度                        |
| Token                 | 模型处理文本和上下文的计算单位                          |
| 多智能体模式                | 让多个智能体分工处理、并行研究或交叉验证的模式                  |

  不同端和版本可能同时出现中英文名称。本手册优先使用当前中文知识库中的“新任务、个人网盘、技能、连接器”等名称，并在必要时保留英文。
