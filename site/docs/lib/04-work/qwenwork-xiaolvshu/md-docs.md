# 千问办公小绿书 (/docs)

欢迎来到 &#x2A;*千问办公小绿书（QwenWork Green Book）**。它既是一本千问办公实践手册，也借“小绿书”的谐音表达“效率书”的定位：不堆砌功能名称，而是从真实工作问题出发，帮助你把一次成功变成可复用的工作方法。

  不必先读完所有功能。选择一个现在就需要交付的结果，按照教程完成、检查、修正，再把有效方法沉淀为模板或 Skill。

## 选择你的起点 [#选择你的起点]

## 本手册如何保证可靠 [#本手册如何保证可靠]

* **产品边界写清楚**：功能、套餐、地区与限制说明适用端、账号条件和必要权限。
* **教程必须可验收**：每个任务都说明输入、产出和检查标准。
* **冲突按最新资料处理**：同一环境中的事实冲突时，以用户后提供的最新文档为准。
* **功能状态不会被隐藏**：价格、额度、`Beta`、`WIP`、即将上线、适用端与地区限制不会写成永久事实。
* **建议与事实分开**：实践方法必须能说明输入、权限、产物、验收与失败处理，不能反向冒充产品能力。
