# 反馈与共创 (/docs/community)

本站通过结构化模板收集问题和案例。所有内容先进入候选队列，再完成查重、权利、脱敏和完整性审核；产品功能猜测、无法复现的演示和包含敏感信息的材料不会直接进入手册。

&lt;Mermaid
  chart="flowchart LR
  A[提交场景需求卡] --> B[查重 权利与安全检查]
  B --> C\{适合进入案例\}
  C -->|否| D[记录拒绝或待补原因]
  C -->|是| E[submitted 已审核案例]
  E --> F\{独立复现\}
  F -->|失败| G[保留限制和失败记录]
  F -->|通过| H[verified 已复现案例]
  H --> I[maintained 正式教程]"
/>

  模板中只描述资料类型和脱敏样例，不填写密码、Token、客户隐私、内部合同、未公开财务数据或其他无权发布的信息。
