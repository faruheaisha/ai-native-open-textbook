# 个人网盘与任务文件 (/docs/getting-started/files-drive)

个人网盘是千问办公内置的云端文件空间，用于统一保存上传资料、任务产出和需要长期复用的文档。

&lt;Mermaid
  chart="flowchart LR
  A1[本地上传] --> B[个人网盘]
  A2[聊天附件] --> C[当前 Session]
  B --> C
  C --> D[Agent 工作区]
  D --> E[预览与在线编辑]
  E --> F[业务目录归档]
  F --> G[受控存储备份]"
/>

## 两种访问方式 [#两种访问方式]

* **个人网盘页面**：浏览目录、搜索当前文件夹、上传文件、新建文件夹并查看存储用量。
* **新任务输入框**：点击 `+` → `从个人网盘选择`，把已有文件附加到当前任务。

千问办公生成的文件会进入 `Agent 工作区`，并按任务或会话分目录保存。它和普通文件夹一样可以重命名或删除，其中的文件也可以预览、下载、重命名和删除。

  删除 Agent 工作区或其中的任务目录会连同内容一起移除。不要把它当作系统自动备份区。

## 与其他文件空间的关系 [#与其他文件空间的关系]

个人网盘与钉钉云盘不会自动同步。本地文件与个人网盘中的文件通常也是独立副本：上传相当于在个人网盘中创建一份云端副本，原本地文件仍然保留。删除任务不会删除已经保存在网盘中的任务产物。

| 文件用途         | 建议位置   |
| ------------ | ------ |
| 个人反复使用的文件    | 个人网盘   |
| 需要团队共享的文件    | 钉钉云盘   |
| 需要持续检索和问答的内容 | 知识库    |
| 需要批量处理的本机文件  | 本地工作目录 |

## 支持与限制 [#支持与限制]

| 能力        | 当前规则                         |
| --------- | ---------------------------- |
| Office 文件 | 支持的 Office 文档会以在线编辑模式打开并自动保存 |
| 单条消息附件    | 最多 20 个文件，单个最大 500 MB        |
| 同时上传      | 多文件排队，最多同时上传 3 个；大文件会自动分片    |
| 当前目录搜索    | 只按当前目录的文件名过滤                 |
| 选择文件搜索    | “从个人网盘选择”可跨目录按文件名检索并显示路径     |
| 批量操作      | 当前不支持多选或批量操作                 |
| 文件夹下载     | 当前不能直接打包下载文件夹                |
| 删除恢复      | 没有回收站和备份，删除不可恢复              |
| 公开分享      | 当前不能直接生成对外分享链接               |

文件名不能包含 `/` 或 `\`，同一目录不能重名，空文件不能上传。上传中断、断网或关闭千问办公后，未完成的文件需要重新上传。上述数量与大小限制可能随版本调整，以当前界面提示为准。

## 上传并在任务中复用 [#上传并在任务中复用]

    ### 上传文件 [#上传文件]

    在个人网盘当前目录点击“新建”→“上传”，选择一个或多个本地文件，等待进度面板全部完成。

    ### 建立目录 [#建立目录]

    需要分类时使用“新建”→“文件夹”。文件夹名同样不能包含 `/` 或 `\`。

    ### 在新任务中引用 [#在新任务中引用]

    在输入框点击 `+` → `从个人网盘选择`，勾选文件后点击“添加所选”。这样可以复用已有资料，不必再次上传。

  个人网盘删除会永久生效，并立即释放空间。删除文件夹会同时移除其中所有内容；操作前应先预览并下载需要保留的文件。

## 存储空间 [#存储空间]

可以在“个人网盘首页 > 存储空间”查看当前容量与用量。个人网盘空间取决于购买的套餐，套餐权益会变化，购买或升级前仍以当前定价页与订单为准。

| 套餐    | 个人网盘空间 |
| ----- | ------ |
| 免费    | 1 GB   |
| 个人标准版 | 10 GB  |
| 个人高级版 | 20 GB  |

个人网盘本身不消耗积分，只受存储空间限制。达到上限后不能继续上传，已有文件不受影响。

## 文件管理建议 [#文件管理建议]

1. 为长期资料建立清晰的业务目录，不把所有文件留在 Agent 工作区。
2. 文件名包含日期、主题和版本，例如 `2026-07-销售复盘-v2.xlsx`。
3. 重要文件下载到受控存储，并纳入团队备份策略。
4. 涉及隐私或商业秘密时，先确认组织的数据处理规则。
