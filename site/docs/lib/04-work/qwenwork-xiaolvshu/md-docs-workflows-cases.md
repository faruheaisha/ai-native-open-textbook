# 独立案例教程 (/docs/workflows/cases)

每个案例都采用相同结构：场景、输入契约、执行流程、提示词、交付物、验收标准、失败处理、安全边界和复用方法。

  不需要先读完全部案例。选择一个当前要交付的结果，用脱敏样本跑通，再决定是否扩大范围。

返回[场景案例中心](https://qwenwork.org/docs/workflows/case-library)按业务类别选择案例。
