# 连接器与 MCP (/docs/features/connector-pages)

连接器负责把千问办公接到具体的外部平台、账号、数据或工具；MCP（Model Context Protocol）是一套让 AI 以统一方式发现和调用外部工具的协议。

  只有在用户明确开启、配置并完成必要授权后，千问办公才会获得对应访问能力。安装或开启连接器不会提升第三方账号原有权限。

## 三个概念怎么分工 [#三个概念怎么分工]

| 概念    | 主要作用              | 回答的问题          |
| ----- | ----------------- | -------------- |
| Skill | 规定一类任务的步骤、输入和输出   | 这项工作应该怎么做      |
| 连接器   | 接入一个具体账号、数据源或外部系统 | 数据和操作入口在哪里     |
| MCP   | 统一描述工具及参数的调用协议    | AI 如何一致地调用不同工具 |

  连接器和 MCP 能访问什么，取决于服务提供方、当前账号和授予的权限。安装前检查读取与写入范围，任务结束后撤销不再需要的授权。

## 当前公开说明中的连接方向 [#当前公开说明中的连接方向]

| 连接方向          | 可以协助什么                                  | 关键前提                           |
| ------------- | --------------------------------------- | ------------------------------ |
| 浏览器           | 打开页面、点击、提取数据和填写表单                       | 使用当前支持的 Chromium 浏览器扩展，保持必要登录态 |
| macOS 应用      | 读写日历、提醒事项、备忘录、邮件和通讯录                    | 分别授予对应系统权限                     |
| Microsoft 365 | 处理 Outlook、日历、待办、联系人、OneNote 和 OneDrive | 登录正确的 Microsoft 账号并核对授权        |
| 钉钉工作台         | 在企业开通范围内处理待办、日志、考勤、日程和审批                | 完成钉钉账号授权，受组织配置限制               |
| 自定义 MCP       | 接入第三方或本地 MCP 服务                         | 正确配置地址、命令、请求头或环境变量             |

不同账号、使用端和企业配置看到的连接器可能不同。连接前先确认服务提供方、实际账号、读写范围、数据传输范围和撤销方法。

遇到验证码、登录过期、支付、权限提升或不可逆提交时，应由用户接管或再次确认。

## 浏览器与系统应用 [#浏览器与系统应用]

浏览器连接器在已登录的浏览器环境中工作，可以复用当前登录态。当前支持 Chrome、Edge 等 Chromium 内核浏览器，Safari 和 Firefox 暂不支持。首次使用时从“扩展 → 连接器”找到浏览器入口，并按照当前弹窗安装或连接扩展。运行期间需要保持浏览器和扩展可用。

macOS 应用连接器会分别请求日历、提醒事项、备忘录、邮件或通讯录权限。曾经拒绝授权时，需要在系统的“隐私与安全性”中重新开启；只授予当前任务真正需要的应用权限。

## 添加自定义 MCP [#添加自定义-mcp]

当前提供两类添加方式：

* **粘贴 JSON 配置**：适合从可信 MCP 市场或服务方获得完整配置；
* **手动填写**：远程服务可以选择 Streamable HTTP 或 SSE，并填写服务器地址和必要请求头；本地服务可以选择 STDIO，并填写启动命令和必要环境变量。

  API Key、Access Token 和其他凭据不得写进任务 Prompt、文档、截图或代码仓库。添加前确认服务来源，删除或停用后再检查第三方授权是否也需要撤销。

## 生效、接管与排障 [#生效接管与排障]

* 刚开启或关闭连接器后，需要新建一个对话任务才能生效；
* 图形验证码、短信验证、扫码登录和人脸识别需要用户接管；
* 浏览器登录过期时，先由用户重新登录，再继续任务；
* 连接器找不到工具时，先核对启用状态、授权账号和新对话；
* 自定义 MCP 持续超时时，检查网络、服务进程、地址、请求头或环境变量；
* 不再使用时，停用连接器并按服务方规则撤销授权。

## 组合使用 [#组合使用]

连接器可以和文件、Skill、定时任务组合。例如先从网页提取数据，再保存为表格；或读取本地材料后写入日历、邮件和钉钉。复杂流程先在普通对话中完整跑通一次，再决定是否沉淀为 Skill 或定时任务。

  生成和发布网页不属于连接器配置。默认域名、版本回滚、访问保护和待开放能力参见[我的网页](https://qwenwork.org)；专家套件与 Skill 的组合参见[专家套件](https://qwenwork.org)。

IM 频道负责消息从哪里进入和返回，不等于业务系统连接器。钉钉、飞书、微信、Slack 等消息入口的配置和准入策略，参见[IM 频道](https://qwenwork.org)。
