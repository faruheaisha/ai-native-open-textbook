# 调研与分析报告 (/docs/workflows/research-report)

调研任务最常见的失败，是引用了不可靠来源，或者把推断写成事实。开始前先定义问题和证据标准。

## 五种公开调研入口 [#五种公开调研入口]

行业趋势、竞品分析、社媒检索、文献综述和电商选品共享证据链，但材料要求不同：

| 任务   | 优先检查                   |
| ---- | ---------------------- |
| 行业趋势 | 时间窗口、统计口径、事件日期与预测假设    |
| 竞品分析 | 官方产品事实、版本、价格周期和可比性     |
| 社媒检索 | 平台、采样方式、账号真实性和观点偏差     |
| 文献综述 | 检索式、数据库、筛选理由、引用与撤稿状态   |
| 电商选品 | 平台字段、价格与库存日期、评价样本和供应约束 |

## 示例：竞品研究 [#示例竞品研究]

```text
研究 A、B、C 三个竞品最近 12 个月的产品定位、核心功能、定价和目标用户，
生成一份中文 Markdown 报告和对比表。

来源优先级：官方产品页、官方帮助中心、官方公告、监管文件、可信行业媒体。
每个会变化的事实必须附直接来源链接和页面日期；无法验证的内容不要写成结论。
明确区分：已确认事实、基于证据的推断、待验证假设。
价格统一保留原币种与计费周期，不自行换算。
报告末尾列出证据缺口和下一步访谈问题。
```

## 证据分级 [#证据分级]

| 等级 | 示例           | 使用方式       |
| -- | ------------ | ---------- |
| A  | 官方文档、法规、原始数据 | 支撑核心事实     |
| B  | 可信媒体、研究机构    | 交叉验证与行业背景  |
| C  | 社区讨论、评论、社交内容 | 只作为线索或用户观点 |
| D  | 无法定位原始出处的转载  | 不用于关键结论    |

## 验收 [#验收]

* 随机打开至少 5 个链接，确认能直接支持对应陈述；
* 检查发布时间与事件发生时间；
* 价格、版本和功能状态注明适用范围与可变性；
* 对相互冲突的来源说明差异，不静默选择；
* 建议明确说明依据和不确定性；
* 没有大段复制来源文本。
