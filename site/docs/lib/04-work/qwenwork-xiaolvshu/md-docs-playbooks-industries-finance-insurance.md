# 金融与保险落地手册 (/docs/playbooks/industries/finance-insurance)

## 推荐首个试点 [#推荐首个试点]

从内部制度和产品资料检索开始。对每个回答同时给出原文位置、适用范围、版本日期和待合规确认问题，不生成超出已批准材料的解释。

## 低风险工作流 [#低风险工作流]

| 工作流    | 交付物             | 禁止自动决定       |
| ------ | --------------- | ------------ |
| 制度知识检索 | 条款、原文位置、版本和待确认项 | 合规解释与对客承诺    |
| 客户材料预审 | 缺失、过期和主体冲突清单    | 客户资格与风险等级    |
| 理赔案件摘要 | 时间线、材料、保单条款和争议点 | 定责、拒赔、赔付金额   |
| 监管跟踪   | 变化摘要、影响部门和待办    | 法律判断与正式报送    |
| 投研底稿   | 公开资料、数据和证据矩阵    | 自动交易与个性化投资建议 |

## 任务模板 [#任务模板]

```text
请对所附案件材料建立事实时间线，并分别列出：已提供材料、缺失材料、保单相关原文、主体或日期冲突、需要理赔人员判断的问题。不要给出是否赔付、责任比例或金额建议。
```

验收时逐项核对金额、主体、账户、日期和原文引用。材料不得跨客户或跨案件混用，输出权限不得大于输入权限。
