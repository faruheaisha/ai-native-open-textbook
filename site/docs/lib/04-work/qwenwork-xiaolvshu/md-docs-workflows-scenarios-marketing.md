# 营销场景 (/docs/workflows/scenarios/marketing)

营销场景的重点，是从一次“想内容”走向可持续复盘的执行闭环。链路分为热点与内容策划、多平台素材、定时分发、效果监控与迭代四段。

&lt;Mermaid
  chart="flowchart LR
  A[市场与受众证据] --> B[主题和内容假设]
  B --> C[渠道化素材]
  C --> D\{品牌与合规审核\}
  D -->|通过| E[人工或受控分发]
  E --> F[曝光 互动 点击 转化]
  F --> G[复盘与下一轮实验]"
/>

## 四段营销闭环 [#四段营销闭环]

| 阶段    | 任务               | 推荐产物                | 主要风险            |
| ----- | ---------------- | ------------------- | --------------- |
| 调研与策划 | 汇总行业热点、用户问题和平台趋势 | 主题库、证据表、受众假设和内容日历   | 把短期热度当成稳定需求     |
| 批量素材  | 按渠道重写同一主题        | 图文、短视频脚本、公众号、朋友圈和海报 | 事实漂移、版权与渠道格式不符  |
| 定时分发  | 安排节奏、账号、负责人和确认点  | 发布计划、最终素材包与执行清单     | 发错账号、时间、版本或可见范围 |
| 监控复盘  | 整理曝光、互动、点击与转化    | 复盘看板、异常、假设和下一轮动作    | 指标口径变化或错误归因     |

## 策划输入 [#策划输入]

```text
业务目标：认知、线索、报名、销售或留存中的哪一项？
受众：已知需求、使用情境、禁用推断和数据来源。
主题：产品事实、活动规则、价格、时间与可公开信息。
渠道：账号、规格、语气、发布时间和审核要求。
资产：已授权图片、视频、字体、音乐与品牌模板。
指标：口径、归因窗口、目标值和数据负责人。
权限：谁可以预览、审批、排期、发布、暂停和删除。
```

## 从一个母题生成渠道版本 [#从一个母题生成渠道版本]

先固定不可变化的产品事实、证据和行动目标，再为各渠道调整开头、篇幅、画面、互动方式和 CTA。不要让批量生成把同一个未经验证的卖点扩散到全部平台。

    ### 生成主题卡 [#生成主题卡]

    每张卡包含受众问题、核心主张、事实依据、内容角度、目标动作和不可使用的表达。

    ### 先验收一个渠道样本 [#先验收一个渠道样本]

    核对品牌、事实、版权、敏感词、链接和移动端效果，再批量生成其他平台版本。

    ### 把排期与发布分开 [#把排期与发布分开]

    定时任务可以生成内容和执行计划；能否直接发布取决于已开启的连接器、账号权限和目标平台。发布前保留最终审核。

    ### 用统一口径复盘 [#用统一口径复盘]

    记录发布时间、素材版本、受众、花费和指标口径。把结果写成“观察 → 可能解释 → 下一轮实验”，不把单次波动当成结论。

  每次定时运行会创建新对话并消耗 Credits。只有对应连接器、账号授权和目标动作都可用时，任务才可能执行外部发布；验证码或登录验证仍需要人工接管。

## 验收清单 [#验收清单]

* [ ] 每个主张都能回到已确认的产品或活动事实；
* [ ] 各渠道版本保留同一事实口径和正确 CTA；
* [ ] 图片、音乐、字体、人物和引用具备使用权；
* [ ] 发布账号、时间、可见范围、链接和版本已复核；
* [ ] 指标看板写明平台、周期、币种和归因窗口；
* [ ] 优化建议有明确观察周期和停止条件；
* [ ] 可以暂停排期、撤回错误素材并定位发布记录。
