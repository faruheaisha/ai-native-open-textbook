# 场景案例中心 (/docs/workflows/case-library)

案例中心收录十个可以独立执行的教程。每个教程都写清输入、权限、操作、交付物、验收、失败处理与安全边界；另有 [41 条案例索引](https://qwenwork.org)与[视频案例库](https://qwenwork.org)（33 段真实任务录屏、17 条附可粘贴 Prompt），用于发现更多任务。

如果目标不是复现一个案例，而是串联选品、营销、教学或咨询的多段工作，请先进入[场景实战](https://qwenwork.org/docs/workflows/scenarios)选择业务链路。

  chart="flowchart LR
  A[选择案例] --> B[核对前置条件]
  B --> C[准备真实样本]
  C --> D[按教程执行]
  D --> E\{验收通过\}
  E -->|否| F[记录问题并返工]
  F --> D
  E -->|是| G[保存模板与复盘]"

## 如何选择 [#如何选择]

| 情况           | 建议                                           |
| ------------ | -------------------------------------------- |
| 第一次尝试        | 选择低风险、输入完整、结果容易人工检查的案例                       |
| 涉及法律、财务或对外发布 | 先确认专业责任人和提交前确认点                              |
| 要进入团队日常      | 连续成功三次，再沉淀模板、Skill 或定时任务                     |
| 找不到适合的案例     | 使用[场景需求模板](https://qwenwork.org)描述问题 |
