# 成员、角色与积分 (/docs/team/members-credits)

企业后台提供成员、席位和积分管理；邀请链接有效期、积分有效期和完整权限矩阵仍可能因组织配置而不同，以下内容不替代当前后台说明。

## 当前公开的企业版权益 [#当前公开的企业版权益]

官方帮助中心已公开企业版权益页，当前列出一个在售套餐：

| 项目    | 当前公开说明                         |
| ----- | ------------------------------ |
| 套餐    | 企业标准版，¥198 / 月，支持月付与年付         |
| 每月积分  | 每席位 2,000 积分，进入组织公共积分池         |
| 可发布网页 | 50 个（Web 端）                    |
| 网盘空间  | 20 GB（Web 端）                   |
| 可用端   | 当前支持 PC 端与 Web 端，桌面客户端将在后续版本开放 |
| 成员角色  | 区分主管理员、管理员与成员；成员需获得坐席后才能执行任务   |

价格、折扣与权益可能调整，采购前以当前订单确认页与合同为准。

## 企业积分包 [#企业积分包]

官方权益页同时列出企业积分包，购买后进入组织公共积分池，有效期为购买成功起一年：

| 积分包          | 当前公开价格   |
| ------------ | -------- |
| 2,000 积分     | ¥100     |
| 20,000 积分    | ¥1,000   |
| 200,000 积分   | ¥10,000  |
| 2,000,000 积分 | ¥100,000 |

## 当前公开说明中的管理能力 [#当前公开说明中的管理能力]

| 管理项   | 公开页面中的说明                                          | 使用时如何确认              |
| ----- | ------------------------------------------------- | -------------------- |
| 成员角色  | 主管理员、管理员、成员三种；只有具备管理权限的成员才能进入管理后台                 | 以当前成员列表的角色标注为准       |
| 成员状态  | 无坐席、已分配坐席、坐席申请中、待审批申请、待接受邀请五种；无坐席成员可以进入页面，但无法执行任务 | 以当前成员列表和成员实际登录状态为准   |
| 邀请方式  | 邮件邀请、钉钉选人组件或链接邀请三种；链接邀请需要管理员审核                    | 发送前核对组织、对象、有效期和可撤销方式 |
| 对话可见性 | 管理员不可以查看成员的全部对话                                   | 涉及合规与审计需求时以当前后台说明为准  |
| 积分管理  | 企业积分进入组织共享池，可设置组织和个人使用限额                          | 以当前套餐、结算周期和后台可配置项为准  |
| 席位增加  | 支付完成后立即生效；每增加一个席位，组织积分池增加“2,000 × 订阅剩余时间比例”的积分    | 提交前检查应付金额、生效时间和成员影响  |
| 席位减少  | 下次续费时生效；席位不足时需要重新分配成员                             | 提交前检查续费日期、已分配成员和数据处理 |

邀请链接有效期、单次邀请数量和完整权限矩阵尚未在公开文档中稳定确认，不应自行补全。

## 钉钉组织绑定规则 [#钉钉组织绑定规则]

* 一个钉钉组织只能绑定一个千问办公组织；
* 一个钉钉账号可以绑定多个千问办公组织；
* 更换绑定的钉钉组织本期暂未开放，首次绑定前应确认组织选择无误。

## 开通前记录 [#开通前记录]

| 项目   | 要记录什么             |
| ---- | ----------------- |
| 成员身份 | 姓名、部门、岗位和唯一账号     |
| 业务需要 | 需要使用哪些任务、数据和外部系统  |
| 权限范围 | 只读、写入、发布、审批或管理员能力 |
| 积分边界 | 可接受的周期额度、告警阈值和审批人 |
| 责任人  | 谁批准、谁复核、谁负责后续回收   |

## 成员生命周期 [#成员生命周期]

* 开通时只授予完成职责所需的功能与数据范围；
* 主管理员手机号与通知邮箱用于接收组织级通知，应长期有效、不随单个员工离职失效，人员变动时先更新联系方式与继任安排；
* 岗位变化时重新核对组织角色、钉钉权限、连接器和定时任务；
* 暂停、移除或注销前先查看当前界面的影响说明和数据保留规则；
* 离职时同时回收企业账号、第三方授权、共享文件和自动化责任；
* 所有高权限和积分变更保留申请人、批准人、时间与原因。

## 企业积分规则 [#企业积分规则]

较新 FAQ 对企业积分给出了更具体的当前规则：

| 项目   | 当前公开说明                       |
| ---- | ---------------------------- |
| 席位积分 | 每个企业版席位每个订阅月包含 2,000 积分      |
| 使用方式 | 所有席位积分进入组织公共积分池，由有企业版权限的成员共享 |
| 结转   | 当月未用完的席位积分不结转到下个订阅月          |
| 积分包  | 购买后进入组织公共积分池，有效期为购买成功起一年     |
| 扣减顺序 | 先扣当月席位积分，再扣积分包；多个积分包先用最早到期的  |
| 购买前提 | 积分包不能脱离有效企业席位单独使用            |

采购页、合同和企业后台是数量与规则的最终依据。模型、文件、工具调用、多智能体、定时任务和重复执行都会增加消耗；企业侧应先用真实小样本测量，再设置周期预算和异常告警。

调高组织或个人限额不会增加企业实际积分；需要补充资源时，应增购有效席位或使用当前企业后台提供的积分包。新增席位立即生效并按剩余周期计算费用和首期积分；减少席位在下一次续费时生效。

  积分限制的是资源消耗，不代表成员被授权访问所有数据或外部系统。数据权限必须通过组织角色、连接器、MCP 和第三方系统权限单独控制。
