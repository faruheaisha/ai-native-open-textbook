# 教育场景 (/docs/workflows/scenarios/education)

教育场景的核心是把零散知识、学习目标与反馈组织成内容体系。教师和学生可以沿不同路线使用；千问办公适合整理、生成草稿和分析材料，不替代教学判断、考试评价、学术署名或录用决定。

## 教师与学生路线 [#教师与学生路线]

| 使用者 | 场景      | 推荐输入                 | 可验收产物              |
| --- | ------- | -------------------- | ------------------ |
| 教师  | 备课与开发课程 | 学员画像、目标、课时、标准与参考资料   | 课程大纲、教案、课件、练习与答案依据 |
| 教师  | 招生与精准营销 | 课程事实、适用对象、价格、时间和渠道规范 | 招生页面、素材矩阵与报名数据看板   |
| 教师  | 教学与个性评估 | 作业、测验、课堂反馈和评分规则      | 学情报告、薄弱点证据和教学调整建议  |
| 学生  | 学习与备考   | 考纲、教材、真题、当前水平和可用时间   | 知识图谱、复习计划、练习与错题复盘  |
| 学生  | 科研与学术研究 | 研究问题、数据库范围、文献与引用规范   | 检索式、文献表、证据摘要和写作提纲  |
| 学生  | 就业与求职   | 真实经历、作品、目标岗位和公司公开资料  | 匹配分析、简历草稿、面试题与跟进清单 |

## 输入契约 [#输入契约]

```text
对象：年级、学习阶段或岗位目标；不提供无关身份信息。
目标：完成哪项教学、学习、研究或求职任务。
依据：课程标准、考纲、评分规则、引用规范或岗位要求。
材料：允许使用的教材、讲义、作业、文献和个人经历。
输出：难度、时长、格式、数量和可访问性要求。
验收人：教师、学生本人、研究指导者或职业顾问。
禁区：不得编造成绩、经历、引用、研究结果或录用承诺。
```

## 推荐执行方式 [#推荐执行方式]

    ### 先建立目标与评价标准 [#先建立目标与评价标准]

    把“学会”“提升”改成可观察目标，例如能解释概念、完成哪类题、提交哪种研究材料或展示哪项真实经历。

    ### 生成一个知识单元 [#生成一个知识单元]

    先产出一节课、一组练习或一页简历，检查难度、事实、答案和措辞，再批量扩展。

    ### 用真实反馈调整 [#用真实反馈调整]

    根据测验、作业、课堂观察或面试反馈更新材料。报告保留样本量和评价规则，不给学生贴固定能力标签。

    ### 由责任人确认使用 [#由责任人确认使用]

    教材、招生发布、成绩评价、论文提交和求职投递，都由相应责任人完成最终核验。

## 教育场景的红线 [#教育场景的红线]

  成绩、作业、联系方式、健康和家庭信息都可能属于敏感数据。只提供完成任务所必需的最小范围，去除无关身份字段，并按学校或组织规则控制保存与共享。

* 不把模型生成内容作为未经核验的标准答案；
* 不伪造参考文献、实验数据、证书、项目或工作经历；
* 不替学生完成应由本人独立完成的考试、论文或考核；
* 不以单次作业或少量数据推断能力、人格或升学结果；
* 招生内容只使用已经确认的课程、师资、价格和效果信息；
* 涉及录取、成绩、处分或录用的决定保持人工责任。
