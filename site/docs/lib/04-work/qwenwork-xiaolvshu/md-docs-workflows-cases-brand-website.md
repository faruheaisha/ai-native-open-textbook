# 品牌官网搭建 (/docs/workflows/cases/brand-website)

## 场景与目标 [#场景与目标]

适合品牌、活动和业务团队制作介绍型网站或落地页。先确认事实与信息架构，再进入视觉和开发，避免用漂亮页面掩盖内容问题。

产品官网与活动页面都可以使用本教程中的品牌事实、转化路径、响应式和上线验收流程。

## 品牌简报 [#品牌简报]

```text
品牌名称：[名称]
定位：[解决什么问题]
目标受众：[谁会使用或购买]
核心产品：[产品与证据]
转化目标：[咨询、预约、购买或下载]
页面：[首页、产品、案例、关于、联系等]
视觉约束：[品牌色、字体、已有 VI、禁止风格]
素材：[已授权图片、视频、Logo 和文案]
```

## 执行流程 [#执行流程]

1. 核对品牌事实、用户和转化目标；
2. 输出站点地图、页面目标和内容缺口；
3. 用低保真结构确认信息层级与行动路径；
4. 基于授权素材生成页面并适配手机和桌面；
5. 检查链接、表单、错误状态、性能、无障碍和 SEO；
6. 明确发布环境、域名、回滚与维护责任人。

## 验收标准 [#验收标准]

* 页面内容与批准资料一致，不虚构客户、数据和能力；
* 主要任务在手机和桌面均可完成；
* 表单说明收集目的、必要字段和隐私规则；
* 图片、字体、商标和案例具备使用授权；
* 有上线前清单、停止发布和版本回退方式。

## 失败处理与复用 [#失败处理与复用]

素材不足时使用明确占位，不从未知来源抓取图片。将站点地图、内容模板和发布检查表保存为后续活动页的基础模板。
