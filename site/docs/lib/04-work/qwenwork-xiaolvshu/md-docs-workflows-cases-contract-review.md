# 合同预审 (/docs/workflows/cases/contract-review)

## 场景与责任边界 [#场景与责任边界]

适合在法务正式审核前整理合同事实、风险和待确认事项。AI 不能代替专业法律意见，也不能在未授权情况下改写或发送合同。

## 输入契约 [#输入契约]

* 合同原文及全部附件；
* 合同类型、交易目标和我方身份；
* 我方市场地位、关键商务底线和标准条款；
* 交付、验收、付款和期限等业务事实；
* 适用地区、行业合规要求和审查深度。

## 四层审查 [#四层审查]

| 层级 | 重点                     |
| -- | ---------------------- |
| 基础 | 主体、日期、金额、定义、编号、附件和交叉引用 |
| 商业 | 交付、验收、付款、价格调整、服务水平和连续性 |
| 法律 | 违约、解除、赔偿、责任限制、争议解决和证据  |
| 合规 | 数据、知识产权、行业监管、反商业贿赂和授权  |

```text
请站在 [我方身份] 立场审查这份 [合同类型]。
交易目标：[目标]；不可接受风险：[底线]。
按基础、商业、法律、合规四层输出风险清单，标注原条款位置、风险等级、理由、建议修改和待业务确认项。
不要补写合同中不存在的事实。
```

## 交付与验收 [#交付与验收]

* 风险清单能定位原条款，建议修改不改变已确认商务事实；
* 区分致命、重要、一般和提示性问题；
* 主体、金额、期限、责任上限和争议解决逐项复核；
* 所有修改由业务负责人和法务共同确认；
* 材料不完整时先交付缺失清单，不输出“审查通过”。
