# 功能状态与可用范围 (/docs/features/preview-capabilities)

公开教程说明“产品如何设计”，当前账号界面决定“现在能否使用”。功能还会受 Web、钉钉或桌面端、客户端版本、操作系统、套餐、企业配置和灰度范围影响。

  同一个名称可能代表不同端的实现。先区分使用端，并以当前账号界面显示的明确状态为准。

| 电脑操作             | 当前公开文档已移除该功能介绍                     | 不再作为教程推荐，仅保留[撤回说明](https://qwenwork.org/docs/features/computer-use)；界面仍可见时以当前端为准 |

## 本次主要冲突结论 [#本次主要冲突结论]

### 定时任务统一云端调度 [#定时任务统一云端调度]

此前按 Web 云端与桌面本地两套调度描述定时任务。上游 2026-08 重建后的公开文档明确调度统一在云端进行：设备休眠或关机时任务仍会触发；仅当任务使用本地连接器（浏览器自动化、本地应用操作）时，才要求设备保持唤醒且联网。

### Pages 数据库 [#pages-数据库]

较早 Pages 详情把数据库标为即将上线；次日更新的个人权益页明确个人标准版和高级版 Web 数据库权益，产品简介也明确 Web 和钉钉端网页全栈制作。因此数据库不再统一写成“未开放”，但实际创建入口仍需账号验证。

### 应用快照 [#应用快照]

较早学习页使用 Beta，较新的桌面页和系统设置把它作为常规能力描述。本站移除 Beta 标签，但保留系统权限、版本差异和敏感屏幕测试要求。

### 模型切换不再限定 PC [#模型切换不再限定-pc]

新 Web 与桌面文档都说明可以在同一任务的后续步骤切换模型并保留上下文。具体模型名单仍是高时效信息。

### 语言按使用端区分 [#语言按使用端区分]

较早通用设置页写“仅简体中文”，更新更晚的桌面设置页列出中文与 English。本站只确认桌面端选择器，不外推到 Web 或钉钉。

## 待确认项 [#待确认项]

本次站点导航中存在两个不能作为正式产品页面使用的链接：

* 企业管理页链接返回 404；
* 钉钉移动端链接返回产品首页，没有文档正文，也未进入 sitemap。

这些链接不会被当作已开放功能证据。安装页还对 macOS 应用路径和登录方式出现不一致，本站因此只保留可验证的系统要求与安装流程，并要求以当前安装器和登录页为准。

## 实际验收方法 [#实际验收方法]

1. 记录使用端、客户端版本、系统、账号、空间、组织和测试时间；
2. 当前端没有入口时记录“当前账号不可见”，不拼接隐藏地址；
3. 入口存在时使用测试账号和脱敏数据；
4. 分别验证读取、写入、发送、删除和撤销授权；
5. 截图记录成功范围、失败状态和实际菜单；
6. 产品状态变化后，按当前界面的明确状态修订内容。
