# 制作汇报演示 (/docs/workflows/presentations)

好的 PPT 是为一次沟通或决策服务，不是把报告逐段搬到幻灯片。

“生成可编辑、指定风格的办公 PPT”是常见任务。指定风格时应提供品牌模板、受众与示例页；没有模板时先确认结构样稿，不用视觉效果掩盖缺少证据的结论。

## 示例：季度经营汇报 [#示例季度经营汇报]

```text
根据附件的季度数据和复盘文档，制作一份 12 页以内的中文经营汇报 PPT。

受众：总经理和业务负责人；会议时长 15 分钟。
目标：说明本季度结果、偏差原因、下季度三项优先动作和需要决策的问题。
每页只保留一个核心结论，标题写成结论句。
所有数字注明来源文件和 Sheet；没有来源的判断标记“假设”。
图表优先于大段文字，不使用装饰性 3D 图表。
最后一页必须列出需要确认的决策与负责人。
输出可编辑 PPTX，并附一份逐页讲稿。
```

## 推荐结构 [#推荐结构]

1. 封面与汇报目标；
2. 一页执行摘要；
3. 核心指标总览；
4. 关键增长与下降因素；
5. 区域或产品拆解；
6. 风险与问题；
7. 下季度优先动作；
8. 资源与决策请求；
9. 附录数据口径。

## 验收 [#验收]

* 标题能独立表达结论；
* 数据与底表一致，单位和时间范围明确；
* 页面在投影尺寸下仍清晰可读；
* 图表不是截图，或至少提供可追溯数据；
* 动画和装饰不干扰信息；
* 文件可以正常打开并继续编辑；
* 讲稿与页面内容一致。
