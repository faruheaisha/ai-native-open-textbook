# 千问办公能力地图 (/docs/features/capability-map)

千问办公的核心不是某一个模型，而是把理解、生成、数据、工具和办公系统串成可以交付的任务。下面的能力地图来自千问办公新人上手指南，并按实际选型方式重新整理。

&lt;Mermaid
  chart="flowchart TD
  A[自然语言与多模态输入] --> B[任务理解与拆解]
  B --> C1[钉钉办公协作]
  B --> C2[研究与数据分析]
  B --> C3[内容与网页创作]
  B --> C4[浏览器与文件执行]
  C1 --> D[文档 表格 汇报 会议]
  C2 --> D
  C3 --> D
  C4 --> D
  D --> E[人工验收与交付]"
/>

## 理解与交付 [#理解与交付]

| 能力      | 可以解决什么                                                         |
| ------- | -------------------------------------------------------------- |
| 自然语言理解  | 把口语化需求拆成搜索、读取、生成、编辑、发送和归档等步骤                                   |
| 多模态理解   | 读取图片、截图、音频、视频和网页链接，提取结构化信息                                     |
| 多类型产物输出 | 生成文档、PPT、表格、PDF、HTML 报告、网页、代码和多媒体内容                            |
| 模型调用    | 在基础、高级、经济（经济实惠，适合简单任务）和 `Qwen3.8-Max` 之间选择，或按任务调用图像、视频、语音和音乐能力 |

### 任务界面 [#任务界面]

## 钉钉办公协作 [#钉钉办公协作]

在当前账号原有权限和用户授权范围内，可用的协作对象包括：

* 工作汇报、钉钉文档、知识库、日程会议和 AI 听记；
* 钉钉 AI 表格、消息、群聊、邮件、云盘和待办；
* 通讯录、考勤、DING 与审批。

进一步阅读[钉钉办公协作](https://qwenwork.org)。

## 研究与数据 [#研究与数据]

| 能力    | 典型任务                       |
| ----- | -------------------------- |
| 数据分析  | 数据清洗、统计、趋势、排名、异常识别和可视化报告   |
| 电商数据源 | 商品寻源、同款对比、供应链、品类趋势和评论洞察    |
| 多渠道调研 | 跨网页、新闻与内容平台搜索，形成客户、竞品和行业研究 |

进一步阅读[调研、数据与电商](https://qwenwork.org)。

## 执行与自动化 [#执行与自动化]

| 能力         | 使用边界                                 |
| ---------- | ------------------------------------ |
| 定时任务       | 云端统一调度，设备休眠或关机仍会触发；每次触发新建独立对话并消耗积分   |
| 本地连接器任务    | 使用浏览器自动化、本地应用操作等本地连接器时，要求设备唤醒且联网     |
| 网页全栈制作     | Web 与钉钉端支持静态、动态网页和符合套餐的数据库能力；桌面端仍待开放 |
| 浏览器自动化     | 在用户授权和登录后操作网页；遇到验证码、权限墙应暂停           |
| 本地文件操作     | 只在明确授权的目录内批量整理、转换、提取和归档              |
| 垂类工作台      | 通过设计画布、幻灯片大纲和 Markdown 编辑器交付对应产物     |
| IM 与 Hooks | 从聊天平台远程交互，或在桌面 Agent 事件上运行确定性本地检查    |

进一步阅读[创作、开发与自动化](https://qwenwork.org)。

模型选择会影响速度、复杂任务表现和用量，参见[模型选择与用量优化](https://qwenwork.org)。

  企业开通状态、地区、版本、席位、算力和第三方授权都可能影响实际可用范围。涉及外部提交、财务、法律、发票或批量变更时，必须保留人工确认与验收。
