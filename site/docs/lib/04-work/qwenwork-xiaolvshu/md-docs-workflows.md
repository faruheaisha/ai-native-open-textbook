# 办公实战 (/docs/workflows)

本部分不追求“万能提示词”，而是展示如何把模糊需求变成可执行、可检查、可复用的任务。

## 六类常见任务 [#六类常见任务]

常见任务可以分为六类。本站把它们映射到已经包含输入、步骤和验收的教程。

| 最新任务入口  | 包含的典型产物或动作                  | 进入本站教程                                                                                                                                |
| ------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 生成内容    | 可编辑 PPT、Word、Excel          | [文档](https://qwenwork.org/docs/workflows/office-docs)、[演示](https://qwenwork.org/docs/workflows/presentations)、[表格](https://qwenwork.org/docs/workflows/spreadsheets)                              |
| 分析数据    | 本地文件、在线文件、可视化报告、经营异常监控      | [表格分析](https://qwenwork.org/docs/workflows/spreadsheets)、[调研报告](https://qwenwork.org/docs/workflows/research-report)                                                          |
| 钉钉深度集成  | 汇报、知识、会议、AI 表格、消息、邮件、云盘、待办等 | [钉钉办公](https://qwenwork.org/docs/features/dingtalk-work)、[会议与知识](https://qwenwork.org/docs/workflows/meeting-knowledge)                                                       |
| 生成多媒体   | 图片、视频与文字转语音                 | [创作、开发与自动化](https://qwenwork.org/docs/features/creation-automation)                                                                                       |
| 信息调研    | 行业、竞品、社媒、文献和电商选品            | [调研与电商能力](https://qwenwork.org/docs/features/research-commerce)、[调研报告](https://qwenwork.org/docs/workflows/research-report)                                                   |
| 制作网站与应用 | 官网、活动页、看板、后台、小游戏和教学页        | [创作与开发](https://qwenwork.org/docs/features/creation-automation)、[品牌官网](https://qwenwork.org/docs/workflows/cases/brand-website)、[业务系统](https://qwenwork.org/docs/workflows/cases/business-system) |

## 通用任务模板 [#通用任务模板]

```text
目标：我要交付什么，给谁使用。
输入：可使用哪些文件、链接和背景资料。
范围：必须包含什么，不要做什么。
格式：文件类型、结构、语言、篇幅和命名方式。
事实规则：哪些信息必须引用，缺失时如何标记。
验收：用哪些可检查条件判断完成。
安全：哪些操作需要先询问或授权。
```
