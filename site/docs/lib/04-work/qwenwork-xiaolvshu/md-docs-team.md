# 团队与企业版 (/docs/team)

较新公开 FAQ、官方帮助中心权益页和 Web 平台页确认了企业标准版定价、成员与席位、组织共享积分、订阅和资源管理等方向。后台菜单、连接器范围与完整权限矩阵仍应以当前企业后台为准。

  官方帮助中心已公开企业版权益页（定价、席位积分、积分包），较新企业文档也明确管理员不可以查看成员的全部对话；但 SSO 协议和完整权限矩阵仍未在公开文档中稳定确认，本站不补写这些细节。

## 适用场景 [#适用场景]

* 多人共享经过验证的文件、模板和 Skill；
* 统一管理成员、积分和用量边界；
* 通过当前可用的连接器或 MCP 接入业务系统；
* 建立组织内部技能与流程治理；
* 对成员权限、数据边界和外部操作实施统一规则。
