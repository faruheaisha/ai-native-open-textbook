# 医疗与健康服务落地手册 (/docs/playbooks/industries/healthcare)

## 推荐首个试点 [#推荐首个试点]

将已经批准的服务制度整理为员工培训材料、岗位检查清单和常见问题。试点不使用真实患者病历，不涉及诊断、分诊或治疗建议。

## 可用场景 [#可用场景]

* 行政会议纪要、行动项和责任人整理；
* 已批准患者服务材料的通俗化草稿；
* 预约、随访和服务反馈的共性问题归类；
* 排班、物资和服务量的运营报告草稿；
* 制度版本对照、员工培训和题库生成。

## 红线 [#红线]

不独立诊断、分诊、开具处方、修改病历或推荐治疗。真实健康数据必须获得授权并遵守组织隐私规则；临床内容始终由具备资质的人员复核。

团队上线前结合[团队安全与内容治理](https://qwenwork.org/docs/team/security)明确数据留存、访问范围和事故报告流程。
