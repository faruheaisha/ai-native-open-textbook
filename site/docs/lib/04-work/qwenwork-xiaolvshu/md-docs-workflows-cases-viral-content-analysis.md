# 爆款内容拆解 (/docs/workflows/cases/viral-content-analysis)

## 场景与目标 [#场景与目标]

适合内容运营、品牌市场和创作者研究某个话题为什么获得较高互动。目标是形成证据充分的分析底稿，不是机械模仿单篇内容。

## 输入契约 [#输入契约]

| 输入   | 要求              |
| ---- | --------------- |
| 研究主题 | 一个明确话题、品类或用户问题  |
| 时间范围 | 写明开始和结束日期       |
| 平台范围 | 说明要比较的平台及登录权限   |
| 代表样本 | 内容链接、截图或已整理的样本表 |
| 目标受众 | 描述受众与希望支持的业务决策  |

## 执行流程 [#执行流程]

    \### 建立样本池
    扩展关键词，记录标题、发布时间、互动、正文结构和评论样本。

    \### 统一比较口径
    分析开场、叙事、信息密度、视觉包装、情绪和行动引导。

    \### 提取反馈
    区分支持、质疑、追问和未满足需求，不用少量评论代表全部受众。

    \### 形成机会
    输出可复用模式、不可照搬因素和后续选题，并标注证据来源。

```text
围绕 [话题] 分析 [时间范围] 内的代表性内容。
按标题、开场、结构、视觉包装、用户反馈和传播触发点比较。
输出样本表、共性模式、平台差异、不可照搬因素和 10 个后续选题。
每条结论引用样本编号；证据不足时标记“待验证”。
```

## 交付与验收 [#交付与验收]

* 交付样本表、模式清单、评论洞察、选题池和证据索引；
* 每条结论可以回到样本，不把互动相关性写成因果；
* 平台算法、发布时间和账号体量等差异单独说明；
* 标题与表达不得侵犯版权、商标或人格权益。

## 失败处理与复用 [#失败处理与复用]

样本不足时扩大时间范围或缩小问题，不凑结论。跑通后可以保存字段定义、评分规则和验收清单，供[内容雷达](https://qwenwork.org)持续使用。
