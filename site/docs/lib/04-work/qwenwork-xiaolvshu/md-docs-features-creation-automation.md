## 多类型产物与模型 [#多类型产物与模型]

千问办公可以交付文档、PPT、表格、PDF、HTML 报告、网页、代码、图片、音视频等内容。多模态能力包括：

| 模型能力    | 适用场景                 | 示例                                   |
| ------- | -------------------- | ------------------------------------ |
| 图片生成与编辑 | 营销海报、商品图、PPT 配图、视觉创意 | GPT Image、Nano Banana Pro、Midjourney |
| 视频生成与编辑 | 短视频广告、商品展示、品牌宣传片     | Veo、Kling、Wan、Seedance               |
| 语音生成    | 视频配音、广告旁白、有声书、角色音频   | MiniMax Speech                       |
| 音乐生成    | 短视频 BGM、品牌音乐、广告配乐    | MiniMax Music                        |

模型清单更新较快，选择时关注输入限制、生成成本、商用条款和当前账号是否可用，而不是依赖固定名称。

生成多媒体任务包含图片、视频和文字转语音等入口。生成前应提供用途、尺寸或时长、风格、必须出现与禁止出现的元素、授权素材和验收标准；音视频还要确认声音、音乐、人物肖像与商用许可。

## 网页与轻量业务系统 [#网页与轻量业务系统]

可以从自然语言、草图、图片或表格生成响应式网站、数据看板、H5、产品演示和包含增删改查的轻量业务系统。正式上线前至少检查：

较新产品页明确 Web 与钉钉端支持网页全栈制作；符合权益的动态网页可以使用数据库，桌面客户端入口仍待开放。发布、版本、配额和删除规则见[我的网页](https://qwenwork.org)。

制作网站与应用可以覆盖产品官网、活动页面、数据看板、管理后台、小游戏和教学页。它们共享开发流程，但验收重点不同：

| 类型       | 首要验收                   |
| -------- | ---------------------- |
| 产品官网与活动页 | 产品事实、转化路径、表单、SEO 与发布版本 |
| 数据看板     | 指标口径、筛选、空数据、更新时间和权限    |
| 管理后台     | 角色、字段、状态、错误恢复、审计与备份    |
| 小游戏      | 规则、交互、素材版权、性能与异常状态     |
| 教学页      | 学习目标、内容准确性、可访问性与反馈方式   |

* 手机与桌面端布局；
* 表单校验、错误状态和空数据状态；
* 权限、隐私与敏感信息；
* 数据备份与回滚；
* 域名、发布环境和维护责任人。

## 浏览器自动化 [#浏览器自动化]

PC 客户端在用户授权并完成登录后，可以执行点击、输入、筛选、上传、下载、截图和导出。钉内网页端是否支持同样范围，以当前界面为准。遇到验证码、登录失效、支付、权限提升或不可逆提交时，应暂停并交给用户确认。

## 本地文件操作 [#本地文件操作]

PC 客户端适合在用户指定目录内完成批量重命名、内容提取、格式转换、摘要和归档。不要授权整个主目录；先在副本或少量文件上试运行，并提供变更清单。

## 定时运行 [#定时运行]

Web 端可以在关闭浏览器后继续运行云端任务；桌面客户端则可以让任务读取本地目录、浏览器和系统应用，但依赖电脑和客户端保持可运行。开始长期运行前，先确认使用端，再验证时区、设备条件、数据重复、失败处理、通知对象和最大资源消耗。更多信息见[定时任务](https://qwenwork.org)。

## 垂类工作台 [#垂类工作台]

桌面端还提供设计、幻灯片和写作工作台。它们分别通过画布与 Design Plan、大纲驱动的 HTML 幻灯片、Markdown 文件树和编辑器组织交付。需要持续迭代设计、演示或长文时，优先进入[设计、幻灯片与写作工作台](https://qwenwork.org)，不要把所有产物都塞进通用对话。

  发布网页、发送消息、提交表单、覆盖文件、批量写入和开票等动作，应在执行前展示目标、影响范围和最终参数，不能只依赖一条模糊指令。
