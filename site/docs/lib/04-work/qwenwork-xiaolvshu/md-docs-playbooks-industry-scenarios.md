# 更多行业使用场景 (/docs/playbooks/industry-scenarios)

本页只列出可以由千问办公现有办公能力支持的场景：读取授权资料、整理文档与表格、生成草稿、形成检查清单、跟踪公开信息和按计划输出报告。涉及专业判断、生产控制、资金、诊疗、审批与公共权力的环节，必须由具备责任和资质的人完成。

## 场景选择矩阵 [#场景选择矩阵]

| 行业        | 推荐从哪里开始          | 暂不自动化什么          |
| --------- | ---------------- | ---------------- |
| 制造与工业     | 质量资料、工单与交接班报告    | 设备控制、工艺参数与安全联锁   |
| 物流与供应链    | 运单单证、异常清单与客户通知草稿 | 自动改线、放货与费用确认     |
| 银行与保险     | 制度检索、材料预审与案件摘要   | 授信、定价、理赔与投资决策    |
| 医疗与健康服务   | 行政记录、患者材料与运营报表   | 诊断、处方、分诊与治疗建议    |
| 医药与生命科学   | 文献、试验材料与合规文档     | 受试者安全与监管结论       |
| 文旅与酒店     | 行程草案、服务知识与评价分析   | 动态定价、退款与安全承诺     |
| 地产与物业     | 项目资料、工单与巡检报告     | 房价判断、工程签证与费用审批   |
| 能源与公用事业   | 巡检记录、规程检索与服务工单   | 调度控制、停送电与安全许可    |
| 公共服务与社会组织 | 政策材料、办事指南与公众意见整理 | 资格认定、执法、福利与许可决定  |
| 汽车与出行服务   | 售后工单、培训与用户反馈     | 车辆控制、维修安全结论与责任认定 |
| 农业与食品     | 批次记录、供应商材料与市场简报  | 农药处方、食品放行与安全判定   |
| 软件与信息服务   | 需求、知识库、测试与服务复盘   | 未经评审的生产变更与权限操作   |

## 制造与工业 [#制造与工业]

| 使用场景    | 输入              | 交付物与验收                  |
| ------- | --------------- | ----------------------- |
| 质量问题归档  | 检验记录、不良描述、图片和批次 | 缺陷分类、批次影响和待确认原因；不得虚构根因  |
| 工单与交接班  | 维修记录、停机时间和人员备注  | 设备、现象、处理、遗留项与负责人清单      |
| 供应商质量沟通 | 来料记录、标准与历史问题    | 差异表、证据包和沟通草稿；结论由质量负责人确认 |
| 作业指导书整理 | 已批准规程、变更单和培训材料  | 版本对照、步骤摘要和培训题；不修改控制参数   |

推荐试点：选择一个产品线的一种质量报告，使用固定字段整理过去一周记录，由质量工程师逐条核验后再扩大范围。

  千问办公可以整理设备资料和人员记录，但不能替代 PLC、MES、安全联锁或具备认证要求的工业控制系统。

## 物流与供应链 [#物流与供应链]

| 使用场景    | 交付物              | 关键检查              |
| ------- | ---------------- | ----------------- |
| 运输单证整理  | 提单、运单、装箱单和发票字段表  | 单号、主体、数量、单位和日期    |
| 在途异常日报  | 延误、破损、拒收和缺件清单    | 状态来源、更新时间、责任人与下一步 |
| 供应链风险简报 | 供应商、区域、交期与公开动态摘要 | 信息日期、影响范围和未知项     |
| 客户通知草稿  | 延误说明、补充材料请求和处理进展 | 不承诺未经批准的时间、赔偿或责任  |

推荐试点：先处理一种固定格式的运输单证；复杂版式和低置信度字段进入人工队列，不能直接触发放货或结算。

## 银行、证券与保险 [#银行证券与保险]

| 使用场景      | AI 可以做             | 人工关口               |
| --------- | ------------------ | ------------------ |
| 制度与产品知识检索 | 汇总条款、适用范围、版本和待确认问题 | 合规人员确认解释口径         |
| 客户材料预审    | 检查缺失字段、过期文件和主体不一致  | 不判断客户资格或风险等级       |
| 理赔或案件摘要   | 整理时间线、保单条款、材料与争议点  | 理赔、定责和反欺诈结论由专业人员作出 |
| 监管变化跟踪    | 形成变化摘要、影响部门和待办清单   | 法务合规判断与正式报送        |
| 投研底稿整理    | 公开资料、财报数据和观点证据表    | 不自动交易，不给出个性化投资承诺   |

金融数据需要按组织规则脱敏和授权。金额、身份、账户、产品适用性和对客话术都应设置独立复核点。

## 医疗与健康服务 [#医疗与健康服务]

适合从行政与非诊疗场景开始：

* 将授权的会议或访谈材料整理为行政纪要和待办；
* 把患者服务材料改写为不同阅读难度的说明草稿；
* 整理预约、随访和服务反馈中的共性问题；
* 汇总运营数据，形成床位、排班、物资或服务量报告草稿；
* 将已批准制度转为员工培训材料和检查清单。

  不让通用办公 Agent 独立诊断、分诊、开具处方或修改病历。健康数据必须经过授权并遵守隐私要求；所有临床内容由具备资质的人员复核。

## 医药与生命科学 [#医药与生命科学]

| 场景       | 交付物              | 必须保留的记录         |
| -------- | ---------------- | --------------- |
| 文献与指南跟踪  | 检索式、文献表、证据摘要和未知项 | 来源、版本、日期和筛选理由   |
| 临床试验材料盘点 | 文档清单、版本差异和缺失项    | 原文件、版本链和人工确认人   |
| 安全信息初步整理 | 个例材料字段表和待补充信息    | 不做因果性和严重性最终判断   |
| 医学事务内容   | 已批准资料范围内的问答或培训草稿 | 批准版本、适用对象和禁用表述  |
| 监管提交准备   | 目录、交叉引用和一致性检查清单  | 数据出处、上下文用途与责任签署 |

在药研和监管场景中，应先定义 AI 的明确用途、数据治理、验证方法和生命周期记录，不能只凭一次演示进入正式流程。

## 文旅、酒店与会展 [#文旅酒店与会展]

| 场景      | 交付物               | 风险边界              |
| ------- | ----------------- | ----------------- |
| 行程方案草稿  | 日程、交通、预算和备选方案     | 实时价格、开放状态与签证要求需复核 |
| 酒店服务知识  | 多语言 FAQ、服务话术和交接清单 | 不暴露住客身份、房间或行踪     |
| 评价与投诉分析 | 主题、情绪、证据摘录和改进建议   | 不自动承诺退款或补偿        |
| 会展运营    | 嘉宾资料、议程、物料和现场任务表  | 个人信息、肖像与发布授权      |
| 季节性营销   | 内容日历、素材清单和页面草稿    | 版权、价格与活动规则        |

推荐试点：从已确认产品与价格表生成一套多语言服务 FAQ，并由运营与法务共同抽样检查。

## 房地产、园区与物业 [#房地产园区与物业]

* 项目资料盘点：按地块、楼栋、专业、日期和版本整理文件；
* 招商与客户研究：形成企业公开资料、需求假设和沟通准备，不把推断写成客户事实；
* 物业工单分析：分类高频问题、超时工单、重复报修和责任部门；
* 巡检报告：将照片、记录与整改结果整理为清单，安全隐患由专业人员判断；
* 租赁材料：检查合同、证照和交付清单是否齐全，金额与法律条款人工复核；
* 园区月报：汇总服务量、能耗、活动、投诉和重点事项。

工程签证、估价、房价预测、费用审批和安全责任不交给办公 Agent 自动决定。

## 能源与公用事业 [#能源与公用事业]

| 场景      | 推荐输出              | 停止条件              |
| ------- | ----------------- | ----------------- |
| 巡检记录整理  | 异常、位置、时间、证据和待办    | 出现安全、停运或环境风险立即升级  |
| 规程与知识查询 | 原文位置、版本和摘要        | 找不到有效版本时不继续建议     |
| 客户服务工单  | 分类、影响范围、回复草稿和升级路径 | 费用争议、停供或人身安全问题转人工 |
| 项目与检修周报 | 进度、风险、资源与下一步      | 不自动修改检修计划和工作许可    |
| 能耗与排放报告 | 数据口径、趋势、异常和待核验项   | 计量缺失或口径变化时暂停发布    |

千问办公只能支持信息工作，不能接管电力、燃气、供水、矿山或其他关键基础设施的实时调度与控制。

## 公共服务与社会组织 [#公共服务与社会组织]

适合的场景包括：

1. 将已发布政策整理为办事指南、材料清单和内部 FAQ；
2. 对公众意见、问卷和服务反馈做主题归类与证据摘录；
3. 整理会议材料、项目档案、采购文件和执行进展；
4. 为公益项目生成活动方案、志愿者手册和影响报告底稿；
5. 将多语言或无障碍要求纳入服务内容草稿检查；
6. 跟踪公开政策变化并通知责任部门复核。

  资格认定、福利分配、执法、许可、处罚和公共资源配置必须保持法定程序、解释能力、申诉渠道与人工责任，不能由通用办公 Agent 自动作出。

## 汽车、经销与出行服务 [#汽车经销与出行服务]

| 场景     | 交付物                | 人工责任         |
| ------ | ------------------ | ------------ |
| 售后工单整理 | 故障描述、时间线、已做检查和待确认项 | 维修方案与安全结论    |
| 经销商运营  | 线索、活动、库存和服务指标周报    | 客户授权、价格与优惠承诺 |
| 用户反馈分析 | 车型、版本、问题主题和证据摘录    | 召回、质量与责任判断   |
| 技术培训   | 已批准手册的学习路径、题库和速查表  | 版本、适用车型和操作安全 |
| 车队服务   | 维保到期、异常记录和调度沟通草稿   | 驾驶、路径与实时车辆控制 |

## 农业、食品与餐饮供应链 [#农业食品与餐饮供应链]

* 批次与供应商材料：整理产地、批号、检验、交付和缺失文件；
* 市场与采购简报：跟踪公开价格、供给和天气信息，明确查询日期；
* 生产与门店记录：汇总损耗、退货、客诉和异常，不代替食品安全判定；
* 菜单与产品研发：生成创意、成本字段和试验记录模板，配方与过敏原人工确认；
* 培训与检查：将已批准卫生制度转成岗位清单和测验；
* 召回材料准备：整理批次范围、通知对象和沟通草稿，召回决定由负责人执行。

农药、兽药、过敏原、保质期、食品放行与召回都属于高风险事项，必须基于真实检测、法规和责任人判断。

## 软件、SaaS 与信息服务 [#软件saas-与信息服务]

| 场景     | 交付物                | 验收方式              |
| ------ | ------------------ | ----------------- |
| 客户需求整理 | 需求、原话、约束、未决问题和验收条件 | 客户或产品负责人确认        |
| 服务知识库  | 故障现象、排查步骤、版本与升级路径  | 使用真实工单回放测试        |
| 测试设计   | 场景矩阵、边界、异常和回归清单    | 与需求和实际系统逐项对照      |
| 发布准备   | 变更说明、影响范围、检查和回滚步骤  | 研发、测试与运维共同签署      |
| 客户成功复盘 | 使用情况、问题、机会假设和跟进项   | 不把推断写成客户承诺        |
| 安全材料整理 | 问卷草稿、控制证据索引和差距清单   | 安全人员确认，不暴露密钥与架构细节 |

## 如何选择第一个行业试点 [#如何选择第一个行业试点]

给候选场景各打 1—5 分：

| 维度   | 高分条件               |
| ---- | ------------------ |
| 发生频率 | 每周或每天重复出现          |
| 输入稳定 | 文件、字段和来源容易获得       |
| 输出稳定 | 有固定模板或系统字段         |
| 验收容易 | 责任人能在较短时间内检查       |
| 风险可控 | 错误不会直接产生安全、资金或法律后果 |
| 复用价值 | 多人、多项目或多周期可以使用     |

优先选择总分高、风险低的场景。首次上线只使用真实小样本，记录准确率、人工返工时间、异常类型和资源消耗；连续稳定后再扩大数据量或加入定时任务。

  [行业落地手册](https://qwenwork.org/docs/playbooks/industries)为以上 12 个行业分别提供首个试点、执行工作流、任务模板、验收指标与停止条件。
