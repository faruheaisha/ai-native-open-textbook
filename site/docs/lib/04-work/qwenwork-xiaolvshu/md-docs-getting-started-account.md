# 登录与账号准备 (/docs/getting-started/account)

## 先确认使用入口 [#先确认使用入口]

千问办公目前可通过钉钉 PC 端、网页端和 PC 客户端使用。登录方式、可见功能和数据边界取决于使用端、当前账号和组织配置。

| 入口      | 登录流程                                  |
| ------- | ------------------------------------- |
| 钉钉 PC 端 | 将钉钉升级到最新版，在左侧栏打开“千问办公”，按提示绑定手机号       |
| 网页端     | 打开 `qwenwork.cn/app/`，使用钉钉扫码或手机号验证码登录 |
| PC 客户端  | 从 `qwenwork.cn` 下载，安装后按当前登录页提供的方式登录   |

Web 文档说明首次使用手机号登录时会绑定手机号；桌面端安装文档出现过不同登录描述，因此本站不把 Web 登录方式直接外推到客户端。首次使用前仍应确认：

* 当前钉钉或手机号属于正确的个人与组织身份；
* 浏览器允许必要 Cookie；
* 网络环境可以正常打开实际产品入口；
* 企业用户已获得所需功能和数据权限；
* 准备一个不含敏感信息的小任务验证当前端能力。

  Web 首次登录后会根据账号进入个人空间、一个企业空间，或在多个企业空间之间选择。发送文件和连接外部账号前，先核对当前空间，避免把个人资料带入错误组织。

## 登录失败的自查顺序 [#登录失败的自查顺序]

    ### 检查账号输入 [#检查账号输入]

    确认钉钉账号、手机号、所属组织和当前使用端与预期一致。

    ### 排除浏览器问题 [#排除浏览器问题]

    暂时关闭可能拦截 Cookie 或脚本的扩展，或使用无痕窗口重新尝试。

    ### 记录问题信息 [#记录问题信息]

    保存出现问题的时间、页面地址、完整错误文字和截图。

    ### 联系支持 [#联系支持]

    提供脱敏后的账号标识、使用端、所属组织、问题时间、截图和错误信息；不要在公开渠道发送密码或验证码。

## 使用前的安全设置 [#使用前的安全设置]

* 独立账号使用高强度密码，钉钉账号遵循组织的安全策略；
* 企业账号遵循组织的身份与离职管理规则；
* 定期检查已连接的连接器、MCP 和浏览器授权；
* 不再使用的第三方授权应及时断开或撤销；
* 注销账号前先下载需要保留的文件。
