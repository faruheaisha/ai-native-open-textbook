# 个人 IP 打造 (/docs/workflows/cases/personal-brand)

## 场景与目标 [#场景与目标]

适合独立专业人士、设计师和创作者建立清晰的线上专业形象。重点是把已有能力组织成可证实的表达，不是制造夸张人设。

## 输入材料 [#输入材料]

* 个人经历、专业方向和希望服务的人群；
* 代表作品、项目角色、过程和可公开结果；
* 服务范围、合作流程和不提供的服务；
* 可公开的客户评价、证书或媒体记录；
* 现有主页、内容和视觉偏好。

## 执行流程 [#执行流程]

&lt;Mermaid
  chart="flowchart LR
  A[经历与作品] --> B[证据盘点]
  B --> C[一句话定位]
  C --> D[作品与服务结构]
  D --> E[个人品牌页]
  D --> F[内容主题库]
  E --> G[真实受众反馈]
  F --> G
  G --> C"
/>

1. 将事实、能力主张和证据分开整理；
2. 提出两到三个定位方向，说明取舍；
3. 建立作品分类、案例叙述和服务路径；
4. 输出品牌页结构、个人介绍和联系入口；
5. 建立与定位一致的内容主题，而不是追逐所有热点。

## 验收与安全 [#验收与安全]

* 每项能力主张至少有经历、作品或第三方证据支持；
* 明确本人在团队项目中的真实职责；
* 客户名称、评价和数据获得公开授权；
* 不使用无法证明的头衔、收入、排名或客户背书；
* 联系方式只公开必要信息，避免暴露私人账号。
