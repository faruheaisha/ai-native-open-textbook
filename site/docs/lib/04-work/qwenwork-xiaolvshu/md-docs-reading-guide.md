# 阅读与学习指南 (/docs/reading-guide)

这套手册面向三类读者：第一次接触 AI Agent 的个人用户、希望解决具体办公任务的实践者，以及负责团队落地的管理员。

## 新手路线 [#新手路线]

    ### 完成快速开始 [#完成快速开始]

    认识产品、账号、界面、个人网盘和积分，并完成第一个可验收任务。

    ### 掌握三个核心能力 [#掌握三个核心能力]

    依次理解新任务、个人网盘、模型与技能，再了解钉钉办公能力。

    ### 跑通一个办公案例 [#跑通一个办公案例]

    从文档、表格、PPT、调研或会议任务中选择一个真实需求。

    ### 沉淀复用 [#沉淀复用]

    保存经过验证的提示词、输入资料、验收标准和失败回退方法。

## 团队落地路线 [#团队落地路线]

团队负责人不应只关注“能不能做”，还要同步记录：

* 输入资料的来源与权限边界；
* 哪些操作需要人工授权；
* 输出结果由谁验收、如何验收；
* 失败时如何停止、恢复或回退；
* 哪些成果可以保存为 Skill、模板或自动化任务；
* 使用端、套餐、积分和当前功能状态是否满足生产使用要求。

  一个案例只有在输入可控、结果可检查、失败可回退、责任人明确时，才适合进入团队日常工作。
