# 项目内容标准

这个仓库的目标是成为值得收藏的 Dify 中文教程，而不是零散笔记。每篇内容都应该满足以下标准。

## 每篇教程必须包含

- 学习目标。
- 适合读者。
- 前置知识。
- 操作步骤。
- 判断标准。
- 常见错误。
- 练习或交付物。
- 后续阅读。

## 写作要求

- 先解释为什么，再解释怎么做。
- 不默认读者懂大模型、RAG、API、Docker。
- 避免只堆截图位置，应解释每个设置的影响。
- 每个复杂概念至少给一个生活化类比或业务例子。
- 避免“根据情况调整”这种空话，要说明如何判断。

## 示例要求

每个示例都应该说明：

- 业务背景。
- 输入。
- 处理过程。
- 输出。
- 为什么这样设计。
- 可能失败的地方。

## 收藏价值标准

一篇内容值得收藏，通常具备至少两个特点：

- 能被反复查阅。
- 能直接复制改造。
- 能减少试错成本。
- 能帮读者做判断。
- 能覆盖官方文档没有串起来的实践路径。
