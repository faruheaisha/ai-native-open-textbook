# Dify 官方资料入口

Dify 更新速度很快。本仓库会尽量保持内容可用，但涉及界面、部署命令、环境变量、节点能力、模型能力时，请以官方资料为准。

## 官方入口

- Dify Docs: https://docs.dify.ai/
- Dify GitHub: https://github.com/langgenius/dify
- Dify Cloud Studio: https://cloud.dify.ai/
- Dify Marketplace: https://marketplace.dify.ai/

## 官方文档中需要重点阅读的主题

- Key Concepts：理解 Dify App、Workflow、Chatflow、变量和 DSL。
- Build Agent：理解 Agent Prompt、变量、工具、知识库、调试和发布。
- Tools：理解插件工具、OpenAPI 工具、Workflow as Tool、MCP 工具。
- Docker Compose：理解自部署最低配置、启动服务和容器组成。

- 本仓库负责中文学习路径、实战判断、模板和检查清单。
- 当本仓库内容和官方文档不一致时，以官方文档为准。
