# 练习 02：企业 FAQ 知识库

## 目标

构建一个适合客服场景的 FAQ 知识库。

## 任务

1. 准备 20 条常见问题。
2. 按主题整理成文档。
3. 写知识库描述。
4. 创建 Chatflow。
5. 测试资料内、资料外和模糊问题。

## 知识库主题示例

- 账号注册。
- 套餐价格。
- 支付和发票。
- 权限管理。
- 售后流程。
- 常见报错。

## 验收标准

- 至少 15 个资料内问题能正确回答。
- 至少 5 个资料外问题不会编造。
- 模糊问题会追问。
- 敏感问题会建议人工确认。
