# 知识库描述模板

## 通用模板

```text
本知识库包含{{资料范围}}，主要覆盖{{主题一}}、{{主题二}}、{{主题三}}。

适合回答：
1. {{适合问题一}}
2. {{适合问题二}}
3. {{适合问题三}}

不适合回答：
1. {{不包含内容一}}
2. {{不包含内容二}}
3. {{不包含内容三}}

使用边界：
- 如果资料中没有明确依据，请回答无法确认。
- 不要推测未公开政策、价格、承诺或未来计划。
- 遇到冲突信息时，优先提示用户联系人工确认。
```

## 示例：产品 FAQ

```text
本知识库包含 2026 年公开版产品帮助中心资料，主要覆盖账号注册、功能介绍、套餐价格、发票、权限、常见故障和售后流程。

适合回答：
1. 用户如何开始使用产品。
2. 不同套餐的功能差异。
3. 常见报错和解决方法。

不适合回答：
1. 未公开折扣。
2. 内部财务、人事和合同。
3. 未来路线图和未发布功能。

使用边界：
- 如果资料中没有明确依据，请回答“根据当前资料无法确认”。
- 不要编造价格、承诺或政策。
```
