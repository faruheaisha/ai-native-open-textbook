# 练习 01：做一个个人资料问答助手

## 目标

用 Dify 做一个能回答你个人资料或项目资料的助手。

## 准备资料

选择一种资料：

- 个人简历。
- 项目介绍。
- 产品说明。
- 课程大纲。

## 要求

- 创建一个聊天应用。
- 写清楚助手能回答什么。
- 上传一份资料到知识库。
- 至少测试 10 个问题。
- 遇到资料外问题时必须回答无法确认。

## 验收

| 项目 | 是否完成 |
| --- | --- |
| 应用能正常打开 |  |
| 知识库已上传资料 |  |
| 资料内问题答对 |  |
| 资料外问题不编造 |  |
| 输出格式稳定 |  |
