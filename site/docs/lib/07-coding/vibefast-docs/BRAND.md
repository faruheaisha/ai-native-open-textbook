# VibeFast 文档

## Brand Naming

- Brand: `vibefast.app`
- Product: `vibefast.app template`
- Course: `vibefast.app course`
- Keep the concept name `Vibe Coding` unchanged

## Writing Rules

- Use `vibefast.app` for the public brand name
- Use `vibefast.app template` when referring to the paid product
- Use `vibefast.app course` when referring to the free tutorial course
- Do not rename repo URLs, file paths, commands, environment variables, or code identifiers unless the product implementation changes too
