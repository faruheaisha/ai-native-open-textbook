# Phase 12: Multimodal AI

> Models that see, hear, read, and reason across modalities.

## Start this phase on GitHub

**Prerequisites:** Phase 7 Transformers and Phase 4 Computer Vision.

**First lesson:** [Vision Transformer Patch Tokens](https://github.com/rohitg00/ai-engineering-from-scratch/blob/d18b8fe5a913c46011a3b06cb6ebd6a924414fd3/phases/12-multimodal-ai/01-vision-transformer-patch-tokens/README.md)

Run this command from the repository root:

```bash
python3 phases/12-multimodal-ai/01-vision-transformer-patch-tokens/code/main.py
```

Keep the command, exit code, patch grid and sequence lengths, parameter counts,
and one sentence explaining why higher resolution creates more visual tokens.

**Next action:** Change one image or patch size, predict the sequence length,
then continue to [CLIP and Contrastive Pretraining](https://github.com/rohitg00/ai-engineering-from-scratch/blob/d18b8fe5a913c46011a3b06cb6ebd6a924414fd3/phases/12-multimodal-ai/02-clip-contrastive-pretraining/README.md).
