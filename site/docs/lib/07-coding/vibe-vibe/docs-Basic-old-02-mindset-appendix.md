# 附录：心法篇补充材料

本附录为第二章「心法篇」提供补充材料，帮助你更好地理解和应用七个思维模型。

## 附录内容导航

| 附录 | 内容 | 适合谁 |
|-----|------|-------|
| [A. 思维模型速查表](/lib/07-coding/vibe-vibe/docs-Basic-old-02-mindset-appendix-A-templates) | 七个模型的模板汇总，带填写示例 | 需要快速查阅模板的读者 |
| [B. 扩展案例库](/lib/07-coding/vibe-vibe/docs-Basic-old-02-mindset-appendix-B-case-studies) | 6 个真实案例的思维模型应用 | 想看更多实例的读者 |

| [D. 深度参考资源](/lib/07-coding/vibe-vibe/docs-Basic-old-02-mindset-appendix-D-references) | 框架出处、推荐书单、在线资源 | 想深入学习的读者 |

## 如何使用本附录

**场景一：正在做项目，需要快速查模板**
→ 直接翻阅 [A. 思维模型速查表](/lib/07-coding/vibe-vibe/docs-Basic-old-02-mindset-appendix-A-templates)

**场景二：想看看别人是怎么用这些思维模型的**
→ 阅读 [B. 扩展案例库](/lib/07-coding/vibe-vibe/docs-Basic-old-02-mindset-appendix-B-case-studies)

**场景三：感觉自己哪里没想清楚，但不知道问题在哪**
→ 用 [C. 常见误区诊断](/lib/07-coding/vibe-vibe/docs-Basic-old-02-mindset-appendix-C-mistakes) 自检

**场景四：想深入了解这些框架的理论背景**
→ 参考 [D. 深度参考资源](/lib/07-coding/vibe-vibe/docs-Basic-old-02-mindset-appendix-D-references)

## 与正文的关系

本附录是正文的**补充**，而非替代。

- 如果你还没读过正文，建议先阅读第二章各节内容
- 附录提供的是「工具性」材料：模板、案例、误区清单、参考资源
- 正文提供的是「理解性」内容：为什么需要这些思维模型、如何思考

**建议的使用方式**：先读正文理解原理，再用附录辅助实践。
