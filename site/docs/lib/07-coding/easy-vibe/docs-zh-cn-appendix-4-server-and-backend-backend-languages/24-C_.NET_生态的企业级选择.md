| 应用方向 | 细分示例与说明 | 典型应用 / 程序 |
| :--- | :--- | :--- |

| **数据分析** | ML.NET；数据处理；报表系统；商业智能 | ML.NET<br>Power BI<br>数据分析<br>报表系统 |
