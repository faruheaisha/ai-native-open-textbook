## 0. 引言：檔案上傳下載這麼「慢」的動機

想像一下這個場景：你在一個圖片社群上傳了一張 10MB 的高清照片，結果等了半分鐘才傳完；而你的朋友在北京，點擊下載卻只要 2 秒。為什麼同一張檔案，上傳和下載的體驗天差地別？

或者再想想：你的電商網站雙十一舉辦活動，商品詳情頁突然湧入百萬流量，伺服器直接「躺平」。是頻寬不夠？還是架構設計有問題？

這些問題的答案，都藏在**物件儲存**和 **CDN** 這對「黃金搭檔」裡。
