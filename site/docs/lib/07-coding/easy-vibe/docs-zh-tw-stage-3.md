# 高級開發

歡迎來到 **高級開發** 階段！在這裡，你將構建複雜的跨平台應用，掌握微信小程序實戰開發，並探索更深入的 AI 原生應用開發。

## 你將學到什麼

### 核心技能

深入掌握 MCP 協議與 Claude Code 高級技巧，提升開發效率：

- **Claude Code 快速入門核心指南** — 快速掌握 Claude Code 的核心用法，包括安裝、配置、基本操作和實用技巧

- **MCP 與 Claude Code 完全指南** — 掌握 Model Context Protocol (MCP)，擴展 AI 編程工具的能力邊界

- **Claude Code Skills 完全指南** — 將專業知識、工作流程和最佳實踐封裝為可複用的技能包

- **如何讓編碼工具長時間工作** — 學習如何讓 AI 編碼工具處理長時間運行的複雜任務

- **Claude Agent Teams 完全指南** — 讓多個 AI 實例像真正的開發團隊一樣協作

- **Claude Code 超能力：工程級開發** — 使用 Superpowers 框架幫助 AI 編寫工程級代碼

- **Claude Code 工作流最佳實踐** — 掌握 Claude Code 在不同場景下的最佳實踐

- **GitHub Issues 驅動開發實戰** — 用真實倉庫走通需求討論、任務依賴、逐票實現、測試和審查

### 跨平台開發

構建微信小程序、Android 和 iOS 應用，實現跨平台覆蓋：

- **如何為你的應用選擇合適的平台** — 根據用戶場景和需求找到最合適的開發平台

- **如何構建微信小程序** — 從零開始開發微信小程序，掌握核心開發工作流程

- **如何構建微信小程序（包含後端）** — 構建帶有後端支持的完整微信小程序應用

- **如何構建安卓應用** — 使用現代跨平台框架構建 Android 原生應用

- **如何構建 iOS 應用** — 開發並發布 iOS 應用，掌握 iOS 生態的開發規範

- **如何構建 PWA 本地應用** — 將網頁變成真正的應用，支持離線使用和桌面安裝

- **如何構建瀏覽器 AI 助手擴展** — 一鍵總結任意網頁，打造你的瀏覽器 AI 助手

- **如何構建跨平台 Electron 桌面應用** — 構建適用於 Windows、macOS 和 Linux 的語音轉文字桌面應用

- **如何快速構建並鑄造 NFT** — 10 分鐘入門版，從零開始編寫 NFT 智能合約並完成鑄造

- **如何構建 VS Code 擴展** — 構建你的 AI 項目助手，支持多文件問答和自定義快捷鍵

- **如何構建工業級 Qt 桌面應用** — 構建水泵監控 HMI 系統，掌握工業桌面應用開發

### 個人品牌

打造屬於自己的個人網站與技術博客，建立個人影響力：

- **如何構建屬於自己的個人網站與學術博客** — 使用現代化技術棧搭建高性能、高顏值的個人博客

### AI 能力附錄

探索 RAG、LangGraph 等高級 AI 技術，構建複雜的 AI 應用工作流：

- **什麼是 RAG 以及它如何工作** — 深入理解檢索增強生成 (RAG) 的原理及其在 AI 應用中的價值

- **中高級 RAG 與工作流編排 - 以 LangGraph 為例** — 學習使用 LangGraph 編排複雜的 AI 工作流，構建高級 RAG 系統

## 適合人群

- 具備全棧開發經驗，想挑戰更複雜應用的高級開發者
- 希望掌握跨平台開發技術的工程師
- 想要深入了解 AI 原生應用開發的探索者
- 希望建立個人技術品牌的技術博主

## 前置要求

- 完成「初中級開發」階段，或具備全棧開發經驗
- 熟悉前端框架（如 React/Vue）和後端開發
- 了解基本的 AI 概念和 API 使用

準備好挑戰高級開發了嗎？點擊左側導航開始學習吧！
