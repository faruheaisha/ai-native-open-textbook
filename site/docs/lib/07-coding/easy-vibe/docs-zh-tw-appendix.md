# 附錄

歡迎來到 **附錄** 部分！這裡匯集了人工智能基礎與全棧開發的基礎知識，是你學習過程中的重要參考資料庫。

## 內容分類

### 人工智能基礎

了解人工智能的核心概念、發展歷史及前沿技術原理：

- **提示詞工程** — 掌握與 AI 高效對話的技巧，解鎖大模型的潛力

- **人工智能進化史** — 回顧 AI 發展歷程中的關鍵里程碑，理解技術演進脈絡

- **大語言模型** — 深入淺出解析大語言模型（LLM）的工作原理與應用

- **多模態大模型** — 探索能夠處理圖像、音頻等多種數據模態的先進模型

- **AI 繪畫原理** — 揭秘 AI 圖像生成的底層邏輯與技術實現

- **AI 音頻模型** — 了解 AI 在語音合成、識別與音樂生成領域的應用

- **上下文工程** — 學習如何優化上下文管理，提升 AI 任務的長程連貫性

- **Agent 智能體** — 探索具備自主決策與執行能力的 AI 智能體架構

- **AI 能力詞典** — AI 領域常用術語與核心概念的速查手冊

### 前端基礎

夯實前端開發的技術基礎：

- **HTML/CSS/JS 基礎** — 構建 Web 頁面的三大基石，前端開發的入門必修課

- **前端進化史** — 了解前端技術棧的演變歷程，把握技術發展趨勢

- **前端性能優化** — 學習提升網頁加載速度與交互流暢度的關鍵策略

- **Canvas 2D 入門** — 掌握 Canvas 繪圖 API，實現炫酷的圖形與動畫效果

- **URL 到瀏覽器顯示** — 全鏈路解析瀏覽器渲染頁面的完整過程

- **瀏覽器調試器** — 熟練使用開發者工具，高效定位與解決前端問題

### 後端基礎

掌握後端開發的核心概念：

- **後端進化史** — 從單體到微服務，探索後端架構的演進之路

- **後端編程語言** — 對比主流後端語言的特性與適用場景，選擇最佳技術棧

- **數據庫原理** — 理解數據庫核心原理，掌握數據存儲與檢索的藝術

- **系統緩存設計** — 學習緩存策略，提升系統的高並發處理能力

- **消息隊列設計** — 掌握消息隊列在解耦、削峰填谷中的關鍵作用

- **鑒權原理與實戰** — 構建安全的身份認證與權限管理系統

- **埋點設計** — 科學設計數據埋點，為產品決策提供數據支持

- **資料視覺化與儀表板** — 選對圖表、設計儀表板，並避開容易誤導讀者的視覺化陷阱

- **線上運維** — 掌握系統部署、監控與故障排查的運維技能

### 通用技術

軟件開發的基礎知識：

- **API 入門** — API 接口設計與開發的基礎知識

- **IDE 原理** — 了解集成開發環境（IDE）的內部工作機制

- **終端入門** — 掌握命令行終端的基本操作，提升開發效率

- **Git 詳細介紹** — 深入理解 Git 版本控制原理與高級用法

- **計算機網絡** — 網絡協議與通信原理的基礎知識

- **部署與上線** — 應用部署發布的完整流程與最佳實踐

## 使用建議

- 遇到不熟悉的技術概念時，先來這裡尋找解釋
- 建議通讀一遍，建立完整的知識體系
