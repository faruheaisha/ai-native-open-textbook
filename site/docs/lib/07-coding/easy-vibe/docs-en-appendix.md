# Appendix

Welcome to the **Appendix** section! This is a collection of artificial intelligence fundamentals and full-stack development basics, serving as an important reference library during your learning journey.

## Content Categories

### AI Fundamentals

Understand the core concepts, development history, and cutting-edge technical principles of artificial intelligence:

- **Prompt Engineering** — Master the art of efficient dialogue with AI to unlock the potential of large models

- **AI Evolution History** — Review key milestones in AI development and understand the trajectory of technological evolution

- **Large Language Models** — Deep yet accessible explanation of how Large Language Models (LLMs) work and their applications

- **Multimodal Large Models** — Explore advanced models capable of processing multiple data modalities such as images and audio

- **AI Image Generation Principles** — Uncover the underlying logic and technical implementation of AI image generation

- **AI Audio Models** — Understand AI applications in speech synthesis, recognition, and music generation

- **Context Engineering** — Learn how to optimize context management to improve long-range coherence of AI tasks

- **Agent Intelligence** — Explore AI agent architectures with autonomous decision-making and execution capabilities

- **AI Capability Dictionary** — A quick reference handbook for commonly used terms and core concepts in the AI field

### Frontend Basics

Solidify the technical foundation of frontend development:

- **HTML/CSS/JS Basics** — The three pillars of building web pages, essential for frontend development beginners

- **Frontend Evolution History** — Understand the evolution of frontend technology stacks and grasp technology development trends

- **Frontend Performance Optimization** — Learn key strategies to improve webpage loading speed and interaction smoothness

- **Canvas 2D Basics** — Master the Canvas drawing API to achieve cool graphics and animation effects

- **From URL to Browser Display** — Full-chain analysis of the complete process of browser rendering pages

- **Browser DevTools** — Proficiently use developer tools to efficiently locate and solve frontend issues

### Backend Basics

Master the core concepts of backend development:

- **Backend Evolution History** — From monolithic to microservices, exploring the evolution of backend architecture

- **Backend Programming Languages** — Compare the characteristics and applicable scenarios of mainstream backend languages to choose the best technology stack

- **Database Principles** — Understand core database principles and master the art of data storage and retrieval

- **System Cache Design** — Learn caching strategies to improve system high-concurrency processing capabilities

- **Message Queue Design** — Master the key role of message queues in decoupling and peak shaving

- **Authentication Principles & Practice** — Build secure identity authentication and permission management systems

- **Tracking Design** — Scientifically design data tracking to provide data support for product decisions

- **Data Visualization and Dashboards** — Choose the right charts, design dashboards, and avoid misleading visualization traps

- **Online Operations** — Master operations skills for system deployment, monitoring, and troubleshooting

### General Skills

Basic knowledge of software development:

- **API Basics** — Basic knowledge of API interface design and development

- **IDE Principles** — Understand the internal working mechanism of Integrated Development Environments (IDEs)

- **Terminal Basics** — Master basic command-line terminal operations to improve development efficiency

- **Git Detailed Introduction** — Deeply understand Git version control principles and advanced usage

- **Computer Networks** — Basic knowledge of network protocols and communication principles

- **Deployment & Launch** — Complete process and best practices for application deployment and release
