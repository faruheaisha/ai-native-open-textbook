# Advanced Development

Welcome to the **Advanced Development** stage! Here, you will build complex cross-platform applications, master WeChat Mini Program development in practice, and explore deeper AI-native application development.

## What You Will Learn

### Core Skills

Master the MCP protocol and advanced Claude Code techniques in depth to improve development efficiency:

- **Claude Code Quickstart Core Guide** — Quickly master Claude Code

- **MCP and Claude Code Complete Guide** — Master the Model Context Protocol (MCP) and expand the capability boundaries of AI coding tools

- **Claude Code Skills Complete Guide** — Package professional knowledge, workflows, and best practices into reusable skill bundles

- **How to Make Coding Tools Work for a Long Time** — Learn how to let AI coding tools handle long-running, complex tasks

- **Claude Agent Teams Complete Guide** — Let multiple AI instances collaborate like a real development team

- **Claude Code Superpowers for Engineering-Grade Development** — Use the Superpowers framework to help AI write engineering-grade code

- **Claude Code Workflow Best Practices** — Master Claude Code best practices in different scenarios

- **End-to-End Development with GitHub Issues** — Use a real repository to connect requirements, dependencies, implementation, tests, and review

### Cross-Platform Development

Build WeChat Mini Programs, Android and iOS applications, and achieve cross-platform coverage:

- **How to Choose the Right Platform for Your App** — Find the most suitable development platform based on user scenarios and needs

- **How to Build a WeChat Mini Program** — Develop a WeChat Mini Program from scratch and master the core development workflow

- **How to Build a WeChat Mini Program (with Backend)** — Build a complete WeChat Mini Program application with backend support

- **How to Build an Android App** — Use modern cross-platform frameworks to build Android native applications

- **How to Build an iOS App** — Develop and publish iOS applications while mastering iOS ecosystem development standards

- **How to Build a PWA Local App** — Turn a web page into a real app with offline use and desktop installation support

- **How to Build a Browser AI Assistant Extension** — Summarize any web page with one click and build your browser AI assistant

- **How to Build a Cross-Platform Electron Desktop App** — Build a speech-to-text desktop application for Windows, macOS, and Linux

- **How to Quickly Build and Mint an NFT** — A 10-minute starter version to write an NFT smart contract and mint from scratch

- **How to Build a VS Code Extension** — Build your AI project assistant with multi-file Q&A and custom shortcuts

- **How to Build an Industrial-Grade Qt Desktop App** — Build a water-pump monitoring HMI system and master industrial desktop application development

### Personal Brand

Build your own personal website and technical blog to establish personal influence:

- **How to Build Your Own Personal Website and Academic Blog** — Use a modern tech stack to build a high-performance, visually polished personal blog

### AI Capabilities Appendix

Explore advanced AI technologies such as RAG and LangGraph to build complex AI application workflows:

- **What Is RAG and How It Works** — Deeply understand the principles of Retrieval-Augmented Generation (RAG) and its value in AI applications

- **Intermediate and Advanced RAG with Workflow Orchestration - Using LangGraph as an Example** — Learn to use LangGraph to orchestrate complex AI workflows and build advanced RAG systems

## Who Is This For

- Advanced developers with full-stack development experience who want to challenge more complex applications
- Engineers who want to master cross-platform development technologies
- Explorers who want to deeply understand AI-native application development
- Technical bloggers who want to establish their personal technical brand

## Prerequisites

- Complete the "Junior-to-Intermediate Development" stage, or have full-stack development experience
- Be familiar with frontend frameworks (such as React/Vue) and backend development
- Understand basic AI concepts and API usage
