# 进阶开发

欢迎来到 **进阶开发** 阶段！在这里，你将构建复杂跨平台应用，掌握微信小程序实战，探索更深入的 AI 原生应用开发。

## 你将学到什么

### 核心技能

深入掌握 MCP 协议与 Claude Code 高级技巧，提升开发效率：

- **Claude Code 快速上手核心指南** — 快速掌握 Claude Code 的核心用法，包括安装配置、基础操作和实用技巧

- **MCP 与 Claude Code 完全指南** — 掌握 Model Context Protocol (MCP)，扩展 AI 编程工具的能力边界

- **Claude Code Skills 完全指南** — 将专业知识、工作流程和最佳实践打包成可复用技能包

- **如何让 Coding Tools 长时间工作** — 学习如何让 AI 编码工具处理长时间运行的复杂任务

- **Claude Agent Teams 完全指南** — 让多个 AI 实例像真正的开发团队一样协同工作

- **Claude Code Superpowers 工程级开发** — 使用 Superpowers 框架让 AI 写出工程级代码

- **Claude Code 工作流最佳实践** — 掌握 Claude Code 在不同场景下的最佳实践

- **GitHub Issues 驱动开发实战** — 用真实仓库走通需求讨论、任务依赖、逐票实现、测试和审查

### 多平台开发

构建微信小程序、Android 和 iOS 应用，实现跨平台覆盖：

- **如何选择你的应用该开发的平台** — 根据用户场景和需求，找到最适合的开发平台

- **如何构建微信小程序** — 从零开始开发微信小程序，掌握小程序开发的核心流程

- **如何构建微信小程序（包含后端）** — 构建带有后端支持的完整微信小程序应用

- **如何构建安卓程序** — 使用现代跨平台框架构建 Android 原生应用

- **如何构建 iOS 程序** — 开发并发布 iOS 应用，掌握 iOS 生态的开发规范

- **如何开发 PWA 本地应用** — 让网页变成真正的 App，支持离线使用和桌面安装

- **如何开发浏览器 AI 助手插件** — 一键总结任意网页，打造你的浏览器 AI 助手

- **如何开发跨平台 Electron 桌面程序** — 构建语音转文字的桌面应用，支持 Windows、macOS、Linux

- **如何快速开发并铸造 NFT** — 10 分钟上手版，从零开始编写 NFT 智能合约并铸造

- **如何开发 VS Code 插件** — 打造你的 AI 项目助手，支持多文件问答和自定义快捷键

- **如何开发工业级 Qt 桌面应用** — 构建水泵监控 HMI 系统，掌握工业级桌面应用开发

### 个人品牌

打造属于自己的个人网站与技术博客，建立个人影响力：

- **如何构建属于自己的个人网页与学术博客** — 使用现代化技术栈搭建高性能、高颜值的个人博客

### AI 能力附录

探索 RAG、LangGraph 等高级 AI 技术，构建复杂的 AI 应用工作流：

- **什么是 RAG 以及它如何工作** — 深入理解检索增强生成 (RAG) 的原理及其在 AI 应用中的价值

- **中高级 RAG 与工作流编排 - 以 LangGraph 为例** — 学习使用 LangGraph 编排复杂的 AI 工作流，构建高级 RAG 系统

## 适合人群

- 具备全栈开发经验，想挑战更复杂应用的高级开发者
- 希望掌握跨平台开发技术的工程师
- 想要深入了解 AI 原生应用开发的探索者
- 希望建立个人技术品牌的技术博主

## 前置要求

- 完成「初中级开发」阶段，或具备全栈开发经验
- 熟悉前端框架（如 React/Vue）和后端开发
- 了解基本的 AI 概念和 API 使用
