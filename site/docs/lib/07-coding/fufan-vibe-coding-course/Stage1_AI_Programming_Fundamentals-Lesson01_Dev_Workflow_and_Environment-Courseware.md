## Live Session Topic

Vibe Coding - Programming Paradigm and Development Workflow in the AI Era

## Session Outline

### 1. AI Programming Paradigm Introduction
- Traditional Programming vs AI-Assisted Programming
- Vibe Coding Core Philosophy
- Key Elements for Development Efficiency
- AI Programming Tools Ecosystem Overview

### 2. Getting Started with Cursor
- Cursor Core Features Introduction
- In-depth Analysis of Four Q&A Modes
  - Chat: Quick Q&A and code consultation
  - Composer: Multi-file collaborative editing
  - Agent: Autonomous task execution
  - Inline: Real-time code completion
- Keyboard Shortcuts and Workflow Optimization

### 3. Development Environment Setup
- Git Version Control Basics
- GitHub Collaboration Workflow
- Project Initialization and Dependency Management
- Development and Debugging Environment Setup

### 4. Hands-on Project: ChatGPT Clone
- Project Requirements Analysis and Architecture Design
- Frontend Stack: React + Vite + Tailwind CSS
- Backend Stack: FastAPI + SQLite
- OpenAI API Integration
- Server-Sent Events (SSE) Implementation
- Markdown Rendering and Code Highlighting

### 5. Hands-on Project: DeepSeek Chat System
- DeepSeek Reasoning Mode and Chat Mode
- Thinking Process Visualization UI Design
- Phased Development Process
- State Management (Zustand)
- Real-time Streaming Interactive Experience

### 6. AI-Assisted Development Best Practices
- How to Ask Questions Effectively
- Code Review and Optimization Techniques
- Common Issues and Solutions
- Development Path from Prototype to Production
