# Lesson 08: OpenSpec 入门实战

[English](/lib/07-coding/fufan-vibe-coding-course/Stage5_OpenSpec_Applied-Lesson08_OpenSpec_Getting_Started) | 中文

本课介绍 OpenSpec 文档驱动开发方法论，并通过构建个人品牌展示站，完整体验从规范到落地的全流程。

## 主题

- OpenSpec 核心概念与工作流
- 规范文档驱动的 AI 开发实践
- 个人品牌展示站项目：从规范到上线
- 基于 OpenSpec 的变更管理（proposal & tasks）
