# 阶段五：OpenSpec 应用实战

[English](/lib/07-coding/fufan-vibe-coding-course/Stage5_OpenSpec_Applied) | 中文

## 学习目标

掌握 OpenSpec 文档驱动开发方法论：通过结构化规范文档，借助 AI 工作流将需求高效转化为可运行应用。

## 课程列表

- **[Lesson 08](/lib/07-coding/fufan-vibe-coding-course/Stage5_OpenSpec_Applied-Lesson08_OpenSpec_Getting_Started)**：OpenSpec 入门实战
  - OpenSpec 核心概念与工作流
  - 规范文档驱动的 AI 开发实践
  - 从规范到落地的项目实战

- **[Lesson 09](/lib/07-coding/fufan-vibe-coding-course/Stage5_OpenSpec_Applied-Lesson09_OpenSpec_Advanced_Practice)**：OpenSpec 应用进阶
  - 进阶工程化工作流（从 3 命令到 7 命令）
  - 生产级规范文档管理
  - 基于 OpenSpec 的复杂项目编排
