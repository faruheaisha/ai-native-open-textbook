掌握 Spec-Kit——SDD 框架的全新进化：从 OpenSpec 基础迈向可扩展的生产级规范驱动开发。

## 课程列表

- **[Lesson 10](/lib/07-coding/fufan-vibe-coding-course/Stage6_SpecKit_Applied-Lesson10_SpecKit_Getting_Started)**：Spec-Kit 入门实战
  - 从 OpenSpec 到 Spec-Kit：框架演进
  - Spec-Kit 核心概念与 CLI 工作流
  - 项目脚手架搭建与实战

- **[Lesson 11](/lib/07-coding/fufan-vibe-coding-course/Stage6_SpecKit_Applied-Lesson11_SpecKit_Advanced_Practice)**：Spec-Kit 应用进阶
  - Spec-Kit 生产级进阶工作流
  - Agent Hub：端到端全栈 SDD 实战
  - 基于 Spec-Kit 的 Next.js + MCP 集成
