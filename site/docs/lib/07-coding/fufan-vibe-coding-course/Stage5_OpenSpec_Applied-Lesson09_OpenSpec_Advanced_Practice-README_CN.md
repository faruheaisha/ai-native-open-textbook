# Lesson 09: OpenSpec 应用进阶

[English](/lib/07-coding/fufan-vibe-coding-course/Stage5_OpenSpec_Applied-Lesson09_OpenSpec_Advanced_Practice) | 中文

本课将 OpenSpec 从 3 命令入门提升到完整的 7 命令工程化工作流，掌握生产级规范驱动开发的进阶实践。

## 主题

- OpenSpec 进阶工程化工作流（7 命令）
- 生产级规范文档管理
- 基于 OpenSpec 的复杂项目编排
- 规范驱动迭代的真实应用场景
