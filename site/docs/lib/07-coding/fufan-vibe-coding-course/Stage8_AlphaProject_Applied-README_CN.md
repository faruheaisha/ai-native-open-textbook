# 阶段八：AlphaProject 综合项目实战

[English](/lib/07-coding/fufan-vibe-coding-course/Stage8_AlphaProject_Applied) | 中文

## 学习目标

综合项目实战 —— 基于 Vibe Coding 从零到一打造「智能投研（量化交易方向）」真实项目，覆盖市场调研、需求分析、前端 UI 设计、前后端开发、部署上线、运行监控的完整交付链路。

## 课程列表

- **[Lesson 14](/lib/07-coding/fufan-vibe-coding-course/Stage8_AlphaProject_Applied-Lesson14_AlphaProject_Research_PRD)**：AlphaProject 上篇 —— 深度调研 & 产品需求文档生成
  - 行业研究与竞品分析
  - 量化交易领域建模
  - 借助 AI 生成产品需求文档（PRD）

- **[Lesson 15](/lib/07-coding/fufan-vibe-coding-course/Stage8_AlphaProject_Applied-Lesson15_AlphaProject_Architecture_UI)**：AlphaProject 中篇 —— 技术架构选型、UI 设计 & Claude Code 环境配置
  - 前后端技术栈选型
  - 平台前端 UI 设计
  - Claude Code 环境初始化与项目配置

- **[Lesson 16](/lib/07-coding/fufan-vibe-coding-course/Stage8_AlphaProject_Applied-Lesson16_AlphaProject_Testing)**：AlphaProject 下篇 —— 全栈测试体系
  - 后端 / 前端 / 全栈切片 / 全链路四层测试
  - 测试路由策略与测试体系蓝图
  - 通过 `run-feature` 闭环特性工作流
