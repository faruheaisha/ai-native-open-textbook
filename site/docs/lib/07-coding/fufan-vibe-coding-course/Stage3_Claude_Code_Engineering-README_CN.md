# 阶段三：Claude Code 工程化实战

[English](/lib/07-coding/fufan-vibe-coding-course/Stage3_Claude_Code_Engineering) | 中文

## 学习目标

训练“从零创造”能力：借助 AI 工具完成原型设计，并用 Claude Code 推进复杂业务逻辑落地。

## 课程列表

- **[Bonus | 【加餐】](/lib/07-coding/fufan-vibe-coding-course/Stage3_Claude_Code_Engineering-LessonBonus_Claude_Code_Quickstart-README_CN)**：Claude Code 快速入门公开课（建议先学）
- **[Lesson 05](/lib/07-coding/fufan-vibe-coding-course/Stage3_Claude_Code_Engineering-Lesson05_Claude_Code_Architecture-README_CN)**：Claude Code 架构拆解与 CLI
- **[Lesson 06](/lib/07-coding/fufan-vibe-coding-course/Stage3_Claude_Code_Engineering-Lesson06_Multimodal_RAG_System-README_CN)**：多模态 RAG 知识库系统

## 推荐学习路径

建议先学习 **Bonus | 【加餐】** 打好 Claude Code 基础，再进入 Lesson 05 和 Lesson 06。

## 项目实战

- **[Fufan CC Flow](/lib/07-coding/fufan-vibe-coding-course/Stage3_Claude_Code_Engineering-LessonBonus_Claude_Code_Quickstart-fufan-cc-flow-fufan-cc-flow-src)**：Claude Code 快速入门配套实战项目

## 学习成果

能够将模糊需求转化为端到端实现：原型 + 数据模型 + 后端逻辑 + 可运行系统。
