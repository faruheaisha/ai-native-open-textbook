## Delete API Key

&lt;Tip>This endpoint requires an **L2 Header**.&lt;/Tip>

Delete an API key used to authenticate a request.

**HTTP Request:**

```bash  theme={null}
DELETE {clob-endpoint}/auth/api-key
```
