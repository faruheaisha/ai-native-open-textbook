## Get API Keys

&lt;Tip>This endpoint requires an **L2 Header**. &lt;/Tip>

Retrieve all API keys associated with a Polygon address.

**HTTP Request:**

```bash  theme={null}
GET {clob-endpoint}/auth/api-keys
```
