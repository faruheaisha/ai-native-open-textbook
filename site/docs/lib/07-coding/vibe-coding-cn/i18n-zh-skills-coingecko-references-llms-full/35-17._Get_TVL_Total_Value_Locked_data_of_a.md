## 17. Get TVL (Total Value Locked) data of a Coin

* Use [/coins/id](https://docs.coingecko.com/reference/coins-id) endpoint by supplying coin ID.

* Example of responses:

    ```json JSON theme=\{null\}
    "total_value_locked":
    \{
        "btc": 72324,
        "usd": 4591842314
    \}
    ```
