# Frontend Instructions

Read `AGENTS.md` and `agent_docs/code_patterns.md` before UI work.

- Match the design direction in `agent_docs/project_brief.md`.
- Keep components accessible, responsive, and easy to scan.
- Verify user-visible changes in a real browser or device viewport.
- Do not add UI libraries unless `agent_docs/tech_stack.md` approves them.
- For AI UI, test loading, refusal, fallback, and error states.
