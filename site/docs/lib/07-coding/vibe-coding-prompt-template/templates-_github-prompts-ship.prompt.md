# Ship Prompt

Prepare this branch for handoff.

Check:

- `git status --short`
- relevant tests, typecheck, lint, build
- browser/device evidence for UI changes
- AI eval/tool-call evidence for AI or MCP changes
- `REVIEW-CHECKLIST.md`

Return:

- Summary of changes
- Verification evidence
- Unresolved risks
- Rollback notes
- Recommended next step
