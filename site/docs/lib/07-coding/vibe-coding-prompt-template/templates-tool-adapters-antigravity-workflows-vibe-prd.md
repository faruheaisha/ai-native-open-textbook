# /vibe-prd — Step 2: PRD

Step 2 of the vibe-coding workflow: define WHAT to build, WHO it's for, and WHY it matters.

**Read `part2-prd-mvp.md` at the repository root and follow it as the single source of truth.** (If it isn't in this project, ask the user to paste it.)

The essentials:
- Check `docs/research-*.md` first and reuse it (especially its `## Handoff Context` block) instead of re-asking.
- Ask questions ONE at a time and wait for each answer.
- Echo back a verification summary and get a "yes" before generating.
- Write the PRD to `docs/PRD-[AppName]-MVP.md`.

Done? Point the user to the next stage: `/vibe-techdesign`.
