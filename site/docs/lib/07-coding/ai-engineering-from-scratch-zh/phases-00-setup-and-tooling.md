# 阶段 0：环境与工具

> 为之后的所有学习准备好环境。

## 在 GitHub 上开始本阶段

**前置要求：** 无。起步只需要 Git 和 Python 3.11 或更新版本；其他工具只在你的学习路径需要时再安装。

**第一课：** [开发环境](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/00-setup-and-tooling/01-dev-environment/README.md)

从仓库根目录运行这条会识别学习路径的预检命令：

```bash
python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route beginner
```

记录命令、仓库根目录这一工作目录、退出码、必需检查的结果，以及输出的 `Next:` 命令。可选项未通过不算失败。

**下一步：** 修复所有必需项失败，重复运行直到命令以 0 退出，然后继续学习[Git 与协作](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/00-setup-and-tooling/02-git-and-collaboration/README.md)。
