## 在 GitHub 上开始本阶段

**前置要求：** 阶段 7 的 Transformer 与阶段 4 的计算机视觉。

**第一课：** [视觉 Transformer 的图像块 token](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/12-multimodal-ai/01-vision-transformer-patch-tokens/README.md)

从仓库根目录运行：

```bash
python3 phases/12-multimodal-ai/01-vision-transformer-patch-tokens/code/main.py
```

记录命令、退出码、图像块网格和序列长度、参数量，以及一句解释：为什么更高分辨率会产生更多视觉 token。
