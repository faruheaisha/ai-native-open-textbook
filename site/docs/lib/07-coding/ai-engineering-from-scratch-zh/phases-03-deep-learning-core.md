# 阶段 3：深度学习核心

> 从第一性原理理解神经网络。在自己造出一个之前，先不用框架。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 1 的线性代数直觉。建议完成阶段 2，以掌握模型评估相关术语。

**第一课：** [感知机](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/03-deep-learning-core/01-the-perceptron/README.md)

从仓库根目录运行：

```bash
python3 phases/03-deep-learning-core/01-the-perceptron/code/perceptron.py
```

记录命令、退出码、收敛后的逻辑门结果、单层感知机在 XOR 上的失败，以及最终两层网络对 XOR 的预测。

**下一步：** 解释为什么一条线性边界无法解决 XOR，然后继续学习[多层网络与前向传播](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/03-deep-learning-core/02-multi-layer-networks/README.md)。
