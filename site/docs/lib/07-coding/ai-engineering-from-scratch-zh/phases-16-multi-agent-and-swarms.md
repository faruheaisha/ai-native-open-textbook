# 阶段 16：多 Agent 与群体

> 协调、涌现与集体智能。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 14“Agent 工程”。第一个 TypeScript 演示需要 Node.js 20+ 和 `npx`。

**第一课：** [为什么需要多 Agent](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/16-multi-agent-and-swarms/01-why-multi-agent/README.md)

从仓库根目录运行：

```bash
npx --yes tsx phases/16-multi-agent-and-swarms/01-why-multi-agent/code/single_vs_multi.ts
```

记录命令、退出码、单 agent 与多 agent 的 token 和工具调用总量，以及一项足以让额外协调成本值得付出的权衡。

**下一步：** 改变任务，再次比较两种方法，然后继续学习[FIPA-ACL 的传承与言语行为](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/16-multi-agent-and-swarms/02-fipa-acl-heritage/README.md)。
