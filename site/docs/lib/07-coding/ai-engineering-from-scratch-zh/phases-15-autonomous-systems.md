# 阶段 15：自主系统

> 无需人工干预也能安全运行的 agent。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 14 第 01 课“Agent 循环”。

**第一课：** [长周期 agent](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/15-autonomous-systems/01-long-horizon-agents/README.md)

从仓库根目录运行：

```bash
python3 phases/15-autonomous-systems/01-long-horizon-agents/code/main.py
```

记录命令、退出码、时间跨度预测、累积可靠性表，以及在开始长时运行前你会要求的一项运维控制措施。
