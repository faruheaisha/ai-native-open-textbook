# 阶段 5：NLP，从基础到进阶

> 语言是通往智能的接口。掌握其中的每一层。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 2 第 14 课“朴素贝叶斯”。第一课只需 Python 3.11+。

**第一课：** [文本处理](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/05-nlp-foundations-to-advanced/01-text-processing/README.md)

从仓库根目录运行：

```bash
python3 phases/05-nlp-foundations-to-advanced/01-text-processing/code/main.py
```

记录命令、退出码、token 列表、词干、词形还原结果，以及一个词干提取丢失含义而词形还原保住含义的例子。

**下一步：** 加入一个带标点和不规则动词的句子，检查结果，然后继续学习[词袋模型与 TF-IDF](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/05-nlp-foundations-to-advanced/02-bag-of-words-tfidf/README.md)。
