# 阶段 19：综合项目

> 证明你所学的一切。构建可放进作品集的系统。

## 在 GitHub 上开始本阶段

**前置要求：** 选择一个其列出前置阶段都已完成的项目。终端原生 coding agent 项目需要阶段 11、13、14、15 和 17。

**起始项目：** [终端原生 Coding Agent](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/19-capstone-projects/01-terminal-native-coding-agent/README.md)

从仓库根目录运行：

```bash
python3 phases/19-capstone-projects/01-terminal-native-coding-agent/code/main.py
```

记录命令、退出码、最终计划状态、预算总额、轨迹事件，以及在接入真实模型前你会改变的架构决策。

**下一步：** 从[阶段 19 的完整项目列表](/lib/07-coding/ai-engineering-from-scratch-zh/overview#phase-19)选择与你目标相符的综合项目。项目是选择，不是必须按编号完成的顺序；动手前写下验收证据。

用[跨阶段路线图](/lib/07-coding/ai-engineering-from-scratch-zh/ROADMAP)补齐任何前置知识缺口。
