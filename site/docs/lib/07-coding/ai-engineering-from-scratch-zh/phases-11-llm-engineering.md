# 阶段 11：LLM 工程

> 让 LLM 在生产应用中真正干活。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 10 的第 01 至 05 课，或具备等价的分词、数据管线、预训练和扩展知识。

**第一课：** [提示词工程](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/11-llm-engineering/01-prompt-engineering/README.md)

从仓库根目录运行：

```bash
python3 phases/11-llm-engineering/01-prompt-engineering/code/prompt_engineering.py
```

记录命令、退出码、生成的 prompt 元数据、测试结果，以及一次 prompt 改动及其造成的输出差异。该演示使用模拟模型响应，无需 API key。

**下一步：** 解释哪个 prompt 变量改变了行为及其原因，然后继续学习[Few-Shot、Chain-of-Thought 与 Tree-of-Thought](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/11-llm-engineering/02-few-shot-cot/README.md)。
