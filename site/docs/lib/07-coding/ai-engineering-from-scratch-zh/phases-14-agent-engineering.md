# 阶段 14：Agent 工程

> 现代 AI 工程的核心。从第一性原理构建 agent。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 11“LLM 工程”与阶段 13“工具与协议”。

**第一课：** [Agent 循环](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/14-agent-engineering/01-the-agent-loop/README.md)

如果不需要学完整个阶段，可以选择两条聚焦路径：

- [Agent 辅助工程](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/learning-paths/using-coding-agents.json)：涵盖任务界定、仓库证据、harness、隔离、验证、评审和可持续的反馈。
- [产品判断与交付](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/learning-paths/shaping-the-build.json)：涵盖目标、工作流发现、假设、切片、规格、指标、分阶段发布和反馈责任。

从仓库根目录运行：

```bash
python3 phases/14-agent-engineering/01-the-agent-loop/code/main.py
```

记录命令、退出码、思考-行动-观察轨迹、最终答案、回合数，以及终止运行的确切停止条件。

**下一步：** 改变脚本化任务或回合预算，预测效果，然后继续学习[ReWOO 与 Plan-and-Execute](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/14-agent-engineering/02-rewoo-plan-and-execute/README.md)。
