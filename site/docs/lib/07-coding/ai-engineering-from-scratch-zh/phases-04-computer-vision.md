# 阶段 4：计算机视觉

> 从像素到理解，覆盖图像、视频与 3D。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 1 第 12 课“张量运算”以及阶段 3 第 11 课“PyTorch 入门”。第一个演示只需要 NumPy。

**第一课：** [图像基础](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/04-computer-vision/01-image-fundamentals/README.md)

从仓库根目录运行：

```bash
python3 phases/04-computer-vision/01-image-fundamentals/code/main.py
```

记录命令、退出码、HWC 和 CHW 的形状、归一化后的通道统计、像素往返差异和插值粗糙度。该演示生成确定性的合成图像，不使用网络。

**下一步：** 解释 HWC 与 CHW 中哪一条轴发生了变化，然后继续学习[从零实现卷积](https://github.com/fancyboi999/ai-engineering-from-scratch-zh/blob/109181ce68128c1bf27ec20867177007a8bace89/phases/04-computer-vision/02-convolutions-from-scratch/README.md)。
