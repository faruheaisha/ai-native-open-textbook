## 附：看完这 5 篇，你应该注意到的答题模式

所有维度的高手答都有几个共同特征：

| 特征 | 说明 |
|---|---|
| **有判断标准** | 不说“看情况”，而是给出具体的判断维度 |
| **有层次结构** | 回答是分层的（三层防线、三段记忆、三维看板） |
| **有业务场景** | 每个方案都绑定了具体的业务案例 |
| **有工程经验** | 提到了“我们的做法”——不是背的，是做过的 |
| **有权衡意识** | 不只说优点，也说代价和适用边界 |

面试官要的不是“你知道多少概念”，而是“你能不能在真实约束下做出合理决策”。
