# AI Engineering Coach（微软）

The Improve section identifies bad habits and helps you adopt better practices for AI-assisted development.

- [Anti-Patterns](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/anti-patterns/README.md) -- Detectors across four categories with scores and actionable recommendations, backed by an editable rule engine
- [Rule Editor](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/rule-editor/README.md) -- Create, edit, and live-test detection rules as markdown, with form-based or raw-source editing and AI-assisted drafting
- [Rule Playground](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/rule-playground/README.md) -- Interactive REPL for the rule DSL with a field browser, function catalog, and metric list
- [Data Explorer](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/data-explorer/README.md) -- Browse every request/session field, view distributions, and run ad-hoc filters
- [Skill Finder](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/skill-finder/README.md) -- Find repeated prompts and matching community skills
- [Context Health](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/context-health/README.md) -- Evaluate context quality and window management
