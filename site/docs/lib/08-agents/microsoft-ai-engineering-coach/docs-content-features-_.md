# AI Engineering Coach（微软）

AI Engineer Coach organizes its capabilities into three areas that mirror a continuous improvement cycle: **Observe** your usage, **Measure** your output, and **Improve** your practices.

## Observe

- [Dashboard](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/observe/dashboard/README.md) -- At-a-glance practice scores, activity charts, and skill recommendations
- [Timeline](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/observe/timeline/README.md) -- Gantt-style session timeline showing when and how long you worked with AI
- [Coding Moments](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/observe/coding-moments/README.md) -- Screenshot gallery from AI coding sessions with story reels and workspace filtering

## Measure

- [Output](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/measure/output/README.md) -- AI-generated lines of code and model usage breakdown
- [Burndown](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/measure/burndown/README.md) -- Track AI credit consumption against your monthly allowance *(temporarily disabled)*
- [Activity Patterns](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/measure/patterns/README.md) -- Work-hour heatmaps, calendar views, and per-project breakdowns

## Improve

- [Anti-Patterns](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/anti-patterns/README.md) -- Scored detectors for prompt quality, session hygiene, code review, and tool mastery, backed by an editable rule engine
- [Rule Editor](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/rule-editor/README.md) -- Edit, clone, live-test, and AI-draft detection rules written as markdown
- [Rule Playground](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/rule-playground/README.md) -- Interactive REPL for the rule DSL with a field browser, function catalog, and metric list
- [Data Explorer](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/data-explorer/README.md) -- Inspect request/session fields and distributions
- [Skill Finder](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/skill-finder/README.md) -- Discover repeated prompts and matching community skills
- [Context Health](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/improve/context-health/README.md) -- Evaluate context quality and session management efficiency

## Chat

- [Chat Participant](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/features/chat/README.md) -- Conversational access to all coaching data via `@aicoach` in VS Code chat, with slash commands and agentic tool orchestration

## Level Up

- [Learning Center](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/level-up/learning/README.md) -- Personalized quizzes and challenges built from your actual usage
- [Achievements](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/level-up/achievements/README.md) -- XP-based progression with Bronze, Silver, Gold, and Diamond tiers
- [Agentic SDLC](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/level-up/sdlc/README.md) -- Track how you use AI across the full development lifecycle
- [Share](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/level-up/share/README.md) -- Generate shareable stat cards
