# AI Engineering Coach（微软）

The Level Up section turns your AI usage data into a progression system with learning, achievements, and social features.

- [Learning Center](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/level-up/learning/README.md) -- Personalized quizzes and challenges built from your actual usage
- [Achievements](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/level-up/achievements/README.md) -- XP-based progression with tiered badges
- [Agentic SDLC](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/level-up/sdlc/README.md) -- Track AI usage across the software development lifecycle
- [Share](https://github.com/microsoft/AI-Engineering-Coach/blob/18b1a3d16b586c171426c6a407cc5c2dc073556e/level-up/share/README.md) -- Generate shareable stat cards for your team
