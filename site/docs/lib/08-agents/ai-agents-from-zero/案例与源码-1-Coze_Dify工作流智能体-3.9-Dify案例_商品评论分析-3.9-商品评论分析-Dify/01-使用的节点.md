### 使用的节点

| 节点名称         | 类型 / 能力           | 作用                                                                 |
| ---------------- | --------------------- | -------------------------------------------------------------------- |
| **开始**         | 对话流输入            | 接收用户上传的 CSV 文件（商品评论数据），作为后续流程的数据源。      |
| **文档提取器**   | 转换 → 文档提取器     | 解析上传的 CSV 文档，输出可供下游使用的文档对象。                    |
| **提取文本**     | 转化 → 代码执行       | 从文档中抽取原始文本内容，供切分与元数据提取使用。                   |
| **切分元数据**   | 转化 → 代码执行       | 按表格/行结构切分文本，为「提取元数据」准备输入。                    |
| **提取元数据**   | 大模型 + 结构化输出   | 从切分结果中提取商品标题、ASIN、链接、星级统计等字段，得到元数据。   |
| **分析和建议**   | 大模型（如 DeepSeek） | 基于差评内容，从产品本身、店铺服务、物流、价格四维度分析并给出建议。 |
| **正在分析提示** | 直接回复              | 在分析过程中向用户输出「正在分析」等中间提示。                       |
| **汇总生成结果** | 代码节点              | 将元数据与「分析和建议」的文本合并为统一的 `final_result` 结构。     |
| **整理输出**     | 大模型                | 按固定 Markdown 模板（图片、链接、评论数量、分析、建议）整理输出。   |
| **输出最终结果** | 直接回复              | 将整理后的 Markdown 报告返回给用户。                                 |
