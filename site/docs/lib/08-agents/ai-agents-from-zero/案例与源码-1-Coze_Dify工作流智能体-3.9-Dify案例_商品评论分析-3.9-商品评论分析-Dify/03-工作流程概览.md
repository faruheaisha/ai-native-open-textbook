### 工作流程概览

```
开始(input_file: CSV)
    ↓
文档提取器 → 解析上传文档
    ↓
提取文本 → 得到原始文本
    ↓
切分元数据 → 按表结构切分
    ↓
提取元数据 → 大模型抽取 product_title、asin、星级等 → meta_data
    ↓
直接回复「正在分析提示」
    ↓
分析和建议(meta_data 对应评论文本) → 四维度分析 + 选品建议 → analysis_and_suggestion
    ↓
汇总生成结果(代码：meta_data + analysis_and_suggestion) → final_result
    ↓
整理输出(大模型：按 Markdown 模板格式化) → 格式化报告
    ↓
输出最终结果(直接回复) → 返回用户
```
