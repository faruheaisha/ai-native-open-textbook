**输出节点**用于在工作流执行过程中向调用者输出消息，当工作流被 Agent 调用时，执行至输出节点时，该节点的**输出内容**会被传递给 Agent，再被后者打印在用户对话窗口。

![2.产品名称输入提示](/mirror/d8/d809acfa45d52e8893977f83516bd4543d1fcee6.png)

**流式输出**选项打开时，**输出内容**会被“逐字”输出，未打开时会“一次性整体”输出。

##### 3-1.问答节点介绍

创建问答节点

**提问内容**是工作流运行至当前节点时，输出给用户的提示。

**问答节点**有两种回答方式：

1. 直接回答

顾名思义，选择这种方式，节点会将用户输入封装在`USER_RESPONSE`变量中，将提问内容封装在`QUESTION_DATA`变量中。

这种方式下，问答节点相当于一个分支结构，根据用户回答或选择，工作流将执行不同的分支结构。

![3-1.问答节点介绍](/mirror/00/0031cb81129cbbbf55cf893638fbab87be21816c.png)

###### 1.根据名称长度赋值 ifshort

这是个代码节点

![1.根据名称长度赋值 ifshort](/mirror/a2/a26156366efc5dc374477f79536964edd84bfa9c.png)

代码如下：

```python
# 在这里，您可以通过 'args'  获取节点中的输入变量，并通过 'ret' 输出结果
# 'args' 已经被正确地注入到环境中
# 下面是一个示例，首先获取节点的全部输入参数params，其次获取其中参数名为'input'的值：
# params = args.params;
# input = params['input'];
# 下面是一个示例，输出一个包含多种数据类型的 'ret' 对象：
# ret: Output =  { "name": '小明', "hobbies": ["看书", "旅游"] };

async def main(args: Args) -> Output:
    params = args.params
    ifshort = len(params["input"]) <= 9
    # 构建输出对象
    ret: Output = {
        "ifshort": ifshort
    }

    return ret
```

`name`：对应产品名称

Agent 调用工作流时默认会从**现存聊天记录**中选择语义符合的变量作为开始节点的输入参数。

**当聊天记录中没有产品信息时**，我们会要求 Agent 从数据库表**product_list**中提取信息，后者会将查询到的数据**赋值给和字段同名**的工作流输入**参数**。

为了确保参数可以被正确填充，<strong>开始节点</strong>的<strong>参数名必须和</strong>数据库表的产品名称和产品描述<strong>字段名保持一致</strong>。因此，这里必须是<strong>`name`和`description`</strong>。

而 BOT_USER_INPUT 固定为用户和 Agent 交互时输入的文本，和用户变量无关。

  4. 强调用户价值体验
