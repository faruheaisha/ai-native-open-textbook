## 6、平台、部署与模型服务术语

| 术语                 | 一句话解释                           | 解决的问题 / 易混点                                 | 建议先看                                                                                                                                 |
| -------------------- | ------------------------------------ | --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Coze**             | 偏零代码、模板化、快速搭建的 AI 平台 | 更适合快速验证、平台化操作体验                      | [3](/lib/08-agents/ai-agents-from-zero/3-基于Coze_Dify平台的智能体开发)、[5](/lib/08-agents/ai-agents-from-zero/5-Python调用Coze平台工作流)                                                              |
| **Dify**             | 偏开发者和团队协作的 AI 应用平台     | 更适合工作流、知识库、API 调用和私有化部署          | [3](/lib/08-agents/ai-agents-from-zero/3-基于Coze_Dify平台的智能体开发)、[4](/lib/08-agents/ai-agents-from-zero/4-Python调用Dify平台工作流)、[6](/lib/08-agents/ai-agents-from-zero/6-Coze与Dify的Windows平台部署#_4、dify-的安装和启动) |
| **Workflow**         | 固定或半固定的流程编排               | 在 Coze、Dify、LangGraph 中都会出现，但不等于 Agent | [3](/lib/08-agents/ai-agents-from-zero/3-基于Coze_Dify平台的智能体开发)、[4](/lib/08-agents/ai-agents-from-zero/4-Python调用Dify平台工作流)                                                              |
| **API Key**          | 接口调用身份凭证                     | 不要和模型名、Base URL 混成一类                     | [4](/lib/08-agents/ai-agents-from-zero/4-Python调用Dify平台工作流)、[10](/lib/08-agents/ai-agents-from-zero/10-LangChain快速上手与HelloWorld)                                                            |
| **Base URL**         | 接口地址根路径                       | 决定请求发往哪里                                    | [10](/lib/08-agents/ai-agents-from-zero/10-LangChain快速上手与HelloWorld)、[11](/lib/08-agents/ai-agents-from-zero/11-Model-I-O与模型接入)                                                               |
| **Ollama**           | 本地运行大模型的轻量工具             | 适合本地开发、个人学习、小规模本地部署              | [12](/lib/08-agents/ai-agents-from-zero/12-Ollama本地部署与调用)                                                                                                         |
| **Xinference**       | 统一托管多类模型的模型服务平台       | 更适合把 LLM、Embedding、Rerank 统一暴露出来        | [7](/lib/08-agents/ai-agents-from-zero/7-企业级大模型部署)                                                                                                               |
| **推理引擎**         | 让模型高效运行的底层执行层           | 比如 vLLM、SGLang、Ollama、TEI，重点是跑模型        | [7](/lib/08-agents/ai-agents-from-zero/7-企业级大模型部署)                                                                                                               |
| **模型托管平台**     | 统一管理和暴露模型的服务层           | 重点是统一入口、统一治理                            | [7](/lib/08-agents/ai-agents-from-zero/7-企业级大模型部署)                                                                                                               |
| **OpenAI 兼容 API**  | 模仿 OpenAI 风格的接口形态           | 目的是降低接入成本，不代表底层一定是 OpenAI 模型    | [7](/lib/08-agents/ai-agents-from-zero/7-企业级大模型部署)、[11](/lib/08-agents/ai-agents-from-zero/11-Model-I-O与模型接入)                                                                              |
| **Docker**           | 容器化运行环境                       | 重点不是虚拟机，而是可复制地打包和运行服务          | [8](/lib/08-agents/ai-agents-from-zero/8-Docker快速入门与Dify部署排障/index)                                                                                                   |
| **镜像 / Image**     | 容器运行模板                         | 更像应用快照                                        | [8](/lib/08-agents/ai-agents-from-zero/8-Docker快速入门与Dify部署排障/index)                                                                                                   |
| **容器 / Container** | 镜像启动后的运行实例                 | 一个镜像可以启动多个容器                            | [8](/lib/08-agents/ai-agents-from-zero/8-Docker快速入门与Dify部署排障/index)                                                                                                   |
| **数据卷 / Volume**  | 容器外部持久化存储                   | 删容器不一定删数据，关键看卷是否保留                | [8](/lib/08-agents/ai-agents-from-zero/8-Docker快速入门与Dify部署排障/index)                                                                                                   |
| **Docker Compose**   | 多容器服务编排工具                   | 常用于一次性启动数据库、后端、前端等多服务          | [8](/lib/08-agents/ai-agents-from-zero/8-Docker快速入门与Dify部署排障/index)                                                                                                   |
