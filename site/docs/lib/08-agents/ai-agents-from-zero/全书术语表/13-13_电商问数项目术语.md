## 13、电商问数项目术语

| 术语               | 一句话解释                            | 解决的问题 / 易混点                              | 建议先看                                                                                                                     |
| ------------------ | ------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| **电商问数**       | 自然语言查询业务数据的项目            | 用户问业务问题，系统生成并执行 SQL，返回数据结果 | [实战问数 1](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-1-项目概述与数仓基础)、[实战问数 10](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-10-问数智能体总览与工作流骨架)   |
| **数仓**           | 面向分析的数据集合                    | 不等于线上业务库，强调统计分析和指标口径         | [实战问数 1](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-1-项目概述与数仓基础)                                                                      |
| **元数据**         | 描述数据的数据                        | 比如表名、字段名、字段含义、指标定义             | [实战问数 7](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-7-元数据知识库总览与构建入口)                                                              |
| **元数据知识库**   | 保存表、字段、指标等信息的知识库      | 帮模型理解数据库结构，减少生成 SQL 时瞎猜        | [实战问数 7](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-7-元数据知识库总览与构建入口)                                                              |
| **指标**           | 业务统计口径                          | 比如销售额、订单数、转化率，不能只看字段名猜     | [实战问数 7](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-7-元数据知识库总览与构建入口)                                                              |
| **字段取值召回**   | 查找字段里的典型值或候选值            | 帮模型理解用户说的“华北”“女装”等值该映射到哪里   | [实战问数 11](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-11-关键词抽取与多路召回)                                                                  |
| **多路召回**       | 从多个来源同时找上下文                | 字段、指标、字段取值可以并行召回再合并           | [实战问数 11](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-11-关键词抽取与多路召回)、[实战问数 12](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-12-召回信息合并与上下文构建) |
| **SQL 生成上下文** | 给模型生成 SQL 前整理出的材料         | 包括表结构、字段含义、指标口径、过滤条件等       | [实战问数 13](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-13-SQL生成前的信息过滤与补全)                                                             |
| **SQL 校验**       | 执行前检查 SQL 是否安全、合法、可运行 | 避免错误 SQL 或危险 SQL 直接执行                 | [实战问数 14](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-14-SQL生成与执行闭环)                                                                     |
| **SQL 校正**       | 根据校验错误修正 SQL                  | 让查询形成“生成、校验、修正、执行”的闭环         | [实战问数 14](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-14-SQL生成与执行闭环)                                                                     |
| **QueryService**   | 查询服务封装层                        | 把 API、LangGraph 工作流、依赖组装连接起来       | [实战问数 16](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-16-查询接口实现与依赖组装)                                                                |
| **request_id**     | 请求追踪 ID                           | 用来把一次 API 请求的日志串起来                  | [实战问数 17](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-17-前后端联调与日志追踪)                                                                  |
