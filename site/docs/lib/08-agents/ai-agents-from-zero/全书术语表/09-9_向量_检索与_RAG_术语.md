## 9、向量、检索与 RAG 术语

| 术语                   | 一句话解释                           | 解决的问题 / 易混点                              | 建议先看                                                               |
| ---------------------- | ------------------------------------ | ------------------------------------------------ | ---------------------------------------------------------------------- |
| **Embedding**          | 把文本变成向量表示                   | 让语义相近的文本在向量空间里更接近               | [18](/lib/08-agents/ai-agents-from-zero/18-向量数据库与Embedding实战)                                  |
| **向量**               | 文本、图片等内容的数值表示           | 本教程里主要指文本向量                           | [18](/lib/08-agents/ai-agents-from-zero/18-向量数据库与Embedding实战)                                  |
| **向量数据库**         | 存储和检索向量的数据库或能力         | 核心价值是语义相似检索，不是普通 SQL 查询        | [18](/lib/08-agents/ai-agents-from-zero/18-向量数据库与Embedding实战)                                  |
| **Qdrant**             | 向量数据库                           | 电商问数项目中用于向量检索                       | [实战问数 5](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-5-Qdrant与ES快速入门与接入)          |
| **Elasticsearch / ES** | 搜索引擎                             | 更偏全文检索、关键词检索和倒排索引               | [实战问数 5](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-5-Qdrant与ES快速入门与接入)          |
| **相似度**             | 衡量两个向量有多接近                 | 常见有余弦相似度、点积、欧氏距离等               | [18](/lib/08-agents/ai-agents-from-zero/18-向量数据库与Embedding实战)                                  |
| **切块 / Chunking**    | 把长文切成小段                       | 切太大噪声高，切太碎语义不完整                   | [19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)                                            |
| **Chunk Overlap**      | 相邻切块的重叠区域                   | 用于减少切块断裂导致的信息损失                   | [19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)                                            |
| **元数据 / Metadata**  | 附在文档块上的结构信息               | 比如来源、时间、标题、标签，可用于过滤和解释结果 | [18](/lib/08-agents/ai-agents-from-zero/18-向量数据库与Embedding实战)、[19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)     |
| **Retriever**          | 检索器                               | 负责从知识库里找候选片段                         | [19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)                                            |
| **召回**               | 先找出一批候选内容                   | 重点是别漏掉，不等于最终排序最好                 | [18](/lib/08-agents/ai-agents-from-zero/18-向量数据库与Embedding实战)、[19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)     |
| **Rerank / 重排**      | 对召回结果再排序                     | 把真正最有用的片段放到前面                       | [7](/lib/08-agents/ai-agents-from-zero/7-企业级大模型部署)、[19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)                |
| **过滤 / Filter**      | 按元数据条件缩小检索范围             | 常用于租户隔离、时间范围、文档类型限制           | [19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)                                            |
| **RAG**                | 检索增强生成                         | 先查外部资料，再基于资料生成回答                 | [1-3](/lib/08-agents/ai-agents-from-zero/1-3-RAG_微调_续训与智能体选型)、[19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成) |
| **索引阶段**           | 准备知识库的阶段                     | 包括加载文档、切块、向量化、入库                 | [19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)                                            |
| **检索阶段**           | 用户提问时查找候选内容的阶段         | 是运行时行为                                     | [19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)                                            |
| **生成阶段**           | 把检索结果和问题一起交给模型生成答案 | 不只是拼接片段，还要考虑 Prompt 约束             | [19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)                                            |
| **管道式 RAG**         | 检索步骤基本固定的 RAG               | 更好调试，更适合先学清基础链路                   | [19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)                                            |
| **Agent 式 RAG**       | 是否检索、怎么检索由 Agent 决定      | 灵活度更高，但复杂度和不确定性也更高             | [19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)、[21](/lib/08-agents/ai-agents-from-zero/21-Agent智能体)                   |
| **RAGFlow**            | 面向知识库和 RAG 应用的平台          | 深度研搜项目里用于查询企业内部知识库             | [实战深搜 8](/lib/08-agents/ai-agents-from-zero/实战项目-深度研搜-8-项目总览与工程初始化)              |
