## 8、记忆、会话与持久化术语

| 术语                           | 一句话解释                     | 解决的问题 / 易混点                                       | 建议先看                                                                                                           |
| ------------------------------ | ------------------------------ | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **对话历史**                   | 历史消息内容                   | 是内容本身，不等于系统真的会正确利用它                    | [16](/lib/08-agents/ai-agents-from-zero/16-记忆与对话历史_含Redis基础_)                                                                          |
| **记忆 / Memory**              | 系统利用历史信息的能力         | 可以来自对话历史、数据库、向量库或长期存储                | [16](/lib/08-agents/ai-agents-from-zero/16-记忆与对话历史_含Redis基础_)、[25](/lib/08-agents/ai-agents-from-zero/25-LangGraph高级特性)                                           |
| **RunnableWithMessageHistory** | 给 Runnable 包一层消息历史管理 | 适合理解 LangChain 对话历史接入方式                       | [16](/lib/08-agents/ai-agents-from-zero/16-记忆与对话历史_含Redis基础_)                                                                          |
| **Session ID**                 | 会话标识                       | 用于区分不同用户或不同对话                                | [16](/lib/08-agents/ai-agents-from-zero/16-记忆与对话历史_含Redis基础_)                                                                          |
| **Redis**                      | 常用内存数据库                 | 可用于保存会话历史、缓存、队列等                          | [16](/lib/08-agents/ai-agents-from-zero/16-记忆与对话历史_含Redis基础_)                                                                          |
| **Checkpoint**                 | 执行状态快照                   | 让图或 Agent 能恢复到某个执行点                           | [25](/lib/08-agents/ai-agents-from-zero/25-LangGraph高级特性)、[实战深搜 5](/lib/08-agents/ai-agents-from-zero/实战项目-深度研搜-5-人机协作与中断恢复)                             |
| **Checkpointer**               | 保存和读取 checkpoint 的组件   | 保存某条 thread 上的执行状态，是恢复和 Time-Travel 的基础 | [25](/lib/08-agents/ai-agents-from-zero/25-LangGraph高级特性)、[实战深搜 5](/lib/08-agents/ai-agents-from-zero/实战项目-深度研搜-5-人机协作与中断恢复)                             |
| **Store**                      | 跨线程长期存储                 | 不同于单线程 checkpoint，更适合共享长期记忆或业务数据     | [25](/lib/08-agents/ai-agents-from-zero/25-LangGraph高级特性)、[实战深搜 6](/lib/08-agents/ai-agents-from-zero/实战项目-深度研搜-6-长期记忆与Backend存储)                          |
| **thread_id**                  | 执行线程标识                   | 恢复、中断、进度推送都常依赖它                            | [实战深搜 5](/lib/08-agents/ai-agents-from-zero/实战项目-深度研搜-5-人机协作与中断恢复)、[实战深搜 8](/lib/08-agents/ai-agents-from-zero/实战项目-深度研搜-8-项目总览与工程初始化) |
| **session_dir**                | 当前任务的文件目录             | 用来隔离上传文件、Markdown、PDF 等产物                    | [实战深搜 8](/lib/08-agents/ai-agents-from-zero/实战项目-深度研搜-8-项目总览与工程初始化)                                                          |
