## 14、工程化与交付术语

| 术语                      | 一句话解释                         | 解决的问题 / 易混点                                        | 建议先看                                                                                                                   |
| ------------------------- | ---------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **幂等性**                | 重复执行不会产生额外副作用         | 对删除、扣款、发消息、写库这类 Tool 特别重要               | [17](/lib/08-agents/ai-agents-from-zero/17-Tools工具调用)                                                                                                  |
| **副作用**                | 会真实改动外部世界的动作           | 比如发消息、下单、改数据库、写文件                         | [17](/lib/08-agents/ai-agents-from-zero/17-Tools工具调用)                                                                                                  |
| **超时**                  | 超过时间限制就终止等待             | Tool、模型调用、平台工作流都要考虑                         | [11](/lib/08-agents/ai-agents-from-zero/11-Model-I-O与模型接入)、[17](/lib/08-agents/ai-agents-from-zero/17-Tools工具调用)                                                                 |
| **重试**                  | 失败后再次尝试                     | 不是所有错误都值得重试，有副作用场景尤其谨慎               | [17](/lib/08-agents/ai-agents-from-zero/17-Tools工具调用)、[实战深搜 7](/lib/08-agents/ai-agents-from-zero/实战项目-深度研搜-7-中间件机制与Skills配置)                                     |
| **限流**                  | 控制调用频率                       | 既是稳定性问题，也是成本问题                               | [17](/lib/08-agents/ai-agents-from-zero/17-Tools工具调用)                                                                                                  |
| **鉴权 / Authentication** | 确认你是谁                         | 比如 API Key、Token、登录态                                | [4](/lib/08-agents/ai-agents-from-zero/4-Python调用Dify平台工作流)、[20](/lib/08-agents/ai-agents-from-zero/20-MCP模型上下文协议)                                                          |
| **授权 / Authorization**  | 确认你能做什么                     | 不要和鉴权混为一体                                         | [20](/lib/08-agents/ai-agents-from-zero/20-MCP模型上下文协议)                                                                                              |
| **最小权限**              | 只开放完成任务必需的能力           | Tool、MCP、企业部署都很关键                                | [17](/lib/08-agents/ai-agents-from-zero/17-Tools工具调用)、[20](/lib/08-agents/ai-agents-from-zero/20-MCP模型上下文协议)                                                                   |
| **可观测性**              | 让系统运行过程可追踪、可诊断       | 在复杂 Agent 与 LangGraph 场景里尤其重要                   | [25](/lib/08-agents/ai-agents-from-zero/25-LangGraph高级特性)、[实战问数 17](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-17-前后端联调与日志追踪)                                 |
| **日志 / Logging**        | 记录系统执行过程                   | 是调试和运维的第一入口                                     | [实战问数 17](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-17-前后端联调与日志追踪)                                                                |
| **评估闭环**              | 用数据和指标持续验证系统效果       | RAG、Agent、Prompt 都不能只靠主观感觉判断                  | [19](/lib/08-agents/ai-agents-from-zero/19-RAG检索增强生成)、[21](/lib/08-agents/ai-agents-from-zero/21-Agent智能体)                                                                       |
| **FastAPI**               | Python Web API 框架                | 常用于把 AI 能力暴露成 HTTP 接口                           | [实战问数 15](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-15-API接口基础与FastAPI入门)、[实战深搜 8](/lib/08-agents/ai-agents-from-zero/实战项目-深度研搜-8-项目总览与工程初始化) |
| **SSE**                   | Server-Sent Events                 | 适合服务端向浏览器单向推送流式结果                         | [实战问数 15](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-15-API接口基础与FastAPI入门)                                                            |
| **WebSocket**             | 双向实时通信协议                   | 适合前后端实时交互和进度推送                               | [实战深搜 8](/lib/08-agents/ai-agents-from-zero/实战项目-深度研搜-8-项目总览与工程初始化)                                                                  |
| **ContextVar**            | Python 协程级上下文变量            | 适合 FastAPI 异步请求中隔离 request_id、thread_id 等上下文 | [实战问数 17](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-17-前后端联调与日志追踪)、[实战深搜 8](/lib/08-agents/ai-agents-from-zero/实战项目-深度研搜-8-项目总览与工程初始化)     |
| **依赖注入**              | 把依赖对象交给框架或服务统一组装   | 降低模块耦合，便于测试和替换                               | [实战问数 16](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-16-查询接口实现与依赖组装)                                                              |
| **生命周期事件**          | 应用启动和关闭时的初始化或清理逻辑 | 常用于创建连接池、加载资源、关闭连接                       | [实战问数 15](/lib/08-agents/ai-agents-from-zero/实战项目-电商问数-15-API接口基础与FastAPI入门)                                                            |
