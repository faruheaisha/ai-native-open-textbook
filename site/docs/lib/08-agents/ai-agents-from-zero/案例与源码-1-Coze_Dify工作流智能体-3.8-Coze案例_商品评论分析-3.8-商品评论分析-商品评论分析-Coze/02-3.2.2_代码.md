```python
async def main(args: Args) -> Output:
    params = args.params
    url = params["input"]
    isTure = '.csv' in url
    ret: Output = {
        "key0": isTure,
    }
    return ret
```

该节点用于合法性校验，逻辑是判断链接中是否包含 `.csv` 后缀。
