### 2.4 代码节点

> 目标：提取头条新闻中的 URL

![行业调研 PPT 案例操作截图](/mirror/8a/8a2e2824a660dcf9b256ea15b9d2fcd4b530b903.png)

代码如下：

```python
# 在这里，您可以通过 ‘args’  获取节点中的输入变量，并通过 'ret' 输出结果
# 'args' 和 'ret' 已经被正确地注入到环境中
# 下面是一个示例，首先获取节点的全部输入参数params，其次获取其中参数名为‘input’的值：
# params = args.params;
# input = params.input;
# 下面是一个示例，输出一个包含多种数据类型的 'ret' 对象：
# ret: Output =  { "name": ‘小明’, "hobbies": [“看书”, “旅游”] };

async def main(args: Args) -> Output:
    params = args.params

    url_list = [i['url'] for i in params["input"]]
    # 构建输出对象
    ret: Output = {
        "url_list": url_list
    }
    return ret
```

**本段用到的 Python 用法说明：**

核心是这一行——**列表推导式**（List Comprehension）：

```python
url_list = [i['url'] for i in params["input"]]
```

- `params["input"]`：上一步头条搜索返回的新闻列表，每一项是一条新闻（字典），里面有 `title`、`url`、`summary` 等键。
- `for i in params["input"]`：依次遍历列表里的每条新闻，`i` 就是当前这条新闻（一个字典）。
- `i['url']`：从字典 `i` 里取出键为 `"url"` 的值，即该条新闻的链接地址。
- `[ ... for ... ]`：对每次循环得到的 `i['url']` 收集成一个新列表，整体赋值给 `url_list`。

一句话：**从「新闻列表」里把每条新闻的 `url` 抽出来，组成一个「链接列表」**。等价于用 for 循环写：

```python
url_list = []
for i in params["input"]:
    url_list.append(i['url'])
```

### 2.8 代码 1 节点

因为上一个环节会检索到多个满足的 ppt 模板，这里我们通过代码**只取第一个模板的 id**（即 `data.items[0]['id']`），供后续生成 PPT 时使用。

所以，在主题节点之后，添加新的代码节点。

![行业调研 PPT 案例操作截图](/mirror/60/6076a250ea4e59769d8c88ae7d669c263d2c8b39.png)

![行业调研 PPT 案例操作截图](/mirror/48/4862d5ae81edbcbcc11a6f1d5998173cee988201.png)

代码如下：

```python
async def main(args: Args) -> Output:
    params = args.params
    # 构建输出对象
    ret: Output = {
        "mode_id": params['input'][0]['id']
    }
    return ret
```

### 2.9 generate_presentation 节点

**怎么知道 outline 需要什么格式？**

iSlide - 插件 - 扣子
https://www.coze.cn/store/plugin/7525010179218489379

- **看插件定义**：在 Coze 里添加「iSlide - generate_presentation」节点后，点击该节点，在 **outline** 参数的说明里会看到接口要求的 schema（例如：顶层要有 `title`、`subtitle`，以及 `sections` 数组，每个 section 里有 `contents`，再往下是 `items` 等）。插件文档或参数描述就是格式的权威来源。

![行业调研 PPT 案例操作截图](/mirror/8d/8dbf6386befaeed1eeb2edfd5b7d3bdc0ad8bfb3.png)
