# 质量检查清单

在交付笔记本之前：

- 至少从头到尾运行一次（或在环境允许的范围内尽可能运行）。
- 确保前面的单元格设置了所有必需的状态；避免来自先前运行的隐藏状态。
- 保持输出整洁。当简短摘要足够时，避免产生巨量输出。
- 优先使用小表格、关键指标或简短输出。
- 保持叙述易于浏览。使用标题和简短要点，避免长段落。
- 仅在必要时留下有帮助的待办事项，并对其进行清晰标注。
- 如果无法执行，请指出风险以及如何在本地进行验证。
