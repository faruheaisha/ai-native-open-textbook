## 🌱 开始学习

本课程涵盖构建人工智能代理的基础知识。每节课讲述一个主题，欢迎随意开始学习！

本课程支持多语言。请查看我们的[可用语言](#-multi-language-support)。

如果这是您首次使用生成式人工智能模型构建项目，请查看我们的[生成式人工智能初学者课程](https://aka.ms/genai-beginners)，其中包括 21 个关于GenAI构建的课程。

别忘了为本仓库[点星标（🌟）](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst)并[派生本仓库](https://github.com/microsoft/ai-agents-for-beginners/fork)以运行代码。

### 认识其他学习者，获取答疑支持

如果在构建人工智能代理时遇到困难或有疑问，请加入我们专门的 Discord 频道：[Microsoft Foundry Discord](https://aka.ms/ai-agents/discord)。

### 您需要准备的内容

课程中的每节课都包含代码示例，位于 code_samples 文件夹。您可以[派生本仓库](https://github.com/microsoft/ai-agents-for-beginners/fork)来创建自己的副本。

这些练习中的代码示例使用 Microsoft Agent Framework 及 Microsoft Foundry Agent Service V2：

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - 需要 Azure 账号

本课程使用以下微软的人工智能代理框架和服务：

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

部分代码示例还支持兼容 OpenAI 的替代提供商，如提供大上下文模型（高达 204K 令牌）的 [MiniMax](https://platform.minimaxi.com/)。具体配置信息请参阅[课程设置](/lib/08-agents/microsoft-ai-agents-for-beginners/translations-zh-CN-00-course-setup-README)。

想了解本课程代码运行的详细信息，请访问[课程设置](/lib/08-agents/microsoft-ai-agents-for-beginners/translations-zh-CN-00-course-setup-README)。
