# Quick Self-Check (ungraded) [[quiz2]] 


What?! Another Quiz? We know, we know, ... 😅 But this short, ungraded quiz is here to **help you reinforce key concepts you've just learned**.

This quiz covers Large Language Models (LLMs), message systems, and tools; essential components for understanding and building AI agents.

### Q1: Which of the following best describes an AI tool?


**选项**

- A. A process that only generates text responses
- B. An executable process or external API that allows agents to perform specific tasks and interact with external environments
- C. A feature that stores agent conversations

**答案解析**

- **A**
- **B（正确答案）** — Tools are executable functions that agents can use to perform specific tasks and interact with external environments.
- **C**


---

### Q2: How do AI agents use tools as a form of "acting" in an environment?


**选项**

- A. By passively waiting for user instructions
- B. By only using pre-programmed responses
- C. By asking the LLM to generate tool invocation code when appropriate and running tools on behalf of the model

**答案解析**

- **A**
- **B**
- **C（正确答案）** — Agents can invoke tools and use reasoning to plan and re-plan based on the information gained.
