Best for people who want to shape Prompthon Agentic Labs by adding, revising,
curating, building, or maintaining handbook material.

Start with [Start Here](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/contributor-kit/start-here/README.md) for the contributor path,
then use [Contributing](https://github.com/Prompthon-IO/agent-systems-handbook/blob/main/CONTRIBUTING.md) for the public workflow,

[Prompthon Agentic Labs Structure](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/contributor-kit/lab-structure/README.md) for the
repo
map and reference boundary.
