# Agent Systems Handbook（智能体系统手册）

import SupportCTA from "/snippets/support-cta.mdx";

Best for people who want a high-level understanding of agent systems without
committing to a strict build sequence.

## Recommended reads

- [The Agent Systems](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/foundations/the-agent-system/README.md): start

  with the core definition and operating loop.
- [History Of Agent Ideas](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/foundations/history-of-agent-ideas/README.md): use the
  short historical arc to understand why the field looks the way it does.
- [Agents Vs Workflows](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/foundations/agents-vs-workflows/README.md): clarify the
  boundary between deterministic orchestration and bounded autonomy.
- [Deep Research Agents](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/case-studies/deep-research-agents/README.md): see how one
  of the clearest modern agent products is structured.
- [Ecosystem](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/ecosystem/index/README.md): compare the major tools, platforms, and
  market categories.
- [Radar](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/radar/index/README.md): track what is changing quickly across the field.

## Optional deeper dives

- [Agent Memory And Retrieval](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/patterns/agent-memory-and-retrieval/README.md): go
  here if you want a practical mental model for memory, retrieval, and
  artifacts.
- [Reasoning And Control Patterns](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/patterns/reasoning-and-control-patterns/README.md):
  go here if you want the control-loop view of agent behavior.
- [LLM Foundations For Agent Systems](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/foundations/llm-foundations-for-agent-systems/README.md):
  go here if you want the minimum model literacy behind modern agents.
- [Context Engineering](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/systems/context-engineering/README.md): go here if you
  want the production-minded view of how context is managed over time.
- [AI Education Policy To Practice](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/contributor-kit/reference-notes/ai-education-policy-to-practice/README.md):
  go here if you want a product-agnostic example of turning AI policy language
  into a practical learning activity.

## What this guide optimizes for

- Clear orientation without requiring a fixed sequence
- High-level understanding before implementation detail
- A broad view of the field and its moving parts
