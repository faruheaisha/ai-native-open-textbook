# Ecosystem

This lane is the living comparison layer for tools, products, frameworks, and
infrastructure across the agent market.

## What belongs here

- Model ecosystems
- Framework comparisons
- Agent platforms and hosted builders
- Agent infrastructure
- Evaluation tooling
- Browser and computer-use stacks
- Coding agent tools

## Editorial intent

Organize this lane by topic first, not by region or vendor. Each comparison
page should include global coverage, Chinese ecosystem coverage, open-source
options, hosted options, and clear guidance on who should care.

## Current pages

- [Model Ecosystem Map](/lib/08-agents/agent-systems-handbook/ecosystem-model-ecosystem-map): a beginner map of model
  providers, model categories, access patterns, and selection tradeoffs.
- [Agent Frameworks](/lib/08-agents/agent-systems-handbook/ecosystem-agent-frameworks): a topic-first comparison of

  when to choose builder-first, platform-first, or automation-first surfaces.
- [AI Builder Tools Directory](/lib/08-agents/agent-systems-handbook/ecosystem-ai-builder-tools-directory): a beginner
  directory for choosing assistant, automation, app-builder, and template tools
  by outcome.
