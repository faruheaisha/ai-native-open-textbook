# Agent Systems Handbook（智能体系统手册）

import SupportCTA from "/snippets/support-cta.mdx";

This directory turns the repository into a path-first lab instead of a
single chapter stream.

## Primary guides

- [Explorer](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/reading-paths/explorer/README.md): for people who want a high-level understanding and a
  recommended set of pages rather than a strict sequence.
- [Practitioner](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/reading-paths/practitioner/README.md): for people who want to use agent tools and
  skills in real work without becoming professional agent builders.
- [Builder](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/reading-paths/builder/README.md): for engineers who want a linear path into
  professional agent design and implementation.
- [Contributor](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/reading-paths/contributor/README.md): for people who want to edit, curate, or
  extend the repository itself.

## Shared supporting guides

- [Environment Setup](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/reading-paths/environment-setup/README.md): shared local setup and starter
  verification for practitioner, builder, and contributor paths.
- [Sample Projects](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/reading-paths/sample-projects/README.md): the public index of current
  repo-owned starter projects.
- [Practitioner Skills](https://github.com/Prompthon-IO/agent-systems-handbook/blob/5b71cfa598701a34834f33b42be5f8a422138a3c/skills/README.md): installable Codex skill packages for local-first,
  repeatable workflows.
