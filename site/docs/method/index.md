# 关于本站

本站是一份开放课程与官方文献的编排索引：把散落在各个仓库与站点里的高质量材料，按学习路径组织成一条可以读下去的顺序。

## 正文从哪里来

| 环节 | 做法 |
|---|---|
| 正文 | 与上游快照逐字一致 |
| 链接 | 同课程内文档走站内，其余指回上游原文 |
| 图片 | 指向上游仓库在锚定版本的原图 |
| 可见文本 | 仅去掉仓库门面（徽章、居中 logo、许可与引用尾巴）|
| 翻译 | 英文材料附逐段中文释义，默认收起，不替换原文 |

## 分类口径

| 维度 | 取值 |
|---|---|
| 学习路径 | 8 条，代表知识依赖顺序 |
| 分类 | 系统课程 / 工程手册与指南 / 实践案例与产品 / 源码与实现研读 / 技能、配置与模板 / 速查清单与索引 / 官方文献（外链原文） |
| 分级 | ★★★ 主线 / ★★ 进阶 / ★ 参考 |
| 许可 | 可转载 / 限非商用 / 仅引用（仅引用者只提供外链与索引）|
