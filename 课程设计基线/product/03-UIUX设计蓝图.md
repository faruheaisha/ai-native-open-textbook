## 1. 设计定位

### 1.1 一句话

**看起来像一本可以点的书，而不是一个可以读的产品。**

### 1.2 三条准则

| 准则 | 含义 | 具体取舍 |
|---|---|---|
| 印刷优先，屏幕增强 | 版式先按印刷逻辑成立，交互只是叠加 | 先定行宽、页边、编号、脚注，再定组件 |
| 结构线，不用图标 | 用线宽、线型、方块填充表达状态 | 不引入图标字体；光标、箭头、提示一律由 CSS 与内联 SVG 生成 |
| 颜色克制，语义唯一 | 颜色只承担一种语义 | 蓝=可交互；三色=内容寿命；不新增第四种语义色 |

### 1.3 与同类站点的差异

同类 AI 教程站点的共同视觉特征是：大面积渐变、圆角卡片、发光边框、图标堆叠。本项目的差异化是**出版物质感**——细线、留白、编号、页边锚点、等宽数字。这不是审美偏好，而是功能选择：版式越像正式出版物，读者越会以阅读而非浏览的方式对待内容。

## 2. 视觉语言

### 2.1 字体

| 用途 | 字体栈 | 说明 |
|---|---|---|
| 正文 | 系统无衬线（`-apple-system`, `PingFang SC`, `Microsoft YaHei`, `Noto Sans SC`） | 长文可读性优先；不引入 Web 字体，避免首屏阻塞 |
| 标题 | 衬线（`Georgia`, `Songti SC`, `Noto Serif SC`, `SimSun`, `serif`） | **本版本最大胆的一处改动**：标题用衬线，形成教科书感 |
| 编号 / 日期 / ID / 统计 | 等宽（`ui-monospace`, `SFMono-Regular`, `Cascadia Mono`, `Consolas`） | 学术出版物的数字惯例；同时让"哪些是元数据"一眼可辨 |
| 代码 | 等宽，与编号同族 | 语法高亮沿用构建器主题 |

风险与回退：若中文衬线在目标平台渲染不佳，回退顺序已给出；标题退化为系统无衬线不破坏布局，只损失风格。

### 2.2 字号与行宽

| 元素 | 字号 / 行高 | 约束 |
|---|---|---|
| 正文 | 17px / 1.85 | 行宽 680px，约 38–42 个中文字 |
| H1（章标题） | 34–38px / 1.3 | 与章节号同排或换行 |
| H2 | 23–25px / 1.4 | 左侧 3px 寿命色条 |
| H3 | 18–19px / 1.5 | 不使用色条 |
| 表格 | 14.5px / 1.6 | 表头用等宽小字 |
| 元信息 | 13px / 1.6 | 等宽或半等宽 |
| 引言（章首问题） | 19px / 1.75 | 左缩进 20px，左侧细线 |

### 2.3 色彩

| Token | 浅色 | 深色 | 语义 |
|---|---|---|---|
| Ink | `#14161A` | `#E8E6E1` | 正文 |
| Paper | `#F6F5F1` | `#16171A` | 页面底色（深色为暖黑，非纯黑） |
| Surface | `#FFFFFF` | `#1D1F23` | 卡片与浮层 |
| Line | `#E2E0DA` | `#2C2F34` | 分隔线 |
| Accent | `#1B4DE4` | `#7B9BFF` | 只用于可交互元素 |
| Stable | `#2F7D4F` | 同左 | 稳定核心 |
| Current | `#B07714` | 同左 | 当前实践 |
| Frontier | `#6B3FD4` | 同左 | 前沿快照 |

规则：大面积不出现饱和度高于 Accent 的色块；寿命三色只以 3px 线、方块、文字出现。

### 2.4 结构与留白

- 分隔用 1px 线，不用阴影；浮层允许极轻投影以表达层级。
- 圆角统一：卡片 8px，按钮 6px，标记 3px。
- 段间距 ≥ 1.1em；节间距 ≥ 2.4em。
- 页面纵向节奏：章首块 56px 上留白，节与节之间 44px。

设计决定：
- **删除**价值主张条、内容统计条、"按任务进入"、"终点展示"、"行动号召"五个区块。它们属于产品落地页语言；对应信息已由卷卡与方法链承担。

## 5. 创新交互的视觉方案

### 5.1 页边证据锚点（IX-01）

纸质教材用页边批注承载补充信息，这里沿用同一逻辑。

- 位置：正文栏右侧 160px 页边带，与触发句**垂直对齐**。
- 形态：12×12 的空心方块 + 4px 内点，命中时为实心；悬停/聚焦时显示一行等宽小字 `CLM-08-01-03`。
- 多个锚点相邻时自动错开 24px，避免重叠。
- ≥2560px 视口下，页边带加宽至 200px，锚点可显示两行摘要。
- <1440px 时页边带取消，锚点回落为句末 `▤`（不消失，只换位置）。

### 5.2 对照阅读（IX-06）

- 双栏等宽，中缝为 1px 线。
- 差异行左侧 3px 竖线 + 极浅底色（对比度 < 8%，不干扰阅读）。
- 顶部控制：`并排 / 叠放 / 只看差异`。
- 只看差异时，相同行折叠为一行 `⋯ 3 行相同`，点击展开。
- 两侧同步滚动由行号映射驱动，不用百分比，避免内容长度不等时错位。

### 5.3 选型决策树（IX-07）

单栏卡片式问答，一次只问一个问题。

```
┌────────────────────────────────────────┐
│ 问题 2 / 5                             │
│ 系统能否获得可靠的反馈信号？             │
│                                        │
│  ○ 能，反馈直接来自环境（可验证）         │
│  ○ 能，但反馈来自模型自评                │
│  ○ 不能                                │
│                                        │
│ 进度 ●●○○○            [ 上一步 ]        │
└────────────────────────────────────────┘
```

结果页输出**结论卡**，包含：判定结论、所依据的每一步选择、对应章节与案例链接、复制按钮。结论卡的版式与 PDF 中的同类表格保持一致。

### 5.4 系统卡编辑器（IX-08）

- 左字段表单，右实时预览（YAML 文本）。
- 校验以**下划线 + 一行说明**呈现，不用红色错误弹窗。校验只提示不阻断。
- 未填字段保持空值，导出时保留字段名——**空字段本身就是学习者需要看到的信息**。
- 导出按钮两个：`复制 YAML`、`下载 .md`。

### 5.5 双轨开关（IX-09）

放在阅读页右上角，不属于主导航（它是一次性设置）。

```
显示： 正文 ｜ 正文 + 代码与技术细节        [ 当前：正文 ]
```

开启隐藏后，代码块折叠为一条 40px 高的灰线，左侧写"代码已隐藏（点击展开）"，右侧显示行数。YAML/JSON 产物模板不折叠。

### 5.6 寿命色条（IX-03）

- H2 左侧 3px，高度 = 标题行高，不延伸到段落。
- 悬停显示一行说明：`稳定核心：长期知识，进入 PDF 正文`。
- 色条不是装饰，它替代了"这段内容有多可信"这句话。

## 6. 动效

| 场景 | 时长 | 缓动 | 说明 |
|---|---|---|---|
| 抽屉滑入 / 滑出 | 180ms | `ease` | 只做 `translateX` |
| 浮层遮罩 | 160ms | `ease` | 只做 `opacity` |
| 回放切换步骤 | 120ms | `ease` | 高亮行底色淡入 |
| 悬停反馈 | 120ms | `ease` | 边框颜色 |
| 页面加载 | 无 | — | 不做入场动画 |

禁止：缩放弹跳、视差、滚动触发动画、自动播放、超过 200ms 的过渡。
`prefers-reduced-motion: reduce` 时全部时长归零。

## 7. 深浅色

- **浅色**：纸色 `#F6F5F1`，正文近黑。定位是"白天读的书"。
- **深色**：暖黑 `#16171A`，正文 `#E8E6E1`。定位是"夜里的台灯"，**不是把浅色反相**。具体规则：底色不用纯黑（避免与代码高亮冲突），寿命三色在深色下提高明度 12%，Accent 提亮为 `#7B9BFF`。
- 代码块在深色下使用独立的暗色主题，不跟随页面反相。
- 图片与 SVG 在深色下不反相；涉及反向色的图单独提供深色版本。

## 8. 打印与 PDF

- 版式：A4，正文单栏，页边 22mm，字号 10.5pt，行高 1.6。
- 页眉：卷号 + 章标题；页脚：页码 + 核验日期。
- 章节 H1 单独起页；`本章要点` 与 `练习` 不跨页拆分。
- 交互组件降级：抽屉 → 脚注与证据附录；回放 → 完整轨迹表；决策树 → 决策表 + 流程图；系统卡 → 可填写空白表。
- 颜色：印刷使用同一套 Token，但寿命色转为灰度差异（实心 / 半填充 / 空心），避免黑白打印丢失语义。
- 打印隐藏：导航、侧边栏、检索、回到顶部、按钮。

## 9. 设计验收清单

**视觉**
- [ ] 标题为衬线、正文为无衬线、编号与日期为等宽，三类字体可辨且不冲突。
- [ ] 全站只用一种交互色（Accent）与三档寿命色，无第四种语义色。
- [ ] 分隔全部使用 1px 线；只有浮层允许投影。
- [ ] 正文行宽 680px ± 20px，行高 ≥ 1.8。

**体验**
- [ ] 页边锚点与触发句垂直对齐；锚点相邻时不重叠。
- [ ] 抽屉打开时正文滚动位置不变。

## 11. 待确认的设计决策
