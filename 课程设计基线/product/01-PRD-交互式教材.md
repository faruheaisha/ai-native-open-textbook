## 1. 问题定义

### 1.1 现状

项目已冻结 14 卷知识架构、单一内容真源（`content/`）、网站 + PDF + 开放仓库三载体模型。卷 08 已有 2 章完整正文、2 份 Evidence Packet、12 份 Source Record、1 个设计级 Case Asset Pack。网站骨架已可构建。

### 1.2 四个待解决问题

| 编号 | 问题 | 证据 | 影响 |
|---|---|---|---|
| P1 | **知识被课程外壳淹埋**。章首的"本章承诺 / 阅读时间 / 学完你能做什么 / 验收标准"占用了进入知识前的版面，读者要先跳过运营语言 | 首章原稿 15 节中 2 节为课程元信息，章首组件含 3 张阅读分段卡 | 教材读起来像训练营；与"以知识为中心"的写作立场冲突 |
| P2 | **稳定知识与易过期事实同一语气**。读者无法一眼判断哪句半年后仍成立 | 多数同类教程的共同失效模式；本项目已有 `stability` 字段但仅作元数据 | 读者在不稳定的信息上做长期决策 |
| P3 | **读完不知道自己会不会**。缺少可观察产物与自查路径 | 课程宪法第 16 条要求"学习结果必须可观察、可验收" | 学习停在"看懂了"的自我评价 |
| P4 | **已有优质开放课程可能被重复造轮子**。HF、Microsoft、Anthropic、OpenAI、Datawhale 等已有高质量材料 | `upstream/` 已存 143 条索引快照 | 重复劳动稀释质量，且与宪法第 7 条冲突 |

### 1.3 为什么现在做

正文前两章已成型，是校准"读者看到的形态"的最低成本时点。再往后写，形态返工成本随字数线性增长。

## 2. 产品定位

**一句话**：一套以证据为骨架、以任务为主线、以可检查产物为终点的开放教材，以及承载它的在线阅读与练习环境。

四条不可让渡的产品属性：

1. **教科书形态**：正文只做知识梳理与呈现。不出现面向"学员"的运营语言。
2. **证据可见**：关键主张可回溯到来源、综合等级、分歧与核验日期，且不打断阅读。
3. **失败同等篇幅**：失败模式、边界、不该用的场景与成功路径同等对待。
4. **双载体同源**：网站与 PDF 由同一真源生成，语义一致。

## 3. 非目标（本版本明确不做）

| 不做 | 原因 |
|---|---|
| 视频、直播、打卡、积分、排行榜、证书 | 与"以知识为中心"冲突；属于训练营形态 |
| 账号体系、付费墙、会员 | 本版本以开放阅读为目标释放交付能力 |
| 社区评论、作品广场 | 需要审核与治理能力，本版本只保留勘误通道（FR-8） |
| 产品推荐、优惠、福利信息 | 违反宪法第 13、15 条 |
| 单一产品的完整 API 手册 | 违反宪法第 1、2 条；产品只作为实现出现 |
| 移动端原生 App | 网站响应式足以覆盖；不新增维护面 |

## 4. 用户与场景

| 角色 | 进入动机 | 典型任务 | "成功的样子" | 主要出口 |
|---|---|---|---|---|
| AI 原生用户 | 想知道 Agent 能做什么、不能做什么 | 判断一个产品宣传是否可信 | 能用控制权和反馈描述一个系统 | 卷 01、04 |
| 知识工作者 | 想把重复工作交出去 | 把一条流程改造成可委托的任务 | 有一份自己的任务契约 | 卷 04、08 |
| Builder / Vibe Coder | 想做出来 | 拼一个能跑的最小系统 | 有可运行的循环与一次真实运行记录 | 卷 07、08、09 |
| Agent 开发者 | 想做得可靠 | 让系统在失败时可控 | 有 trace、eval 与失败注入记录 | 卷 08、09、10、12 |
| 工程师 / 研究者 | 想读到边界 | 比对不同来源的定义分歧 | 能引用来源与分歧写自己的结论 | 卷 02、12、14 |

**核心场景（本版本只保证前三个）**

1. 首次到访：30 秒内知道这是什么、从哪里开始、现在有多少内容是真的。
2. 按章精读：在一次连续阅读中完成"概念 → 例 → 反例 → 练习"。
3. 按案例学习：看一条真实轨迹如何失败，再自己复现。
4. 按任务跳读：带着一个任务找到对应章节。
5. 引用与核查：为某个主张找到来源与核验日期。

## 5. 成功度量

本产品**不使用流量指标**。度量分三类：

| 类别 | 指标 | 目标 | 采集方式 |
|---|---|---|---|
| 内容健康 | 断链数、横向溢出页数、控制台错误数 | 全部为 0 | 构建期审计（FR-10） |
| 阅读完整 | 章末"自查"区块触达率 | ≥ 40% 的章页会话 | 前端事件（匿名、无 cookie） |
| 产物转化 | 练习模板的复制/导出次数 | ≥ 1 次/章/日 | 前端事件 |
| 证据触达 | 证据抽屉打开次数 ÷ 章页浏览 | ≥ 15% | 前端事件 |
| 可信维护 | 超期未核验章节数（超过 `review_due`） | 0 | 构建期检查 |

所有前端事件只上报计数，不采集身份、不写 cookie、不使用第三方统计脚本。

## 6. 信息架构

### 6.1 路由表

| 路由 | 页面 | 内容来源 | 状态 |
|---|---|---|---|
| `/` | 封面 + 总目录 + 使用说明 | `data/site-index.json` | 已实现 |
| `/volumes/<卷>/` | 卷首页（卷契约 + 章节矩阵 + 本卷状态） | `content/volumes/<卷>/index.md` | 已实现 |
| `/volumes/<卷>/<章>` | 章节阅读页 | `content/volumes/<卷>/<章>.md` | 已实现 |
| `/cases/` | 案例库 | `data/cases.json` | 已实现 |
| `/cases/<id>` | 案例详情 + 轨迹回放 | `research/<卷>/cases/*.md` | 已实现 |
| `/appendix/` | 附录：术语、寿命与证据等级、许可、勘误 | 待建 | 未开始 |

### 6.2 导航模型

- 顶部导航：卷册目录 / 阅读路径 / 案例库 / 方法链 / 检索。
- 左侧边栏：只在有正文的卷展开章节；未开始的卷不制造空链接。
- 右侧目录：当前页 H2/H3，滚动跟随。
- 章级：上一章 / 下一章（原生），章首元信息行提供证据入口。
- 全局：`Ctrl/⌘+K` 检索，`[` `]` 前后章，`E` 证据，`/` 聚焦检索。

### 6.3 侧边栏约束

侧边栏与首页目录均**由构建脚本生成**。禁止手工维护章节列表；`scripts/build-index.mjs` 是唯一写入方。

## 7. 功能需求

优先级：`P0` 本批次必须完成；`P1` 首批竖切前完成；`P2` 全 14 卷铺开前完成。

### FR-1 阅读页：教科书形态（P0）

**需求**：章节页只呈现知识本身。正文结构为「章标题 → 引导问题 → 编号节 → 本章要点 → 练习 → 参考文献」。页面不得出现：本章承诺、预计阅读时间、学习产出、分段读法、验收/通过标准。

**验收**
- 章首 H1 之后到第一个正文段落之间，只有一行元信息（寿命、最后核验、证据包、证据入口）。
- 全站页面不出现"学完你能做什么""预计 X 分钟""通过/验收"等表述。
- 章末无重复正文内容的页脚区块。
- 正文源文件与渲染结果一致，不靠 CSS 隐藏达到此效果。

**现状**：已实现（正文 2 章、章首/章脚组件、样式均已改造）。

### FR-2 证据层（P0）

**需求**：关键主张可在不离开当前页面的前提下展开证据，证据包含来源、分歧与状态。三处入口：正文行内标记、章首元信息行、证据包页。

**验收**
- 行内标记 `▤` 可键盘聚焦，`Enter` 打开；抽屉以 `role="dialog"` + `aria-modal` 呈现。
- 抽屉含四个视图：主张、分歧、来源、状态；每个分歧条目必须展示"教材决策"字段。
- `Esc` 关闭，焦点返回触发元素。
- 关闭后不改变滚动位置。
- 无 JavaScript 时，正文仍完整可读（证据标记降级为静态链接）。

**现状**：组件已实现，交互未经浏览器验证。

### FR-3 案例与回放（P0）

**需求**：案例是课程的主要说服力来源。列表 → 详情 → 轨迹回放三层。

**验收**
- 案例卡必须显示：任务、证据等级（EVL）、是否有资产包、来源类型。
- 回放支持逐步前进/后退、自动步进、倍速、跳转任意步。
- 每一步展示：状态前、动作、观察、状态后、门（Gate）。
- 失败注入可折叠展开，展示该失败点在真实运行时会发生什么。
- 打印/PDF 时降级为完整静态表，不丢失任何步骤。

**现状**：组件已实现；1 个案例有完整资产包，3 个为占位。

### FR-4 内容寿命（P0）

**需求**：读者必须能区分稳定知识、当前实践与前沿快照。

**验收**
- 三档：`stable` 稳定核心、`current` 当前实践、`frontier` 前沿快照，各有独立视觉标记（实心/半填充/空心方块 + 寿命色）。
- 标记出现在：首页卷卡、卷内章节卡、章节元信息行、证据面板。
- 每个 `current` / `frontier` 条目必须带核验日期。
- 图例可在 1 次点击内到达。

**现状**：标记与图例已实现；首页图例段落位于被裁剪的区块中，需重新落位。

### FR-5 双轨阅读：零代码 / 代码（P1）

**需求**：课程宪法第 11 条要求永远不写代码的学习者也拥有完整路径。同一章内，代码与技术细节必须可整体收起。

**验收**
- 阅读页提供"隐藏代码与技术细节"开关，状态持久化到本地。
- 开启后：代码块折叠为一行摘要，YAML/JSON 模板保留（属于产物而非代码）。
- 正文在两种模式下都语义完整，不出现"见上方代码"的空指代。

**现状**：未开始。需要正文层配合（代码块标注 `data-track="code"`）。

### FR-6 练习与产物（P0）

**需求**：每章结尾提供可完成的练习，并允许学习者产出可带走的文件。练习是学习闭环，不是考核。

**验收**
- 练习使用"练习 / 思考题"命名，不使用"作业 / 验收 / 提交"。
- 结构化练习（系统卡、任务契约、选型备忘录）提供在线填写 + 导出 `.md` / `.yaml`。
- 导出内容包含章号与字段结构，不包含任何身份信息。
- 填写状态保存在浏览器本地，不联网。

**现状**：正文练习已改造；在线填写器未开始。

### FR-7 检索与导航（P1）

**需求**：`Ctrl/⌘+K` 打开检索，支持全文、按卷、按寿命、按证据等级过滤。

**验收**
- 键盘可达：`↑` `↓` 选择、`Enter` 打开、`Esc` 关闭。
- 结果命中词高亮；显示所属卷与章。
- 中文分词失败时退化为子串匹配，不返回空结果。
- 索引在构建期生成，不在客户端拉取原始正文。

**现状**：已实现基础版；交互未经浏览器验证。

### FR-8 诚实降级与勘误（P0）

**需求**：未完成状态必须显式可见，不允许用设计掩盖缺口。

**验收**
- 每卷展示四项状态：证据（CEP）、复现（EVL）、许可、审查。
- 任何"未开始 / 待补 / 无"值使用统一的降级样式。
- 全站提供勘误入口；入口在未建立持久链接前必须显示为"待建立"，不得指向空地址。
- 首页显示数据生成时间与最后核验日期。

**现状**：部分实现（卷页四项状态、首页版本区块）。

### FR-9 双载体一致性（P1）

**需求**：网站与 PDF 由同一真源生成，交互组件在打印时降级。

**验收**
- 任一章节在网站与打印稿中的标题序列、术语、结论完全一致。
- 交互组件（抽屉、回放、检索）在打印时输出静态等价值。
- 生成脚本可证明二者来自同一次构建的真源快照。

**现状**：打印样式已写，未验证。

### FR-10 质量审计（P0）

**需求**：构建期自动审计，产出可复现报告。

**验收**
- 检查项：站内断链、外部链接可达性（抽样）、移动端横向溢出、控制台错误、首屏体积、图片与媒体存在性、超期未核验章节、frontmatter 必填字段。
- 任一 P0 项失败则构建失败。
- 报告落盘为文件，可对比两次构建。

**现状**：未开始。

## 8. 内容模型与数据契约

### 8.1 frontmatter 字段

| 字段 | 用途 | 是否呈现给读者 |
|---|---|---|
| `id` / `volume` / `chapter` | 标识与排序 | 否 |
| `title` / `subtitle` | 标题 | 是 |
| `stability` | 内容寿命 | 是（标记） |
| `last_verified` / `review_due` | 核验日期与复查期限 | 是（核验日期） |
| `evidence_packet` | 证据包编号 | 是 |
| `case_ids` / `source_ids` | 关联案例与来源 | 是（入口） |
| `integration_level` | 多来源综合等级 | 仅证据面板 |
| `status` | 写作状态 | 仅卷页与审计 |
| `estimated_time` / `learning_outcomes` / `prerequisites` / `audiences` | 内部编撰与审计用 | **否**（保留为数据层，不在页面渲染） |

**硬约束**：站点目录、统计数字、侧边栏、案例列表一律来自构建产物，禁止在页面上手写。

## 10. 发布与门禁

内容状态机：`draft → reviewed → publish-ready → published`，只前进不跳级。

**发布门禁（任一不满足则不发布）**

1. 事实主张可回溯到 Source Record，或显式标为 `Editorial Synthesis`。
2. 动态事实带核验日期且未过期。
3. 许可状态已核验，未声明许可的来源不得复用原文。
4. 案例证据等级已标注；EVL-1 不得描述为"已验证"。
5. 四项降级状态在卷页可见。
6. FR-10 审计通过。

## 13. 开放问题
