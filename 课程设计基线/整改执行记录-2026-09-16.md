## 已完成的整改

- `scripts/build-site-content.mjs` 增加 `public` / `local-full` 模式；公开模式过滤 `publishable=false` 来源。
- 增加 `scripts/build-raw-archive.mjs`：原始快照逐文件复制，网页导出型课程的 `derived/` Markdown 也纳入归档，且不覆盖上游 JSON/原件。
- 增加 `scripts/check-raw-integrity.mjs`：批量核对 raw archive 文件大小与 SHA-256。
- 增加 `scripts/build-source-manifest.mjs` 与 `catalog/source-manifest.json`：登记来源、版本、许可、原件聚合哈希和逐文件哈希。
- 增加 `scripts/check-provenance.mjs`：逐页检查 `sourceId/sourceRel/rawUrl/sourceSha256`，防止展示页脱离原件。
- `scripts/extract-upstream-nav.mjs` 增加 Microsoft README 课表解析及无原生导航时的显式 `tree-order` 兜底；`scripts/check-course-nav.mjs` 对 cite-only 资料明确排除，不伪装成课程。
- `scripts/check-links.mjs` 取代临时检查器；VitePress 已关闭默认死链忽略。HTML 检查器现在会把与 `vueSafe` 一致的可恢复上游坏标签标为 `HTML-SAFE-FALLBACK`，真正渲染失败仍返回非零。
- VitePress 配置排除 `public/raw/**`，避免 raw Markdown 被误识别为动态页面；分批构建使用 `TB_BATCH_BUILD=1` 允许跨批次临时路径缺失，完整门禁仍保持严格。
- 超长文件切分失败时改为保留单页，不再静默丢弃；拆分页的 `sourceSha256` 指向完整源文件，另记录 `pageSha256`。
- 增加 PDF 生成脚本 `scripts/build-bluebook-catalog-pdf.py`，并生成第一份目录/证据册：`output/pdf/ai-native-open-textbook-bluebook-catalog-2026-09-17.pdf`。
