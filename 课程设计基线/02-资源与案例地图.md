## 五、复用深度

- `S1 Structural Reuse`：吸收知识组织与教学顺序。
- `S2 Knowledge Reuse`：在许可允许的范围内吸收定义、机制、代码和图。
- `S3 Case / Artifact Reuse`：复用 notebook、workflow、exercise、benchmark、video、diagram、downloadable asset。

每项资源最终只能进入四种处理状态：

- `BUILD`：缺少足够好的内容，自行构建。
- `CURATE`：已有高质量材料，提供导学与课程映射。
- `ADAPT`：内容优秀但需中国语境、产品环境或教学层级本地化。
- `INDEX`：仅保留来源、摘要、用途和关联。

## 六、案例族与通用任务模式

避免因更换产品重复写课。首批 Task Patterns：

- Research：`Search → Select → Extract → Synthesize → Cite → Verify`
- Document：`Files → Extract → Structure → Generate → Review`
- Analysis：`Data → Clean → Analyze → Visualize → Explain`
- Creation：`Brief → Generate → Critique → Revise → Deliver`
- Coding：`Spec → Implement → Test → Fix → Ship`
- Automation：`Trigger → Execute → Verify → Notify`
- Agent：`Goal → Plan/Decide → Tool → Observe → Iterate/Stop`
- Knowledge：`Capture → Organize → Connect → Retrieve → Synthesize → Reuse`

一个任务模式可以挂多个产品实现和多个证据版本；课程只教一次稳定机制。
