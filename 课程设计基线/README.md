## 网站实现进度（2026-09-11）

网站工程已从「骨架」推进到「可在本机完整运行、具备上线条件」。**部署地点未定，当前只在本机运行。** 构建与部署细节见 [`../site/README.md`](../site/README.md)。

编排形态对齐技术文档站：顶部四个一级入口（开始 / 教材 / 案例 / 方法），左侧全局目录（开始、教材 14 卷、案例与证据），正文页带右侧「本页目录」，卷页与章页共用同一套排版。首页为教材目录页：入口卡 → 14 卷目录 → 四条阅读路径 → 能力链 → 标记图例。

已实现并逐项验证的能力：

- **构建期检索索引**：按卷与内容寿命过滤，`Ctrl`/`⌘`+`K` 唤起，Esc / 遮罩关闭，↑↓ 选择，Enter 打开。
- **章页证据抽屉**：主张 / 分歧 / 来源 / 状态四页，Tab 焦点循环，Esc 关闭，焦点归还触发按钮。
- **案例回放**：自动步进、1× / 2× 变速、暂停、节点直接跳转、失败轨迹静态表；打印时降级为静态表。
- **中文 404 页**、内容寿命标记、诚实降级四项状态。

排版遵循「正文只做知识梳理」：章首不使用承诺段、不标阅读时长、不写「学完能做什么」；卷页与章页均为编号小节 + 本章要点 + 练习 + 参考文献。正文唯一真源仍是 `content/`。

**上线条件**均已满足或已备好：`robots.txt`、`sitemap.xml`、中文 404、favicon 齐备；全站内部链接统一走 `withBase`，支持子路径部署；`DOCS_HOST` / `DOCS_BASE` 由环境变量提供，未设置时按部署平台注入的变量自动推断；仓库根备有 `vercel.json`、`netlify.toml`、`.vercelignore`、`.gitignore`。

**上线前体检**：`cd site && npm run docs:release`（构建 + 体检）。体检脚本 `scripts/check-dist.mjs` 检查站内链接可达性、产物是否混入源目录、robots 与 sitemap 是否自洽。当前 62 个文件 / 1.47 MB / 13 个页面 / 334 条站内链接，零死链。
