# AI 原生开放教材系列：Curriculum Baseline v1.0

## 总体知识路径

```text
认识 AI
  ↓
理解模型
  ↓
理解生态、访问与成本
  ↓
把 AI 用于真实工作
  ├─ 知识与办公
  ├─ 科研
  ├─ 设计与多媒体
  └─ 产品开发
       ↓
理解 Agent
  ↓
理解 Harness
  ↓
理解 Context / Memory / Extensions
  ↓
构建长期 Agent 系统
  ↓
安全、可靠性、本地运行与部署
  ↓
理解 AI 前沿
```

这 14 卷冻结的是知识边界与职责，不是最终章数和小节标题。

卷号表示读者的课程顺序，不表示制作先后。制作顺序已确定为先完成卷 08，再完成卷 04，随后分波次完成其余卷册；最终仍以卷 01–14 统一编入网站和蓝皮书合集。

## 卷 01：AI Foundations, Products & Interaction

**AI 基础、产品形态与交互方式**

职责：建立 AI 世界地图，解决模型、产品、模式、界面和 Agent 长期混淆的问题。

核心知识：AI/ML/生成式 AI、基础模型、Model vs Product、Product vs Mode、Chat/Work/Code/Design/Science、Agent，以及 Web、Desktop、CLI、TUI、IDE Plugin、Mobile、Headless、SDK/API。

三个典型生态：

- OpenAI / ChatGPT：`Model → ChatGPT → Chat / Work / Codex → Web / Desktop / CLI / IDE`
- Anthropic / Claude：`Claude → Chat / Cowork / Code / Design / Science`
- Alibaba / Qwen：中国 AI 生态典型，连接模型、消费产品、API、ModelScope/Hugging Face、图像、代码与 Agent 生态。

中国重点对照：GLM、Kimi、DeepSeek、MiniMax、豆包/ByteDance Seed。比较模型、消费产品、开发平台、开放权重、Coding/Work Agent 与研究生态，而不是分别写说明书。

## 卷 02：AI Models, Architectures & Evaluation

**AI 模型、架构与测评**

职责：解释模型是什么，“强”意味着什么，以及如何按任务选择模型。

核心知识：Token、参数与激活参数、训练与推理、Context、Reasoning、多模态、开放权重、Model Card、License；Transformer、Attention、MoE、长上下文、稀疏/混合架构、训练、SFT、Post-training、RAG、量化与推理基础。

测评不做静态排行榜，而讲清：benchmark、human preference、task-specific eval、速度、价格、上下文、开放性、可部署性和领域偏差。建立 `Task × Model Capability` 选择方法。

典型模型家族用于解释架构与策略，不用于制造永久“第一”：OpenAI、Anthropic、Google、Qwen、DeepSeek、Kimi、MiniMax、GLM、Seed 等。

## 卷 03：AI Ecosystem, Access & Economics

**AI 生态、模型访问与成本**

职责：回答模型在哪里、怎么获得、怎么调用、为什么存在不同套餐与路由层。

主要知识：

- Model Hub：Hugging Face 为国际典型，ModelScope 为中国核心对照；讲 Model、Dataset、Space/Studio、Model Card、Evaluation、权重下载、社区和 inference。
- 模型访问：Official API、Model Provider、Inference Provider、Gateway、Router、Aggregator、Relay。
- 核心案例：OpenRouter，用于解释 model routing、provider routing、fallback、BYOK、隐私、成本/延迟路由。
- 计费：Subscription、PAYG API、Token、Credit、Coding Plan、Token Plan、Usage Pool、Quota、Rolling Window、Rate Limit、Concurrency。

价格、福利、地区可用性、学生计划、API 定价和套餐规则全部动态化；正文只讲稳定机制。

## 卷 04：AI Knowledge Work & Personal Knowledge Systems

**AI 知识工作、办公与个人知识系统**

职责：为不写代码的人提供完整高质量路径，并把“各种 AI 办公任务”与“个人知识库/个人知识系统搭建”连接成一条长期工作链，而不是两组工具教程。

AI Work 主链：

```text
Task Specification → Workspace → Context → Files/Data → Execution
→ Artifact → Verification → Reuse → Automation
```

核心典型：WorkBuddy。重点对照：QwenWork、豆包工作、ChatGPT Work、Claude Cowork、Manus。任务覆盖 Word/长文档、Excel/表格与数据分析、PPT、PDF/扫描件、文件夹整理、会议、邮件、待办、协作、Research、简报、自动化、Skills 和 Connectors。每个任务都以可检查 Artifact 和验收标准结束。

Personal Knowledge Management：

- Obsidian：local-first、Markdown、开放文件、Properties、Plugins、Agent-readable workspace。
- Notion：云工作区、数据库、协作、Agent、Skills 与 Connectors。
- 重要对照：NotebookLM、Zotero。

长期知识链：`Capture → Organize → Connect → Retrieve → Synthesize → Act → Archive → Reuse`。卷内必须有一个贯穿案例，把散乱文件、网页、会议记录和阅读材料转成可维护、可迁移、Agent-readable 的个人知识系统，并处理去重、过期、冲突、隐私、备份和迁移。

## 卷 05：AI Research & AI for Science

**AI 科研、科学工作流与 AI for Science**

职责：按科研过程组织知识，不退化为单个科研产品教程。

```text
Research Question → Literature Search → Evidence → Source Management
→ Screening → Reading → Extraction → Analysis → Scientific Computing
→ Hypothesis → Experiment → Verification → Publication → Discovery
```

核心板块：

- Literature & Evidence：Elicit / PaperQA2；对照 Consensus、NotebookLM、Zotero。
- Scientific Workbench：Claude Science 与 OpenAI/Codex 科研工作流作为双 Source View。
- Domain Scientific Agents：如 Biomni 等领域系统。
- Hypothesis Generation：Google Co-Scientist 等系统用于讲生成、批评、比较、排序和演化。
- Automated Discovery / AI Scientist：Robin、AlphaEvolve 等进入前沿观察。

贯穿原则：确定性工具、test oracle、专家在环、可复现、可审计、科学评测。

## 卷 06：Creative AI, Design & Media Production

**AI 创意、设计与多媒体生产**

职责：按能力系列与生产工作流组织，不做模型列表。

### Series A — Image

文生图、图像编辑、参考控制、风格、角色一致性、文字渲染、布局、字体、图像理解。GPT Image、Qwen Image、Seedream 等作为随时代更新的实现。

### Series B — Video

Text-to-Video、Image-to-Video、Reference-to-Video、音视频联合生成、多镜头、运镜、角色一致性、编辑、扩展、长视频。重点跟踪 Seedance 2.x 及后续迭代；比较 MiniMax H 系列、Wan 等。

### Series C — Audio, Speech & Music

ASR、TTS、Voice Cloning、Voice Conversion、Realtime Voice、Music、Sound Effects。数字人是能力组合应用，不是与视频模型并列的基础模态。

### Series D — Design Systems & Design Agents

Claude Design、Lovart、MiniMax Design 作为不同的 Agentic Design/Creative Workspace 典型；Figma MCP 只承担 `Design Tool ↔ Agent` 接口知识；Open Design 进入开放实现对照。

### Series E — Creative Production Workflows

ComfyUI 用于解释 executable workflow；LibTV 作为视频生产工作流研究对象。研究 storyboard、shot-by-shot、reference assets、human approval、Workflow JSON、template、Skill、App Mode、capability pack 与 downloadable assets。

### Series F — Digital Human & Synthetic Identity

`ASR → Agent → Memory/Persona → TTS/Voice Clone → Avatar → Realtime Interaction`。候选实现包括 GPT-SoVITS、LivePortrait、OpenAvatarChat；同时处理 consent、identity、rights、fraud 与 safety。

## 卷 07：Coding & Shipping in the Agent Era

**Agent 时代的软件开发与产品交付**

职责：回答“代码变便宜后，怎样做出真正有人需要、可持续运行的产品”。

```text
Problem Discovery → User Research → Demand Validation → MVP
→ Specification → Architecture → Reuse → Build → Test → Secure
→ Deploy → Launch → Observe → Feedback → Iterate → PMF
```

重点：

- 从 Reddit、Hacker News、GitHub Issues、Product Hunt、垂直社区和访谈寻找信号，但区分 `Discovery Signal ≠ Demand Validation`。
- 讲清 PoC、Prototype、v0、MVP、Beta、Production。
- Vibe Coding 作为时代实践，落到 AI-assisted / agent-first product engineering。
- Reuse-first Engineering：UI、动效、图标、设计参考、模板、API、Auth、Database、Storage、Email、Search、Analytics、Monitoring、Deployment。精选高质量典型，不做 Awesome List。
- Human–AI Collaboration：人定义 Intent、Constraints、Acceptance、Risk Gate，Agent 承担可验证执行。

## 卷 08：AI Agents & Agentic Workflows

**AI Agent 基础与 Agentic Workflow**

职责：用最少必要抽象建立 Agent 基础，并保留主流定义差异。

核心知识：Agent、Agentic System、LLM role、Tools、Actions、Observation、Agent Loop、Workflow vs Agent、Planning、Agentic RAG、Multi-Agent、Evaluation、Failure Modes。

核心源教材：Hugging Face Agents Course、Anthropic Engineering。重要 Source Views：Microsoft AI Agents for Beginners、Datawhale Hello-Agents、OpenAI Agents SDK。

不制造唯一 Agent 定义；Think–Act–Observe、workflow/agent 区分、Agent + Runtime 等都保留来源语境。

## 卷 09：Harness Engineering

**Agent Harness 与软件工程执行系统**

职责：解释模型如何被运行时、工具、上下文和验证系统变成可工作的软件工程 Agent。

采用 `3+1 Canonical Set`：

- Claude Code：mature batteries-included harness。
- Codex：agent-first、local + cloud、parallel software engineering。
- Pi：minimal、composable、inspectable harness。
- Qoder：中国典型，研究 CLI/TUI、IDE、Editor、Quest、JetBrains Plugin、Cloud Agent、SDK 等完整产品族。

比较实现：OpenCode、ZCode、MiniMax Code、Qwen Code、DeepSeek Harness 等。DeepSeek Harness 主要用于解释插件化、可组合 runtime 与 event log，不承担全卷主角。

## 卷 10：Context, Memory & Agent Extensions

**Context、Memory、长期任务与 Agent 扩展**

职责：连接指令层级、持续目标、计划、规格、上下文、记忆、状态和长期执行。

重点比较 Claude、Codex、Qoder、ZCode；DeepSeek Harness 为重要架构对照。

核心知识：

- Instruction Hierarchy：Organization、User-global、Project、Directory、Task、Runtime。
- Goal：persistent objective。
- Plan：planning-before-execution。
- Spec：specification-driven development。
- Context：Current、Project、Global、Retrieved、Tool、External。
- Memory：Human-authored Instructions、Agent-generated Memory、Conversation History、Retrieved Knowledge、Project Facts、User Memory。
- Compact：context compression。
- State：Resume、Fork、Checkpoint、Session、Branch。
- Long-running Work：跨小时/天的持续任务、恢复与验证。
- Extensions：Prompt、Project Instructions、Slash Commands、Skills、Tools、MCP、Plugins、Connectors、Hooks、Subagents、Extensions。

高质量能力包只选少数代表：Anthropic Skills、Hugging Face Skills、优秀开发者 Skills，以及设计/科研/办公能力包。

## 卷 11：Personal & Persistent Agents

**个人 Agent、长期助理与持续自动化**

职责：研究 always-on、跨渠道、长期记忆、调度和个人上下文系统。

核心典型：OpenClaw（Gateway、Channel、Self-hosted、Session、Memory、Multi-agent）；Hermes（Memory、Skill learning、Cron、Subagent、self-improvement）。

核心知识：Persistent Agent、Personal Context、Personal Memory、Channels、Identity、Scheduling、Cron、Notifications、Automation、Background Work、Skills、Long-term Adaptation。

Digital Persona 在本卷讨论长期身份与记忆；数字人外观和声音生成仍属于卷 06。

## 卷 12：AI Security, Reliability & Governance

**AI 安全、可靠性与控制**

职责：独立处理高权限 Agent 与 AI 软件的安全边界。

板块：

- Agent Runtime Security：以 Codex 等产品的 sandbox、permission、approval、network、secret、credential、telemetry 为案例。
- Prompt Injection / Agent Red Team：研究 GPT-Red 等原始工作。
- Traditional Software Security：Trivy 为开源典型；比较 CodeQL、Semgrep、OSV、OpenSSF Scorecard、Dependabot、SBOM、SLSA、Gitleaks。
- Agent-specific Risks：tool abuse、prompt injection、MCP poisoning、memory poisoning、data exfiltration、malicious Skill、supply chain、privilege escalation、autonomy risk。
- Human Oversight：Approval、Risk Gate、Rollback、Audit。

## 卷 13：Local AI, Self-hosting & Serving

**本地 AI、自部署与推理服务**

职责：从权重到硬件、运行时、本地 API 和生产推理建立完整链路。

```text
Model Hub → Weights → Format → Precision → Quantization → Runtime
→ Hardware → Local API → Serving → Application/Agent
```

核心：Ollama（macOS、Windows、Linux、模型、本地 API、Agent 集成）；MLX 为 Apple Silicon 专题；vLLM / SGLang 用于 Production Serving；llama.cpp 用于解释 GGUF、量化和 CPU/GPU 推理底层意义。

硬件知识：unified memory、VRAM、GPU、CUDA、ROCm、Apple Silicon、KV Cache、Context、Quantization、Concurrency。硬件建议必须来自官方要求、可信 benchmark 和实测，禁止用参数量心算运行内存。

## 卷 14：Frontier AI — AGI, Self-Improving Systems & AI Scientists

**前沿 AI、AGI、自进化系统与 AI Scientist**

职责：只收录有论文、技术报告、代码、实验或 benchmark 支撑的前沿方向，不做 AI 新闻卷。

主题：AGI、ASI、Levels of AGI、Autonomous Agents、Agentic RL、Self-improving / Self-evolving Agents、Recursive Improvement、AI Scientist、Automated Research、Automated Alignment Research、Multi-agent Collectives、Verifier-driven Improvement、AI Safety。

典型研究线：Co-Scientist、AlphaEvolve 及真正有研究证据的自我改进系统。所有内容明确标注 Established、Developing、Emerging 或 Frontier。
