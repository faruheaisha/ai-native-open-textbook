## 一、Volume Contract

### 本卷承诺

读者完成本卷后，能走通从权重到硬件、运行时、本地 API 与生产推理的完整链路：`Model Hub → Weights → Format → Precision → Quantization → Runtime → Hardware → Local API → Serving → Application/Agent`；能使用 Ollama（macOS/Windows/Linux、模型管理、本地 API、Agent 集成）、MLX（Apple Silicon 专题）、vLLM / SGLang（生产 Serving）、llama.cpp（GGUF、量化、CPU/GPU 推理底层）；能理解 unified memory、VRAM、GPU、CUDA、ROCm、Apple Silicon、KV Cache、Context、Quantization、Concurrency 与硬件选型方法。

### 本卷不承诺

- 禁止用参数量心算显存；硬件建议必须来自官方要求、可信 benchmark 与实测。
- 不深讲模型架构与训练（卷 02）。
- 不深讲云端访问与计费（卷 03）。
- 不承诺任何硬件组合的通用最优解。

### 前置知识

- 卷 02：量化、上下文、模型规模；卷 03：模型获取。

## 六、Canonical Case 候选

「同一模型的三条运行路径」：同一开放权重模型在本机（Ollama/llama.cpp）、Apple Silicon（MLX）与服务器（vLLM）上运行，记录质量、延迟、吞吐、显存/内存占用与成本，产出选型报告。目标 EVL-5。
