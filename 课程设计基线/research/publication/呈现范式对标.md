# 呈现范式对标：DoubaoWork Guide × 花叔橙皮书

核验日期：2026-09-08  
用途：为双载体出版决策提供案例依据，不作为对标项目的完整评测。

## 对标 1：DoubaoWork Guide

- 官方入口：[在线阅读](https://doubaowork.homes/)
- 公开仓库：[AlephAITech/DoubaoWorkGuide](https://github.com/AlephAITech/DoubaoWorkGuide)
- 身份：社区维护的非官方豆包工作实践指南。
- 本次可验证能力：49 篇指南与案例、31 个真实任务；独立章节、全文搜索、场景任务速达、媒体展示、明暗主题、移动适配；MIT License。
- 内容工程：仓库说明其内容、媒体与界面分层；当前公开实现使用 `site/content/site-content.json`、`site/media/`、`app.js`、`styles.css` 和静态 `index.html`。

### 值得吸收

- “顺序学习”和“按任务查找”并行。
- 章节导航、搜索、前后篇、媒体和移动端构成完整阅读产品。
- 真实任务明确要求背景、输入、过程、交付和验收。
- 开源仓库负责共创，网站负责阅读。

### 不直接复制

- 14 卷大型知识体系不适合单一巨型正文 JSON。
- 产品实践指南的目录逻辑不能代替跨产品知识架构。
- MIT 仓库许可需要逐项确认第三方媒体；不能仅看总许可证。

## 对标 2：花叔橙皮书系列

- 系列入口：[AI 编程橙皮书](https://www.huasheng.ai/orange-books/)
- 单卷样本：[OpenAI Codex 从入门到精通](https://www.huasheng.ai/orange-books/codex/)
- PDF 样本：[OpenClaw 橙皮书](https://pub-161ae4b5ed0644c4a43b5c6412287e03.r2.dev/latest/openclaw.pdf)
- 本次可验证能力：统一卷号与系列页、标题/副标题、页数和发布状态；单卷提供卷首、目录、PDF 下载，部分提供 GitHub、HTML/EPUB 和配套产物。

### 值得吸收

- 强系列感与一眼可懂的单卷承诺。
- 从安装/入门逐步走向完整项目、心智模型和附录。
- PDF 具有版次、适用版本、来源说明和持续更新入口。
- 真实经验与失败信息提高可用性。

### 需要加强

- 动态事实应从正文抽离或带明确核验日期。
- 厂商事实、社区信号和作者判断需要不同证据标识。
- PDF 应绑定不可变 source commit 与在线 Errata。
- PDF 页面中的全部统计、版本、价格和安全事件仍需回到一手来源逐条核验。

## 综合判断

我们不做二选一：

```text
DoubaoWork Guide 的在线学习与任务导航
                    +
花叔橙皮书的系列出版与 PDF 完成度
                    +
本项目的 Evidence Packet / EVL / Stable-Current-Frontier
                    =
AI 原生蓝皮书双载体范式
```

最终差异化不在“页面更漂亮”或“PDF 更多页”，而在同一主张可以从网页或 PDF 一直追溯到来源、案例、版本与编辑决策。
