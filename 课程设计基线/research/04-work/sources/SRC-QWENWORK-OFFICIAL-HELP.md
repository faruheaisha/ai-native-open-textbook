## 事实（均来自官方页面实读）

### 1. 产品定位

> 千问办公是阿里巴巴全新推出的一站式 AI 办公平台，**不止于对话，更注重交付**——用户仅需一句话，即可完成数据分析、PPT 生成、视频剪辑、网页搭建等复杂任务，直接获得可用成果。目前已全面覆盖桌面端、网页端，并深度接入钉钉生态。

### 2. 三种使用方式（入门口径）

| 方式 | 说明 |
|---|---|
| 钉钉内 | 钉钉工作台直接唤起（企业组织可绑定钉钉组织） |
| 网页端 | 浏览器访问 `qwenwork.cn/signin`，免安装即用 |
| 桌面客户端 | 可直连本地文件系统，处理文档/表格/图片/视频；支持 computer use、Hooks、IM |

### 3. 网页端核心

- 自然语言驱动任务执行；交付 Word / Excel / PPT / PDF / 网页 / 报告 / 代码 / 多媒体；
- **网盘**：免费 1 GB / 标准 10 GB / 高级 20 GB；
- **扩展广场**：专家套件（Expert Kits）+ 技能（Skills）+ 连接器（Connectors）三类，连接器需授权；
- **QwenWork Pages**：创建与发布静态/动态网页；
- **云端定时任务**：表单/对话/模板三种创建方式；一次性 / 间隔 / 每小时 / 每天 / 每周 / 每月 / 自定义周期表达式；关闭浏览器仍执行，结果可推送邮件或消息。

### 4. 桌面端核心

自然语言任务 + 文件 + 技能 + 连接器 + **电脑操控（Computer Use）** + IM + **Hooks**；系统设置含全局快捷键、语音输入、**应用快照**（截图/取文）、QuickPick 快速任务窗口。

**"意识"（Awareness）机制**：跨会话记忆与个性化——意识模式 / 自动记忆开关、协作风格（`SOUL.md`）、**工作手册（`AGENTS.md`）**、`USER.md` 画像、长短期记忆。

> 观察：`AGENTS.md` 作为"工作手册"出现在千问办公桌面端的官方概念里，说明该文件名正在成为跨厂商的约定（卷 09/卷 10 的 Harness 与上下文工程叙事需要吸收这条证据）。

### 5. 企业版

- 版本：**企业标准版**与**企业旗舰版**；旗舰版提供**开发者文档**；
- 控制面：组织资料、管理员角色、用户与用户组、模型策略组、模型目录、连接器访问策略、订阅与配额、审计日志（管理日志 / AI 日志）、用量分析看板、个性化（首页推荐 / 导航）；
- 安全：Hooks 规则、敏感词、IM 渠道、受信设备、受信网络；
- 采购：企业版商品含**席位 + 积分包**；积分包需有效期内的席位才能使用（席位与积分的组合计费）。
