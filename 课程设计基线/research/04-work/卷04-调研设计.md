## 一、Volume Contract

### 本卷承诺

读者完成本卷后，能把“各种 AI 办公任务”组织成一条统一工作链：`Task Specification → Workspace → Context → Files/Data → Execution → Artifact → Verification → Reuse → Automation`；能覆盖 Word/长文档、Excel/表格与数据分析、PPT、PDF/扫描件、文件夹整理、会议、邮件、待办、协作、研究、简报与自动化；能搭建一个可维护、可迁移、Agent-readable 的个人知识系统，并处理去重、过期、冲突、隐私、备份与迁移。

### 本卷不承诺

- 不写厂商手册；产品只是实现（WorkBuddy、QwenWork、豆包工作、ChatGPT Work、Claude Cowork、Manus 等作为实现节点）。
- 不做零散工具技巧合集；每个任务都结束于可检查 Artifact。
- 不深讲 Agent 与 Workflow 的工程实现（卷 08 首讲）。
- 不深讲 Skill / Connector / MCP 的协议与开发（卷 10）。
- 不承诺产品界面与操作步骤的跨版本稳定性；界面细节进入 Live Facts。

## 四、个人知识系统生命周期（PKM Lifecycle）

```text
Capture → Organize → Connect → Retrieve → Synthesize → Act → Archive → Reuse
```

- Capture：入口统一、来源标注、去重。
- Organize：目录 vs 标签 vs 属性；项目化组织。
- Connect：链接、双链、引用、上下文。
- Retrieve：检索、问答、对照。
- Synthesize：写作、比较、决策产物。
- Act：任务化、自动化、交付。
- Archive：过期、归档、版本。
- Reuse：模板、Skill、可迁移结构。

代表系统对照（Source View，不排名）：Obsidian（local-first / Markdown / 开放文件）、Notion（云工作区 / 数据库 / 协作）、NotebookLM（来源问答）、Zotero（文献与引用）。
