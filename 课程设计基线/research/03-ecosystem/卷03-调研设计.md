## 一、Volume Contract

### 本卷承诺

读者完成本卷后，能回答“模型在哪里、怎么获得、怎么调用、为什么同一模型有不同价格与限制”；能讲清 Model Hub（Hugging Face / ModelScope）、API / Provider / Inference Provider / Gateway / Router / Aggregator / Relay 的区别；能用 OpenRouter 案例解释路由、回退、BYOK、隐私与成本/延迟策略；能读懂订阅、Token 计费、Credit、Coding/Token Plan、Quota、Rolling Window、Rate Limit 与 Concurrency 这些机制。

### 本卷不承诺

- 不写死价格、套餐、免费额度与学生福利；全部进入 Live Facts。
- 不深讲本地部署与推理服务（卷 13）。
- 不深讲 Agent 与 Harness（卷 08–11）。
- 不推荐“最划算”的单一选择；讲机制与判断方法。

### 前置知识

- 卷 01：Model / Product 分层。
- 卷 02：Token、上下文与推理成本。

## 六、Canonical Case 候选

「一条调用的全链路成本实验」：同一 prompt 经直连 API 与经 Router（含回退）两条路径执行，记录价格、延迟、失败率与数据边界，产出成本/风险对照。目标 EVL-5。

- 向前移交：访问与配额机制 → 卷 07、08、09；Relay/路由风险 → 卷 12；本地替代 → 卷 13。

## 八、开放问题与风险

- 价格与套餐属高频动态事实，必须与正文分离。
- Relay/中转类服务的安全与合规边界需谨慎表述，避免推荐风险路径。
- 中国可访问性与支付方式的地区差异需要单独记录。
