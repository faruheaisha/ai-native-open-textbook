## 一、这份文件回答什么

卷 08 的正文写作不要求从零开始。本文件把四门上游课程逐个教学单元映射到卷 08 的章节候选，回答三个问题：

1. 某一章已经有哪些现成的高质量材料可以吸收（避免重复造轮子）。
2. 上游材料以什么方式进入课程：结构参照（S1）、知识吸收（S2）、案例/资产复用（S3），以及 BUILD / CURATE / ADAPT / INDEX 处理建议。
3. 哪些章节上游覆盖不足，必须自建。

映射是**教学支持度判断**，不是复制清单。任何进入正文的内容仍须经过 Source Record、Chapter Evidence Packet 和编辑综合；许可约束见第六节。

## 五、必须自建（BUILD）的部分

- 第 9 章 Agent Task Specification：上游没有系统覆盖，需自建任务规格 schema 与验收方法。
- 第 8 章 HITL 与 Termination：审批、预算、停止与移交状态机需自建。
- 第 3 章选型 rubric：何时用 Agent 的判断标准需综合 Anthropic 与 Microsoft 后自建。
- 第 13 章案例证据：上游案例提供结构，但 EVL 等级要靠本团队复现提升。
- 第 14 章跨卷移交：与卷 09/10/12 的边界说明属于本系列自建内容。
