## 逐条要点

### 1. microsoft/AI-Engineering-Coach（3,767★，MIT）★ 本批最有价值

- **定位（README 实读）**："better agentic engineering. Analyze your AI coding assistant usage — any harness, one dashboard."
- **它做什么**：
  - 读**本地** AI 会话日志 → 转成可操作洞察，**数据不出本机**
  - 进度追踪：练习评分、周趋势、每日活动图
  - **45 条反模式规则**，覆盖五类：提示质量 / 会话卫生 / 代码评审 / 工具掌握 / 上下文管理
  - 产出度量：按语言、工作区、模型、harness 统计 AI 生成代码量
  - **Skill 发现**：找出重复出现的提示词，转成可复用 skill
  - 上下文健康评分：agentic readiness 检查、instruction-file 审计、工作区上下文地图
- **形态**：VS Code 扩展（要求 VS Code 1.115+），仓库含 `src/`、`docs/`、`skills/`、`scripts/`、`tests/`、`.claude/`、`.devcontainer/`
- **为什么重要**：这是卷 08 一直缺的"**可观测性 / 反馈回路**"的**机构级公开实践**，而且它把"重复提示词 → Skill"这条路径做成了产品功能，直接把卷 08 与卷 10 连起来。
- 快照：387 文件，blob 校验 **PASS**（含 4 个符号链接，已补全）。

### 2. baby-llm/baby-agent（479★，Apache-2.0）

- **定位**：面向**没有 LLM 背景但会 Go** 的后端工程师，"跳过数学推导，从工程实现理解核心概念"。
- **路径**：第一章 初识 LLM（Raw HTTP / SSE 流式 / SDK 对比）→ 第二章 赋予 AI 手脚（Function Calling / Agent Loop / ReAct / 本地工具封装）→ 第三章 可视化（Reasoning 展示、TUI）→ 后续：上下文工程、Memory、Agentic RAG、Skills、MCP、Guardrails、Web 服务化、评测与可观测性。
- **值得抄写的边界声明（README 实读）**：
  > "本项目是**教学仓库**……**不是**'开箱即用的生产框架'，也**不建议直接用于生产环境的二次开发**……更适合作为**原理参考 + 原型验证**的起点，你需要根据自己的场景补齐工程化能力与安全边界。"
- **教学价值**：卷 08 目前唯一以 **Go** 为主线的实现向教程，可作为"语言无关性"的对照样本（Python 主线之外的第二个实现视角）。
