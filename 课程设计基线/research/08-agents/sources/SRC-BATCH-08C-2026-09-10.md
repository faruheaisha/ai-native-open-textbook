## 逐条说明

### 1. datawhalechina/deepagents-in-action（内容 NC / 代码 MIT）

- 定位：《Deep Agents 实战》——LangChain 官方大使出品，基于 LangChain / LangGraph 生态，从零构建生产级 AI Agent。
- 目录（content/）：ch07-skills、ch09-human-in-the-loop、ch12-mcp、ch13-grading-rubrics、ch14-streaming 等，**与卷 08/卷 10 的单元分布高度重合**（skills、MCP、HITL、评测 rubric、流式）。
- 许可形态与 `zero2Agent` 同类：**仓内混合**，须逐文件判断（正文 NC、代码 MIT）。
- 仓库最近推送 2026-09-04，属于"正在更新中"的课。

### 2. microsoft/LangChain4j-for-Beginners（MIT）

- 微软官方课程线（与 `generative-ai-for-beginners`、`ai-agents-for-beginners` 同一模式），章节：01-introduction → 02-prompt-engineering → 03-rag → 04-tools → 05-mcp，含 `docs/` 与多语言 `translations/`（本快照排除多语言，仅保留主语言 + 代码）。
- 教学价值：**Java 生态的 Agent 课程**，可作为"同一概念在不同语言栈的落地"对照单元。

### 3. decodingai-magazine/second-brain-ai-assistant-course（MIT）

- 定位：用 LLM、agents、RAG、fine-tuning、LLMOps 构建"第二大脑"AI 助手。
- 结构：notebook + 源码混合，属"项目制课程"。

### 4. ed-donner/production（MIT）

- 与已收录的 `ed-donner/agents`（6,145★）同作者，主题是"生成式 AI 与 Agentic AI 进入生产"（Production）。两仓库构成"开发 → 生产"的课程连续体。

### 5. Osly-AI/PocketManus（MIT）

- 用 PocketFlow 的节点式工作流复刻 Manus 风格的 agent 与工具编排，是"产品逆向学习"的样本（与卷 04 的 Manus 缺口互补：产品行为可从此类复刻项目观察，但不能替代官方文档）。
