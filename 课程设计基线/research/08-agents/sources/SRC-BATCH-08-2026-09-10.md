### 1. AI 智能体实战速成指南（didilili/ai-agents-from-zero）

- 定位（README 自述）：面向“AI 智能体 / 大模型应用开发工程师”岗位的系统教程，覆盖系统教程 + 可跑源码 + 面试题库 + 企业级实战项目。
- 快照实读结构（33 章 + 资源页）：
  - 认知与选型：1-1 大模型认知与工程概览、1-2 提示词工程基础、1-3 RAG/微调/续训与智能体选型

  - LangChain 主线：9 架构、10 快速上手、11 Model I/O、12 Ollama 本地部署、13 提示词模板、14 输出解析器、15 LCEL、16 记忆与历史（含 Redis）、17 Tools、18 向量库与 Embedding、19 RAG、20 MCP
  - LangGraph 主线：21 Agent 智能体、22 概述、23 图与状态、24 节点与边、25 高级特性、26 多智能体与 A2A、27 Skills 与 AI 编程工具实践
  - 微调主线：28–33 微调流程、数据准备、训练原理、LLaMA-Factory 实战、评估与部署、显存优化与多卡
  - 附加：术语表、新手常见问题、面试题库、工具导航、更新日志、两个完整实战项目（电商问数 = NL2SQL + LangGraph；深度研搜 = DeepAgents 多智能体）
