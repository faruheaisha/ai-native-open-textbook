## 一、Volume Contract

### 本卷承诺

读者完成本卷后，能解释模型是什么、参数与 Token 意味着什么、“模型很强”在不同维度上分别指什么；能读懂 Transformer / Attention / MoE / 长上下文 / 稀疏与混合架构的基本机制；理解训练、SFT、Post-training、RAG、量化与推理的关系；并能用 `Task × Model Capability` 方法为真实任务选择模型，而不是背诵排行榜。

### 本卷不承诺

- 不用单一名次或榜单给模型排“永久第一”。
- 不要求读者手写训练代码或复现论文实验。
- 不展开部署、服务化与本地运行（卷 13 首讲）。
- 不展开 API 接入、Provider 与计费（卷 03 首讲）。
- 不把前沿自我改进系统当作成熟工程（卷 14）。

### 前置知识

- 卷 01：Model / Product / Mode / Surface 分层。

## 六、Canonical Case 候选

「同一任务的模型选型实验」：给定一个真实任务（如“长文档摘要与结构化抽取”），在不少于三个模型/配置上做受控对比，记录质量、延迟、成本与失败模式，产出选型矩阵。目标 EVL-5。
