## 各来源要点

### 1. Context Engineering Intro（coleam00）

- 定位（README 自述）：把“上下文工程”作为让 AI 编码助手真正可用的方法，示例以 Claude Code 为中心但可迁移到其他助手。
- 快照实读结构：除正文外含 `PRPs/`（Product Requirement Prompts）模板、示例项目、`.claude/commands` 等。
- 教材价值：卷 10 的入门骨架来源；“先写规约再让 Agent 执行”的思路与卷 08 的 Task Specification 呼应。
- 风险：以单一工具为示例，通用化时需要另找跨工具证据。

### 2. Prompt Engineering Guide（dair-ai）

- 定位：提示工程 / 上下文工程 / RAG / Agents 的系统性指南，含多语言（含中文）翻译、notebook、幻灯片与配套站点。
- 许可：MIT（`LICENSE.md`）。
- 教材价值：卷 01（基础）、卷 10（上下文工程）的术语与教学顺序参考。
- 风险：部分章节更新节奏慢于模型迭代；术语需要与卷 02 的 Canonical Concept Registry 对齐。
- 注意：仓库含大量引用论文与图片，媒体与第三方内容需逐项核权；引用论文以原论文为准。

### 3. Agent Skills（addyosmani/agent-skills）

- 定位（README 自述）：面向 AI 编码代理的生产级工程 skills 合集。
- 教材价值：卷 10 的“Skill 作为可复用能力单元”的实践样本；与 `muratcankoylan/Agent-Skills-for-Context-Engineering` 形成“工程技能 vs 上下文工程技能”对照。
- 风险：skills 的质量与适用边界未经独立评审；skill 格式与工具版本强相关。

### 4. Awesome Context Engineering（Meirtz）

- 定位：上下文工程综述 + 论文、框架与实现指南索引（README 自述“从 prompt engineering 到 production-grade AI systems”）。
- 教材价值：卷 10 的文献地图；用于发现原始论文（论文本身按 T1 处理）。
- 风险：清单型来源，不作为事实依据。

### 5. Agent Skills for Context Engineering（muratcankoylan）
