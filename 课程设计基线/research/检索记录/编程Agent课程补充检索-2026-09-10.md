## 三、观察到的新趋势（供卷 07 / 09 / 10 选题）

1. **Skills 成为独立品类**：`superpowers`（284k★）、`mattpocock/skills`（258k★）、`anthropics/skills`（175k★，本项目按要求暂不扩展）三家同时进入 GitHub 星标前列，说明 2026 年生态重心从「提示词」转向「可复用能力包」。
2. **Harness 从工具用法升级为工程学科**：出现 `harness-engineering`（文集 + 现场指南）、`ECC`（性能优化系统）、`pilot-shell`（专业上下文与 harness 工程）等以 “harness engineering” 自我命名的项目。
3. **Vibe Coding 叙事完成转向**：`zai-org/GLM-5` 的仓库副标题直接写 “From Vibe Coding to Agentic Engineering”，与 `claude-code-best-practice` 的 “from vibe coding to agentic engineering” 措辞一致，可视为 2026 年的行业共识表述。
4. **跨平台 CLI 聚合器出现**：`farion1231/cc-switch`（132k★）统一管理 Claude Code / Codex / OpenCode / OpenClaw / Grok Build；`tiann/hapi`（5k★）做移动端。说明「多工具并存」已是稳定现实，而非过渡状态。
5. **垂直领域 Agent 课程开始出现**：`data-agent-tutorial`（Text2SQL）、`production-agentic-rag-course`、`strands-agents-course`（AWS 云侧）。
