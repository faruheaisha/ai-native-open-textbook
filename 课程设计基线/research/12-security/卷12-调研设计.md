## 一、Volume Contract

### 本卷承诺

读者完成本卷后，能独立处理高权限 Agent 与 AI 软件的安全边界：理解 Agent Runtime Security（以 Codex 等产品的 sandbox、permission、approval、network、secret、telemetry 为案例）、Prompt Injection 与 Agent Red Team 的原始工作、传统软件安全工具链（Trivy、CodeQL、Semgrep、OSV、OpenSSF Scorecard、Dependabot、SBOM、SLSA、Gitleaks）、Agent 特有风险（tool abuse、prompt injection、MCP poisoning、memory poisoning、data exfiltration、malicious Skill、supply chain、privilege escalation、autonomy risk）与人机监督机制（Approval、Risk Gate、Rollback、Audit）。

### 本卷不承诺

- 不替代专业安全审计与合规审查。
- 不做漏洞利用教学；红队内容只到方法与防御。
- 不深讲 Agent 基础与 Harness（卷 08、09）。
- 不把安全写成一次性清单；讲可运营的机制。

### 前置知识

- 卷 07：软件交付；卷 08–11：Agent、Harness、扩展与长期系统。

## 六、Canonical Case 候选

「一次高权限 Agent 的风险审查」：为一个具备文件、网络与凭证访问的 Agent 建立威胁模型，实施最小权限与审批门，执行一次受控注入测试，记录结果与修复。目标 EVL-5。

- 安全内容的双重用途风险：攻防细节需按防御导向编写。
