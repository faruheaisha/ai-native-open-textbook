## 一、Volume Contract

### 本卷承诺

读者完成本卷后，能画出 AI 世界地图：分清模型、产品、模式、界面与 Agent 五个层次；看懂 OpenAI/ChatGPT、Anthropic/Claude、阿里/Qwen 三个典型生态的结构；能对中国主流模型与产品（GLM、Kimi、DeepSeek、MiniMax、豆包/Seed）做同样的结构化判断；并针对自己的任务选择合适入口（Chat / Work / Code / Design / Science）与交互形态（Web / Desktop / CLI / TUI / IDE Plugin / Mobile / Headless / SDK / API）。

### 本卷不承诺

- 不展开模型架构、训练与推理原理（卷 02 首讲）。
- 不展开 API、Provider、路由与计费机制（卷 03 首讲）。
- 不做产品功能清单、套餐对比或“最强产品”排名。
- 不深讲 Agent 工程与 Harness（卷 08–11）。
- 产品名称、界面与套餐属于动态事实，正文只保留结构，具体值进入 Live Facts。

### 前置知识

无。本卷是全系列阅读入口。

## 八、开放问题与风险

- 中文译名未统一：Mode、Surface、Interface 的译法需在术语回查中决定（决策队列 P1）。

- 中国对照的叙事风险：必须讲生态结构差异，而不是“国产替代”叙事。
