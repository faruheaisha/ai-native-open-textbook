### 关键事实

- 原课程：**Stanford CS146S "The Modern Software Developer"**（Fall 2025）。官方站点 `themodernsoftware.dev`，讲师 Mihail Eric。
- 课程主题（`cs146s-cn` README 实读）：**MCP、Agent Skills、spec-driven development、loop engineering、software factory** —— 这五个词是 2026 年 AI 原生软件开发的**主流术语集**，且来自学术课程而非厂商，**权威性显著高于社区内容**。
- 课程目标（README 实读）："LLM 正在把软件开发从以人工编写代码为主的过程，转变为开发者与能力日益增强的 Coding Agent 协作的过程……你将学习如何为 Agent 提供合适的上下文与能力，把产品需求转换为可执行的规格。"
- **授权链样本（`AlexAnys/agent-first-dev`）**：其 `LICENSE` 开头写明 "Original course materials copyright (c) Mihail Eric (Stanford CS146S). **Used with permission.** Original source: https://themodernsoftware.dev"。这是一个**规范的衍生作品授权声明写法**，可作为本项目的合规模板参考（但该仓库本身为 NC，不可迁入）。

### 风险与边界

- **官方作业仓库无 LICENSE** → 只能 INDEX + 引导学生到官方站点。
- `cs146s-cn` README 含**付费赞助广告位**（Atlas Cloud / APIMart），引用时须剥离。
- 中文版明确自述"非官方项目"，**课程内容版权归原课程方**：仓库 MIT 不覆盖课程文本的原始版权。引用课程原意时以官方为准。

- `vibe-security-skill`：把"vibe coding 的安全债"变成可执行的审计流程 —— **卷 07 与卷 12 的天然接口**。它同时也是"Skill 形态承载安全知识"的样本（卷 10）。

- `cloudflare/vibesdk`：Cloudflare 开源，说明厂商已把 vibe coding 当作**平台级能力**而非玩具。快照为上限子集（420/799）。
