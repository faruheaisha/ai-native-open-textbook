## 本批次带来的课程设计判断

1. **中文 Vibe Coding 教程已完成从“提示词技巧”到“多工具协同”的迭代**：`ai-coding-guide-zh` 直接以 Claude Code / OpenClaw / Codex / WorkBuddy 四线并列组织，卷 07 需要处理“多工具并存”的教学现实，而不是只讲单一工具。
2. **作业与练习的梯度设计**：CS146S 的 8 周作业梯度（提示技术 → 应用搭建 → 前后端 → Agent 协作）比大多数中文教程更完整，卷 07 的练习体系应以其为基线之一。
3. **清单型来源（awesome-vibe-coding）适合做“发现层”**，不能承担事实责任；本项目的 Source Record 纪律要求每条事实回到 T1/T2。
4. **许可分层明显**：MIT/CC0 可直接改编；无许可（`easy-vibe`、`vibe-vibe`）只能 INDEX。
