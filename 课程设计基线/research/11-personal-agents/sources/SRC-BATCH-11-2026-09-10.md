## 各来源要点

### 1. Awesome OpenClaw Usecases（hesamsheikh）

- 定位（README 自述）：社区收集的 OpenClaw 用例集，“让生活更省事”。
- 教材价值：卷 11 的任务地图来源——长期助理能做什么、边界在哪里。
- 风险：用例多为个人自述，缺少可复现证据；按 T3 处理，正文引用需标注“社区自述”。

### 2. Awesome OpenClaw Skills（VoltAgent）

- 定位：从官方 Skills Registry 过滤分类出的 5,400+ skills 合集。
- 教材价值：卷 11 与卷 10 的“技能生态规模与分类”证据；可用于讨论技能发现、质量与安全筛选问题。
- 风险：数量口径来自 README 自述；技能质量与安全性未经审查（安全交卷 12）；体量大，正文只引用分类与统计，不逐条镜像。

### 3. Build Your Own OpenClaw（czl9707）

- 定位（README 自述）：一步一步构建你自己的 AI agent 的指南。
- 教材价值：卷 11 的“从使用者到构建者”进阶来源；与卷 09 的 harness 主题衔接。
- 风险：教学实现与生产实现差距需说明。

### 4. Awesome OpenClaw Tutorial（xianyu110）

- 定位：中文 OpenClaw 教程（安装、配置、实战案例、避坑）。
- 许可：**GPL-3.0**（`LICENSE` 实读）。文档采用强 copyleft 许可证，若与其它许可内容混编需仔细处理；本项目正文不进 GPL 内容，只做 INDEX 与链接。
- 教材价值：中文社区上手路径与常见坑的对照来源。
