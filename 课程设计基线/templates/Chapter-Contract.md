# 模板：章首契约与章节结构（Chapter Contract）

用法：每章正文在标题之后、正文之前提供「§0 本章承诺与读法」。适用于 14 卷全部章节。

来源规范：`../research/publication/课程编排范式-橙皮书双样本.md` §8。

---

## 章首三要素（必须在正文最前，读者可见）

```markdown
# 第 <N> 章　<章标题>

<钩子：一个具体场景或一个反常识问题，2–3 句。不用"本章将介绍……"开头。>

## 0. 本章承诺与读法

> **本章承诺**：<读完你能做什么，≤40 字。必须可验收，禁止"理解""掌握"。>

<阅读成本与分段。若全章 ≤25 分钟，只写一行；超过则必须给分段表。>

| 读法 | 覆盖小节 | 时长 | 读完后你手上有 |
|---|---|---|---|
| 第一次 | §1–§N | 约 M 分钟 | <可留下的产物> |
| 第二次 | §N–§M | 约 M 分钟 | <可留下的产物> |

> 只有一次完整时间时，读 §<x>、§<y>、§<z>。<哪些小节可以留到动手时再回看。>
```

**硬约束**：

- 承诺句 ≤ 40 字，且必须能被本章的验收标准检查。
- 分段表中每一段都必须以"可留下的产物"结束，不能以"读完了"结束。
- 只有一次时间的读法必须真的成立：跳过的小节不能阻塞后续章节。

## 正文八要素（顺序可按章节类型调整，但不得删除）

```text
1. Promise        承诺与学完你能做什么（章首）
2. Explanation    概念解释与来源对照
3. Canonical Case 典型案例（每章 ≤1 个）
4. Hands-on       可跟做的动手环节
5. Artifact       可检查的产物
6. Failure & Safety 失败、边界与风险
7. Evaluation     本章验收标准
8. Further Sources 原始来源与进一步学习
```

## 结构载体配比（硬约束）

每章至少使用以下载体中的 **3 种**；**禁止出现连续超过 600 字没有结构载体的纯散文**。

| 载体 | 用途 |
|---|---|
| 对比表 | 区分易混概念 |
| 层级表 | 角色 / 职责 / 关键细节 |
| 箭头流程 | 系统路径与状态转移 |
| 命令 / 配置块 | 可直接复制执行 |
| 图示 | 结构与关系 |
| Callout（`注意` / `核心建议` / `为什么这很重要？`） | 判断与风险，与事实陈述分层 |
| 失败样例 | 反例与边界 |

**判断与事实必须分层**：作者判断放进 callout，不混进事实段落。

## 收束方式（三选一，不强制统一）

| 章节类型 | 收束方式 |
|---|---|
| 概念型 | `本章小结`（≤200 字）+ 验收标准 |
| 实战型 | `验收清单`（可勾选）+ 产物说明 |
| 分析型 | `结论与开放问题`（明确哪些是未定的） |

## 章尾必备（在收束之后）

- `原始来源与进一步学习`
- `版本信息`（本章内容核验日期、适用版本、与前一版的差异）

## 难度曲线（卷级约束，写卷时检查）

```text
第 1–3 章     建立期：概念清晰、零前置、必须能跑通一个小结果
第 4–N-2 章   爬升期：引入复杂度、失败模式、多来源对照
第 N-1 章     整合期：Spine Case 收束，全部概念一起用
第 N 章       迁移期：方法论升华 + 开放问题 + 下一卷入口
```

反模式：把最难的概念放在第 1 章；把贯穿案例全部放在最后。
